German credit：切片だけのモデル

全体の対数オッズ

🎯 これだけ覚えればOK

予測変数がないとき、切片は「全体の log odds」。Good = 1。

ドイツの顧客 1,000 人のデータ（GermanCredit）。信用が Good の人 700 人、Bad の人 300 人。contrasts() で Good = 1 と確認します。

mod0 <- glm(Class ~ 1, binomial(), data = gc2)
summary(mod0)$coefficients
Estimate Std. Error z value Pr(>|z|) (Intercept) 0.8472979 0.06900652 12.27852 1.181419e-34
🔁
確率 0.7 → オッズ 0.7 / 0.3 = 2.33 → 対数オッズ log(2.33) = 0.847（= 切片）
🍎 ひとことで

切片 0.847 は、全体の確率 0.7 を「オッズ → log」に変えた数。確率・オッズ・対数オッズの往復ができるようにしておこう。

🤔 答えられるかな？（クリックで答えが開く）

Q1. Class の 1 は Good と Bad のどちら？A. Good（contrasts() で確認）。
Q2. 切片 0.847 はどう出る？A. log(0.7 / 0.3) = 0.847。

二値の予測変数：切片

ForeignWorker は 0 = 外国人

🎯 これだけ覚えればOK

切片は「x = 0 の人たちの log odds」。外国人 (FW = 0) の Good 確率は 33/37 = 0.892。

ForeignWorker は0 = 外国人、1 = 国内（ふつうと逆！）。外国人 37 人、国内 963 人です。

FW = 0（外国人）FW = 1（国内）
Bad4296
Good33667
mod_fw <- glm(Class ~ ForeignWorker, binomial(), data = gc2)
summary(mod_fw)$coefficients
Estimate Std. Error z value Pr(>|z|) (Intercept) 2.110213 0.5294184 3.985908 6.722255e-05 ForeignWorker -1.297783 0.5340052 -2.430281 1.508712e-02
🧮
切片 2.1102 → exp() でオッズ 8.25 → 8.25 ÷ (1 + 8.25) = 0.8919 = 33/37
⚠️ 係数が負 → 0 から 1（外国人 → 国内）で Good の log odds が下がる → 外国人のほうが Good になりやすい。
🍎 ひとことで

予測変数が入ったら、切片は「x = 0 のときの対数オッズ」。exp() でオッズ、odds ÷ (1 + odds) で確率に戻す。

🤔 答えられるかな？（クリックで答えが開く）

Q1. FW = 0 はどんな人？A. 外国人労働者（yes）。
Q2. 外国人の Good 確率は？A. 33/37 = 0.892（オッズ 8.25）。
Q3. 係数が負だと何が言える？A. FW が 0 → 1 で Good が減る。外国人のほうが良い信用になりやすい。
③

二値の予測変数：係数

オッズの比（割り算）の log

🎯 これだけ覚えればOK

係数 = ln（新しいオッズ ÷ 古いオッズ）。足し算ではなく割り算。

x = 0（外国人）x = 1（国内）
確率0.89190.6926 (= 667/963)
オッズ8.252.2534
➗
2.2534 ÷ 8.25 = 0.2731　→　ln(0.2731) = −1.2978 = 係数
odds1 / odds0
log(odds1 / odds0)
[1] 0.2731368 [1] -1.297783
🔑 オッズが同じなら x ÷ x = 1。下がると 1 より小さい小数。0.273 は約 73% の減少（国内のオッズは外国人の 0.273 倍）。
⚠️ 確率の差（0.891 − 0.693）は係数ではない。比は「新 ÷ 古」の向きで。
🍎 ひとことで

係数は「x を 0 → 1 にしたとき、オッズが何倍になるか」の log。0.273 倍 = 約 73% 減。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 係数はどう計算する？A. 新しいオッズ ÷ 古いオッズ を取り、自然対数にする。
Q2. 0.273 は何を表す？A. 国内のオッズが外国人の 0.273 倍（約 73% 減）。
Q3. 確率の引き算でもよい？A. だめ。割り算（オッズの比）。

連続の予測変数 Age

1 歳ごとにオッズ 約 1.019 倍

🎯 これだけ覚えればOK

連続変数でも同じ。係数 = 1 単位増えたときの対数オッズの変化。どの年齢でも同じ。

平均年齢は Bad が 34.0 歳、Good が 36.2 歳。Age の係数は 0.0184（p = 0.0042）。

Age確率オッズ
00.55011.2225
10.55461.2453
🎂
1.2453 ÷ 1.2225 = 1.0186　→　ln(1.0186) = 0.0184 = 係数
55 → 56 歳でも 33 → 34 歳でも、比は同じ 1.0186。
  1. 回帰を実行 → 2. 式に代入 → 3. x = 0 の確率 → 4. オッズ → 5. x = 1 の確率 → 6. オッズ → 7. 比 → 8. log ＝ 係数
🎯 暗記は不要。でも試験では知っていると楽。
🍎 ひとことで

年齢が 1 歳増えるごとに、Good のオッズは約 1.019 倍。比はどの年齢でも同じ。

🤔 答えられるかな？（クリックで答えが開く）

Q1. Age の係数 0.0184 の意味は？A. 1 歳増えると対数オッズが 0.0184 増える（オッズ約 1.019 倍）。
Q2. 55 → 56 と 33 → 34 で比は違う？A. 同じ 1.0186。

Shiny アプリ

LLM と作るダッシュボード

🎯 これだけ覚えればOK

モデルは公開して使われてこそ価値がある。LLM には小さく頼み、エラーは貼って直す。

Loan Default のデータ（255,000 行 × 18 列）から 50,000 行を無作為抽出し、ロジスティック回帰で default の確率を予測。LoanID は除く。有意でない変数は除く（手動でもステップワイズでも同じ結果）。

入力確率表示
ふつうの借り手約 6%、のちに約 8%低リスク
信用スコア悪い＋高額ローン約 12%まだ低リスク
🧠 Education は水準を 1 つだけ外せないので、ワンホット符号化を使う（人が LLM に提案する）。
⚠️ 実行中の Shiny は停止してから再実行。公開は shinyapps.io、成果は GitHub と履歴書へ。
🍎 ひとことで

掃除 → モデル → アプリ → 公開。LLM には一度に全部ではなく小分けで頼む。

🤔 答えられるかな？（クリックで答えが開く）

Q1. なぜ小分けでプロンプトを出す？A. 一度に頼みすぎるとミスが増え、直しにくいから。
Q2. エラーが出たら？A. エラー文をそのまま LLM に貼って直してもらう。

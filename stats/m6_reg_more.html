🧩 回帰④：カテゴリ変数と重回帰

ここまでの回帰は「数値の説明変数 1 つ」でした。この回では 2 つ拡張します。①性別や居住地のような「カテゴリ」でも予測できること、②説明変数を複数入れる「重回帰」です。最後に M6 全体（相関 → 回帰 → 推測 → 拡張）を振り返ります。

①

ダミー変数：カテゴリを説明変数にする

基準カテゴリと、係数の意味

まず復習です。応答変数（response）は連続値の totalGivingAmount（総寄付額）、説明変数（explanatory variable）は数値の largestGiftAmount（最大の 1 回の寄付額）。ここまでと同じ回帰です。

model_largest <- lm(totalGivingAmount ~ largestGiftAmount, data = sampleDonors)
summary(model_largest)
Coefficients: Estimate Std. Error t value Pr(>|t|) (Intercept) 51.817 27.292 1.899 0.0636 . largestGiftAmount 3.910 0.782 5.000 8.07e-06 *** Residual standard error: 138.8 on 48 degrees of freedom Multiple R-squared: 0.3424, Adjusted R-squared: 0.3287

切片 51.817、傾き 3.910、標準誤差、t 値、p 値、R² は、これまでの推測の回で見たものです。このモデルで予測（prediction）するには predict() を使います。モデルの名前と、説明変数と完全に同じ名前の列を持つデータフレームを渡します。

predict(model_largest, data.frame(largestGiftAmount = 50))
1 247.2973

R は 50 に傾き 3.910 を掛けて切片 51.817 を足します（51.817 + 3.910 × 50 ≈ 247.3）。最大寄付額が $50 の人の総寄付額は約 $247 と予測されます。

⚠️ data.frame(largestGiftAmount = 50) の列名は、モデルに使った変数名と完全に一致させます。綴りや大文字小文字が違うとエラーになります。

カテゴリ変数（categorical variable）を説明変数にする

同じことがカテゴリ変数でもできます。しかもとてもよく使われます。ここで大切なのは、応答変数は連続値のまま、説明変数だけがカテゴリになることです。例として gender（性別）で総寄付額を予測します。標本の内訳を table() で確認しましょう。

table(sampleDonors$gender)
model_gender <- lm(totalGivingAmount ~ gender, data = sampleDonors)
summary(model_gender)
female male 27 22 Coefficients: Estimate Std. Error t value Pr(>|t|) (Intercept) 139.17 33.05 4.211 0.000114 *** gendermale 22.08 49.32 0.448 0.656465 Residual standard error: 171.7 on 47 degrees of freedom (1 observation deleted due to missingness) Multiple R-squared: 0.004245, Adjusted R-squared: -0.01694

標本には女性 27 人、男性 22 人。出力の説明変数名が gendermale になっている点が、これまでとの大きな違いです。回帰式は次のとおりです。

ŷ = 139.17 + 22.08 × male　（male = 0 は「男性ではない」、male = 1 は「男性」）

この male のように 0 と 1 だけを取る変数をダミー変数（dummy variable / indicator variable）と呼びます。R が自動で作ってくれます。ダミー変数が 0 のグループ（ここでは女性）を基準カテゴリ（reference group / baseline）と言い、R が自動で選びます（通常はアルファベット順で最初の水準。ここでは female）。どちらが基準になるかは本質ではありません。基準が male なら変数名は genderfemale になり、同じ内容を逆の言い方で表すだけです。

性別ごとの総寄付額（点は寄付者 1 人、赤線は平均）
横軸は 0/1 のダミー変数。2 つの平均を結んだ直線の傾きが、そのまま 22.08 です（sampleDonors の 49 人、性別が欠損の 1 人は除く）。

講義が示した押さえるべき 3 点は次のとおりです。

  1. カテゴリ変数も予測変数（predictor）として使える（実際にとても一般的）。
  2. 予測値の出し方：predict() に gender = "male" のように水準を渡す。
  3. 22.08 の解釈。
predict(model_gender, data.frame(gender = "male"))
predict(model_gender, data.frame(gender = c("male", "female")))
1 161.2455 1 2 161.2455 139.1667

男性： 139.17 + 22.08 × 1 = 161.25 → 約 $161。女性： 139.17 + 22.08 × 0 = 139.17 → 約 $139。つまり切片 139.17 は基準カテゴリ（女性）の予測値です。

🔑 係数の意味（解釈）：「寄付者が男性なら、女性より総寄付額が 22.08 多いと予測される」。ダミー変数の係数は、そのカテゴリと基準カテゴリの「差」です（男 161.25 − 女 139.17 = 22.08）。
⚠️ 講師の注意：この性別の係数は統計的に有意ではありません（p = 0.656、とても高い）。観察された男女差は偶然（random sampling）かもしれず、「一般に男性のほうが多く寄付する」と受け取ってはいけません。理由は 2 つ。①これは特定の団体の限られた標本であること、②p 値がとても高いこと。R² も 0.004（0.4%）しかありません。
🍎 かんたん説明

カテゴリは「0 か 1 のスイッチ」に直して使います。スイッチが 0 の人（基準）が切片、1 の人は「切片 ＋ 係数」。係数は基準とのちがいです。ただし p 値が高いときは、そのちがいを信用しすぎないこと。

💻 ミニ練習：男性の予測値を出す

model_gender を使って、男性の寄付者の総寄付額の予測値を求める R コードを書いてください。

predict(model_gender, data.frame(gender = "male"))

結果は 161.2455（約 $161）。139.17 + 22.08 × 1 の計算を R が代わりにやってくれます。列名 gender と水準 "male" は、データに入っている綴りどおりに書きます。

②

多カテゴリの場合：水準が増えると 0/1 の項が増える

urbanicity の 5 水準

カテゴリが 3 つ以上でも考え方は同じです。urbanicity（居住地域）の水準は city・rural・suburb・town・urban の 5 つ。標本での人数は次のとおりです。

table(sampleDonors$urbanicity)
model_urbanicity <- lm(totalGivingAmount ~ urbanicity, data = sampleDonors)
model_urbanicity
city rural suburb town urban 9 14 7 8 11 Coefficients: (Intercept) urbanicityrural urbanicitysuburb urbanicitytown 199.28 -113.63 18.72 -84.47 urbanicityurban -60.47

係数がたくさん出ました。回帰式は次のとおりです。

ŷ = 199.28 − 113.63 (rural) + 18.72 (suburb) − 84.47 (town) − 60.47 (urban)

各カッコは 0/1 のダミー変数です。5 水準なら基準を除いた 4 個のダミー変数（水準の数 − 1）が入り、基準は city です。

  • rural（rural = 1、他は 0）：199.28 − 113.63 × 1 = 85.65 → 約 $85
  • suburb：199.28 + 18.72 × 1 = 218.00 → $218
  • city：式に city が見当たらず戸惑いますが、基準カテゴリなので切片そのものです（他の項はすべて 0 を掛けるだけ）。→ $199.28
居住地域ごとの総寄付額の平均 ＝ 各水準の予測値
カテゴリだけの回帰の予測値は、その水準の標本平均に一致します。基準 city の高さが切片、他の棒は「切片 ＋ 係数」です。
predict(model_urbanicity, data.frame(urbanicity = c("city", "rural", "suburb", "town", "urban")))
1 2 3 4 5 199.27778 85.64286 218.00000 114.81250 138.80909

2 水準との違いは、0 と 1 を入れる項が増えるだけという点です。ただし、この回帰でも係数の p 値は大きく（最小でも rural の 0.12）、R² も約 0.09 と小さいので、性別のときと同じく「地域でこれだけ寄付が違う」と言い切ることはできません。

💡 覚え方：k 個の水準のカテゴリ変数 → ダミー変数 k − 1 個 ＋ 切片（＝基準カテゴリ）。予測したい水準の項に 1、残りに 0 を入れて足し算します。
🍎 かんたん説明

5 つの地域のうち 1 つ（city）を「ものさしの 0 地点」にして、残りの 4 つは「city よりいくら多い／少ない」で表します。city の予測値は切片そのままです。

💻 ミニ練習：rural の予測値

model_urbanicity で、rural に住む寄付者の総寄付額の予測値を求める R コードを書いてください。

predict(model_urbanicity, data.frame(urbanicity = "rural"))

結果は 85.64286（約 $85）。199.28 − 113.63 に相当します。

重回帰：複数の説明変数と調整済み R²

「他を一定にしたとき」の読み方

データは米国西部の公立大学 9 校。1 行が 1 つの大学で、卒業率 rate（%）、学生 1 人あたり支出 expend（ドル）、SAT の中央値 SAT が入っています（例：卒業率 75%、支出 6960 ドル、SAT 1242）。

大学123456789
rate (%)7571.559.356.452.44845.842.741.1
expend ($)696072745361537450705226592756005073
SAT1242111410141070920888970937871

問いは「卒業率を何で予測するのがよいか」。1 つ目は「1 人あたりの支出を増やせば卒業率は上がるか」（大学にとって切実な問い）、2 つ目は「SAT の中央値が高ければ卒業率は上がるか」。まず単回帰を 2 本作って比べます。

model_expend <- lm(rate ~ expend)
model_SAT <- lm(rate ~ SAT)
summary(model_expend)
summary(model_SAT)

どちらも p 値は有意ですが、R² は支出が約 62%、SAT が約 84%（0.618 と 0.835）です。出力から必要な値だけ取り出すには $ を使います。

summary(model_expend)$r.squared
summary(model_SAT)$r.squared
summary(model_SAT)$coefficients

⚠️ 2 つのモデルの傾きどうしは直接比べられません。支出の傾きは「1 ドルあたり」(0.0117)、SAT の傾きは「1 点あたり」(0.0916) と単位が違うからです。選ぶ基準は低い p 値と高い R² です。
SAT の中央値と卒業率（9 校）と回帰直線
ŷ = −37.20 + 0.0916 × SAT。点が直線の近くに並び、R² = 0.835 です。

結論は、SAT のほうがよい予測変数。大学へのメッセージは「ただお金を投入すればよいわけではない。SAT の高い学生を引きつけることが大切（そうした学生ほど卒業しやすい）」です。

重回帰（multiple regression）

2 つの変数を別々のモデルに入れず、1 つのモデルに両方入れるのが重回帰です。一般形は単回帰と似ていますが、変数の数だけ係数が増えます。

ŷ = b₀ + b₁x₁ + b₂x₂ + … + bₖxₖ　（例：x₁ = SAT、x₂ = expenditure）

R では lm(y ~ x1 + x2) のように、説明変数を + でつなぐだけです。

model_mult <- lm(rate ~ expend + SAT)
summary(model_mult)
Coefficients: Estimate Std. Error t value Pr(>|t|) (Intercept) -37.777476 16.503961 -2.289 0.0620 . expend 0.002011 0.004115 0.489 0.6425 SAT 0.080646 0.027766 2.905 0.0272 * Residual standard error: 5.579 on 6 degrees of freedom Multiple R-squared: 0.8413, Adjusted R-squared: 0.7884 F-statistic: 15.9 on 2 and 6 DF, p-value: 0.003999

切片のほかに、expend と SAT それぞれの傾きが 1 つのモデルに入りました。SAT は有意（p = 0.027）、expenditure は有意ではありません（p = 0.64）。

調整済み R²（adjusted R²）

重回帰では普通の R² ではなく調整済み R² でモデルを評価します。変数を足せば（役に立たなくても）R² は下がりません。そこで無駄な説明変数が多いモデルにペナルティを課すのが調整済み R² です。新しい変数が「偶然で期待される以上」にモデルを改善したときだけ上がります（計算式もありますが、講義では省略されました）。R² を人工的に大きく見せるために手当たりしだいに変数を入れてはいけません。

モデルR²調整済み R²
支出のみ rate ~ expend0.6180.564
SAT のみ rate ~ SAT0.8350.811
重回帰 rate ~ expend + SAT0.8410.788

SAT のみの R² は 0.835 で、重回帰の R² 0.841 はわずかに高いだけです。しかし調整済み R² は 0.788 に下がります。役に立たない expenditure を入れたぶん、罰を受けたのです。つまり変数を増やして複雑にするより、SAT だけのほうがよいモデルです（SAT 単独の調整済み R² は 0.811 で、重回帰の 0.788 より高い）。

重回帰の係数の解釈：「他を一定にしたとき」

解釈の言い方は単回帰の傾きとほぼ同じですが、重要な一言が加わります。重回帰の SAT の係数は 0.0806（≈ 0.081）なので、次のように言います。

🔑 「median SAT が 1 点増えるごとに、卒業率は 0.081% 増えると予測される。ただし expenditure は一定（holding expenditure constant）としたとき。」
支出が同じ（またはとても近い）2 つの大学なら、SAT が 1 点高いと卒業率が 0.081% 高い、という意味です。

1 点の増加は実務ではあまりにも小さいので、意味のある単位に直して述べます。0.081 に 100 を掛けると小数点が動いて、「median SAT が 100 点増えるごとに、卒業率は 8.1% 増えると予測される（expenditure を一定にしたとき）」。SAT が 1 点上がることは実質的に意味がない一方、100 点の差は十分に大きく、卒業率の 8.1% という数字も読みやすくなります。

⚠️ SAT の傾きは、単回帰では 0.0916、重回帰では 0.0806 と値が変わります。重回帰の係数は「他の変数の影響を差し引いたあとの効果」だからです。係数を読むときは必ず「他を一定にしたとき」を付けましょう。
🍎 かんたん説明

重回帰は「いくつもの理由を 1 つのモデルに入れる」こと。調整済み R² は「入れすぎたら減点」の採点で、係数は「ほかの条件をそろえたとき、この変数だけ 1 つ増えたら予測がいくつ変わるか」を表します。

💻 ミニ練習：重回帰モデルを作る

卒業率 rate を expend と SAT の両方で予測するモデルを model_mult に保存し、その要約を表示する R コードを書いてください。

model_mult <- lm(rate ~ expend + SAT)
summary(model_mult)

説明変数は + でつなぎます。summary() の出力で、SAT は有意、expenditure は有意でないことが確認できます。

💻 ミニ練習：調整済み R² を取り出す

model_mult の調整済み R² の値（0.788）だけを取り出す R コードを書いてください。

summary(model_mult)$adj.r.squared

結果は 0.788363。普通の R² は summary(model_mult)$r.squared（0.8412723）で、取り出し方は同じです。

④

まとめ：M6 の全体像

相関 → 回帰 → 推測 → 拡張

M6 は「2 つの変数の関係を、まず見て、次に式にして、最後に偶然かどうかを確かめる」流れでした。最後の拡張の回で、その道具をカテゴリ変数と複数の説明変数に広げました。

1. 相関
散布図と相関係数 r で「関係の強さと向き」を見る。r は −1〜+1。相関 ≠ 因果。
→
2. 回帰
最小二乗法の直線 ŷ = b₀ + b₁x、残差、係数の解釈、残差プロット、R²。
→
3. 推測
傾きの信頼区間と有意性検定（t 検定、p 値）で、標本から母集団を語る。
→
4. 拡張
カテゴリ変数（ダミー）と重回帰（調整済み R²、他を一定に）。
ステップR のコードこの M6 で見た数字の例（donors, n = 50）
見る・相関plot()、cor()散布図を描いてから r を計算する
回帰lm(y ~ x)ŷ = 51.817 + 3.910 × largestGiftAmount、R² = 0.3424
推測summary()、confint()傾き 3.910、SE 0.782、t = 5.000、p = 8.07e-06
予測predict()最大寄付 $50 → 約 $247
カテゴリlm(y ~ gender)切片 139.17（女性）、gendermale 22.08、p = 0.656
重回帰lm(y ~ x1 + x2)rate ~ expend + SAT：R² 0.841、調整済み R² 0.788
✅ 回帰結果を読むときのチェックリスト
  1. p 値は低いか（係数は偶然ではなさそうか）。標本が限られ p が高ければ、一般化しない。
  2. R²（重回帰では調整済み R²）は高いか。
  3. 係数を、意味のある単位で、変数の単位つきで言えるか（重回帰なら「他を一定にしたとき」）。
  4. カテゴリ変数なら、基準カテゴリはどれか。係数は基準との「差」。
  5. 相関・回帰は関連を示すだけで、原因を証明しない。
📝 課題（portfolio）：自分の興味のあるデータを見つけ、自分で重回帰モデルを（1 つでも複数でも）作りましょう。R² と調整済み R² を比べ、各説明変数が有意かどうかを確認し、そのデータとプロジェクトを portfolio に入れます。
🍎 かんたん説明

M6 は「関係を見る（相関）→ 式にする（回帰）→ 偶然かどうか確かめる（推測）→ 使える範囲を広げる（カテゴリ・重回帰）」の 4 ステップ。最後は、p 値・R²・単位つきの言い方をセットで確認する習慣が大切です。

💻 ミニ練習：まとめの練習：寄付データで重回帰

sampleDonors で、totalGivingAmount を largestGiftAmount と gender の 2 つで予測するモデルを model_two に保存し、調整済み R² を取り出す R コードを書いてください。

model_two <- lm(totalGivingAmount ~ largestGiftAmount + gender, data = sampleDonors)
summary(model_two)$adj.r.squared

📖 用語集

categorical variable
カテゴリ変数
性別・居住地のように、いくつかの水準を持つ質的な変数。
dummy variable
ダミー変数
0 と 1 だけを取る変数。1 つの水準に 1 つ対応する。
reference group
基準カテゴリ
ダミー変数がすべて 0 のグループ。その予測値が切片。
level
水準
カテゴリ変数が取る値（city, rural など）。
predict()
予測
モデルと新しいデータから予測値を出す関数。列名は完全一致。
multiple regression
重回帰
説明変数を複数入れた回帰。lm(y ~ x1 + x2)。
adjusted R²
調整済み R²
無駄な説明変数にペナルティを課した R²。
holding constant
他を一定にして
他の説明変数の値を固定したときの効果、という重回帰の係数の読み方。
predictor
予測変数
応答を予測するために使う説明変数。
response variable
応答変数
予測したい連続値の変数（totalGivingAmount, rate）。

💡 学習のヒント

カテゴリの係数は「基準との差」、重回帰の係数は「他を一定にしたときの 1 単位あたりの効果」。p 値が高いときは一般化しない、調整済み R² で変数の入れすぎをチェック。

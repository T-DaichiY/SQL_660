①

t 手順を使っていい条件

まず確かめること

🎯 これだけ覚えればOK

t 手順の前に「データを信用していいか（代表的か）」を確かめる。

🗑️
Garbage in, garbage out.悪いデータから、よい区間や p 値は作れない。
確認することひとこと
① 代表的か（最重要）A の生徒だけ調べても、クラス全体のことは分からない
② 量的変数かカテゴリには t 検定・t 区間を使わない
③ 正規に近いか小標本なら、強い歪み・外れ値に注意（標本が大きければ CLT で OK）
④ 独立？対応？2標本のとき。2標本 t か paired t かを決める
⑤ 10%条件母集団が標本の10倍超なら OK。いちばん重要度が低い

母集団が小さいときは、標準誤差に有限母集団修正係数（FPC）を掛けます。N = 1500、n = 500 なら次の値です。

sqrt((1500 - 500) / (1500 - 1))
[1] 0.8167689
📏
FPC は 1 より小さい。使わないと標準誤差は大きめ（過大評価）になり、区間は少し広くなるだけ。
🍎 かんたん説明

母集団が標本の10倍より大きければ、FPC は不要。アメリカ全体から 50,000 人なら不要。1500 人から 500 人なら必要。

🤔 答えられるかな？（クリックで答えが開く）

Q1. いちばん大事な条件は？A. データが母集団を代表していること（実験なら処置が無作為に割り当てられていること）。
Q2. 標本が小さいとき、何を確かめる？A. 強い歪みや外れ値がないか（データを図にして見る）。
Q3. FPC を使わないとどうなる？A. 標準誤差が少し過大評価され、区間が少し広くなる。過小評価にはならない。
②

外れ値のあるデータ

所得データ n = 25

🎯 これだけ覚えればOK

小標本＋外れ値＋歪みのときは、t 区間は信用しすぎない。

🖼️
まず図を描く。ヒストグラム・箱ひげ図・QQプロット。

ある会社の所得データ（n = 25）。1つだけ 385 という大きな値があります。

summary(incomes)
boxplot.stats(incomes)$out
Min. 1st Qu. Median Mean 3rd Qu. Max. 1.00 18.00 26.00 47.76 56.00 385.00 [1] 385
  • 平均（47.76）が中央値（26）よりずっと大きい → 右に歪んでいる。
  • 箱ひげ図で 385 は外れ値。標本は n = 25 と小さい。
  • 通常の t 区間は 17.1 〜 78.4。でも外れ値のせいで信用しにくい。
  • まず 385 が本物か typo かを確認する（所得ならたぶん本物）。
t.test(incomes)$conf.int[1:2]
[1] 17.11469 78.40531
🍎 かんたん説明

QQプロット（qqnorm() と qqline()）では、正規に近ければ点が赤い直線に乗る。ここでは 385 が大きく外れる。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 平均が中央値よりずっと大きいのは何のサイン？A. 右に歪んでいる（大きい外れ値がある）サイン。
Q2. QQプロットで正規に近いとどう見える？A. 点が直線（qqline）の上に並ぶ。
Q3. 外れ値を見つけたら最初にすることは？A. 本物のデータか、入力ミス（typo）かを確認する。

ブートストラップ t 区間

データ自身に分布を語らせる

🎯 これだけ覚えればOK

ブートストラップ＝元のデータから「引いて戻す」を何万回もやって、t* の本当の形を調べる。

🔁
復元抽出（replace = TRUE）で、同じ大きさの再標本を作る。これがブートストラップの命。
  1. 元の標本から同じ大きさで復元抽出（5, 7, 10 → 7, 7, 10 のように重複あり）。
  2. t* = (x̄* − x̄) / (s*/√n) を計算（μ は使わない。区間づくりなので）。
  3. 10,000 回くり返す。
  4. 2.5% 点と 97.5% 点を quantile() で求める（qt() の代わり）。
set.seed(100)
xbar <- mean(incomes); N <- 10^4; n <- length(incomes)
Tboots <- numeric(N)
for (i in 1:N) {
  x <- sample(incomes, size = n, replace = TRUE)
  Tboots[i] <- (mean(x) - xbar) / (sd(x) / sqrt(n))
}
quantile(Tboots, c(0.025, 0.975))
2.5% 97.5% -5.356196 1.396638 
xbar - quantile(Tboots, c(0.975, 0.025)) * sd(incomes) / sqrt(n)
97.5% 2.5% 27.02235 127.29020
区間下限上限
通常の t 区間17.178.4
ブートストラップ t 区間27.0127.3
↔️
ブートストラップの分位点は左右対称とは限らない（−5.36 と 1.40）。t 分布の分位点は必ず対称（±2.06）。
🍎 かんたん説明

外れ値のせいで「もっと大きい平均もありうる」。ブートストラップ区間は上側が大きく伸びてそれを表す。正規性に頼らない（ノンパラメトリック）ので、どんな統計量にも使える。

🤔 答えられるかな？（クリックで答えが開く）

Q1. ブートストラップで必ず TRUE にする引数は？A. replace = TRUE（復元抽出）。
Q2. t* の式で μ ではなく x̄ を使うのはなぜ？A. 仮説検定ではなく信頼区間を作っていて、仮定する母平均がないから。
Q3. 通常の t 区間とくらべて、ブートストラップ区間の上限は？A. かなり高い（78.4 → 127.3）。外れ値の影響を反映している。
④

p 値の注意

有意性の落とし穴

🎯 これだけ覚えればOK

p 値が小さい＝効果が大きい、ではない。信頼区間で大きさを見る。

⚖️
統計的有意性 ≠ 実用的有意性。
  • p 値の目安：1% 未満 very strong、1〜5% strong、5〜10% weak、10% 超 insufficient。
  • 4.9% と 5.1% で結論を真っ二つにしない。p 値は「さらに調べよう」の合図。
  • 薬の例：p ＜ 1% でも、信頼区間が「1〜2 ポンド減」なら、実用的には小さい効果。
tA <- 1.5 / (8 / sqrt(2500))   # n = 2500
tA
2 * pt(tA, df = 2499, lower.tail = FALSE)
1.5 + c(-1, 1) * qt(0.975, 2499) * 8 / sqrt(2500)
[1] 9.375 [1] 1.497508e-20 [1] 1.186254 1.813746

（イメージの仮想例。p 値は極小でも、平均の減少の区間は 1.19〜1.81 ポンド。）

🚫
棄却できなくても、帰無仮説が正しいとは言えない。検出力不足（underpowered）かもしれない。
🕵️
p-hacking はダメ。20 個のサブグループに分ければ、平均 1 個は偶然 p ＜ 5% になる（第1種の過誤）。
🍎 かんたん説明

棄却域（critical region）のやり方もある：最初に臨界値を決め、検定統計量がそれより極端なら棄却。この授業では p 値を使う。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 「統計的に有意」と「実用的に有意」は同じ？A. ちがう。p 値が小さくても、効果（信頼区間）が小さいことがある。
Q2. 帰無仮説を棄却できなかったら「帰無仮説は正しい」と言える？A. 言えない。受け入れ（accept）はしない。検出力不足の可能性もある。
Q3. p-hacking とは？A. p 値を小さくするためにサブグループ探しなど、あらゆることをすること。避けるべき。

💡 まとめ

• いちばん大事：データは母集団の代表か

• 小標本＋外れ値・歪み → t 区間は危ない

• FPC を使わないと SE は過大評価（区間が少し広い）

• ブートストラップ：replace = TRUE で何度も再標本

• p 値が小さくても、効果の大きさは信頼区間で確認

ランダムな試行・標本空間・事象

確率の言葉をそろえる

ランダムな試行（random experiment）は、結果がはっきり決まっていて、どれになるかは偶然で決まる手続きです。コイン投げ、サイコロ、Web 広告のクリック（する／しない）、株価の1年後（上がる／下がる／変わらない）など。

用語意味サイコロ1個の例
標本空間 S起こりうる結果すべてS = {1, 2, 3, 4, 5, 6}
結果 outcomeS の要素1つ4
事象 event結果の集まり偶数 E = {2, 4, 6}
根元事象 simple event結果1つだけの事象{6}

コインを2回投げると、S = {(表,表), (表,裏), (裏,表), (裏,裏)} の4通りです。「(表,裏)」と「(裏,表)」は別の結果であることに注意しましょう。

🍎 かんたん説明

標本空間＝くじ箱の中身全部、事象＝その中で「当たり」と決めたくじの集まり。

②

R でランダムな試行をシミュレーションする

sample() と set.seed()

sample(候補, size = 回数, replace = TRUE) で、候補から無作為に選べます。replace = TRUE は復元抽出（選んだものを戻す＝サイコロをくり返し振る）です。

die <- 1:6
set.seed(2026)
sample(die, size = 10, replace = TRUE)
[1] 5 1 1 6 5 3 4 4 5 4

乱数は実行のたびに変わります。set.seed() で種を決めると、同じ結果を再現できます（レポートや課題で大切）。

sample(die, size = 6, replace = FALSE)
sample(die, size = 7, replace = FALSE)
[1] 2 6 4 3 1 5 Error: cannot take a sample larger than the population when 'replace = FALSE'
⚠️ replace = FALSE（非復元抽出）では、一度選んだものは戻らないので、候補の数（6）より多くは選べずエラーになります。名簿から重複なく人を選ぶときは FALSE、サイコロのようにくり返すときは TRUE。
③

確率とオッズ

分母が違う2つの表し方
📐 確率 P(A) ＝ A に当てはまる結果の数 ÷ 全部の結果の数（すべて同じ確からしさのとき）
📐 オッズ ＝ 成功の数 ÷ 失敗の数（「成功:失敗」とも書く）

サイコロで偶数が出る確率は 3/6 = 0.5、オッズは 3:3 = 1:1。6 が出る確率は 1/6、オッズは 1:5 です。

データから確率を推定することもできます。あるオンラインショップの1か月の注文 2,500 件のうち、返品が 175 件だったとします（架空のデータ）。

orders <- 2500
returns <- 175
returns / orders                  # probability of a return
returns / (orders - returns)      # odds of a return
[1] 0.07 [1] 0.07526882

「無作為に1件選ぶと、約 7% の確率で返品」「長い目で見ると約 7% が返品」と解釈します。オッズは約 0.075（≒ 1:13）。

⚠️ R に 175 / 2,500 とカンマ付きで書くとエラーです。また a + b + c / total は「c だけを total で割ってから足す」計算になります。分子全体をかっこで囲む：(a + b + c) / total。
範囲例
確率 probability0〜1（0＝起こらない、1＝必ず起こる）0.07
百分率 percentage0%〜100%7%
割合 proportion確率と同じ数値。ただし「偶然」の意味は含まない全注文の 7% が返品

大数の法則

くり返すほど確率に近づく

コインを投げた回数が少ないと、表の割合は 0.5 から大きくずれます。回数を増やすと、割合はだんだん 0.5 に近づきます。これが大数の法則（law of large numbers）で、確率を「長い目で見た相対度数」と解釈する根拠です。

set.seed(550)
flips <- sample(c("H", "T"), size = 2000, replace = TRUE)
prop_heads <- cumsum(flips == "H") / seq_along(flips)
prop_heads[c(10, 100, 1000, 2000)]
plot(prop_heads, type = "l", ylim = c(0, 1), las = 1,
     xlab = "Number of flips", ylab = "Proportion of heads")
abline(h = 0.5, col = "red", lty = 2)
[1] 0.400 0.480 0.510 0.499
⚠️ 大数の法則は「長い目で見ると」の話です。「表が5回続いたから次は裏が出やすい」という考えはギャンブラーの誤謬。コインに記憶はなく、次の1回の確率は 0.5 のままです。
💻 ミニ練習：サイコロの大数の法則

set.seed(1) のあと、サイコロを 6000 回振るシミュレーションをして、6 が出た割合を求めてください（理論値は 1/6 ≈ 0.167）。

set.seed(1)
rolls <- sample(1:6, size = 6000, replace = TRUE)
mean(rolls == 6)

rolls == 6 は TRUE/FALSE のベクトル。mean() を取ると TRUE の割合になる。結果は 1/6 に近い値になる。

💡 学習のヒント

確率＝成功 ÷ 全体、オッズ＝成功 ÷ 失敗。確率 1/6 のオッズは 1:5。オッズ 1:3 の確率は 1/4。分母の違いを意識する。

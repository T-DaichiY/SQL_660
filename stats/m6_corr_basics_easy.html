散布図ってなに？

2つの数を点で描く

🎯 これだけ覚えればOK

散布図は「向き・形・強さ・特別な点」の4つを見る。

🖼️
数字の表だけだと気づけないことも、図にするとすぐ分かる。2つの数の関係を見るには散布図を描こう。

散布図は、同じ人（もの）で測った2つの数を、横軸と縦軸にして点で描いた図です。例：検索結果の「順位（1〜10位）」と「クリックした人の割合」。

見るところひとこと順位とクリック率の例
向き direction左から右へ見て、上がる？下がる？下がる（negative）
形 formまっすぐ？曲がってる？曲がってる（non-linear）
強さ strength点が1本の線にどれだけ近い？近い（strong）
特別な点はずれた点（outlier）・かたまり（cluster）なし
🍎 かんたん説明

plot(x, y, pch = 16) で散布図。pch = 16 は塗りつぶしの丸。xlab・ylab で軸の名前を付けます。

📝
There is a strong negative non-linear association between position and click-through rate.

🤔 答えられるかな？（クリックで答えが開く）

Q1. 散布図に使うのは、どんな種類の変数2つ？A. 量的変数（数）2つ。
Q2. 「下がっている」は向きで言うと？A. negative（負）。左から右へ読んで下りなら負、上りなら正。
Q3. 「correlation（相関）」という言葉は、どんな変数に使える？A. 量的変数のときだけ。カテゴリ変数なら association か relationship。
②

相関係数 r

いっしょに動く度合いを1つの数で

🎯 これだけ覚えればOK

r は −1 〜 +1。符号が向き、大きさ（|r|）が強さ。

🔢
相関係数 r：−1 〜 +1 の数。＋は右上がり、−は右下がり、0は「直線の関係なし」。
|r|（符号をとった大きさ）強さ（この授業の基準）
0.5 以下weak（弱い）
0.5 〜 0.8moderate（中くらい）
0.8 より大きいstrong（強い）

順位とクリック率は曲線でも、cor(position, rate) は −0.902（強い負）。r = ±1 になるのは、点がぴったり一直線のときだけです。

⚠️
r = 0 は「線形の関係がない」だけ。U字のカーブがあっても r はほぼ 0（例：0.006）。だから先に散布図を見る。
🎯
外れ値に弱い！たった1点で r が −0.235 から −0.968 に変わる例。
🍎 かんたん説明

試験では、散布図の画像を見て r を当てる問題が出ます。「右上がりで点が線に近い → 1 に近い正の数」のように、向きと強さから推理しよう。

🤔 答えられるかな？（クリックで答えが開く）

Q1. r = −0.97 はどんな関係？A. 強い負の相関（右下がりで、点がほぼ一直線）。
Q2. r = 0.3 は強い？弱い？A. 弱い（0.5 以下）。
Q3. 外れ値を1つ除くと r はどう変わった？A. −0.235 から −0.968 へ。外れ値が相関を弱めていた。r は外れ値に強くない（not resistant）。

donors で探索

実データで散布図と cor

🎯 これだけ覚えればOK

summary → 散布図 → cor の順。列は donors$列名。

🔍
データを手に入れたら：summary → 散布図 → cor。

donors は、退役軍人の団体にダイレクトメールで寄付を募った結果のデータ（95,412人、22変数）です。

donors <- read.csv("donors.csv")
summary(donors)
plot(donors$averageGiftAmount, donors$numberGifts,
     cex = 0.5, las = 1, pch = 16)
cor(donors$averageGiftAmount, donors$numberGifts)
[1] -0.2569922
  • donors$列名 と書かないと「object not found」。R はどのデータか分からないから。
  • r は負だけど弱い（−0.26）。形は曲線。大多数は「平均 $100 未満・100回未満」のかたまり。
  • ほかに、回数は多いけど金額が小さい人、金額は大きいけど回数が少ない人もいる。→ 図にしないと分からない発見！
  • jitter：重なった点を少しずらして、点の多さ（密度）を見えるようにする。
🍎 かんたん説明

Your turn：donors から好きな2変数を選んで、散布図と相関を。自分のデータで練習して、LinkedIn やポートフォリオに載せるのもおすすめ。

🤔 答えられるかな？（クリックで答えが開く）

Q1. plot(averageGiftAmount, numberGifts) がエラーになるのはなぜ？A. R がどのデータフレームか分からないから。donors$averageGiftAmount のように書く。
Q2. jitter って何のため？A. 重なった点を少しずらして、点がどれだけ集まっているか見やすくするため。

相関行列と散布図行列

たくさんの変数を一度に

🎯 これだけ覚えればOK

cor() に量的な列をまとめて入れると相関行列。NA があるなら use = "complete.obs"。

🧮
相関行列：全部の組み合わせの r を表にしたもの。

量的変数だけを選んで cor() に入れます。欠損値（NA）があると NA だらけになるので、use = "complete.obs" を付けます。

donorsNumeric <- donors[ , c("numberChildren", "incomeRating",
                             "wealthRating", "smallestGiftAmount",
                             "yrsFirstDon")]
round(cor(donorsNumeric, use = "complete.obs"), 2)
incomeRatingwealthRatingsmallestGiftAmountyrsFirstDon
incomeRating1.000.450.11−0.06
wealthRating0.451.000.06−0.02
smallestGiftAmount0.110.061.00−0.46
yrsFirstDon−0.06−0.02−0.461.00

（5変数のうち、説明に使う4つだけ抜き出した表。numberChildren は他とほぼ無関係。）

  • 対角線はいつも 1（自分自身との相関）。
  • 折り返すと同じ値（A と B の相関＝B と A の相関）。
  • いちばん強い正：income と wealth（0.45）。絶対値で最大：yrsFirstDon と smallestGiftAmount（−0.46）。どちらも weak。
🍎 かんたん説明

散布図をまとめて見るなら pairs()。pairs(~ a + b + c, data = donors, na.action = na.omit) の書き方もあります。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 相関行列の対角線は？A. いつも 1。
Q2. cor(donorsNumeric) が NA だらけのとき、付ける引数は？A. use = "complete.obs"
Q3. 散布図をまとめて描く関数は？A. pairs()

💡 まとめ

• 散布図：向き・形・強さ・特別な点

• r：−1〜+1、|r| ≤ 0.5 weak、> 0.8 strong

• r = 0 は「直線の関係なし」

• 外れ値で r は大きく変わる

• 相関行列：対角線は1、折り返すと同じ

🎯 推測の基礎②：片側／両側検定・α・第1種／第2種の誤り

仮説検定の「ルール」を決める3つの道具を学びます。どちらの端を見るか（片側・両側）、どこから「珍しい」と呼ぶか（有意水準 α = 0.05 の由来）、そして検定が間違うとき、どんな間違い方があるか（第1種・第2種の誤り）です。

①

片側検定と両側検定

仮説に「向き」があるか？

帰無仮説（null hypothesis, H₀）と対立仮説（alternative hypothesis, H₁）は、ふつう「差はない vs 何か差がある」の形です。ただし対立仮説には向き（direction）を付けることもできます。

  • 向きなし：H₀「身長に男女差はない」 vs H₁「男性と女性では身長が違う」。女性が高くても男性が高くても H₁ に当てはまります。→ 両側検定（two-tailed test）
  • 向きあり：H₀「身長に男女差はない」 vs H₁「男性の方が女性より高い」。片方のグループがもう一方より上だ、と方向まで言っています。→ 片側検定（one-tailed test）

両側検定では、検定統計量（test statistic）が帰無仮説の値より高すぎても低すぎても「珍しい」と判断します。この違いは、分布のどの端（tail）に確率を置くかを変えます。有意水準を α = 0.05（5%）とすると、置き方は次のとおりです。

  • 両側：上側 2.5% ＋ 下側 2.5%（合計 5%）。どちらの端に入っても仮説の条件を満たす。
  • 片側：仮説の方向の端に 5% を全部置く。反対側の 2.5% は使わず、その分を仮説の側に足して「広げる」。
α = 0.05 の置き方（標準正規分布の例：赤い部分が「棄却域」）
両側検定：上 2.5% ＋ 下 2.5%
臨界値 ±1.96
片側検定（H₁：上側が大きい）：上 5%
臨界値 +1.645
棄却域の合計はどちらも 5%。片側では全部を仮説の方向に集めるので、その方向では臨界値が小さくなります（1.96 → 1.645）。
帰無仮説対立仮説検定の種類α = 0.05 の置き方
H₀：男女で身長に差はないH₁：男女で身長が違う両側（two-tailed）上 2.5% ＋ 下 2.5%
H₀：男女で身長に差はないH₁：男性の方が女性より高い片側（one-tailed）上 5%（仮説の方向）

いつ使い分けるか？差がどちらに出るか分からない探索的な状況では、少し「釣り（fishing）」をするように「上でも下でも、何か珍しいことが起きていないか」を見ます。このときは両側です。一方、データを見る前に理論や先行研究から「こちらが高いはずだ」という方向が決まっているなら、下側の 2.5% を使わずに上側へ 5% 全部を置く片側が使えます。

⚠️ 入門レベルでは、基本的に両側検定を使います。片側検定は「向きを事前に決めてあった」ときだけです。データを見てから「女性の方が高そうだから、女性＞男性の片側にしよう」と選ぶのは、5% を都合よく動かすことになり、してはいけません。また、仮説と逆の方向に差が出たときは、どれだけ大きな差でも片側検定では「有意」になりません（②で確認します）。
📌 なぜ知っておく必要があるか：検定の出力を読むときと、t の表で臨界値（critical value）を引くときです。表には 0.05・0.01 などの列が両側用と片側用に分かれているので、どちらの列を見るかを知っている必要があります。
🍎 かんたん説明

両側は「どっちかに珍しければOK」で、5% を両端に半分ずつ。片側は「この方向だけ見る」と決めて、5% を片端にまとめて置く。迷ったら両側。

💻 ミニ練習：z の臨界値を求める

標準正規分布で、α = 0.01 のときの臨界値を、両側と片側の2つ、R（qnorm）で求めてください。両側は 1 - α/2、片側は 1 - α の分位点を使います。

qnorm(1 - 0.01/2)   # two-tailed, alpha = 0.01
qnorm(1 - 0.01)     # one-tailed, alpha = 0.01
[1] 2.575829 [1] 2.326348

両側 2.576（約2.58）、片側 2.326（約2.33）。同じ α でも片側の方が臨界値が小さく、仮説の方向では「有意」になりやすくなります。

②

臨界値とp値をRで確かめる

t の表の「両側」「片側」の列、そして向きを間違えると…

まず、α = 0.05 の分布の端の面積が本当に 5% になっているかを確かめましょう。pnorm(…, lower.tail = FALSE) は「その値より右側の面積」を返します。

2 * pnorm(1.96, lower.tail = FALSE)   # two-tailed: 2.5% + 2.5%
pnorm(1.645, lower.tail = FALSE)      # one-tailed: 5% in one tail
[1] 0.04999579 [1] 0.04998491

両側では 1.96 の外側（上 2.5% ＋ 下 2.5%）、片側では 1.645 の右側が、ともに約 0.05 です。同じことを qnorm()（面積から臨界値を求める関数）で逆向きに確かめます。

qnorm(1 - 0.05/2)   # two-tailed, alpha = 0.05
qnorm(1 - 0.05)     # one-tailed, alpha = 0.05
[1] 1.959964 [1] 1.644854

t 分布では、臨界値は自由度（df）によって変わります。自由度 20 での t の表を R で作ってみましょう。教科書や講義の t の表と同じく、両側の行と片側の行があります。

alpha <- c(0.05, 0.01)
crit <- rbind(two_tailed = qt(1 - alpha/2, df = 20),
              one_tailed = qt(1 - alpha,   df = 20))
colnames(crit) <- c("alpha=0.05", "alpha=0.01")
round(crit, 3)
alpha=0.05 alpha=0.01 two_tailed 2.086 2.845 one_tailed 1.725 2.528
📖 読み方：α = 0.05 で自由度 20 のとき、両側検定なら |t| ≥ 2.086、片側検定なら t ≥ 1.725（仮説の方向）で「有意」。同じ t の値でも、どちらの列を見るかで結論が変わりうるのが、この単元のポイントです。

次は、講義の男女のテスト得点の例です。女性の平均が 60 点、男性の平均が 50 点。H₀「男女で得点に差はない」 vs H₁「差がある（両側）」を検定します（R では t.test() が既定で両側）。

women <- c(64, 58, 66, 55, 62, 57, 60, 63, 59, 56)
men   <- c(52, 49, 57, 45, 53, 50, 48, 55, 47, 44)
mean(women)
mean(men)
[1] 60 [1] 50
t.test(women, men)
Welch Two Sample t-test data: women and men t = 5.6493, df = 17.609, p-value = 2.528e-05 alternative hypothesis: true difference in means is not equal to 0 95 percent confidence interval: 6.275189 13.724811 sample estimates: mean of x mean of y 60 50

p = 2.528e-05（= 0.00002528）で、α = 0.05 よりずっと小さいので H₀ を棄却します。次に、向きを間違えた片側検定をしてみます。「女性が男性より低い」（alternative = "less"）という仮説を立てると…

t.test(women, men, alternative = "less")$p.value
[1] 0.9999874

p ≈ 1 です。データは女性の方が 10 点も高いので、「女性が低い」という向きの仮説には全く支持がありません。片側検定は、決めた方向にしか反応しません。

最後に、片側検定の「落とし穴」を見ましょう。次の2グループでは、両側 p = 0.0697（5% を超える）なのに、片側にすると p が半分の 0.0348 になって「有意」になります。

x <- c(14, 11, 13, 15, 12, 10, 16, 12)
y <- c(12, 9, 12, 9, 13, 9, 13, 11)
t.test(x, y)$p.value                          # two-tailed
t.test(x, y, alternative = "greater")$p.value # one-tailed (x > y)
[1] 0.06967655 [1] 0.03483828
⚠️ 片側 p 値は、（差が仮説の方向にあるとき）両側 p 値のちょうど半分になります。だからこそ、「両側では有意にならなかったので、後から片側に切り替える」ことは許されません。片側にするかどうかは、データを見る前に理論で決めておきます。迷ったら両側（t.test の既定）を使います。
🍎 かんたん説明

t.test()は何も言わなければ両側。alternative = "greater" や "less" を付けると片側になり、p 値は（方向が合っていれば）半分になる。ただし片側は事前に方向を決めたときだけ。

💻 ミニ練習：片側検定の p 値

x <- c(14, 11, 13, 15, 12, 10, 16, 12) と y <- c(12, 9, 12, 9, 13, 9, 13, 11) について、「x の平均が y より大きい」という向きの仮説（片側）の p 値を t.test() で求めてください（$p.value を使います）。

x <- c(14, 11, 13, 15, 12, 10, 16, 12)
y <- c(12, 9, 12, 9, 13, 9, 13, 11)
t.test(x, y, alternative = "greater")$p.value
[1] 0.03483828

p = 0.0348。両側の p 値（0.0697）のちょうど半分です。向きを事前に決めていた場合に限り、この値で判断できます。

③

α = 0.05 はどこから来たのか

Fisher・印刷された表・「ただの慣習」

仮説検定の考え方を、もう一度「モデルの当てはまり」で眺めてみましょう。対立仮説はモデル（model）で表せます。独立2標本の t 検定なら、「データは全体の平均（grand mean）1つで説明できる」（帰無仮説：差なし）か、「グループごとの平均で説明した方がよい」（対立仮説：差あり）かを比べます。

score <- c(women, men)
group <- rep(c("women", "men"), each = 10)
sum((score - mean(score))^2)        # error if we use ONE grand mean
sum((score - ave(score, group))^2)  # error if we use the TWO group means
[1] 782 [1] 282

全体平均1つで説明すると、各データとのズレ（誤差）の二乗和が 782、グループごとの平均だと 282 に減りました。グループ平均を使うと、データへの当てはまりがずっと良くなっています。当てはまりが良いほど、対立仮説への信頼が増します。

ただし、どちらの仮説が正しいかを確実には言えません。そこで、「もし母集団に効果がなかったら（H₀ が真なら）、このくらい良く当てはまる確率はどれだけか」を計算します。これが p 値（p-value）です。anova()で2つのモデルを比べると、その確率が出ます。

anova(lm(score ~ 1), lm(score ~ group))
Analysis of Variance Table Model 1: score ~ 1 Model 2: score ~ group Res.Df RSS Df Sum of Sq F Pr(>F) 1 19 782 2 18 282 1 500 31.915 2.329e-05 *** --- Signif. codes: 0 ‘***’ 0.001 ‘**’ 0.01 ‘*’ 0.05 ‘.’ 0.1 ‘ ’ 1

p = 2.329e-05。これは等分散を仮定した t 検定（var.equal = TRUE）の p 値と同じです。

t.test(score ~ group, var.equal = TRUE)$p.value
[1] 2.329275e-05

では、p がどれだけ小さければ「偶然ではない」と呼ぶのでしょうか。その線引きが 0.05 です。

  • Ronald Fisher が、結果を「本物」と受け入れる基準として 95% の閾値（threshold）、つまり p = 0.05 を使うよう提案しました。しかしこれは厳格な規則ではありません。現在 0.05 を使うのは、主に慣習（convention）であり、強い根拠があるわけではありません。
  • 現代の有意性検定（significance testing）は、Jerzy Neyman と Egon Pearson の考え方と Fisher の考え方を組み合わせたものです。
  • 0.05 が定着した理由はおそらく、印刷された表です。約 100 年前、研究者は電卓もコンピュータも持っていませんでした。有意かどうかを調べる唯一の方法は、0.05・0.02・0.01 の列が並んだ印刷物の表を引くことでした。便利な列として 0.05 が選ばれ続けたのです。

Fisher 自身も、こう述べています。

💬 “No scientific worker has a fixed level of significance, at which, from year to year and in all circumstances, he rejects hypotheses. He rather gives his mind to each particular case in light of his evidence and his ideas.”
（どの科学者も、毎年・あらゆる状況で仮説を棄却する、固定の有意水準など持っていない。むしろ個々のケースで、証拠と自分の考えに照らして判断する。）― Ronald Fisher

だから私たちは、効果量（effect size）のような追加の指標も使います（次の講義で学びます）。有意性（statistical significance）が重要なのは、(1) 簡単な目安（benchmark）になるから、(2) みんながそう教わっているから、の2つの理由が主です。p 値は役に立ちますが、万能ではありません。

⚠️ p 値だけを示して、ほかの情報（効果量など）を添えない人は、「何をしているか分かっていない」か「誤解させようとしている」かのどちらかです。p 値の良い点と限界の両方を理解し、より良い報告の仕方を身につけましょう。
🍎 かんたん説明

0.05 は神様が決めた線ではなく、Fisher が目安にしたものが、100年前の印刷された表の便利さもあって定着した習慣。使うときは「5% は絶対ではない」と覚えておく。

💻 ミニ練習：当てはまりの比較

women と men から score（20人分を連結したベクトル）と group（"women"/"men" を各10回）を作り、lm() で全体平均だけのモデル（score ~ 1）とグループ別平均のモデル（score ~ group）を anova() で比較するコードを書いてください。

score <- c(women, men)
group <- rep(c("women", "men"), each = 10)
anova(lm(score ~ 1), lm(score ~ group))

F = 31.915、p = 2.329e-05。グループ平均のモデルの方が、誤差の二乗和が 782 → 282 に減っており、H₀（差なし）の下ではこんなに良く当てはまる確率はごくわずか、と読みます。

④

第1種の誤りと第2種の誤り

Type I error / Type II error

講義の例に戻ります。男女のテスト得点に差があるかを調べます。H₀「男女に差はない」、H₁「差がある」。女性の平均は 60 点、男性は 50 点で、10 点の差がありました。平均の差だけでは判断できないので、有意性検定を使ってこの差が本物か、偶然かを決めます。

細かい技術をいったん忘れて大きく見ると、結論は正しいか、間違っているかのどちらかです。そして H₀ が本当は真の場合も偽の場合も、私たちは正しくも間違ってもあり得ます。これを整理したのが次の 2×2 の表（decision table）です。

私たちの結論 ＼ 本当のこと（unknown）H₀ は真（本当は差がない）H₀ は偽（本当は差がある）
H₀ を棄却する
（reject H₀：差があると結論）		第1種の誤り（Type I error）
false positive・確率 α		誤りなし（正しい）
確率 1 − β ＝ 検出力（power）
H₀ を棄却しない
（fail to reject H₀）		誤りなし（正しい）
確率 1 − α		第2種の誤り（Type II error）
false negative・確率 β

表の列（本当のこと）は「不明（unknown）」です。本当のことが分かっているなら、そもそも検定はいりません。分からないから検定をし、分からないから間違いが起こりえます。

  • 第1種の誤り（Type I error）＝ 真の H₀ を棄却してしまう（false positive：本当は何も起きていないのに「ある」と言う）。α = 0.05 なら、効果が全くなくても、偶然だけで約 5% の割合でこの誤りが起こります。
  • 第2種の誤り（Type II error）＝ 偽の H₀ を棄却しない（false negative：本当は何か起きているのに「ない」と言う）。

覚え方は妊娠の例えです。

場面検定の言い方誤りの種類
妊娠していない人に「妊娠しています」と言う何も起きていないのに「ある」と言った第1種の誤り（false positive）
妊娠している人に「妊娠していません」と言う確かに何か起きているのに「ない」と言った第2種の誤り（false negative）

この2つの誤りの確率に名前が付いています。α ＝ 第1種の誤りの確率、β ＝ 第2種の誤りの確率、そして 検出力 power ＝ 1 − β（本当に効果があるとき、それを見つける確率）です。下の図は、帰無仮説が真の世界（左の山）と偽の世界（右の山）を重ね、臨界値（点線）で線を引いたものです。

α と β の位置（模式図）
点線より右を「棄却」と呼ぶ。左の山（H₀ が真）で点線より右にはみ出した赤い部分が α（第1種の誤り）。右の山（H₀ が偽）で点線より左にある黄色い部分が β（第2種の誤り）。右の山の点線より右側の面積が検出力。図では、右の山の中心を 2.8 に置いており、片側 α = 0.025（臨界値 1.96）のとき検出力は約 0.80 です。

α が「偶然の 5%」であることを、Rで実験して確かめましょう。H₀ が本当に真（2グループを同じ分布 rnorm から取る）という状況で t 検定を 10000 回繰り返し、p < 0.05 になった割合を数えます。

set.seed(1)
p <- replicate(10000, t.test(rnorm(20), rnorm(20))$p.value)  # H0 is TRUE
mean(p < 0.05)   # proportion of false positives (Type I errors)
mean(p < 0.01)
[1] 0.05 [1] 0.0094

p < 0.05 の割合はほぼ 0.05、p < 0.01 の割合はほぼ 0.01 です。効果が全くなくても、α の割合で「有意」が出る、これが第1種の誤りです。

次は反対に、H₀ が偽（2グループの真の平均が 0.5 違う）で、各グループ n = 20 のとき、検定が見逃す（p ≥ 0.05 になる）割合です。

set.seed(2)
p2 <- replicate(10000, t.test(rnorm(20, mean = 0), rnorm(20, mean = 0.5))$p.value)  # H0 is FALSE
mean(p2 >= 0.05)  # proportion of misses (Type II errors)
[1] 0.6676

約 67% は見逃しています。これが第2種の誤りで、power.t.test() の理論値とも合います。

pw <- power.t.test(n = 20, delta = 0.5, sd = 1, sig.level = 0.05)
pw$power        # power = 1 - beta
1 - pw$power    # beta (Type II error rate)
[1] 0.3377084 [1] 0.6622916

検出力は約 0.34、つまり β ≈ 0.66 です。n が小さいと、本物の効果も見逃しやすいのです。検出力 0.80 を目指すには、各グループ何人必要でしょうか。

power.t.test(power = 0.80, delta = 0.5, sd = 1, sig.level = 0.05)$n
[1] 63.76576

約 63.77 → 切り上げて各グループ 64 人です。検出力と効果量、サンプルサイズは、次の講義の主題です。

⚠️ 今の段階では、第1種とは何か・第2種とは何かを例と一緒に言えれば十分です。α と β、検出力の計算は後で重要になります。また、「α を 0.05 に設定する」と言うべきところを「p 値を 0.05 に設定する」と言わないようにしましょう。設定するのは有意水準 α で、p 値はデータから計算される値です。
📌 結論の読み方：H₀ を棄却したときに起こりうる誤りは第1種、棄却しなかったときに起こりうる誤りは第2種です。同時に両方を犯すことはありません。
🍎 かんたん説明

第1種＝ないのに「ある」と言う（誤報）。第2種＝あるのに「ない」と言う（見逃し）。α は誤報の率、β は見逃しの率。

💻 ミニ練習：第2種の誤りの確率 β

power.t.test() を使って、効果量 delta = 0.5、sd = 1、α = 0.05、各グループ n = 64 のときの第2種の誤りの確率 β（= 1 − 検出力）を求めてください。

1 - power.t.test(n = 64, delta = 0.5, sd = 1, sig.level = 0.05)$power
[1] 0.1985414

β ≈ 0.199（約 0.20）。n = 64 で検出力が約 0.80 になるので、見逃しの確率は約 20% です。

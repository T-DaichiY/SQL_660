二元表と3つの検定

変数が2つになったら

🎯 これだけ覚えればOK

カテゴリ変数が2つ → 二元表。計算は同じで、「均質性」と「関連（独立性）」の2種類がある。

📋
一元表＝変数1つ（NHLの誕生四半期）
二元表＝変数2つ（怒りのレベル × 心臓病の有無）
検定グループ変数こんな問い
適合度（GOF）1つ1つ割合は予想どおり？
均質性2つ以上2つ薬A・薬B・プラセボで副作用の割合は同じ？
関連（独立性）1つ2つ髪の色と目の色は関係ある？

どの検定でも、χ² = Σ (O − E)² ／ E、χ²分布で p 値、p < α なら棄却、という流れは同じです。違うのは仮説の言い方・自由度・期待度数の式。

二元表では：df = (行数 − 1) × (列数 − 1)、E = 行合計 × 列合計 ÷ 総計。

🍎 ひとことで

まず「変数はいくつ？グループはいくつ？」。1つの集団で2つの変数の関係を調べるなら、関連（独立性）の検定。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 怒りと心臓病の例はどの検定？A. 1つの無作為標本・カテゴリ変数2つなので、関連（独立性）の検定。
Q2. 2行3列の表の自由度は？A. (2−1)×(3−1) = 2。

怒りと心臓病のデータ

実際の研究（N = 8474人）

怒りっぽい人は心臓病（CHD）になりやすい？ 人を追いかけて調べた前向き観察研究のデータです。怒りや心臓病は人に「割り当てる」ことができないので、実験ではなく観察です。

lowmoderatehigh
CHD あり5311027
CHD なし30574621606
anger_counts <- c(53, 110, 27, 3057, 4621, 606)
CHD_anger <- matrix(anger_counts, nrow = 2, ncol = 3, byrow = TRUE)
rownames(CHD_anger) <- c("yes", "no")
colnames(CHD_anger) <- c("low", "moderate", "high")
CHD_anger
low moderate high yes 53 110 27 no 3057 4621 606
⚠️ 合計は入れない！入れると R が「新しい群」と勘違いします。

人数が違うので、割合で比べます（列ごとに100%）。

round(proportions(CHD_anger, margin = 2), 3) * 100
low moderate high yes 1.7 2.3 4.3 no 98.3 97.7 95.7
📊
CHD になった割合：low 1.7% → moderate 2.3% → high 4.3%
人数は moderate が最多でも、割合は high が最大
🍎 ひとことで

群の人数が違うときは、度数ではなく割合で比べる。margin = 2 は「列ごと」。

🤔 答えられるかな？（クリックで答えが開く）

Q1. byrow = TRUEは何の指定？A. 数字を行ごとに詰める指定。
Q2. なぜ割合で比べる？A. 群の人数が大きく違うから。
③

検定してみよう

仮説 → 期待度数 → chisq.test → 結論
  • H₀：怒りのレベルと CHD に関連はない（独立）。差は偶然。
  • Hₐ：関連がある（独立でない）。

期待度数は「関連がなければこうなるはず」の人数。yes・low のセルは：

190 * 3110 / 8474
[1] 69.73094

期待は約 69.7 人、実際は 53 人でした。全セルのずれを合計して判断します。

chisq.test(CHD_anger)
Pearson's Chi-squared test data: CHD_anger X-squared = 16.077, df = 2, p-value = 0.0003228
✅
χ² = 16.08、df = 2、p = 0.0003
p が小さい → H₀ を棄却。関連があるという説得力のある証拠あり

条件のチェック（3つ）

  • 無作為標本？ → はい
  • 期待度数はすべて 5 以上？ → 最小は 14.2 なのでOK（$expected で確認）
  • 母集団は標本の10倍以上？ → 8474 × 10 = 84,740 人超と考える
⚠️ 「証明された」とは書かない。書くのは「説得力のある証拠がある」。
⚠️
Type I error＝本当は関連がないのに「ある」と結論してしまう誤り。
例：効果のない怒りの教育や治療に、お金と時間をかけてしまう。
🍎 ひとことで

手順：仮説 → 期待度数 → chisq.test() → 条件 → p 値で結論 → 誤りの可能性。

🤔 答えられるかな？（クリックで答えが開く）

Q1. E₁₁ の式は？A. 行合計 × 列合計 ÷ 総計 = 190 × 3110 ÷ 8474 ≈ 69.7。
Q2. p = 0.0003 の意味は？A. H₀が正しいとき、これ以上極端な結果が偶然で出る確率が約0.03%。とても低いので、偶然説は捨てる。
Q3. 今回のあり得る誤りは？A. H₀を棄却したので Type I error。

生データから・まとめ

table() と3つの検定の復習

仕事では、度数表ではなく生データ（1人1行）が渡されます。table() で度数表にして、chisq.test() へ渡すだけです。例は openintro::diabetes2（治療法 × 結果）。

library(openintro)
chisq.test(table(diabetes2))
Pearson's Chi-squared test data: table(diabetes2) X-squared = 8.1645, df = 2, p-value = 0.01687

$expected で条件（すべて 5 以上）を確認、$residuals（(O − E)／√E）で目立つセルを探します。rosi の failure は期待より少なめ（残差 −1.584）でした。

適合度均質性関連／独立性
En × 割合行合計 × 列合計 ÷ 総計
dfk − 1(行数−1)×(列数−1)
🎉
χ² の公式 Σ (O − E)² ／ E、χ²分布、結論の流れは3つとも同じ！
🍎 ひとことで

生データなら chisq.test(table(データ))。3つの検定は E と df と仮説の言い方が違うだけ。

🤔 答えられるかな？（クリックで答えが開く）

Q1. diabetes2 の結果は？A. χ² = 8.1645、df = 2、p = 0.01687。
Q2. 残差の式は？A. (O − E) ／ √E。

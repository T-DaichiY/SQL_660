標準誤差と中心極限定理

平均のゆれを測る

🎯 これだけ覚えればOK

SE ＝ s ÷ √n。標本平均が「どれくらいゆれるか」の大きさ。人数が多いほど小さくなる。

🎯
クラスから5人ずつ何回も選んで平均を出すと、毎回ちがう。その平均たちのばらつきが標準誤差（SE）。

標本を何回も取ると、標本平均は毎回少しずつちがいます。これが標本のばらつき。平均たちを並べた分布が標本分布で、そのSDがSEです。

🔔
中心極限定理（CLT）：n が十分大きいとき、
① 標本平均の分布は正規分布　② 中心は母平均 μ　③ 広がりはSE ＝ s/√n
set.seed(1)
pop <- rexp(100000, rate = 1/10)
means <- replicate(10000, mean(sample(pop, 25)))
c(mean(means), sd(means))
[1] 10.035030 2.008706

母集団は右に歪んでいる（平均10、SD約10）のに、n = 25 の標本平均は中心が約10、SDが約2.0（= 10/√25 = 2）になりました。

🍎 かんたん説明

SD は「個々のデータ」のばらつき、SE は「平均」のばらつき。SE は人数が増えると小さくなる（n が4倍で半分）。

🤔 答えられるかな？（クリックで答えが開く）

Q1. SE を表す式は？A. SE ＝ s ÷ √n。
Q2. n を25から100にするとSEは？A. 半分になる（√4 ＝ 2 で割られる）。
Q3. CLT の3つの事実は？A. 正規分布・平均＝母平均 μ・SD＝SE。
②

信頼区間

1.96 × SE

🎯 これだけ覚えればOK

95% 信頼区間 ＝ 標本平均 ± 1.96 × SE。区間が狭いほど、くわしく分かっている。

📐
正規分布の真ん中 95% は −1.96〜+1.96 に入る。だから 1.96 × SE を平均の前後にとる。

GPA の例：標本平均 2.75、s ＝ 0.6、n ＝ 36。SE ＝ 0.6/√36 ＝ 0.1。

xbar <- 2.75; s <- 0.6; n <- 36
se <- s / sqrt(n)
xbar + c(-1, 1) * 1.96 * se
[1] 2.554 2.946

95% 信頼区間は [2.554, 2.946]。適当な「±0.2」や「±1」と違い、理由のある幅です。

⚠️
「95%」の意味：同じやり方で区間を何回も作ると、そのうち約95%が本当の母平均をつかまえる。手元の1本が当たる確率が95%、という意味ではありません。
🍎 かんたん説明

釣りのあみを100回投げると、だいたい95回は魚（本当の平均）がかかる、というイメージ。あみ（区間）を細くするには、人数 n を増やす。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 95%CIの式は？A. x̄ ± 1.96 × SE。
Q2. 1.96 はどこから？A. 標準正規分布の真ん中95%の境界（qnorm(0.975)）。
Q3. 区間が狭いと？A. 推定の精度が高い（標本が代表的）。
③

効果量

p 値だけでは分からない

🎯 これだけ覚えればOK

p 値は人数 n で変わる。効果量は「差の大きさ」。d の目安は 0.2 / 0.5 / 0.8、r の目安は 0.1 / 0.3 / 0.5。

⚖️
同じ「平均の差2・SD10」でも、1群 n＝20 なら p ＝ 0.531、n＝500 なら p ＝ 0.0016。差の大きさ（d ＝ 0.2）は同じ。
効果量smallmediumlarge
Cohen's d0.20.50.8
Pearson's r0.10.30.5
⚠️ d と r は別のものさし。混ぜないこと。
🙋
「有意だから重要」と言われたら →「効果量は？」

人数が足りなくて p ＝ 0.063（有意でない）でも、d ＝ 0.8（大）ということがあります（平均の差8、SD10、1群n＝12）。逆に、人数を増やして無理に有意にするのはp-hackingで、やってはいけません。

🍎 かんたん説明

p 値＝「差がありそうか」、効果量＝「差はどれくらいか」。両方見る。

🤔 答えられるかな？（クリックで答えが開く）

Q1. d＝0.5 は？A. medium（中）。r の medium は 0.3。
Q2. n を増やすと p と d はどうなる？A. p は小さくなりやすいが、d はほとんど変わらない。
Q3. 有意でない（p＝0.06）なら効果はゼロ？A. いいえ。人数不足で効果を見逃しているだけかもしれない。
④

検出力

見つけられる確率

🎯 これだけ覚えればOK

検出力 ＝ 本当にある効果を見つける確率。目安は 0.8。効果量・n・α・検出力は、3つ決まれば残り1つが決まる。

効果量 d必要な n（1群、α＝0.05、power＝0.8）
0.2（small）394
0.5（medium）64
0.8（large）26
power.t.test(delta = 0.5, sd = 1, sig.level = 0.05, power = 0.8)$n
[1] 63.76576

小さな効果を見つけたいなら、たくさんの人が必要。n＝20 では d＝0.5 の効果を見つける確率は約 34%（0.3377）しかありません。

🍎 かんたん説明

検出力は「ちゃんと見つけられる力」。ちいさな効果ほど、たくさんの人が必要。有意かどうかより、効果量・人数・検出力を一緒に見るのが大人の統計。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 検出力の目安は？A. 0.8。
Q2. 効果量を小さくすると必要な n は？A. 大きくなる（d＝0.2で394、d＝0.8で26）。
Q3. 検出力＝？（βとの関係）A. 1 − β（βは効果を見逃す確率）。

①

Rにデータを入れる：group と weight_loss

減量プランの例・factor（因子）

前の講義（ANOVA 3）では、スプレッドシートで ANOVA を手計算しました。題材は減量プランの比較です。3か月後の減量（pounds）を、Plan 1（4人）・Plan 2（3人）・Plan 3（3人）の計10人で調べました。今回はそのデータを R に入れて、同じ答えが一瞬で出ることを確かめます。

Rでは、データを「どの群か」（group）と「測定値」（weight_loss）の2本のベクトルで表します。先頭から同じ順番に並べるのが約束です（最初の4個が Plan 1 の人、次の3個が Plan 2、最後の3個が Plan 3）。

# 群の番号（Plan 1 が4人、Plan 2 が3人、Plan 3 が3人）
group <- c(1, 1, 1, 1, 2, 2, 2, 3, 3, 3)
group
[1] 1 1 1 1 2 2 2 3 3 3

見た目は数字ですが、この 1, 2, 3 は平均を取りたい数量ではなく、ただの名前（ラベル）です。そこで as.factor() を使い、因子（factor）＝カテゴリ変数に変えます。

group <- as.factor(group)
group
[1] 1 1 1 1 2 2 2 3 3 3 Levels: 1 2 3

出力に Levels: 1 2 3 が付きました。これは「この変数は 3つの水準（level）を持つ名義変数（nominal variable）」という意味です。量的変数（quantitative）でも間隔尺度でもありません。

続いて、減量の値を同じ順番で入力します（c() は combine／concatenate＝まとめる関数）。

weight_loss <- c(7, 9, 5, 7,    # Plan 1
               9, 11, 7,     # Plan 2
               15, 12, 18)   # Plan 3
weight_loss
[1] 7 9 5 7 9 11 7 15 12 18
オブジェクト型中身
groupfactor（因子）Plan 1, 2, 3 のラベル（10個）
weight_lossnumeric（数値）各人の減量 (lb)（10個）
⚠️ factor にし忘れると結果が変わります。数値のまま aov() に渡すと、R は 1, 2, 3 を「量」として扱い、群の自由度が 2 ではなく 1 になってしまいます（直線回帰になるため）。
grp_n <- c(1, 1, 1, 1, 2, 2, 2, 3, 3, 3)   # as.factor() していない
summary(aov(weight_loss ~ grp_n))
Df Sum Sq Mean Sq F value Pr(>F) grp_n 1 105.65 105.65 19.96 0.00209 ** Residuals 8 42.35 5.29
Df が 1 と 8 になっており、講義の 2 と 7 とは別物です。
🍎 かんたん説明

group は名前札、weight_loss ははかった数。1・2・3 は足したり平均したりする数ではないので、as.factor() で「これは名前だよ」と R に教えます。

💻 ミニ練習：データを入力する

減量データ（Plan 1: 7, 9, 5, 7／Plan 2: 9, 11, 7／Plan 3: 15, 12, 18）を R に入力してください。群を表す group（as.factor() で因子にする）と、測定値 weight_loss を作ります。

group <- as.factor(c(1, 1, 1, 1, 2, 2, 2, 3, 3, 3))
weight_loss <- c(7, 9, 5, 7, 9, 11, 7, 15, 12, 18)

group と weight_loss は同じ順番・同じ長さ（10個）にそろえます。群は as.factor() で因子に。

②

aov() と ANOVA表の読み方

aov／summary／anova(lm)

R で ANOVA をする方法は主に2つあります。まず1つ目、aov() です。

aov(weight_loss ~ group)
Call: aov(formula = weight_loss ~ group) Terms: group Residuals Sum of Squares 114 34 Deg. of Freedom 2 7 Residual standard error: 2.203893 Estimated effects may be unbalanced

モデル式（formula）の読み方：~（チルダ。多くのキーボードで 1 の左隣、Shift を押して入力）の左が応答変数（response）＝予測したいもの（減量）、右がモデル（説明変数）＝予測に使うもの（群）です。「group は weight_loss を説明するよいモデルか？」を調べる ANOVA です。aov は R に最初から入っている組み込み関数で、パッケージの読み込みは不要です。

このままでも、平方和（Sum of Squares）と自由度（Deg. of Freedom）が読み取れます。

  • 群の平方和 114、残差（Residuals＝誤差）の平方和 34。合計 114 + 34 = 148 は、全員を全体平均と比べた全体のばらつき（SST）です。
  • 自由度は群が 2（群の数 3 − 1）、残差が 7。合計 2 + 7 = 9 で、人数 10 − 1 = 9 と一致します。
全体のばらつき 148 の内訳
群の違いで説明できる分（SSB）が大部分を占めています。

実際にはもっと情報の多い summary() を使うのが普通です。これが一元配置分散分析表（one-way ANOVA table）で、読めることが試験でも問われます。

summary(aov(weight_loss ~ group))
Df Sum Sq Mean Sq F value Pr(>F) group 2 114 57.00 11.73 0.00581 ** Residuals 7 34 4.86 --- Signif. codes: 0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
列意味この例での計算
Df自由度 degrees of freedom群 = 3 − 1 = 2、残差 = 10 − 3 = 7
Sum Sq平方和 sum of squares114、34
Mean Sq平均平方 mean square ＝ Sum Sq ÷ Df114 ÷ 2 = 57、34 ÷ 7 = 4.86
F valueF比 ＝ 群の Mean Sq ÷ 残差の Mean Sq57 ÷ 4.86 ≈ 11.73
Pr(>F)p値0.00581

「F比（ratio）」と呼ぶのは、群の平均平方（モデルが説明できる分）÷ 残差の平均平方（説明できない分）という割り算だからです。試験では、表の一部の数字だけを与えて空欄の数字を計算させる問題が出ます。Sum Sq と Df から Mean Sq、Mean Sq から F、と自分で埋められるようにしておきましょう。

星印（Signif. codes）：p値の右の記号は、どの有意水準で有意かを示します。ここは **（p = 0.0058 は 0.01 より小さい）なので、有意水準 α = 0.05 でも 0.01 でも有意です。***（0.001）は付いていないので、α = 0.001 では有意とは言えません。

⚠️ F値の丸め：同じ F が 11.73（summary）や 11.735（anova）と表示されるのは、表示桁数が違うだけです。真の値は 11.7353…。

2つ目の方法は、線形回帰（lm()）を経由するやり方です。ANOVA と線形回帰は実は同じ仲間（後の M6 で扱います）。lm() だけだと係数が出るだけであまり役に立ちません。

lm(weight_loss ~ group)
Call: lm(formula = weight_loss ~ group) Coefficients: (Intercept) group2 group3 7 2 8

（Plan 1 の平均 7 が切片、Plan 2 は +2、Plan 3 は +8 で、それぞれ平均 9 と 15 に対応します。）この線形モデルを anova() に渡すと、同じ分散分析表が得られます。先ほどの aov() ではなく、anova() であることに注意。

anova(lm(weight_loss ~ group))
Analysis of Variance Table Response: weight_loss Df Sum Sq Mean Sq F value Pr(>F) group 2 114 57.000 11.735 0.005811 ** Residuals 7 34 4.857 --- Signif. codes: 0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

数値はどちらも同じで、丸めの桁数が違うだけです（summary(aov()) は p値を有効数字3桁、anova() は 4桁で表示）。

書き方出力
aov(y ~ g)SS と df だけの短い結果
summary(aov(y ~ g))完全な ANOVA 表（Mean Sq, F, p値）。最もよく使う
anova(lm(y ~ g))同じ表（線形回帰経由）。丸めが少し違う

実務では、スプレッドシートで平方和を計算したりはしません。summary(aov()) の1行で終わりです。ただし手計算（ANOVA 3 と本ページ④）の意味が分かっているからこそ、表を正しく読めるのです。

🍎 かんたん説明

summary(aov(減量 ~ 群)) と打つと表が出ます。Mean Sq は「Sum Sq ÷ Df」、F は「上の Mean Sq ÷ 下の Mean Sq」。星 ** は「有意だよ」の合図です。

💻 ミニ練習：ANOVA表を出す

group と weight_loss は入力済みとして、summary() と aov() を使って一元配置分散分析表を出すコードを書いてください。さらに、lm() と anova() を使う別の書き方も1行書いてください。

summary(aov(weight_loss ~ group))
anova(lm(weight_loss ~ group))

~ の左が応答変数（weight_loss）、右が群（group）。どちらも Df 2 と 7、Sum Sq 114 と 34、F ≈ 11.73 が出ます。

③

pf() でp値を求める・F分布を描く

pf、curve、臨界値

ANOVA 表には p値が最初から出ています。それでも、練習問題などで F値を手計算で出した後に、表を使わず技術（R）で p値を出したいことがあります。そのための関数が pf() です。

確率分布の関数は、頭文字で役割が決まります。p は probability（確率＝左側の面積）、d は density（密度）、q は quantile（分位点）。分布の名前を後ろに付けます。これまでに pnorm・pbinom・pt を見てきましたが、F分布なら pfです。

頭文字意味F分布での関数
p確率（面積）pf(F, df1, df2)
d密度（曲線の高さ）df(x, df1, df2)
q分位点（臨界値）qf(p, df1, df2)
pf(11.735, 2, 7, lower.tail = FALSE)
[1] 0.005811518

引数は順に、F統計量 11.735、分子の自由度 df1 = 2（群の自由度。numerator）、分母の自由度 df2 = 7（誤差・残差の自由度。denominator）です。df1 + df2 = 2 + 7 = 9 ＝ N − 1（全体の自由度）になるのが常です。

lower.tail = FALSE が必要な理由：F の p値は観測した F より右側（それ以上極端な値）の面積です。何も指定しないと R は左側を返すので、FALSE にして右側を求めます。結果は 0.0058（正確には 0.005811…）で、ANOVA 表の Pr(>F) と一致します。

⚠️ 小数と％を混同しないこと。p = 0.0058 は 5.8% ではありません。100 倍して 0.58% です。

F分布を描いてみる。p値が曲線のどこなのかを目で確認しましょう。

curve(df(x, df1 = 2, df2 = 7), from = 0, to = 12,
      xlab = "F", ylab = "")
abline(v = 11.735, col = "red")
  • curve()：式から曲線を描く関数。x は「ここに x が入る」目印なので、そのまま x と書く。
  • df(x, df1 = 2, df2 = 7)：ここでの df はデータフレーム（data frame）ではなく、F分布の密度（density）。
  • from = 0, to = 12：横軸の範囲。xlab = "F" で横軸ラベル、ylab = "" で縦軸ラベルは空に。
  • abline(v = 11.735, col = "red")：v は vertical（縦線）。F = 11.735 の位置に赤線。
F分布（df1 = 2, df2 = 7）と、観測した F = 11.735
赤線より右側の面積が p値＝0.0058（図では細すぎてほとんど見えません）。オレンジの部分は有意水準 5% の棄却域（F > 4.74）。作図の計算は R の df(x, 2, 7) による。

表で使う場合は、表の最上段（横）が df1 = 2、左端（縦）が df2 = 7 です。

結論（p値による方法）：p = 0.0058 は非常に小さい。つまり、本当は全プランの平均が同じなのに、この実験のような結果が偶然だけで出る確率はごくわずか。よって帰無仮説（H₀：すべての平均が等しい）を棄却し、少なくとも1組の平均が違うという証拠がある。

臨界値による方法（教科書やサイトによってはこちら）：F表から、α = 0.05 の臨界値（critical value）を探します。R でも求められます。

qf(0.95, 2, 7)
[1] 4.737414

臨界値は約 4.74。これより右の F はすべて有意です。今回の F = 11.7 は 4.74 より大きいので、H₀ を棄却します。2つの方法の結論は必ず一致します。

方法比べるものこの例結論
p値p と α0.0058 < 0.05H₀ を棄却
臨界値F と F臨界11.7 > 4.74H₀ を棄却
⚠️ ANOVA は「どのプランが違うか」までは教えてくれません。教えてくれるのは「どこかに差がある」ことだけ（omnibus test）。どのペアが違うかは、次のページの多重比較（post hoc test）で調べます。
🍎 かんたん説明

p値はF の赤線より右にある、ほんの少しの面積。ここが小さいほど「偶然ではなさそう」。pf(F, 2, 7, lower.tail = FALSE) で求めます。F が 4.74 より大きければ有意、とも言えます。

💻 ミニ練習：pf() で p値を求める

F = 5.12、分子の自由度 2、分母の自由度 12 のとき、右側の p値を求める pf() のコードを書いてください。

pf(5.12, 2, 12, lower.tail = FALSE)

出力は [1] 0.02467623（約 0.025）。次の単元の例題の p値です。lower.tail = FALSE を付け忘れると左側の面積（0.975…）が出てしまうので注意。

④

ANOVA の計算：SST・SSB・SSW・MS・F

5ステップの手計算

ここからは、ANOVA の数学（計算）です。R や他のソフトを使えば計算は不要ですが、昔ながらの手計算こそ、仕組みを理解する近道です。コードを走らせるだけでは見えない「何をしているか」が見えてきます。計算は5ステップで、最後に F表（chart）を見ます。

5ステップ：① 全体の平方和 SST → ② モデル（群）の平方和 SSM（= SSB）→ ③ 残差の平方和 SSR（= SSW）→ ④ 平均平方 MS → ⑤ F比 ＋ F表で判定

まず用語の整理。名前は教材によって違いますが、中身は同じです。

この講義別名意味
SST（total）SS total全員を全体平均（grand mean）と比べたばらつき
SSM（model）SSB（between）／SS group群平均が全体平均からどれだけ離れているか（群の違いで説明できる分）
SSR（residual）SSW（within）／SS error各人が自分の群の平均からどれだけ離れているか（説明できない分）

例題：3群・15人（各群 5人）

別のデータで、3つの群の平均は 2.2、3.2、5.0、全体平均（grand mean）は 3.47（正確には 10.4 ÷ 3 = 3.4667）です。

ステップ1：SST（全体の平方和）　群は無視して、全員を全体平均と比べます。各得点 − 全体平均 を二乗して全部足す。これはデータ全体の分散を、n − 1 で割らずに求めたものです。つまりSST ＝ 全体の分散 × (n − 1)。この例では SST = 43.74。n − 1 = 14 で割れば全体の分散（grand variance）は約 3.12 で、行ったり来たりできます。全体の自由度は dfT = N − 1 = 15 − 1 = 14。

ステップ2：SSM（モデルの平方和）　目的は「全体平均で説明するより、群平均で説明するほうがばらつきを多く説明できるか」を見ること。各群の平均から全体平均を引いて二乗し、その群の人数を掛けて足します。

SSM = Σ nj (x̄j − x̄)² = 5(2.2 − 3.47)² + 5(3.2 − 3.47)² + 5(5.0 − 3.47)² ≈ 20.13　（dfM = k − 1 = 3 − 1 = 2）

ステップ3：SSR（残差の平方和）　説明できなかった分。引き算で出せます：SSR = SST − SSM = 43.74 − 20.13 = 23.61。自由度は dfR = dfT − dfM = 14 − 2 = 12（= N − k = 15 − 3）。自由度は3つあるが、2つ分かれば3つ目は引き算で出る（14 = 2 + 12）。

ステップ4：平均平方（MS）　平方和は人数が多いほど大きくなる（標本の大きさに依存する）ので、自由度で割って調整します。MSM = 20.13 ÷ 2 ≈ 10.07、MSR = 23.61 ÷ 12 ≈ 1.97。

ステップ5：F比　「説明できた分 ÷ 説明できない分」＝ モデルのよさ ÷ そのダメさ。t検定の「差 ÷ ばらつき」と同じ発想です。F = 10.07 ÷ 1.97 ≈ 5.12。

F表で判定　分子の自由度（モデル）= 2、分母の自由度（残差）= 12 のとき、α = 0.05 の臨界値は 3.89。表によって見出しが dfn／dfd（numerator／denominator）や V1／V2、M／R など違いますが、中身は同じ（分子＝モデル、分母＝残差）。

qf(0.95, 2, 12)
pf(5.12, 2, 12, lower.tail = FALSE)
[1] 3.885294 [1] 0.02467623

F = 5.12 > 3.89 なので H₀ を棄却（p = 0.0247 < 0.05 でも同じ結論）。少なくとも1つの群の平均は他と違う。ただし F検定はomnibus testで「どの群か」までは分かりません。そこで次にpost hoc testが必要になります。

量計算値
df（全体／モデル／残差）N − 1／k − 1／N − k14／2／12
SSTΣ(x − x̄)² ＝ 分散 × (N − 1)43.74
SSMΣ nj(x̄j − x̄)²20.13
SSRSST − SSM23.61
MSM／MSRSSM÷2／SSR÷1210.07／1.97
FMSM ÷ MSR5.12（臨界値 3.89、p = 0.0247）

同じ手順を、減量データで R に任せる

講義の 3プラン・10人のデータにこの5ステップをそのまま当てはめると、R の表と同じになります（SSB は「人数 × (群平均 − 全体平均)²」で 4×9 + 3×1 + 3×25 = 114）。

weight_loss <- c(7, 9, 5, 7, 9, 11, 7, 15, 12, 18)
group <- as.factor(c(1, 1, 1, 1, 2, 2, 2, 3, 3, 3))
gm     <- mean(weight_loss)                    # 全体平均
gmeans <- tapply(weight_loss, group, mean)     # 群平均
n      <- tapply(weight_loss, group, length)   # 群の人数
sst <- sum((weight_loss - gm)^2)               # 全体の平方和
ssb <- sum(n * (gmeans - gm)^2)                # 群間の平方和
ssw <- sst - ssb                               # 群内（残差）の平方和
msb <- ssb / (3 - 1)
msw <- ssw / (10 - 3)
F   <- msb / msw
c(sst = sst, ssb = ssb, ssw = ssw, msb = msb, msw = msw, F = F)
sst ssb ssw msb msw F 148.00000 114.00000 34.00000 57.00000 4.85714 11.73529

（出力は summary(aov()) の表と同じ：SS が 114 と 34、MS が 57 と 4.86、F が 11.73。）

🔎 R の分散分析表に「Total」の行はありません。R が出す表は「群（group）」と「Residuals」の2行だけ。全体の 148（または 43.74）は、2つの SS を足して自分で求めます。
⚠️ 試験で求められること：理屈（何をしているか）を理解したうえで、F統計量を計算し、臨界値 F を見つけ、仮説について判断すること。そのために必要な式は上の表にある数個だけです。
🍎 かんたん説明

ばらつきを「群の違いで説明できる分」と「説明できない分」に分け、それぞれを自由度で割って、割り算したものが F。F が臨界値より大きければ「群の違いは偶然ではなさそう」。

💻 ミニ練習：SSBとFを計算する

weight_loss と group が入力済みとして、全体平均 gm と群ごとの平均・人数を求め、ssb（群間の平方和）を計算するコードを書いてください。

gm <- mean(weight_loss)
gmeans <- tapply(weight_loss, group, mean)
n <- tapply(weight_loss, group, length)
ssb <- sum(n * (gmeans - gm)^2)
ssb

ssb は 114（= 4×3² + 3×1² + 3×5²）。これを 2 で割ると MSB = 57。残差の SSW = 148 − 114 = 34 を 7 で割ると 4.86。

📖 用語集

analysis of variance (ANOVA)
分散分析
3群以上の平均の差を、ばらつきの比（F）で調べる検定。
factor
因子（カテゴリ変数）
as.factor() で作る、名前（水準）を持つ変数。
response / explanatory
応答変数／説明変数
~ の左が応答、右が説明（モデル）。
sum of squares (SS)
平方和
偏差を二乗して足したもの。SST = SSB + SSW。
mean square (MS)
平均平方
SS ÷ 自由度。
F ratio
F比
MS(群) ÷ MS(残差)。モデルのよさ ÷ そのダメさ。
degrees of freedom
自由度
群 k − 1、残差 N − k、全体 N − 1。
residual
残差
自分の群の平均からのずれ。説明できない分。
pf()
F分布の確率
pf(F, df1, df2, lower.tail = FALSE) で右側の p値。
critical value
臨界値
棄却域の境目。qf(0.95, df1, df2)。
omnibus test
総括的検定
どこかに差があることだけを示し、どの群かは言わない。
post hoc test
事後検定
ANOVA 後に、どのペアが違うかを調べる。

💡 学習のヒント

表の読み方は「Mean Sq = Sum Sq ÷ Df」「F = 上の MS ÷ 下の MS」。p値は pf(F, df1, df2, lower.tail = FALSE)。ANOVA 表に Total の行は出ません。

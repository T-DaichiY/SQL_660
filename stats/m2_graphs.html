📊 基本のグラフ：ヒストグラム・ドット／幹葉・棒グラフ

①

ヒストグラムで形を見る

右に歪む・左に歪む・左右対称

ヒストグラムは量的データを区間（bin）に分けて、各区間の個数を柱にしたグラフです。たくさんのデータの形をつかむのに向いています（個々の値は見えなくなる）。

donors <- read.csv("donors.csv")
donors1_20 <- donors[1:20, ]
par(mfrow = c(1, 3))
hist(donors$totalGivingAmount[donors$totalGivingAmount < 600], main = "Right-skewed",
     xlab = "Total $ given (< 600)", col = "lightblue")
hist(donors$wealthRating, main = "Left-skewed", xlab = "Wealth rating", col = "lightblue")
hist(donors$incomeRating, main = "Roughly symmetric", xlab = "Income rating", col = "lightblue")
par(mfrow = c(1, 1))

（寄付総額は最大 9,485 まであり柱がつぶれるので、600 未満だけを描いています。）

形見た目平均と中央値
右に歪む（right / positive skew）裾が右に長い平均 > 中央値
左に歪む（left / negative skew）裾が左に長い平均 < 中央値
ほぼ左右対称真ん中で折ると重なる平均 ≈ 中央値
c(mean = mean(donors$wealthRating, na.rm = TRUE), median = median(donors$wealthRating, na.rm = TRUE))
mean median 5.345699 6.000000

wealthRating は平均が中央値より小さく、左に歪んでいることと一致します。ほかに、山の数（単峰・二峰）や、どの値もほぼ同じ高さの一様（uniform）という形もあります。

⚠️ 歪みの向きは裾（tail）がある側で呼びます。山が右に寄っていると「右に歪んでいる」と言いたくなりますが、それは左に歪んだ分布です。
②

ドットプロットと幹葉図

少ないデータなら値まで見える

データが少ないときは、1つ1つの値が見えるグラフが便利です。

stripchart(donors1_20$age, method = "stack", pch = 16, cex = 2,
           ylim = c(0, 3), xlab = "Age (first 20 donors)")

幹葉図（stemplot）は、十の位を幹、一の位を葉として並べます。横に倒したヒストグラムに、実際の値が書き込まれたものです。

stem(donors1_20$age)
The decimal point is 1 digit(s) to the right of the | 3 | 8 4 | 466 5 | 6 | 025 7 | 00258

読み方：「3 | 8」は 38 歳、「7 | 00258」は 70, 70, 72, 75, 78 歳です。

ドットプロット・幹葉図
良い点実際の値が見える／形がわかる／すき間（gap）やかたまり（cluster）が見える
弱い点データが多いと使えない／幹葉図は読みにくい（上司への報告には不向き）

カテゴリのグラフ：度数表と棒グラフ

ヒストグラムは使えない

urbanicity（都市度）のようなカテゴリ変数に、hist() や stripchart() は使えません。

hist(donors$urbanicity)
Error: 'x' must be numeric

カテゴリはまず数えます。table() で度数、proportions() で割合です。

table(donors$urbanicity)
round(proportions(table(donors$urbanicity)), 3) * 100
city rural suburb town urban 19689 19790 21924 19527 12166 city rural suburb town urban 21.1 21.3 23.5 21.0 13.1

棒グラフは表を作ってから barplot() に渡します。

barplot(table(donors$urbanicity), las = 1, ylab = "Count",
        main = "How do we increase the number of urban donors?",
        col = c(rep("gray", 4), "red"))
⚠️ 棒グラフには「中心」も「歪み」もありません。カテゴリの並び順は自由なので、並べ替えれば形が変わるからです。またヒストグラムは棒グラフではない（柱が接していて、横軸は数直線）。
🥧 円グラフはよく見かけますが、人は角度から量を読み取るのが苦手で、棒の長さのほうが比べやすいです。カテゴリが互いに重ならず合計100% になる場合にしか使えない点にも注意。
④

2つのカテゴリ変数

二元表と積み上げ棒グラフ

「住んでいる地域」と「郵送に反応したか」の関係を見るには、二元表（two-way table）を作ります。

table(donors$urbanicity, donors$respondedMailing)
round(proportions(table(donors$urbanicity, donors$respondedMailing), margin = 1), 3)
FALSE TRUE city 18683 1006 rural 18863 927 suburb 20737 1187 town 18521 1006 urban 11589 577 FALSE TRUE city 0.949 0.051 rural 0.953 0.047 suburb 0.946 0.054 town 0.948 0.052 urban 0.953 0.047

margin = 1 は「行ごとに割合を出す」指定です。各地域のうち何割が反応したかを比べられます。

barplot(table(donors$respondedMailing, donors$urbanicity), legend.text = c("No", "Yes"),
        las = 1, ylab = "Count", main = "Responded to mailing, by urbanicity")
📗 R4DS（Wickham & Grolemund, R for Data Science）より：EDA は「データについて問いを立て、図と変換で答えを探し、答えから次の問いを作る」くり返し。まず1つの変数のばらつき（variation）を見て、次に2つの変数がいっしょに変わるか（covariation）を見る。カテゴリ×カテゴリなら度数の表、カテゴリ×量なら箱ひげ図が出発点。
出典: R4DS Ch.5 Exploratory Data Analysis（内容を要約・日本語で再構成）
💻 ミニ練習：カテゴリの度数と割合

donors$socioEconomicStatus の度数表と、割合（%・小数第1位）を求め、棒グラフを描いてください。

t <- table(donors$socioEconomicStatus)
t
round(proportions(t) * 100, 1)
barplot(t)

average が約52%、highest が約31%、lowest が約17%（NA を除く）。順序のあるカテゴリなので、lowest → average → highest に並べ替えると読みやすい：t[c("lowest", "average", "highest")]。

➡️ 次の講義へ：中心だけでなくばらつきも要約しましょう。次の 5数要約・箱ひげ図・IQRへ。

📖 用語集

histogram
ヒストグラム
量的データを区間（bin）に分けた度数の柱。
right-skewed
右に歪んだ
右に長い裾。平均 > 中央値。positive skew。
left-skewed
左に歪んだ
左に長い裾。平均 < 中央値。negative skew。
symmetric
左右対称
中央で折ると重なる形。平均 ≈ 中央値。
unimodal / bimodal
単峰／二峰
山が1つ／2つ。
dotplot (stripchart)
ドットプロット
1つの値を1つの点で積む。少量データ向き。
stemplot
幹葉図
幹（十の位）と葉（一の位）で値を並べる。
barplot
棒グラフ
カテゴリの度数・割合の棒。順番や間隔に意味はない。
two-way table
二元表（クロス表）
2つのカテゴリ変数の組み合わせの度数。

💡 学習のヒント

ヒストグラムは「量的」、棒グラフは「カテゴリ」。棒グラフに中心や歪みはない（並べ替えれば形が変わるから）。

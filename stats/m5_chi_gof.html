🎲 χ²①：適合度検定（Goodness-of-Fit Test）

①

適合度検定のセットアップ

NHL選手の誕生日は一様に散らばっている？

講義で使う題材は、Malcolm Gladwell の本 Outliers の文脈です。「NHL（ナショナル・ホッケー・リーグ）選手の誕生日は、1年を通じて均等（uniform）に分布していると言えるか？」を調べます。もし年の前半に生まれた子のほうが有利なら（学年の中で体が大きいなど）、前半生まれが多くなるはず、というのが Gladwell の主張です。

データは、最近のシーズンのNHL選手から無作為抽出した80人について、生まれた四半期（quarter）を数えたものです。1〜3月が Q1、4〜6月が Q2、7〜9月が Q3、10〜12月が Q4 です。

まず3つの問いで道具を選ぶ

  • どんなデータ？ 「どの四半期か」は数値ではなく区分なのでカテゴリカルデータ（categorical data）です。
  • グループやサンプルはいくつ？ 80人の1つのサンプルだけです。
  • これまでの検定は使える？ いいえ。平均の推測（t検定・信頼区間）も ANOVA も量的データ（quantitative data）が前提でした。カテゴリを数える今回は別の道具が要ります。

観測した度数（observed counts）をRに保存します。

observed <- c(32, 20, 16, 12)   # Q1, Q2, Q3, Q4 に生まれた人数
四半期ごとの観測度数（80人）
赤い点線は「完全に一様」ならこうなるはずの20人。Q1が32人と大きく上にずれています。

もし一様なら、4つの数字は互いにとても近い（本当は全く同じ）はずです。実際には違うので、「一様ではない」という初期的な（preliminary）証拠はあります。ただし、無作為抽出には標本変動（sampling variability）があるので、80人をちょうど20人ずつに分けて得られるとは限りません。問題は「この差は偶然で説明できる程度か、それとも偶然では説明しにくいほど大きいか」です。

2つの統計的説明（モデル）

  • 説明1（偶然）：NHLの誕生日は本当に一様で、観測値が20からずれたのは標本変動のせいにすぎない。別のサンプルなら別の数字になる。
  • 説明2（Gladwellの説）：NHLの誕生日は一様ではない。

有意性検定（significance test）のねらいは、「説明1が正しいとして、観測と同じかそれ以上の差が偶然だけで出る確率はどれくらいか」を求めることです。その確率が非常に小さければ説明1を退け、そうでなければ説明2の証拠にはなりません。

仮説の立て方

帰無仮説 H₀（null hypothesis）：誕生日は四半期の間で一様に分布している（何も面白いことは起きていない）。
対立仮説 Hₐ（alternative hypothesis）：誕生日は一様に分布していない（Gladwellの主張）。

記号で書くと、p_Q1 を「NHL選手全体のうち Q1 生まれの割合」として:

H₀： p_Q1 = p_Q2 = p_Q3 = p_Q4（すべて 25%）
Hₐ： 少なくとも1つの割合が他と等しくない（25%ではない）

厳密には、1つが25%からずれれば別のどれかも必ずずれるので「少なくとも2つ」と言えますが、講師は「そこは気にしなくてよい」と言っています。またいつも25%とは限りません。月ごとに見る（12区分）なら各 1/12 になり、区分の数が変われば確率も変わります。

期待度数 E の計算

H₀が正しいとき各区分に入る人数の期待度数（expected count）は、E = n × p（標本サイズ × H₀の確率）です。ここでは 80 × 0.25 = 20 ずつ。

expected <- c(20, 20, 20, 20)   # 80 * 0.25
⚠️ 期待度数は「平均的にこうなる」という値です。1回の80人のサンプルがちょうど20,20,20,20になるという意味ではなく、無作為抽出を何度も繰り返して平均をとれば各四半期に20人ずつ、という意味です。

χ²検定の3つの条件

この授業で扱う検定には、それぞれ条件（conditions）があります。条件を満たしてはじめて、あとで求める答えが正当になります。

条件NHLの例での確認
① 無作為抽出（random sample）または無作為割り当てGladwell は80人を無作為抽出した。NHL全体に一般化したいので重要（都合のよい選手だけを選ぶ「いいとこ取り」では代表性がない）
② 期待度数がすべて 5 以上すべて 20 ≥ 5 で OK
③ 観測が独立とみなせる（independence）非復元抽出なので厳密には独立でないが、母集団が十分大きければ問題ない。10%ルール：母集団は 80 × 10 = 800人より多い（NHL全体の10%が80人より大きい）と考える

条件がそろったので、χ²適合度検定（chi-square goodness-of-fit test, GOF）を使います。「観測した分布が、期待する分布にどれだけうまく当てはまる（fit する）か」を調べる検定です。χ²（chi-squared）はギリシャ文字のカイ（χ）を2乗した名前です。

🍎 かんたん説明

「1つのカテゴリ変数」を数えて、「こうなるはず」という割合と比べるのが適合度検定。期待度数は n × p、条件は「無作為・期待度数≥5・独立（10%ルール）」の3つ。

💻 ミニ練習：観測度数と期待度数を作る

別の調査で、無作為抽出した60人の選手の誕生日を季節4区分で数えたところ、観測度数は 21, 15, 12, 12 でした。H₀（4区分で一様）のもとでの期待度数を、標本サイズに確率をかけて求めてください。observedとexpectedを作り、expectedの値を表示します。

observed <- c(21, 15, 12, 12)
n <- sum(observed)
expected <- n * rep(0.25, 4)
expected

n = 60、E = 60 × 0.25 = 15 が4区分すべてに入ります。期待度数はすべて 5 以上なので、条件②も満たします。

②

χ²検定統計量を手計算する

観測と期待のズレを1つの数にする

速い計算方法は後で見ますが、まず手順（mechanics）を見ておくと、この数字が何を意味しているかが分かります。観測度数 observed と期待度数 expected がRに保存されている状態から始めます。

  1. 偏差（deviation）を出す：観測 − 期待。各区分が期待からどれだけ離れているか。
  2. 2乗する：プラスとマイナスが打ち消し合わないように（標準偏差のときと同じ発想）。
  3. 期待度数で割る：「重みつきの寄与（weighted contribution）」にする。
  4. 足し合わせる：合計が χ² 検定統計量。
observed - expected
(observed - expected)^2
(observed - expected)^2 / expected
sum((observed - expected)^2 / expected)
[1] 12 0 -4 -8 [1] 144 0 16 64 [1] 7.2 0.0 0.8 3.2 [1] 11.2
四半期観測 O期待 EO − E(O − E)²(O − E)² / E
Q13220121447.2
Q22020000.0
Q31620−4160.8
Q41220−8643.2
合計8080022411.2

4つの区分があるので寄与は4つです（10区分なら10個）。Q1 は期待より12人多く、一番遠くにあります。Q2 の20人は期待どおりなので寄与は0です。合計してχ² = 11.2。

なぜ期待度数で割るのか

観測0・期待10の場合と、観測990・期待1,000の場合を比べましょう。どちらも差は10、2乗すると100で同じです。しかし驚きの大きさは全く違います。1,000を期待して990なら「ほぼ期待どおり」ですが、10を期待してゼロなら「ちょっと信じがたい」ですよね。

場合(O − E)²÷ E驚き
観測 0、期待 10100100 / 10 = 10大きい
観測 990、期待 1,000100100 / 1000 = 0.1とても小さい

期待度数で割る（重みをつける）ことで、この違いが数字に反映されます。

式で書く

χ² = Σ (Oᵢ − Eᵢ)² / Eᵢ

これは「(O₁ − E₁)²/E₁ + (O₂ − E₂)²/E₂ + (O₃ − E₃)²/E₃ + (O₄ − E₄)²/E₄」を省略して書いたものです。Σ（シグマ）は「全部足す」という記号で、添え字 i は「何番目の区分か」を表します。

🍎 かんたん説明

χ² は「(観測 − 期待)² ÷ 期待」を全区分で足した数。期待どおりなら 0 に近く、ズレが大きいほど大きくなります。今回は 7.2 + 0 + 0.8 + 3.2 = 11.2。

💻 ミニ練習：χ²を手計算する

観測度数が c(21, 15, 12, 12)、期待度数が c(15, 15, 15, 15) のとき、χ²検定統計量を「観測−期待」の2乗を期待で割って合計する手順で求めてください。

observed <- c(21, 15, 12, 12)
expected <- c(15, 15, 15, 15)
sum((observed - expected)^2 / expected)

寄与は 2.4, 0, 0.6, 0.6 で、合計は 3.6 です。

③

p値をχ²分布から求める

自由度 df = k − 1 と右側の面積

χ² = 11.2 がどれくらい珍しいかを知るには、p値を求めます。そのために、まず自由度（degrees of freedom, df）が必要です。

適合度検定の自由度：df = k − 1（k = カテゴリの数）

これまでの自由度は標本サイズから決まることが多かったのですが、ここではカテゴリの数を使います（標本サイズではない）。4つの四半期なので df = 4 − 1 = 3。

⚠️ 他の資料では、カテゴリ数を c や、さらに紛らわしく n と書くことがあります。n は通常「標本サイズ」を表す記号ですが、ここでは「カテゴリの数」と定義されているはずです。意味を確認しましょう。

条件（期待度数がすべて 5 以上など）を満たしていれば、検定統計量は自由度 3 の χ²分布（chi-square distribution）にしたがいます。t分布が自由度で形を変えたように、χ²分布も自由度ごとに形が変わります。形は正規分布とは違って右に裾が長い（right-skewed）ことが特徴です。

自由度3のχ²分布と、χ² = 11.2 より右の面積（p値）
p値は「検定統計量が11.2以上」になる確率、つまり赤い部分の面積です。

① 表を使う

χ²分布表（chi-square probability table）の df = 3 の行を見ます（右側の面積ごとの境界値）。

右側の面積（p値）0.100.050.0250.020.01
df = 3 の境界値6.2517.8159.3489.83711.345

11.2 は 9.84 と 11.34 の間にあるので、p値は 1% と 2% の間です。表の弱点は、範囲しか分からないことです。

② Rの pchisq() で正確に求める

引数は q（検定統計量）、df（自由度）、lower.tail。pchisq は初期設定が左側（lower tail）の面積を返しますが、p値が欲しいのは右側（upper tail）なので、lower.tail = FALSE にします。

df <- 4 - 1
pchisq(q = 11.2, df = df, lower.tail = FALSE)
[1] 0.01069213
⚠️ lower.tail = FALSE を忘れると、右側ではなく左側の面積（0.989）が出て、結論が逆になります。適合度検定では常に右側です。

p値は約 0.0107（約1%）で、たしかに表の範囲（1〜2%）に入っています。

p値の解釈

「NHL選手の誕生日が一様に分布している（H₀）と仮定すると、標本変動だけで今回のようなデータかそれ以上に極端なデータが得られる確率は 0.0107 である。」

標本データのかわりに検定統計量で言ってもかまいません。その場合も「11.2 以上（or more）」と付けることが大切です。p値は11.2ちょうどの確率ではなく、11.2より右側全体の面積だからです。

🍎 かんたん説明

df は カテゴリ数 − 1。p値は χ² 分布の右側の面積なので pchisq(統計量, df, lower.tail = FALSE)。χ²=11.2、df=3 なら p ≈ 0.0107。

💻 ミニ練習：pchisqでp値を求める

χ² = 3.6、カテゴリ数が 4（df = 3）のときのp値を、右側の面積としてpchisq()で求めてください。

pchisq(q = 3.6, df = 3, lower.tail = FALSE)

p値は約 0.308 です。0.05よりずっと大きいので、この小さなズレは偶然で十分説明できる範囲です。

④

検定の結論とRの関数

結論に入れる3つのこと

p ≈ 1% を使って結論を書きます。有意性検定の結論には、次の3つを入れます。

  1. p値と有意水準 α（significance level）の比較。指定がなければ α = 5%（0.05）。ただし本当は研究を始める前に決めておくものです。第1種の過誤・第2種の過誤の考え方や、何を「驚くべき」とみなし何を偶然とみなすかが、α で決まるからです。
  2. H₀を棄却する（reject）か、棄却できない（fail to reject）か。
  3. 対立仮説に対する証拠の強さ（convincing evidence があるか）。
p ≈ 0.011 < α = 0.05 なので H₀ を棄却する。「出生が一様なのはただの偶然」という最初の説明を退ける。
したがって、「NHL選手の誕生日は、今回のシーズンについて、四半期の間で一様に分布していない」という対立仮説の説得力のある証拠（convincing evidence）がある。

言葉づかいの注意

  • 「証明（proof）」とは言わない。「だから誕生日は一様ではない」と断定すると証明のように聞こえます。統計では証拠（evidence）と言います。約1%の確率で、今回の差が標本変動だけで出た可能性（第1種の過誤）が残るからです。
  • 母集団（NHL全体）について述べる。「今回の観測度数 32, 20, 16, 12 が一様でない」のは見れば明らか（それが最初の証拠）です。知りたいのは、NHL全選手に一般化できるかです。
  • データのシーズンに限定する。Gladwell は1シーズンのデータだけを使っているので、将来や過去のシーズンに当てはまるかは分かりません。
p値と αH₀結論起こりうる誤り
p < α棄却対立仮説の説得力のある証拠がある。統計的に有意（statistically significant）第1種の過誤（Type I）の可能性
p > α棄却できない（fail to reject）対立仮説の説得力のある証拠はない。有意ではない第2種の過誤（Type II）の可能性

今回は p < α なので「有意」。第1種の過誤とは、H₀が実は正しいのに「何か面白いことが起きている」と結論してしまうことで、その可能性が約1%あります。

Rの関数で一発で求める

手計算を毎回するわけにはいきません。lsr パッケージ（教科書 Learning Statistics with R のパッケージ）の適合度検定の関数は、検定統計量・p値のほか観測度数・期待度数・指定した確率もまとめて表示してくれます（base Rの chisq.test() でもできます）。

# install.packages("lsr")   # 初回だけ（コメントを外して実行）
library(lsr)                # コードの中に書く
lsr::goodnessOfFitTest

ポイントは2つです。

  • library(lsr) をコードに書く。パネルのチェックボックスをクリックしてもパッケージは使えますが、コードを受け取った人が「チェックを入れてください」という注意書きを読まなくても、自動で動くようにするためです。
  • lsr:: を付けるとその関数の出どころが分かる。後でコードを読み返したとき、どのパッケージの関数かを思い出せます。パッケージ名は小文字の lsr です。

落とし穴：渡すのは「度数」ではなく「データそのもの」

この関数が欲しいのは1人1人のデータ（各人がどの四半期か）で、集計済みの度数ではありません。度数をそのまま渡すと、次のようなエラーや間違った結果になります。

  • observed をそのまま渡す → エラー「引数 x は factor でなければならない」（数値のまま）。
  • as.factor(observed) に変える → 警告（近似が不正確かも）。度数 12, 16, 20, 32 が「カテゴリの名前」として扱われ、観測度数が 1, 1, 1, 1、χ² = 0、p値 = 1 になってしまう。

度数の表しかないときは、rep() で元のデータを復元してから渡します。誰が実際にどの月生まれかは分かりませんが、「Q1が32人」は分かっているので十分です。

nhl_data <- c(rep("Q1", 32), rep("Q2", 20), rep("Q3", 16), rep("Q4", 12))
lsr::goodnessOfFitTest(as.factor(nhl_data), p = c(0.25, 0.25, 0.25, 0.25))
Chi-square test against specified probabilities Data variable: as.factor(nhl_data) Hypotheses: null: true probabilities are as specified alternative: true probabilities differ from those specified Descriptives: observed freq. expected freq. specified prob. Q1 32 20 0.25 Q2 20 20 0.25 Q3 16 20 0.25 Q4 12 20 0.25 Test results: X-squared statistic: 11.2 degrees of freedom: 3 p-value: 0.011

観測度数 32, 20, 16, 12、期待度数 20、χ² = 11.2、df = 3、p = 0.011 と、手計算の結果と一致しました。

📝 結果の報告の書き方：χ²(3) = 11.2, p < 0.05。対立仮説を支持する証拠がある。特に、Q1 に生まれた選手の数が期待よりずっと多く、これが検定統計量 11.2 への最大の寄与（7.2）だった。
🍎 かんたん説明

結論は「p と α の比較 → H₀を棄却するか → 対立仮説の証拠（証明とは言わない）」の3点。Rでは度数ではなく元データ（rep() で復元）を lsr::goodnessOfFitTest() に渡す。

💻 ミニ練習：度数から元データを復元する

観測度数が Q1 = 32, Q2 = 20, Q3 = 16, Q4 = 12 のとき、rep() で元データ nhl_data を作り、table() で度数を確認してください（as.factor() も使います）。

nhl_data <- c(rep("Q1", 32), rep("Q2", 20), rep("Q3", 16), rep("Q4", 12))
table(as.factor(nhl_data))

表示は Q1 32, Q2 20, Q3 16, Q4 12 になります。この元データを lsr::goodnessOfFitTest(as.factor(nhl_data), p = c(0.25, 0.25, 0.25, 0.25)) に渡せば χ² = 11.2 が得られます。

適合度検定の例2：広告の人種の割合

最初から最後まで自力で解く（α = 0.01）

この動画は、適合度検定の全工程を自分で解いてから答え合わせする形式です。題材は、フィラデルフィアで放映されたテレビ広告に登場する人物の人種（ethnicity）の割合が、国勢調査（census）の割合と同じかどうか。有意水準は α = 0.01 です。

観測した人物は404人で、アフリカ系アメリカ人（African American）57人、アジア系（Asian）11人、白人（Caucasian）330人、ヒスパニック（Hispanic）6人。国勢調査の割合（H₀の確率）は、順に 0.177, 0.032, 0.734, 0.057 です。

手順1：期待度数

observed <- c(57, 11, 330, 6)
null_p   <- c(0.177, 0.032, 0.734, 0.057)
n <- sum(observed)
n
expected <- n * null_p
expected
[1] 404 [1] 71.508 12.928 296.536 23.028

404人のうち17.7%なら 71.5人、73.4%なら約296人、5.7%なら約23人、という計算です。

手順2：仮説と条件

  • H₀：広告に登場する人種の割合は国勢調査の割合と同じ。
    記号では p_AA = 0.177, p_Asian = 0.032, p_White = 0.734, p_Hispanic = 0.057。
  • Hₐ：広告の割合は国勢調査と同じではない（少なくとも1つの割合が違う）。
条件確認
無作為抽出この問題文だけでは不明。元の論文を読まないと分からない。フィラデルフィアの広告が代表的か分からないので、一般化には慎重に
期待度数 ≥ 5すべて満たす（最小は12.9）。χ²分布を使うために重要
独立非復元抽出だが、母集団の人物は 10 × 404 = 4,040人より多いと仮定する

手順3：検定統計量とp値

度数の表しかないので、rep() で元データを復元します。as.factor() で包むのを忘れると「x は factor でなければならない」というエラーになります。

commercial_data <- c(rep("African American", 57), rep("Asian", 11),
                     rep("Caucasian", 330), rep("Hispanic", 6))
length(commercial_data)
lsr::goodnessOfFitTest(as.factor(commercial_data), p = null_p)
[1] 404 Chi-square test against specified probabilities Data variable: as.factor(commercial_data) Hypotheses: null: true probabilities are as specified alternative: true probabilities differ from those specified Descriptives: observed freq. expected freq. specified prob. African American 57 71.508 0.177 Asian 11 12.928 0.032 Caucasian 330 296.536 0.734 Hispanic 6 23.028 0.057 Test results: X-squared statistic: 19.599 degrees of freedom: 3 p-value: <.001

観測度数・期待度数・確率が先ほど入力したものと一致していることを確認します。χ² = 19.599、df = 4 − 1 = 3、p値は 0.001 未満というとても小さい値です。正確なp値は、また lower.tail = FALSE で求めます。

pchisq(q = 19.599, df = 3, lower.tail = FALSE)
[1] 0.0002055213
📝 p値の解釈：広告の人種の割合が国勢調査の割合と同じ（H₀）と仮定すると、標本変動だけでこのくらい極端な検定統計量かそれ以上が得られる確率は 0.0002 である。
自由度3のχ²分布と χ² = 19.599
19.6 はグラフの右端のほうにあり、右側の面積（p値）はほとんど見えないほど小さい。

手順4：結論

p ≈ 0.0002 < α = 0.01 → H₀ を棄却。広告に登場する人種の割合は、この調査の期間のフィラデルフィアの広告について、国勢調査の割合と同じではないという説得力のある証拠があります。

⚠️ 「証明された」とは言わず、「だからテレビ局に人種差別がある」とも言いません（そうかもしれませんが、この検定で言えることではありません）。言えるのは「地域の人口構成が広告に適切に反映されていないという証拠があり、さらなる調査が必要」ということまでです。

手順5：どの人種が一番χ²に寄与したか

各区分の寄与 (O − E)² / E を計算します。

contribution <- (observed - expected)^2 / expected
contribution
sum(contribution)
[1] 2.9434758 0.2875297 3.7764025 12.5913142 [1] 19.59872
人種観測 O期待 E寄与 (O − E)² / E
African American5771.52.94
Asian1112.90.29
Caucasian330296.53.78
Hispanic623.012.59

寄与の合計が 19.599。4番目のヒスパニックの 12.59 が全体の大半を占めます。期待は約23人なのに観測は6人だけ。つまり、ヒスパニックの登場人物が期待よりずっと少ないことが、国勢調査とのズレのいちばんの原因です。

🍎 かんたん説明

χ² = 19.599、df = 3、p ≈ 0.0002。ヒスパニックの寄与（12.59）が最大で、期待23人に対して観測6人と大幅に少ない。結論は「証拠がある」まで。

💻 ミニ練習：寄与から最大の区分を探す

例2のデータ（observed = 57, 11, 330, 6、確率 0.177, 0.032, 0.734, 0.057）で、期待度数 expected と各区分の寄与 contribution を求め、さらに chisq.test() でχ²とp値を確認してください。

observed <- c(57, 11, 330, 6)
null_p <- c(0.177, 0.032, 0.734, 0.057)
expected <- sum(observed) * null_p
contribution <- (observed - expected)^2 / expected
contribution
chisq.test(observed, p = null_p)

寄与は 2.94, 0.29, 3.78, 12.59。chisq.test は X-squared = 19.599, df = 3, p-value = 0.0002055 を返します（この関数には、度数をそのまま渡せます）。

goodness-of-fit test (GOF)
適合度検定
観測した度数の分布が、期待する分布に当てはまるかを調べるχ²検定。
observed count (O)
観測度数
データで実際に数えた各区分の人数・個数。
expected count (E)
期待度数
H₀が正しいときの平均的な度数。E = n × p。
chi-square statistic (χ²)
χ²検定統計量
Σ (O − E)² / E。ズレが大きいほど大きい。
contribution
寄与
各区分の (O − E)² / E。どの区分がズレの原因かが分かる。
degrees of freedom (df)
自由度
適合度検定では カテゴリ数 − 1。
chi-square distribution
χ²分布
右に裾が長い分布。形は自由度で決まる。
p-value
p値
H₀を仮定して、観測以上に極端な統計量が出る確率（右側の面積）。
significance level (α)
有意水準
結論を決める基準。指定がなければ0.05。研究前に決める。
reject H₀ / fail to reject H₀
H₀を棄却 / 棄却できない
p < α なら棄却、p > α なら棄却できない。
Type I / Type II error
第1種・第2種の過誤
Type I は正しいH₀を棄却、Type II は誤ったH₀を棄却しそこなう。

💡 学習のヒント

適合度検定の流れは「仮説 → 期待度数 → 条件確認 → χ² → df = k − 1 → pchisq(..., lower.tail = FALSE) → 結論（evidence）」。Rに渡すのは度数ではなく元データ、というのも覚えておきましょう。

①

前提と条件のチェックリスト

代表性・量的変数・正規性・独立性・10%条件

前の動画までで、1標本・2標本・対応ありの t 検定と t 区間を学びました。これらをまとめて t-procedures（t 手順）と呼びます。どの手順も、使ってよいための前提（assumptions）と条件（conditions）があります。本当はこれまでの検定・区間のたびに確認すべきでしたが、動画が長くなりすぎるので省いていました。時間があれば、これまでの例に戻って「そもそもその検定や区間を使ってよかったのか」を確かめてみましょう。

条件チェックリスト（重要な順）

#確認することひとこと
①Representative?　データは母集団を代表しているか？　実験なら、処置は無作為に割り当てられたか？いちばん大事。
②Data type?　注目する変数は量的変数（quantitative）か？カテゴリ変数に t 検定・t 区間は使わない。
③Normality?　母集団はほぼ正規分布か？小標本では強い歪み・外れ値に注意。
④Independent or dependent?　2つの群は独立か、対応（paired）か？1標本なら確認不要。
⑤10% condition　非復元抽出で、母集団は十分大きいか？いちばん重要度が低い。

① 代表性：Garbage in, garbage out

たとえば Eastern の授業全体について調べたいのに、成績 A の生徒だけを調べたら、A の生徒どうしは何かが似ていて、そうでない生徒が丸ごと抜け落ちます。実験でも、処置を本人の好みで選ばせると交絡（confounding）が増え、「処置のせいなのか、別の要因のせいなのか」が分けられません。代表的な標本でなければ統計量は偏り（biased）、つまり悪い推定値になります。

⚠️ Garbage in, garbage out.悪いデータでも信頼区間は計算できますが、できあがるのは悪い区間です。悪いデータで有意性検定をしても、p 値は信頼できない p 値になります。

② データの種類・③ 正規性と中心極限定理

中心極限定理（Central Limit Theorem, CLT）：標本サイズが大きくなるにつれ、標本平均（または平均の差、差の平均）の標本分布は正規分布に近づく。だから標本が十分大きければ、正規性の条件はあまり気にしなくてよくなります。

一方、標本が小さくて、変数が正規分布でないと t 手順の信頼性は下がります。たとえば n = 10 で外れ値や強い歪みがあれば、t 検定・t 区間は思ったほど信頼できません。小標本のときは必ず標本データを見て、強い歪みや外れ値がないか確かめます。母集団が正規分布だと信じる理由がある場合は別ですが、たいていは母集団の形を知りません。

④ 独立か対応か

2標本のとき、独立な2標本なら two-sample t、対応のある（paired）データなら paired t を使います。1標本ならこの問いは不要です。

⑤ 10% 条件と有限母集団修正（FPC）

ふつう統計では非復元抽出（sampling without replacement）をします。これまでに使った標準誤差の式は、母集団が無限に大きいと仮定しています。しかし実際に無限の母集団はありません。母集団があまり大きくないなら、標準誤差に有限母集団修正係数（finite population correction factor, FPC）を掛けます。

📐 修正後の標準誤差 ＝ s / √n × √( (N − n) / (N − 1) )　　（N：母集団サイズ，n：標本サイズ）
講義では、元の標準誤差に「この平方根の比」を掛ける、と説明されました。

目安：母集団が標本サイズの 10 倍より大きければ「十分に大きい」とみなし、修正は不要です。

  • 例1（修正不要）：標本が 50,000 人。アメリカの人口（約 3.5 億人）は 10 × 50,000 = 500,000 よりずっと大きい。無限ではないが、標準誤差にはほとんど影響しない。
  • 例2（修正が必要）：MSDS プログラムの現在の学生から 500 人を無作為に選ぶ。全体を 1500 人とすると、10 × 500 = 5000 より小さい。→ FPC を使う。
N <- 1500    # population size
n <- 500     # sample size
sqrt((N - n) / (N - 1))   # FPC
[1] 0.8167689

つまり標準誤差を約 0.817 倍（約 18% 小さく）します。

⚠️ なぜいちばん重要度が低いのか（講師）
  • 母集団は、ふつう標本サイズの 10 倍よりずっと大きいから。
  • 修正係数は 1 より小さいので、使わないと標準誤差は（わずかに）過大評価になり、区間は少し広くなるだけ。修正すると区間は狭くなる。使い忘れても幅への影響は小さく、大きな違いには気づかないことも多い。
過小評価になることはありません。修正が重要になるのは、母集団が小さく、標本がその母集団に対して大きいときです。
🍎 かんたん説明

t 手順を使う前の確認リスト：①代表的か（最重要）②量的変数か③小標本なら歪み・外れ値がないか④独立か対応か⑤母集団は標本の10倍以上か。いちばん大事なのは「データを信用していいか」。

💻 ミニ練習：有限母集団修正係数

母集団 N = 1500、標本 n = 500 のとき、有限母集団修正係数 √((N − n)/(N − 1)) を R で計算してください（N と n に値を入れてから sqrt() を使う）。

N <- 1500
n <- 500
sqrt((N - n) / (N - 1))   # 0.8167689

標準誤差にこの値を掛ける。1 より小さいので、掛けると標準誤差は小さくなる（修正しないと過大評価）。

③

ブートストラップ t 信頼区間

t分布に頼らず、データに分布を語らせる

通常の t 区間は、歪みのある標本、とくに小標本（目安として n < 30）では正確さが落ちます。そこで、t 統計量が t 分布に従うと決めつける代わりに、その実際の分布をブートストラップ（bootstrap）で推定します。

条件の確認は、検定統計量が正しい分布（t 分布）に従うかを確かめるためのものでした。小標本で歪みや外れ値があると、t 分布から計算する分位点（quantile）がずれているので、信頼区間の信頼性が落ちます。

ブートストラップとは

手持ちの標本から、同じ大きさの標本を復元抽出（with replacement）で何度も取り直します。たとえば標本が 5, 7, 10 なら、そこから 3 個を復元抽出で引くので、7, 7, 10 や 5, 10, 5 のように同じ値が重複してもよい。標本が母集団を代表していると信じられるなら、この再標本から母集団の分布のようすを推測でき、統計量のばらつきが分かります。

人気の理由

  • コンピュータで簡単に再標本を作れる。
  • ノンパラメトリック（non-parametric）：正規性の仮定に頼らない。パラメトリックな区間は「正規条件」や「t 統計量が t 分布に従う」ことを前提にするが、その前提が満たされないとき、ブートストラップが役に立つ。
  • どんな統計量でもブートストラップ分布を作れる（自分で作った統計量でもよい）。これまでの t 手順では、決まった式と決まった R 関数が必要だった。

ブートストラップ t 信頼区間の手順

  1. 元の標本から、同じ大きさのブートストラップ再標本を復元抽出する。
  2. ブートストラップ t 統計量を計算する。
  3. これを大量にくり返す（t*が大量にたまる）。
  4. R の qt() の代わりに、たまった t* の経験的な分位点 Q̂（hat は「ブートストラップ分布からの予測」）を求める。
  5. その新しい分位点で区間を作る。
📐 t* ＝ ( x̄* − x̄ ) / ( s* / √n )
x̄*：再標本の平均，s*：再標本の標準偏差，x̄：元の標本平均，n：元の標本サイズ
区間：( x̄ − Q̂₂ · s/√n ,　x̄ − Q̂₁ · s/√n )　（s は元の標本の標準偏差，Q̂₁ ＜ 0 ＜ Q̂₂）
⚠️ 式に μ（未知の母平均）は出てこない。検定ではなく区間を作っているので「母平均が○○」という仮説はなく、代わりに元の標本平均 x̄ を使う。

R で実行（所得データ、B = 10,000 回）

set.seed(100)                      # same random numbers every run

xbar <- mean(incomes)              # original sample mean
N <- 10^4                          # number of bootstrap t's
n <- length(incomes)               # 25
Tboots <- numeric(N)               # storage

for (i in 1:N) {
  x <- sample(incomes, size = n, replace = TRUE)   # resample
  Tboots[i] <- (mean(x) - xbar) / (sd(x) / sqrt(n))
}

Qhat <- quantile(Tboots, c(0.025, 0.975))    # empirical quantiles
Qhat
2.5% 97.5% -5.356196 1.396638
  • set.seed()：乱数のパターンを固定し、毎回同じ答えを得る（書かないと数値が少しずつ変わる）。
  • numeric(N)：結果を入れる空の入れ物を、先に N 個分つくる。
  • for の i は 1 から 10,000 まで。各回で再標本 → t* → Tboots[i] に保存。
  • replace = TRUE がブートストラップの命。講師は「FALSE にして結果を見て、なぜそうなるか考えてみて」と宿題を出しました。→ FALSE だと、25 個全部を並べ替えただけの標本になり、平均も標準偏差も毎回元の標本と同じ。t* はいつも 0 になり、ばらつきを調べられません。
  • 中央の 95% を残すので、両端 2.5% ずつ → 2.5% 点と 97.5% 点を取る。
10,000 個の t* の分布（seed = 100、上のコードの結果）
左に長い裾。t 分布の分位点（±2.06）は左右対称だが、ブートストラップの分位点は −5.36 と 1.40 で対称でない。

もし t 分布が使えると考えるなら、分位点は qt() から得られます。

qt(p = c(0.025, 0.975), df = n - 1)
[1] -2.063899 2.063899

t 分布の分位点はいつも左右対称（片方が正、片方が負で同じ大きさ）ですが、ブートストラップ分布ではそうとは限りません。ここでは −5.36 と 1.40 で、大きく違います。

区間を計算する

# CI
xbar - quantile(Tboots, c(0.975, 0.025)) * sd(incomes) / sqrt(n)
97.5% 2.5% 27.02235 127.29020

式の見た目が少し不思議なのは、Q̂₁ が負だからです。x̄ − (負の数) は足し算になり、x̄ − (正の数) は引き算。下限と上限を小さい順に並べるため、c(0.975, 0.025) と順序を入れ替えて書きます。結果は 27.0 〜 127.3。通常の t 区間と比べます。

t.test(incomes)$conf.int[1:2]
[1] 17.11469 78.40531
区間下限上限幅
通常の 1標本 t 区間17.178.461.3
ブートストラップ t 区間27.0127.3100.3
2つの 95% 信頼区間（x̄ = 47.76）
ブートストラップ区間は、特に上側が大きく伸びる。
✅ ブートストラップ区間の利点（講師）
  1. ノンパラメトリック：正規性や t 分布の仮定に頼らない。1標本 t 区間では、この条件が満たされないと区間が狭すぎる結果になる。
  2. 分布の歪みと外れ値を反映するので、未知の母平均について、より大きな値もありうることを示す（上限が 78 → 127）。
⚠️ 外れ値 1 個が平均と標準偏差を大きく引き上げる。通常の t 区間はそれを分位点にうまく反映できない。「狭いから正しい」わけではない。
🍎 かんたん説明

ブートストラップ＝手持ちのデータから、同じ数だけ「引いて戻す」を何万回もくり返して、t 統計量の本当の形を調べる方法。形がゆがんでいれば、区間もゆがんだ形になる。

💻 ミニ練習：ブートストラップ t 区間

incomes がすでにあるとして、set.seed(100)、xbar、n、10,000 回の for ループ（復元抽出の sample()）で Tboots を作り、quantile() で 2.5% と 97.5% 点を求めてください。

④

有意性についての注意

p値の乱用・統計的有意性と実用的有意性・p-hacking

この動画の目的は、p 値を使うときの注意を伝えることです。

p 値のやり方と棄却域のやり方

教科書やサイトによって、統計的有意性の求め方が違うことがあります。

p 値アプローチ（この授業）臨界域・棄却域（critical / rejection region）
手順p 値を計算し、α（5%）と比べる研究の最初に臨界値を決め、検定統計量がそれより極端なら棄却
判断p ＜ 5% なら帰無仮説を棄却し、対立仮説の証拠とするp 値は計算しない
よく見る場所新しい教科書（講師の印象）古い教科書（講師の印象）

この授業では p 値を使い続けますが、ネットで調べると「棄却域」という言葉に出会うかもしれないので、聞いたことがあるようにしておきましょう。

p 値を「神話」にしない

論文や研究では、p 値が神秘的な力をもつように扱われることがあります。p 値は学術文献で乱用され、誤解されてきました（講義では American Statistical Association の p 値についての声明が紹介されました）。「5% より小さければ棄却、大きければ棄却しない」は入門用の考え方です。もう少し細かくは、こう考えます。

p 値対立仮説への証拠
非常に小さい（1% 未満）very strong evidence
1% 〜 5%strong evidence
5% 〜 10%weak evidence
10% より大きいinsufficient evidence（不十分）

この授業の課題では分かりやすさのために単純にしますが、p 値だけで研究を手早く評価しないように。p 値が 5.1% と 4.9% で「5% より小さいから棄却」と飛びつくのは避けたい。p 値は「何かあるかもしれないから、さらに調べよう」の合図にすぎません。研究デザインは適切か、手順は適切か、条件は満たされているか、データは信頼でき代表的か、そして効果の大きさ（effect size）はどのくらいか——これらを合わせて考えます。

統計的有意性と実用的有意性

p 値が小さいとき「結果は統計的に有意（statistically significant）」と言います。しかし実用的な意味での有意性（practical significance）とは別のものです。

講義の例：体重を減らすと主張する薬の研究で、p 値が 1% を下回るほど小さい結果が出たとします。ところが信頼区間を見ると、平均の減少は 1〜2 ポンドだった。帰無仮説を棄却し「この薬は効く」という証拠は得られますが、実際には 1〜2 ポンドです。体重を減らしたい人の多くは、もっと減らしたいはず。だから信頼区間で効果の大きさ（20〜30 ポンドなのか、1〜2 ポンドなのか）を見ることが大切です。

数値の例（イメージ。講義の数値ではなく、R で計算した仮想例）：標準偏差 8 ポンドとして、

# A: n = 2500, mean loss 1.5 lb, sd = 8
tA <- 1.5 / (8 / sqrt(2500))
tA
2 * pt(tA, df = 2499, lower.tail = FALSE)
1.5 + c(-1, 1) * qt(0.975, 2499) * 8 / sqrt(2500)

# B: n = 16, mean loss 6 lb, sd = 8
tB <- 6 / (8 / sqrt(16))
tB
2 * pt(tB, df = 15, lower.tail = FALSE)
6 + c(-1, 1) * qt(0.975, 15) * 8 / sqrt(16)
[1] 9.375 [1] 1.497508e-20 [1] 1.186254 1.813746 [1] 3 [1] 0.008972737 [1] 1.737101 10.262899
どちらも p ＜ 1%。でも効果の大きさはまるで違う
A は p が極小でも減少はたった約 1.2〜1.8 ポンド。B は p がやや大きくても、区間は 1.7〜10.3 ポンドと幅が広く、効果は大きそうだが不確実。

有意でないとき

⚠️ 帰無仮説を棄却できなかった（fail to reject）からといって、帰無仮説が正しいとは限りません。帰無仮説を「受け入れる（accept）」とは言いません。棄却できなかった理由を考えましょう——たとえば検出力（power）が足りなかった（underpowered）のかもしれません。もっと検出力を上げるべきだったのでは？

有意性を探し回る（p-hacking）

学術の世界では、p 値が小さいほど論文が通りやすいので、p 値を小さくしたくなります。しかし助成金をもらった研究で p 値が小さくならなくても、数字をごまかしてはいけません。誠実さ（integrity）が大切です。

  • 最初の検定で p 値が小さくないとき、データをサブグループに分けて「どれかで p 値が小さくならないか」と探したくなる。
  • α = 5% は 20 回に 1 回。20 個のサブグループに分ければ、平均して1 個は p 値が小さくなる。帰無仮説が本当に正しければ、それは第1種の過誤（Type I error）——有意でないものを有意と思い込んでしまう。
  • そういうサブグループの結果は論文になったりニュースの見出しになったりするかもしれないが、ほんとうは有意ではない。

p 値をできるだけ小さくしようとあらゆることをするのが p-hacking（data snooping、data dredging とも）です。倫理に反することがあり、避けるべきです。

1 - 0.95^20   # chance of at least one p < 0.05 in 20 independent tests (null true)
[1] 0.6415141

（参考：20 個の独立な検定がすべて帰無仮説の下にあるとき、少なくとも 1 個は p ＜ 0.05 になる確率は約 64%。）

🍎 かんたん説明

p 値は「ここに何かあるかも」の目印。p が小さい＝効果が大きい、ではない。必ず信頼区間で大きさを見る。有意でなくても「帰無仮説が正しい」とは言えない。サブグループを探し回って有意を作るのは p-hacking。

💻 ミニ練習：p値と信頼区間

平均の体重減少が 1.5 ポンド、標準偏差 8、n = 2500 のとき、t 統計量 tA を計算し、両側 p 値を pt() で求めてください（lower.tail = FALSE を使う）。

tA <- 1.5 / (8 / sqrt(2500))   # 9.375
2 * pt(tA, df = 2499, lower.tail = FALSE)   # 1.497508e-20

p 値は極めて小さいが、信頼区間は 1.19〜1.81 ポンド。統計的に有意でも、実用的には小さい効果。

①

2標本 t 区間と自由度

差 ± t*×SE、そして Welch の df

これまでは「1つの母集団の平均 μ」を推定していました。ここからは2つの標本から母平均の差を推定します。たとえば「新生児の男の子と女の子で、平均の身長（長さ）に差はあるか」。推定したいパラメータ（parameter）は μ₁ − μ₂（または μ_boy − μ_girl）です。引く順番はどちらでもよいが、式の中では一貫させること。

区間の一般形（ほぼ暗記してほしい形）はいつも同じです。

estimate ± margin of error ＝ (x̄₁ − x̄₂) ± t* × SE

要素2標本の場合
statistic（推定量）x̄₁ − x̄₂（標本平均の差）
standard error 標準誤差SE = √( s₁²/n₁ + s₂²/n₂ )
critical value 臨界値t*（1 − α/2 の分位点、自由度 df）

今回の主題は自由度 df の決め方です。3通りの考え方があります。

方法df特徴
lower estimate（下限）min(n₁ − 1, n₂ − 1)入門書でよく使う。保守的（区間が広め）
upper estimate（上限）n₁ + n₂ − 2大きすぎる見積もり
Welch の近似下の式最も正確。R の t.test() が使う

例：n₁ = 10、n₂ = 20 なら、lower = 9、upper = 28。本当の df はその間のどこかに入ります。

Welch：df = (A + B)² ÷ ( A²/(n₁ − 1) + B²/(n₂ − 1) )　ただし A = s₁²/n₁、B = s₂²/n₂
（式の暗記は不要。「R に任せられる」ことが大事です）

この式を R の自作関数（user-defined function）にしてみます。A と B を先に定義し、分子（numerator）と分母（denominator）に分けると読みやすくなります。

welch_df <- function(n1, n2, sd1, sd2) {
  A <- sd1^2 / n1
  B <- sd2^2 / n2
  numerator   <- (A + B)^2
  denominator <- A^2 / (n1 - 1) + B^2 / (n2 - 1)
  numerator / denominator
}

n1 <- 10;  n2 <- 15
sd1 <- 4.5; sd2 <- 3.2

lower <- min(n1 - 1, n2 - 1)
upper <- n1 + n2 - 2
welch <- welch_df(n1, n2, sd1, sd2)

cat("lower:", lower, "\n")
cat("upper:", upper, "\n")
cat("Welch:", welch, "\n")
lower: 9 upper: 23 Welch: 14.99542

cat() は文字と値をつないで表示する関数で、"\n" は改行です。Welch の df はlower と upper の間（9 < 14.995 < 23）に入っています。

df が小さいと t* は大きい（Goldilocks）

df が小さい分布は裾が重いので、同じ 95% をカバーするには t* を大きくする必要があります。lower（9）は t* が大きすぎ、upper（23）は小さすぎ、Welch がちょうどよい値を与えます。

qt(0.975, df = c(9, 14.99542, 23))
[1] 2.262157 2.131506 2.068658
dft*（95%）評価
9（lower）2.262必要以上に広い区間になる
14.995（Welch）2.132ちょうどよい
23（upper）2.069狭すぎる（過信）
⚠️ 講師の注意：データそのものがあるなら t.test(x, y) が Welch の df も区間も自動で出します。手計算・自作関数が必要なのは要約統計量（n, x̄, s）しかないときだけです。
✍️ チャレンジ課題（講義より）：データから直接 df を返す関数、さらに critical value（qt()）まで返す関数に拡張してみよう。
🍎 かんたん説明

2標本の区間は「差 ± t* × SE」。SE は2つの標本のばらつきを足して √ を取る。自由度は Welch が一番正確で、R が自動でやってくれる。要約値だけのときは自作関数 welch_df() を使う。

💻 ミニ練習：Welch の自由度

n₁ = 12、n₂ = 18、sd₁ = 5、sd₂ = 3 のとき、welch_df() を呼び出し（関数は定義済みとします）、lower estimate（min を使う）も計算してください。

welch_df(12, 18, 5, 3)
min(12 - 1, 18 - 1)

引数の順番は (n1, n2, sd1, sd2)。lower は min(n₁−1, n₂−1)。

②

例：小麦価格の99%信頼区間

9月 − 7月を手順どおりに

例題（USDA の調査）：9月と7月の小麦価格（ドル／ブッシェル）を、それぞれ独立なランダム標本で調べました。99% 信頼区間で「9月 − 7月」の平均価格差を推定します。

月nx̄s
September453.610.19
July902.950.22

パラメータ：9月と7月の母平均価格の真の差（μ_Sep − μ_Jul）。統計量：3.61 − 2.95 = 0.66。差がなければ統計量は 0 に近いはず。0.66 が出た説明は2つ：①本当は差がなく偶然（サンプリングのばらつき）／②価格が本当に上がった。

✍️ 順序のコツ：Sep − Jul にすると差は正の数（価格が上がった）で、統計の専門家でない人にも分かりやすい。Jul − Sep だと負の数になり意味が伝わりにくい。どちらでもよいが、各所で順序を揃える（sd も n も Sep が先）。
wheat_stat <- 3.61 - 2.95
wheat_stat

# degrees of freedom: lower / upper / Welch
45 - 1
90 + 45 - 2
wheat_df <- welch_df(45, 90, 0.19, 0.22)
wheat_df

wheat_SE <- sqrt(0.19^2 / 45 + 0.22^2 / 90)
wheat_SE

t_crit <- qt(1 - 0.01 / 2, df = wheat_df)
t_crit

wheat_ME <- t_crit * wheat_SE
wheat_ME

wheat_stat - wheat_ME
wheat_stat + wheat_ME
[1] 0.66 [1] 44 [1] 133 [1] 100.4483 [1] 0.03660601 [1] 2.625663 [1] 0.09611505 [1] 0.5638849 [1] 0.7561151

SE ≈ 0.037 ドル（約3.7セント）：別の標本を取り直すと差の標本平均は約4セントぶれる、という意味です。99% 信頼なので tail は 1% を半分にした 0.005 を足して 1 - 0.01/2 を qt() に渡します。ME ≈ 0.096 ドル（約10セント）。

99% CI ＝ 0.66 ± 0.096 ＝ (0.56, 0.76) ドル（セントに丸めて 56〜76セント）

解釈：「9月と7月の小麦の母平均価格の差（September − July）を、私たちは 99% の確信で 0.56 ドルから 0.76 ドルの区間が捉えていると言える。」区間は丸括弧 ( , ) で書き、順序（Sep − Jul）を必ず明記します。Markdown では $ が崩れるので、バッククォート `$0.56` で囲むとよい。

区間で「差があるか」を判断する

区間0 を含むか結論
(0.56, 0.76)含まない差の証拠あり（区間が全部正 → 9月の方が高い）
(−0.20, 0.30)含む0 も妥当な値 → 差の証拠なし
順序を逆にした (−0.76, −0.56)含まない符号が反転するだけで結論は同じ

データがあるときのショートカットは t.test(x, y, conf.level = 0.99)$conf.int。$conf.int を外すと検定名が Welch Two Sample t-test と出ます。Welch の df は、100 ではなく標本によって（例では 8 のように）小さくなることもあります。

⚠️ 要約統計量しかない（生データがない）ため、この例では t.test() は使えません。だから式を一つずつ計算しています。
🍎 かんたん説明

流れは「統計量（差）→ df（Welch）→ SE → t* → ME → 差 ± ME」。区間に 0 が入っていなければ「差がある」と言える。

💻 ミニ練習：99% 信頼区間を計算する

wheat_stat（0.66）、wheat_SE、wheat_df が定義済みとして、99% の臨界値 t_crit、誤差 wheat_ME、区間の下限・上限を求めるコードを書いてください。

t_crit <- qt(1 - 0.01 / 2, df = wheat_df)
wheat_ME <- t_crit * wheat_SE
wheat_stat - wheat_ME
wheat_stat + wheat_ME

99% なので α = 0.01、両側なので α/2 = 0.005 を引いた 0.995 の分位点。

2標本 t 検定：出生体重と喫煙

t.test() と手計算

問い：喫煙する母親から生まれた新生児と、喫煙しない母親から生まれた新生児で、出生体重に差があるか（有意水準 α = 0.05）。差の大きさを推定するのではなく、有意性検定（significance test）を行います。データは Intro to Modern Statistics の births14（openintro パッケージ）。今回は要約値ではなく生データから統計量を自分で求めます。

データの読み込みと2グループへの分割

# install.packages("openintro")   # 初回のみ。入っていればコメントアウト
library(openintro)

births <- births14
dim(births)
head(births, 5)

2群に分けるには subset() を使います（今後はもっと便利な方法も出てきます）。代入は = ではなく、「等しい」を調べるのは ==（イコール2つ）に注意。

weights_non   <- subset(births$weight, births$habit == "nonsmoker")
weights_smoke <- subset(births$weight, births$habit == "smoker")

boxplot(weight ~ habit, data = births, horizontal = TRUE, las = 1,
        xlab = "Birth weight (pounds)")

重さは gram ではなくpoundです。箱ひげ図では、非喫煙の中央値が喫煙よりやや大きく、両群とも外れ値が多いことが分かります。

仮説と統計量

H₀：μₙ − μₛ = 0（出生体重に差はない）
Hₐ：μₙ − μₛ ≠ 0（差がある。大きい／小さいの向きは決めない＝両側）

μₙ、μₛ は母集団の平均（標本平均ではない）。統計量は mean(non) − mean(smoke) です。

big_stat <- mean(weights_non) - mean(weights_smoke)
big_stat

mean(births)            # data frame 全体の平均は取れない
mean(births$weight)     # 列（$weight）の平均なら OK
[1] 0.5926801
⚠️ mean(births) のようにデータフレーム丸ごとの平均は NA になる落とし穴があります。$weight のように列を指定すること。na.rm = TRUE が要るかどうかは、NA の有無を確認して判断します。

差は約 0.59 ポンドです。その説明は2つ：①本当は差がないのに偶然 0.59 になった（サンプリングのばらつき）／②母集団でも本当に差がある。有意性検定でどちらが妥当かを調べます。

R のショートカット t.test()

t.test(weights_non, weights_smoke, conf.level = 0.95)

t.test(weights_non, weights_smoke)$p.value
Welch Two Sample t-test data: weights_non and weights_smoke t = 3.8166, df = 131.31, p-value = 0.0002075 alternative hypothesis: true difference in means is not equal to 0 95 percent confidence interval: 0.2854852 0.8998751 sample estimates: mean of x mean of y 7.269873 6.677193 [1] 0.0002075401

α = 5% は両側の 95% 信頼水準に対応します。出力の読み方：t = 3.8（平均の差が H₀ から標準誤差何個分離れているか。3.8 はかなり遠い）、df ≈ 131（Welch）、p = 0.0002075（0.02%）、95% CI = (0.29, 0.90) ポンド。

p 値の解釈：「喫煙・非喫煙の母親の子の平均出生体重に差がない（H₀）と仮定すると、標本平均の差が 0.59 ポンド以上（どちら向きでも）になる確率は 0.0002075（約 0.02%）。」

この確率は非常に小さいので、「偶然だった」という説明①は不自然。①を捨てて②を採用します。結論は3点セットで書きます：

  1. p 値 < α（0.0002075 < 0.05）
  2. H₀ を棄却（reject）
  3. 非喫煙・喫煙の母親の子の母平均出生体重に差があるという説得力のある証拠（convincing evidence）がある
⚠️ 起こりうるエラー：H₀ を棄却したので、誤っているとすれば Type I error（本当は差がないのに差があると結論）。その結果は、たとえば「妊娠中の喫煙は出生体重に影響する」という広告にお金を無駄に使うことです（医学的には禁煙が推奨されている点は別の話）。

区間で判断：95% CI (0.29, 0.90) に 0 が含まれない → 差の証拠あり。含まれていれば証拠なし。

手計算（要約統計量から）

検定統計量の一般形は (statistic − null parameter) ÷ SE。1標本は (x̄ − μ₀) ÷ (s/√n)、2標本は次のとおりです。

t = ( (x̄₁ − x̄₂) − 0 ) ÷ √( s₁²/n₁ + s₂²/n₂ )

要約値（2桁に丸め）：非喫煙 x̄ = 7.27、s = 1.23、n = 867／喫煙 x̄ = 6.68、s = 1.60、n = 114。分子は 7.27 − 6.68 = 0.59（H₀ の差 0 を引く）。

n_non   <- length(weights_non)      # 867
n_smoke <- length(weights_smoke)    # 114

numerator   <- 7.27 - 6.68
denominator <- sqrt(1.23^2 / n_non + 1.60^2 / n_smoke)
t_manual    <- numerator / denominator
c(numerator, denominator, t_manual)

# 両側 p 値：t は正 → 上側確率を 2 倍。df は lower estimate（小さい方の n − 1）
2 * pt(t_manual, df = n_smoke - 1, lower.tail = FALSE)

# 比較：Welch の df（約131）を使うと
2 * pt(t_manual, df = 131.31, lower.tail = FALSE)
[1] 0.5900000 0.1555670 3.7925760 [1] 0.0002411 [1] 0.0002265

手計算の t（3.79）と t.test() の t（3.8166）は、平均と標準偏差を2桁に丸めたため少しずれます（精度が高いのは t.test 側）。それでも小数1桁ではどちらも 3.8 です。p 値の差は、丸めよりも自由度が主因です。手計算では安全側の lower estimate（小さい方の n − 1）を使うため p は少し大きめ（保守的）、t.test は Welch の df ≈ 131 を使います。

関数返すもの用途
qt(p, df)分位点（critical value）信頼区間の t*
pt(t, df)確率（p 値の材料）検定の p 値
⚠️ qt と pt を混同しないこと。接頭辞 p = probability、q = quantile。両側検定なので pt(..., lower.tail = FALSE) を 2倍します。
🍎 かんたん説明

検定は「差が 0 だとしたら、こんな差が偶然出る確率は？」を調べる。p が α より小さければ H₀ を捨てて「差がある証拠あり」。生データがあれば t.test(x, y) の一行で終わり。

💻 ミニ練習：2標本の t 検定

2つの数値ベクトル weights_non と weights_smoke について、両側の Welch 二標本 t 検定（95%）を実行し、p 値だけを取り出すコードを書いてください。

t.test(weights_non, weights_smoke, conf.level = 0.95)
t.test(weights_non, weights_smoke)$p.value

$p.value で p 値だけを取り出せる。

💻 ミニ練習：手計算の p 値

検定統計量 t_manual が正、自由度の下限推定が n_smoke - 1 のとき、両側 p 値を pt() で求めてください。

2 * pt(t_manual, df = n_smoke - 1, lower.tail = FALSE)

t が正なので右の裾（lower.tail = FALSE）、両側なので ×2。

④

対応あり t 区間・検定

差を作って1標本 t

2標本 t は2つの標本が独立であることを前提に SE を計算します。しかし対応のあるデータ（paired data）――1人の個体に2回測定した、あるいは2人をペアにして別々の処理を与えた――では独立ではありません。x₁ と x₂ は通常正の相関をもつので、独立を仮定すると差の標準誤差を過大評価してしまいます。

パラメータは μ₁ − μ₂ の2つではなく、差の母平均 μ_diff 1つ。式は1標本とまったく同じで、データが「各個体の差」になるだけです。

paired t 区間：d̄ ± t* × s_d/√n_d（df = n_d − 1）
paired t 検定：t = (d̄ − 0) ÷ (s_d/√n_d)

例：カフェイン離脱とうつ症状

カフェイン依存の11人のボランティアが、2日間ずつ「通常量のカフェイン」と「プラセボ」のカプセルをランダムな順序で服用し、終了時にうつ症状のテストを受けました（高得点ほど症状が強い）。カフェインを断つとうつ症状が増すか？

Subject1234567891011
caffeine554385002111
placebo16235714246315120
差（placebo − caffeine）11181461963131−1

なぜ paired か：1人の被験者に2つのデータがあるので、独立な2群ではありません。「11人にカフェイン、別の11人にプラセボ」という設計もありえますが、1人が両方の処理を受ける（順序はランダム）方が個人差が除かれてよい設計です（良い実験デザインの原則は掲示板で議論してみよう）。

caff    <- c(5, 5, 4, 3, 8, 5, 0, 0, 2, 11, 1)
placebo <- c(16, 23, 5, 7, 14, 24, 6, 3, 15, 12, 0)

xdiffs <- placebo - caff      # 差は正の数が多くなる向きに
xdiffs

boxplot(xdiffs, horizontal = TRUE,
        xlab = "Difference in depression score (placebo - caffeine)")

mean(xdiffs); sd(xdiffs); length(xdiffs)
[1] 11 18 1 4 6 19 6 3 13 1 -1 [1] 7.363636 [1] 6.917698 [1] 11
⚠️ 変数名に diff を使うと R 組み込みの diff() を上書きしてしまうので、xdiffs のような名前にしましょう。

差の大半は正です。パラメータは差の母平均 μ_diff、推定量は d̄ = 7.36。仮説は H₀：μ_diff = 0（カフェインとプラセボでうつ得点に差はない）、Hₐ：μ_diff ≠ 0。

t.test(xdiffs, conf.level = 0.95, alt = "two.sided")
One Sample t-test data: xdiffs t = 3.5304, df = 10, p-value = 0.005443 alternative hypothesis: true mean is not equal to 0 95 percent confidence interval: 2.716264 12.011009 sample estimates: mean of x 7.363636

これは1標本 t 検定そのものです。方向を指定しないときは両側で、大小の向きを検討するなら alt = で "less" / "greater" を指定しないと p 値を自分で調整することになります。?t.test を見ると alternative と paired = TRUE という引数があります。2つのデータを別々に入れるときは paired = TRUE でペアだと R に教えます（今回は自分で引き算したので不要）。

t.test(placebo, caff, paired = TRUE)$p.value
[1] 0.005442944
⚠️ 研究の問いは「プラセボ時の方がうつ得点が高い」という方向つきなので、厳密には片側の検定・区間が必要です。授業では両側の区間のみを扱うので、ここでは両側検定にしています。

手計算の確認：SE = s_d/√n = 6.92/√11 = 2.086、t* = qt(0.975, 10) = 2.228、t = 7.36 ÷ 2.086 = 3.53、95% CI = 7.36 ± 2.228 × 2.086 = (2.72, 12.01)、両側 p ＝ 2 * pt(3.53, 10, lower.tail = FALSE) ≈ 0.0054。

p 値の解釈：「カフェインとプラセボで（個人のうつ得点に）差がないと仮定すると、標本の平均差が 7.36 以上（どちら向きでも）になる確率は 0.005443。つまり、順序がランダムだったことによる偶然だけで起こる可能性は非常に低い。」

結論（3点）：p 値（0.005443）< α（0.05）→ H₀ を棄却 → 平均の差（placebo − caffeine）が 0 ではないという説得力のある証拠がある。区間(2.72, 12.01) に 0 が含まれないので、同じ結論になります。

✍️ 「p 値とは何か／どう解釈するか」は面接でもよく聞かれる質問です。H₀ が正しいと仮定して、観測した結果以上に極端な結果が偶然で出る確率と言えるようにしておきましょう。
🍎 かんたん説明

対応ありデータは「差」を作って1標本 tにすればよい。df = 人数 − 1。独立を仮定する2標本 t を使うと SE を大きく見積もってしまうので、ペアだと分かったら paired を使う。

💻 ミニ練習：対応ありの検定

ベクトル before と after の対応ありデータについて、差 xdiffs（before − after）を作り、両側の t 検定（95%）を実行するコードを書いてください。

xdiffs <- before - after
t.test(xdiffs, conf.level = 0.95, alt = "two.sided")

差を作って1標本 t。または t.test(before, after, paired = TRUE) でも同じ結果。

📖 用語集

two-sample t interval
二標本 t 区間
2つの独立な標本から μ₁ − μ₂ を推定する区間。(x̄₁−x̄₂) ± t*·SE。
Welch's degrees of freedom
ウェルチの自由度
2標本で最も正確な df の近似。R の t.test() が使う。
lower / upper estimate
自由度の下限／上限
min(n₁−1, n₂−1)／n₁+n₂−2。手計算では下限が保守的。
standard error (SE)
標準誤差
差の SE = √(s₁²/n₁ + s₂²/n₂)。
critical value t*
臨界値
qt() で求める分位点。df が小さいほど大きい。
significance test
有意性検定
H₀ のもとで観測結果がどれだけ珍しいかを p 値で判断する。
p-value
p 値
H₀ が正しいとして、観測以上に極端な結果が偶然で出る確率。
Type I error
第一種の誤り
本当は H₀ が正しいのに棄却してしまう誤り。
paired data
対応のあるデータ
同じ個体の2測定、またはペアにした2個体。独立ではない。
μ_diff
差の母平均
対応ありの t 手続きのパラメータ。差を1標本として扱う。
convincing evidence
説得力のある証拠
p < α、または区間が 0 を含まないときに使う結論の言葉。
qt() vs pt()
分位点と確率
qt は臨界値、pt は p 値の確率を返す。混同しない。

💡 学習のヒント

2標本は「差 ± t*×SE」と「差 ÷ SE」。生データがあれば t.test(x, y)、要約値だけなら手計算。ペアの時は差を作って1標本 t。結論は p と α の比較 → H₀ の棄却 → 文脈つきの結論の3点セットで書きましょう。

散布図：2つの量的変数を見る

向き・形・強さ・特異な特徴

統計学者 John Tukey（箱ひげ図を考案した人）は「絵（図）のいちばんの価値は、予想もしていなかったものに気づかせてくれること」と言いました。平均・中央値・標準偏差・範囲といった要約統計量だけで済ませたくなりますが、必ず可視化（visualize）しましょう。数値を眺めているだけでは見えない発見があります。

これまで学んだ基本のグラフを、「どんなデータか」で整理しておきます（講義の復習）。そして今回は最後の行、量的変数が2つのときの散布図（scatterplot）です。

データ使うグラフ
量的変数 1つdotplot・stemplot・boxplot・histogram
カテゴリ変数 1つbar graph（pie chart は統計家はあまり使わない）
量的変数 1つ × 複数グループ（例：カナダ・メキシコ・アメリカ）parallel boxplots／side-by-side stemplot（2グループのときだけ）
カテゴリ変数 2つmosaic plot・segmented bar graph・side-by-side bar graph
量的変数 2つ（同じ個体で測定）scatterplot（散布図）

例：検索順位とクリック率

企業は自社サイトを検索結果の上位に出そうと努力します。検索結果での順位（position：1位が最初のリンク、2位が2番目…）と、そのリンクをクリックした人の割合（click-through rate）には関係があるでしょうか。モバイル検索の上位10位のクリック率が下のデータです（1位は23.5%の人がクリック、2位は14.94%…）。

position12345678910
rate（%）23.5314.9411.197.475.293.82.792.111.571.18

2つとも数値（量的変数）なので、基本の plot() で散布図が描けます。1つ目に書いたものが x軸、2つ目が y軸です。

position <- 1:10
rate <- c(23.53, 14.94, 11.19, 7.47, 5.29, 3.8, 2.79, 2.11, 1.57, 1.18)

plot(position,                    # variable on x-axis
     rate,                        # variable on y-axis
     pch = 16,                    # filled-in circles
     cex = 2,                     # larger circle size
     las = 1,                     # rotate numbers on y-axis
     xlab = "Position",           # x-axis label
     ylab = "Click-through Rate") # y-axis label
引数意味（講義より）
pch = 16plotting character。16 = 塗りつぶしの丸（既定は白抜きの丸）。数字を変えると形が変わるので試してみよう
cex = 2点の大きさ。講義は画面で教えるので大きくしている
las = 1y軸の数字の向きを読みやすく回転する
xlab / ylabx軸／y軸のラベル。軸には必ずラベルを付ける

変数がデータフレーム df の列のときは plot(df$col1, df$col2) と書きます（次の動画で使います）。

位置とクリック率の散布図（上のデータをそのまま描画）
数字の表だけでは気づきにくいが、図にすると「右下がりで曲がった形」がすぐ見える。

散布図を説明する4つの観点

散布図を見たら、direction（向き）・form（形）・strength（強さ）・unusual features（特異な特徴）の4つを述べられるようにします。

観点見かたこの例
direction 向き左から右へ読む。下がる＝negative（スキーヤーが滑り降りるイメージ）、上がる＝positive、平ら＝向きなしnegative
form 形linear（直線的）か non-linear（曲線など）かnon-linear（曲がっている）
strength 強さ点が傾向（trend）にどれだけ近く沿うか。weak／moderate／strong の区別は次の動画（②）strong（点が曲線にぴったり沿う）
unusual featuresoutlier（傾向から外れた点。たとえば図の上の方にぽつんとある点）や cluster（点のかたまり）なし
✍️ 模範文：There is a strong negative non-linear association between position and click-through rate.（位置とクリック率の間には、強い負の非線形の関連がある。）

数値の表だけを見て、形・強さ・外れ値を見抜くのはとても難しい。これも可視化の利点です。

⚠️ 講師の注意（最後のコメント）
  • 散布図が示すのは傾向（trend）であって、絶対的・決定的（deterministic）な関係ではない。点が曲線や直線の上に完全に乗る必要はない（この例はかなりきれいな部類で、今後はもっと乱れた散布図が出てくる）。
  • 散布図は量的データ用。順序尺度（ordinal）は工夫すれば描ける（この「順位」も ordinal とみなしてよい）が、名義尺度（nominal）では何をしているのか十分注意すること。

correlation・association・relationship

この3つはほぼ同じ意味で使われます（講師の考えでは大きな違いはない）。ただし correlation（相関）と言ってよいのは量的変数どうしのときだけ。カテゴリ変数なら association か relationship を使います。

変数の種類使ってよい言葉
量的 × 量的correlation／association／relationship のどれでもOK
カテゴリ変数を含むassociation／relationship（correlation は使わない）
🍎 かんたん説明

散布図は「2つの数が一緒にどう動くか」を点で見る図。見たら向き・形・強さ・変わった点の4つを言葉にする。表の数字だけでは気づけないことが、図だとすぐ分かる。

💻 ミニ練習：散布図を描く

x を横軸、y を縦軸にして、塗りつぶしの丸（pch=16）・大きさ cex=2・y軸の数字を回転（las=1）・軸ラベル "Position" と "Click-through Rate" を付けた散布図を描く plot() を書いてください（変数名は position と rate）。

plot(position, rate,
     pch = 16, cex = 2, las = 1,
     xlab = "Position", ylab = "Click-through Rate")

1つ目の変数が x軸、2つ目が y軸。pch=16 で塗りつぶし、cex で大きさ、las=1 で y軸の数字の向き、xlab/ylab でラベル。

②

相関係数 r

強さと向きを1つの数で

散布図の「強さ」と「向き」を、1つの数で表したのが相関係数（correlation coefficient）です。①の例は曲線的で線形ではありませんが、計算した相関は r = −0.9 でした。符号のマイナスは、①で見た「右下がり」とまったく同じ意味です。

position <- 1:10
rate <- c(23.53, 14.94, 11.19, 7.47, 5.29, 3.8, 2.79, 2.11, 1.57, 1.18)
cor(position, rate)
[1] -0.9024191

Pearson の相関係数 r

講義で扱うのは Pearson's correlation coefficient（ピアソンの積率相関係数）r です。2つの量的変数の「線形な（直線的な）関連」の強さと向きを表す統計量です。

  • −1 ≤ r ≤ 1（−1 と +1 を含む）。同じことを |r| ≤ 1 とも書く。絶対値 |r| は符号を無視した大きさのこと。
  • r > 0：正の関連（右上がり、positive association）。例 r = +0.9。
  • r < 0：負の関連（右下がり、negative association）。例 r = −0.97。
  • r = 0：線形の関連がない（no linear association）。講義では「linear」が太字で強調されていた。
r のいろいろ（講義の R データ。赤い点線なしの素の散布図）
正の相関
r = 0.897
負の相関
r = −0.897
U字型
r = 0.006（線形の関連なし）
完全な正の直線
r = 1

左2つは hours と score の例（0.897 と −0.897）。真ん中はU字型で r はほぼ 0。右2つは完全に一直線の場合（r = 1, −1）。

r = 0 でもパターンはある（U字型の例）

講師は「r = 0 の例」として2つのグラフを見せました。左はただの点の塊（上がりか下がりか分からない＝線形の関連なし）。右は放物線（U字）のパターンがあるのに、r は −0.12 で 0 にとても近い（講師の作った架空データの値）。つまり 線形の関連はないが、二次（曲線）の関連は存在しうるのです。下は同じ考えを、U字型の別データで R で確かめたものです（r = 0.006）。

hours <- 1:8
score <- c(100, 80, 70, 65, 65, 71, 80, 100)

plot(hours, score, pch = 16, cex = 2, main = "No 'linear' association, but...")
cor(hours, score)
[1] 0.006140287

±1 になるのは「完全な直線」だけ

r = +1 や r = −1 になるのは、すべての点がぴったり直線上に乗るときだけです。講師は2枚のグラフを横に並べるために par(mfrow = c(1, 2))（1行2列）を使いました。

fake_x <- 1:7
par(mfrow = c(1, 2))      # one row, two columns of plots
plot(fake_x, fake_x, pch = 16, main = "r = 1")
plot(fake_x, -fake_x, pch = 16, main = "r = -1")
cor(fake_x, fake_x)
cor(fake_x, -fake_x)
[1] 1 [1] -1

強さの目安（この授業の基準）

強さは |r| が 1 に近いほど strong、0 に近いほど weak。符号ではなく絶対値で判断します（−1 も +1 も強い）。この授業（と多くの入門統計）では次の区分を使います。

strongmoderateweakmoderatestrong
−1 〜 −0.8−0.8 〜 −0.5−0.5 〜 0.50.5 〜 0.80.8 〜 1
💡 つまり「−0.5 から +0.5 の間は weak、0.8 より大きいか −0.8 より小さければ strong、その間が moderate」。「strong」の基準は分野によって違います（エンジニアと、社会学者・人類学者などの社会科学者とでは、強いと感じる値が違う）。でもこの授業では上の表で十分です。

外れ値に弱い：r は resistant ではない

r は外れ値（outlier）に対して頑健ではありません（not resistant）。ここでの外れ値は、見た目で「データの傾向（trend）から外れた点」のこと（後の回帰の動画で、残差 residual が大きい点として出てきます）。

# Scatterplot with outlier
hours <- c(0, 0, 1, 2, 2, 3, 5, 7)
score <- c(100, 80, 70, 65, 60, 50, 10, 100)
cor(hours, score)

# Scatterplot without the outlier (the last point removed)
hoursNoOutlier <- c(0, 0, 1, 2, 2, 3, 5)
scoreNoOutlier <- c(100, 80, 70, 65, 60, 50, 10)
cor(hoursNoOutlier, scoreNoOutlier)
[1] -0.2351088 [1] -0.9676547
たった1点で r が −0.235 から −0.968 に
外れ値あり（赤い点）
r = −0.235
外れ値を除く
r = −0.968
残りの7点は左右のグラフでまったく同じ点（右は軸が 0〜6 に変わって少しずれて見えるだけ）。点線は目安の直線。

外れ値ありの r = −0.235 は、点の大半がほぼ一直線上に並んでいるのに「弱い」と出てしまう見かけにだまされやすい値です。外れ値を1つ除くと、r = −0.968。−1 にとても近い（完全な直線ではないので −1 ではない）非常に強い負の関連です。1つの外れ値が相関を「弱めて」いたわけです。

⚠️ 試験について（講師の予告）：講義の資料にある「Matching Correlations」などの可視化サイトで、いろいろな強さ・向きの相関を当てる練習をしておくこと。試験では、そうした散布図の「スクリーンショット」を見せて、相関（r）を推定したり対応づけたりする問題を出す、と講師は言っています。r が 1 や 0 にどれくらい近いと strong／weak なのか、基準を覚えておきましょう。
⚠️ r は「直線」だけを見ている：r = 0 は「線形の関連なし」であって、「関連なし」ではありません。必ず先に散布図を描いてから r を見ること。
🍎 かんたん説明

r は −1〜+1。符号＝向き、絶対値＝強さ。目安は |r| ≤ 0.5 が弱い、0.8 超が強い、その間が中くらい。外れ値1つで大きく変わる（−0.235 → −0.968）ので、散布図とセットで見る。

💻 ミニ練習：r を計算する

hours <- c(0, 0, 1, 2, 2, 3, 5, 7) と score <- c(0, 10, 50, 60, 65, 70, 80, 100) の相関係数を R で求めるコードを書いてください（結果は約 0.897 で「強い正の相関」になります）。

hours <- c(0, 0, 1, 2, 2, 3, 5, 7)
score <- c(0, 10, 50, 60, 65, 70, 80, 100)
cor(hours, score)

[1] 0.897376。0.8 より大きいので strong、符号が正なので右上がり。散布図 plot(hours, score) も合わせて描いてみよう。

💻 ミニ練習：外れ値を除いた r

外れ値あり（score <- c(100, 80, 70, 65, 60, 50, 10, 100)、hours は上と同じ）のとき r = −0.235 でした。最後の1点（8番目）を取り除いて相関を求めるコードを書いてください（hours[-8] のようにインデックスで除く書き方でもOK）。

hours <- c(0, 0, 1, 2, 2, 3, 5, 7)
score <- c(100, 80, 70, 65, 60, 50, 10, 100)
cor(hours[-8], score[-8])

[1] -0.9676547。マイナスのインデックス [-8] は「8番目を除く」。外れ値を1点除くだけで r が −0.235 から −0.968 に変わる。

donors データで散布図を使って探索する

summary → 散布図 → cor

実データで復習します。donors データセットは『Practical Machine Learning with R』という本に由来するもので、ある退役軍人団体（national veterans organization）が、既存・見込みの寄付者にダイレクトメールで寄付を募ったテスト発送の結果です。donors.csv とノートブック（.Rmd）は同じフォルダに置いておくと読み込めます。

donors <- read.csv("donors.csv")
dim(donors)
[1] 95412 22

環境に donors が現れ、約95,000 件の観測と多数の変数があります。まず初期探索として summary() を見ます。

summary(donors$wealthRating)
Min. 1st Qu. Median Mean 3rd Qu. Max. NA's 0.000 3.000 6.000 5.346 8.000 9.000 44732

summary(donors) は各変数の五数要約（five-number summary）と平均、NA（欠損値）の数を出します。このデータには NA がたくさんあり、たとえば wealthRating は約半数（95,412 件中 44,732 件）が欠けています。

問い①：寄付回数と平均寄付額は相関する？

たくさん寄付した人ほど、1回あたりの金額も大きい？（正の関連かも？）散布図を描いてみます。まずエラーになる書き方：

plot(averageGiftAmount, numberGifts)
Error : object 'averageGiftAmount' not found

「列は目の前にあるのに？」と思いますが、R はどのデータセットの話なのか分からないのです。環境にあるものだけでなく、R には内蔵データセットが山ほど入っているので、ひとつしかなくても推測してくれません。データフレーム名と $ で列を指定して直します。

plot(donors$averageGiftAmount, donors$numberGifts)

白抜きの丸の、簡単な散布図ができます。これだけでも多くのことが分かります。一人の寄付者は平均 $1,000 ですが、寄付はおそらく1回（実際に numberGifts は 1）。別の人は平均額は低い（$10 程度）が200回以上寄付しており、合計すると約 $2,000 以上。組織にとって素晴らしい寄付者です。次に見た目を整えます（点を小さく：cex を 1 より小さく、y軸の数字を回転、丸を塗りつぶし、ラベルを付ける）。

plot(donors$averageGiftAmount,
     donors$numberGifts,
     cex = 0.5,                      # smaller points
     las = 1,                        # rotate numbers on y axis
     pch = 16,                       # solid circle dots
     xlab = "Average Gift amount",
     ylab = "Number of Gifts")

cor(donors$averageGiftAmount, donors$numberGifts)
[1] -0.2569922

r は負です（散布図が「上がり」より「下がり」に見えることと合う）。ただし weak（|r| = 0.26 < 0.5）。しかも、そもそも線形ではなく曲がった（non-linear）形です。講義の4観点でまとめると：

観点donors：平均寄付額 × 寄付回数
directionnegative
formnon-linear（曲線的）
strengthweak（r = −0.257）
unusual features大多数の寄付者は平均寄付額 $100 未満・寄付回数 100 回未満の大きなかたまり。そこから離れて、(a) 寄付回数は多いが平均額は高くない人たち、(b) 平均額は非常に高いが寄付回数は少ない人たち、がいる

組織はこの2つのグループに、それぞれ「たくさん寄付してくれてありがとう」「大口の寄付をありがとう」と連絡できます。donors の数字を眺めるだけでは、これはとても難しい。ここが可視化の利点です。

問い②：寄付回数と「最後の寄付からの月数」は相関する？

monthsSinceLastDonation が 0 なら、今月寄付した人。5 なら最後の寄付から5か月。データでは 0〜23 の値をとります。点が同じ位置に重なると数が分かりません。そこで jitter（ジッター）＝ランダムにほんの少しだけ点をずらすと、重なった点の密度（density）が見えます。

# Without jitter
plot(donors$monthsSinceLastDonation,
     donors$numberGifts,
     cex = 0.5, las = 1, pch = 16,
     xlab = "Months since last donation",
     ylab = "Number of Gifts")

# With jitter: points are shaken a little so they overlap less
plot(jitter(donors$monthsSinceLastDonation, 0.5),
     donors$numberGifts,
     cex = 0.5, las = 1, pch = 16,
     xlab = "Months since last donation",
     ylab = "Number of Gifts")

cor(donors$monthsSinceLastDonation, donors$numberGifts)
[1] -0.1496668

散布図から読めること：「20か月前に最後に寄付した」人たち／「今月寄付した（0）」人たち。たとえば「最後の寄付から16か月たっているが、これまでの寄付回数はとても多い」人は、「長いあいだ寄付がないけれど、いつも寄付してくれた方。またお願いできませんか？」と連絡する価値のある相手です。r = −0.15 は weak な負の相関。

⚠️ jitter は見やすくするための表示だけの工夫です。点が少しずれるだけで、データそのもの（や相関）は変わりません。

🍎 かんたん説明

データを手に入れたらsummary → 散布図 → cor の順に。列は donors$列名 で指定（$ がないと R はどのデータか分からない）。散布図で、数字だけでは見えない「特別な寄付者」が見つかる。

💻 ミニ練習：donors で散布図と相関

donors データフレームの numberGifts（x軸）と totalGivingAmount（y軸）の散布図を、pch = 16・cex = 0.5 で描き、続けて2変数の相関を cor() で求めるコードを書いてください。

plot(donors$numberGifts, donors$totalGivingAmount,
     pch = 16, cex = 0.5, las = 1,
     xlab = "Number of Gifts", ylab = "Total Giving Amount")
cor(donors$numberGifts, donors$totalGivingAmount)

列は donors$列名 で指定する。結果は [1] 0.5997817。0.5〜0.8 なので moderate な正の相関（寄付回数が多い人ほど合計額も大きい傾向）。

④

相関行列と散布図行列

複数の変数を一度に

2変数ずつ相関を計算するのは大変です。複数の変数どうしの相関を一度に計算したものが相関行列（correlation matrix）、複数の散布図を一度に並べたものが散布図行列（scatterplot matrix）です。変数が多いときにとても効率的で、データの中にどんな関係があるかを見渡せます。

準備：長い変数名を短くする（必須ではない）

yearsSinceFirstDonation は名前が長いので、出力がきれいになるよう短くします。names(donors) は列名のベクトルで、11番目の名前がこの変数です。

names(donors)[11]
names(donors)[11] <- "yrsFirstDon"   # rename the 11th column
names(donors)[11]
[1] "yearsSinceFirstDonation" [1] "yrsFirstDon"
💡 環境をクリアして donors を読み込み直せば、元の名前に戻ります（必須の作業ではありません）。

量的変数だけを選ぶ

cor() にデータフレーム全体を渡すと、カテゴリ変数が含まれるのでエラーになります。相関は量的データにしか使えません。そこで donors[ , c(列名)] のように列を選びます。角かっこのカンマの前＝行、後ろ＝列。行を空欄にすると「全部の行」（1行目〜95,412行目を書かなくてよい）。ここでは5つの量的変数を選びました（もっと多くても少なくてもよい）。

donorsNumeric <- donors[ , c("numberChildren",
                             "incomeRating",
                             "wealthRating",
                             "smallestGiftAmount",
                             "yrsFirstDon")]

相関行列と NA の問題

選んだデータフレームを cor() に渡し、round(…, 2) で小数第2位に丸めます。ところが、最初の結果はNA だらけで使えません。

round(cor(donorsNumeric), 2)
numberChildren incomeRating wealthRating smallestGiftAmount numberChildren 1 NA NA NA incomeRating NA 1 NA NA wealthRating NA NA 1 NA smallestGiftAmount NA NA NA 1.00 yrsFirstDon NA NA NA -0.41 yrsFirstDon numberChildren NA incomeRating NA wealthRating NA smallestGiftAmount -0.41 yrsFirstDon 1.00
  • 対角線はいつも 1：変数と自分自身の相関だから（完全な直線＝r = 1）。役に立たない値。
  • 欠損値（NA）が列に含まれると、cor() は計算できず NA を返します。

理由は ?cor のドキュメントの use 引数にあります。use は「欠損値があるとき共分散（相関）をどう計算するか」を指定する文字列で、既定値は "everything"（NA も含めて計算＝問題）。選択肢は "everything"・"all.obs"・"complete.obs"・"na.or.complete"・"pairwise.complete.obs"。ここでは use = "complete.obs"（すべて揃っている行だけを使い、NA のある行は無視）を使います。

相関行列の読みかた

  • 最も強い正の相関：incomeRating と wealthRating（0.45）。
  • ただし絶対値で最大なのは yrsFirstDon（初回寄付からの年数）と smallestGiftAmount（最小の寄付額）の −0.46（講師の言葉：「technically the strongest」）。どちらも |r| < 0.5 なので、この授業の基準ではweak。
  • 対角線に関して対称（symmetric）：折り返すと同じ値。2変数の相関は順序に関係ないから。たとえば「numberChildren と incomeRating」＝「incomeRating と numberChildren」（0.02）。

散布図行列：pairs()

複数の散布図を一度に見るには pairs() を使います（他の方法は DTSC 650 で学びます）。画面に出る数を抑えるため3変数だけ選びます。

pairs(donors[ , c("wealthRating", "smallestGiftAmount", "yrsFirstDon")])

1行にまとめて書くと構文が分かりやすくなります。カンマを忘れずに（行を空欄＝全行）。次の書き方でも同じ散布図行列ができ、データフレームを別に作らなくてよい上、欠損値を除く別の引数 na.action も使えます。

pairs(~ wealthRating + smallestGiftAmount + yrsFirstDon,
      data = donors,
      na.action = na.omit)
⚠️ 散布図行列の読みかた：行と列の変数名が交わるマスに、その2変数の散布図がある。たとえば wealthRating は、その行にある2つのグラフでは y軸、列にある2つのグラフでは x軸。yrsFirstDon は列のグラフで x軸、行のグラフで y軸。また wealthRating は整数の評価値なので、同じ値にたくさんの点が重なってあまり役に立たない散布図になります（jitter の出番）。
🎯 この単元の学習目標：相関行列と散布図行列が何か、どう作り、どう読むか、そして欠損値をどう扱って相関を計算するか。
🍎 かんたん説明

相関行列＝全部の組み合わせの r を表にしたもの（対角線は1、折り返すと同じ）。NA があるなら use = "complete.obs"。散布図行列＝pairs() で散布図を一気に並べたもの。

💻 ミニ練習：相関行列を作る

donors の中の量的変数 numberChildren・incomeRating・wealthRating の3列だけを選んだ donorsNumeric を作り、欠損値のある行を除いて（use = "complete.obs"）相関行列を小数第2位で表示するコードを書いてください。

donorsNumeric <- donors[ , c("numberChildren", "incomeRating", "wealthRating")]
round(cor(donorsNumeric, use = "complete.obs"), 2)

行を空欄（カンマの前）にすると全行。use = "complete.obs" がないと NA が返る。3×3 の行列で、対角線は 1、折り返すと同じ値になる。

💻 ミニ練習：散布図行列

pairs() を使い、donors から wealthRating・smallestGiftAmount・yrsFirstDon の散布図行列を、チルダ（~）を使う書き方で、NA を除く引数も付けて描くコードを書いてください。

pairs(~ wealthRating + smallestGiftAmount + yrsFirstDon,
      data = donors,
      na.action = na.omit)

~ の後ろに変数を + でつなぎ、data = でデータフレームを指定。na.action = na.omit で欠損値のある行を除く。

🧠 頻度論とベイズ：確率の2つの考え方

確率には2つの解釈があります。長い目で見た相対度数とみなす頻度論と、信念の度合いとみなすベイズです。それぞれの長所・短所と、ベイズの定理の計算（検査の陽性の例）を学びます。

①

頻度論：長い目で見た相対度数

統計学の主流の考え方

頻度論（frequentist）では、確率を「同じ試行を無限にくり返したときの相対度数」と定義します。前回の大数の法則がその土台です。この授業の信頼区間や仮説検定（M4 以降）は頻度論の考え方で組み立てられています。

長所短所
世界の事実に根ざしている（客観的）無限のくり返しは現実には存在しない
確率は固定で変わらない1回きりの出来事（明日の試合の勝率）に確率を付けにくい
同じデータを見れば誰でも同じ答え2人の確率が違えば、どちらかが間違い
仮定（例：正規分布）が外れると結論も崩れる
set.seed(7)
sapply(c(10, 100, 10000), function(n) mean(sample(c(0, 1), n, replace = TRUE)))
[1] 0.6000 0.6100 0.5087

コインを 10回・100回・1万回投げたときの表の割合です。回数が増えるほど 0.5 に近づく、これが頻度論の「確率」です。

②

ベイズ：信念の度合い

新しい情報で確率を更新する

ベイズ（Bayesian）の考え方では、確率は「ある人が、その出来事が本当だとどのくらい信じているか」の度合いです（主観確率）。18世紀のトーマス・ベイズにちなみます。

「信念の度合い」は賭けで表せます。「このチームが勝てば 5 ドルもらえ、負ければ 5 ドル払う」賭けに乗るかどうかは、あなたが勝つ確率をどう見積もるかで決まります。90% だと思うなら喜んで乗るでしょう。

長所短所
1回きりの出来事にも確率を付けられる完全に客観的にはなれない
人によって確率が違っても合理的でいられる「誰の信念か」を決める必要がある
事前の情報を使える／新しいデータで更新できる概念も計算も（事前分布・事後分布…）初心者には難しい
機械学習など現代の応用が多い
⚖️ よく言われるまとめ：頻度論は狭すぎる（確率を付けたいものの多くを禁じる）、ベイズは広すぎる（観察者による違いを許しすぎる）。どちらが正しいというより、目的に合わせて使い分けるものです。
③

ベイズの定理を計算する

陽性なら本当に病気？
📐 ベイズの定理：P(H | D) = P(D | H) × P(H) ÷ P(D)
　H＝仮説（病気である）、D＝データ（検査が陽性）。P(H)＝事前確率、P(D | H)＝尤度、P(H | D)＝事後確率。

ある病気の有病率は 1%。検査は、病気の人の 95% を陽性と判定し、病気でない人の 5% も誤って陽性にします（架空の数値）。陽性と出た人が本当に病気である確率は？

prior <- 0.01           # P(disease)
sens  <- 0.95           # P(positive | disease)
false_pos <- 0.05       # P(positive | no disease)
p_pos <- sens * prior + false_pos * (1 - prior)   # P(positive)
posterior <- sens * prior / p_pos
round(c(p_pos = p_pos, posterior = posterior), 3)
p_pos posterior 0.059 0.161

答えは約 16%。陽性でも、本当に病気なのは6人に1人ほどです。病気の人がもともと少ない（基準率 1%）ため、健康な多数の人から出る「偽陽性」の方が多くなるのです。

# Same idea with counts: imagine 10,000 people
sick <- 10000 * 0.01; healthy <- 10000 - sick
true_pos <- sick * 0.95; false_pos_n <- healthy * 0.05
c(true_pos = true_pos, false_pos = false_pos_n, share_sick = round(true_pos / (true_pos + false_pos_n), 3))
true_pos false_pos share_sick 95.000 495.000 0.161
⚠️ 「検査の精度 95%」から「陽性なら 95% 病気」と考えるのは、P(陽性 | 病気) と P(病気 | 陽性) の取り違えです（前回の条件付き確率の注意と同じ）。基準率の無視（base rate fallacy）と呼ばれます。
④

A/B テストでの2つの見方

同じ実験、違う問い

Web サイトのボタンを A 案・B 案で無作為に出し分け、クリック率を比べるA/B テストを考えます。

頻度論のアプローチベイズのアプローチ
問い「差がない」としたら、こんなに差が出る確率は？（p 値）データを見た今、B が A より良い確率は？
事前の知識使わない過去のテスト結果などを事前分布として使う
いつ判断？あらかじめ決めたサンプルサイズまで集めるデータが集まるたびに更新できる
答えの形有意／有意でない「B が良い確率 92%」のような確率

この授業（M4〜M6）では、主に頻度論の道具（信頼区間・仮説検定・p 値）を学びます。ただし「p 値は帰無仮説が正しい確率ではない」など、ベイズの問いと混同しないことが大切です。

💻 ミニ練習：基準率を変えてみる

上の検査の例で、有病率（prior）が 10% の集団だったら、陽性の人が本当に病気である確率はいくつになるか計算してください。

prior <- 0.10
p_pos <- 0.95 * prior + 0.05 * (1 - prior)
0.95 * prior / p_pos

約 0.679（68%）。基準率が上がると、同じ検査でも陽性の信頼度が大きく上がる。

➡️ 次の講義へ：ここからは、偶然の結果を数で表す確率変数と、その分布です。次の 離散分布：一様・二項・幾何・ポアソンへ。

💡 学習のヒント

ベイズの定理は「事前 × 尤度 → 事後」。陽性でも病気とは限らないのは、病気の人がそもそも少ない（基準率が低い）から。

📊 ロジスティック回帰：モデルの評価

予測変数が1つ有意なだけでは足りません。知りたいのはモデル全体がどれだけうまく当てはまっているかです。この回では対数尤度と逸脱度（deviance）、AIC、z値を学び、ロジスティック回帰にはR² がないことも確認します。

①

対数尤度と逸脱度（deviance）

モデル全体の当てはまりを測る

線形回帰では、観測値と予測値を比べて当てはまりを見ました（残差平方和など）。ロジスティック回帰で同じ役目をするのが対数尤度（log likelihood, LL）です。式は覚えなくて大丈夫。「モデルの予測が、観測された結果とどれだけ近いか」を測る、残差平方和の仲間だと考えてください。

💡 対数尤度は大きい（0 に近い）ほど当てはまりが良く、小さい（大きなマイナス）ほど悪い値です。そこで扱いやすいように −2 倍して、小さいほど良い値にしたものが次の「逸脱度」です。

逸脱度（deviance）とは −2 × 対数尤度（−2LL） のこと。実はもう summary() の出力で見ています。

library(AppliedPredictiveModeling)
data(abalone)
AB2 <- abalone[abalone$Type != "I", ]    # M と F だけ
AB2$Type <- droplevels(AB2$Type)         # M = 1, F = 0

model1 <- glm(Type ~ Diameter, family = binomial, data = AB2)
summary(model1)
Call: glm(formula = Type ~ Diameter, family = binomial, data = AB2) Coefficients: Estimate Std. Error z value Pr(>|z|) (Intercept) 1.2891 0.2229 5.782 7.37e-09 *** Diameter -2.5332 0.4902 -5.168 2.37e-07 *** --- Signif. codes: 0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1 (Dispersion parameter for binomial family taken to be 1) Null deviance: 3912.9 on 2834 degrees of freedom Residual deviance: 3885.6 on 2833 degrees of freedom AIC: 3889.6 Number of Fisher Scoring iterations: 4
  • Null deviance（3912.9）：定数項（切片）だけのモデル、つまり予測変数が1つもないときの逸脱度。
  • Residual deviance（3885.6）：Diameter を入れたモデルの逸脱度。

これが、summary() の既定の出力で「モデルの当てはまり」を見せてくれる主な値です。予測変数を足してうまくいったなら、Residual deviance は Null deviance より小さくなります（ここでは 3912.9 → 3885.6）。

画面の数字を眺めるだけでなく、中身を取り出して使いたいときは attributes() でモデルオブジェクトの中身を確認します。

attributes(model1)
$names [1] "coefficients" "residuals" "fitted.values" [4] "effects" "R" "rank" [7] "qr" "family" "linear.predictors" [10] "deviance" "aic" "null.deviance" [13] "iter" "weights" "prior.weights" [16] "df.residual" "df.null" "y" [19] "converged" "boundary" "model" [22] "call" "formula" "terms" [25] "data" "offset" "control" [28] "method" "contrasts" "xlevels" $class [1] "glm" "lm"

必要な値は、いつもの $ で取り出せます。summary() では 3912.9 と丸められていた Null deviance も、小数点以下まで見られます。

model1$null.deviance    # 定数項だけのモデルの逸脱度
model1$deviance         # Diameter を入れたモデルの逸脱度（Residual deviance）
[1] 3912.899 [1] 3885.57
🍎 かんたん説明

逸脱度は「予測のはずれ具合」の点数で、小さいほど良い。Null deviance は「予測変数なし」のときの点数、Residual deviance は「予測変数を入れた」ときの点数です。入れて点数が下がれば、役に立っています。

💻 ミニ練習：対数尤度から逸脱度を求める

model1 の対数尤度 logLik(model1) を使って、逸脱度（−2LL）を求める R コードを書いてください。as.numeric() で数値に変えます。

-2 * as.numeric(logLik(model1))

結果は 3885.57。model1$deviance と同じ値になります。逸脱度 = −2 × 対数尤度、の確認です。

②

逸脱度の差のカイ二乗検定

予測変数を足して良くなったか？

対数尤度に基づく統計量はカイ二乗（χ²）分布に従います。そこで、予測変数を足したことでモデルがどれだけ良くなったかを、χ² 分布で検定できます。手順は3つです。

  1. 逸脱度の差を取る：Null deviance − Residual deviance
  2. 自由度の差を取る：df.null − df.residual（足した予測変数の数）
  3. pchisq() で、その χ² 値以上になる確率（p値）を求める
chi_diff <- model1$null.deviance - model1$deviance
chi_diff
[1] 27.32896
df_diff <- model1$df.null - model1$df.residual
df_diff
[1] 1
pchisq(chi_diff, df_diff, lower.tail = FALSE)
[1] 1.716213e-07

χ² = 27.3、自由度 1、p ≈ 1.7×10⁻⁷。p値は極めて小さい。これは逸脱度の差が大きいからです。つまり「Diameter を入れたモデルは、定数項だけのモデルより有意によく当てはまる」と言えます。逸脱度は「予測変数を足すと下がる」ので、差が大きいほど改善が大きいということです。

💡 この検定は基本の基本（カイ二乗値・自由度・確率）に戻っただけです。「予測変数を1つ足しても有意に改善しないなら、それはかなりダメな予測変数」。何も入っていないモデルより、1つ入れたモデルのほうが良くなってほしいですよね。

補足（講義外）：同じ検定は anova() でも一発で出せます。

anova(model1, test = "Chisq")
Analysis of Deviance Table Model: binomial, link: logit Response: Type Terms added sequentially (first to last) Df Deviance Resid. Df Resid. Dev Pr(>Chi) NULL 2834 3912.9 Diameter 1 27.329 2833 3885.6 1.716e-07 *** --- Signif. codes: 0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
🍎 かんたん説明

「予測変数なし」と「予測変数あり」の点数（逸脱度）の差を、カイ二乗で検定します。差が大きくて p値が小さければ、「入れた意味があった」ということ。

💻 ミニ練習：逸脱度の差の p値を求める

model1 について、null.deviance と deviance の差を χ² 値、df.null と df.residual の差を自由度として、pchisq() で p値（lower.tail = FALSE）を求める R コードを書いてください。

chi_diff <- model1$null.deviance - model1$deviance
df_diff  <- model1$df.null - model1$df.residual
pchisq(chi_diff, df_diff, lower.tail = FALSE)

結果は 1.716213e-07。非常に小さいので、Diameter を入れたモデルは定数項だけのモデルより有意に良いと判断できます。

③

AIC：当てはまりとペナルティ

変数を増やすことへのコスト

重回帰で見た AIC は、ロジスティック回帰では少し違う形になります。講義では次のように説明されました。

AIC = −2 × 対数尤度（逸脱度）＋ 2k　（k = モデルのパラメータの数）

予測変数が増えると 2k のペナルティが増えます。逸脱度は予測変数を足すとほぼ必ず下がるので、これだけで比べると「たくさん入れたモデル」が常に有利になってしまいます。AIC は「足したぶんだけ罰を与える」ことで、本当に役立つ変数だけを残すための指標です。

2つのモデルで比べましょう。model1 は Diameter だけ、model2 は Rings（リング数）を足します。Rings は有意ですが、ぎりぎりです。

model2 <- glm(Type ~ Diameter + Rings, family = binomial, data = AB2)
summary(model2)$coefficients
Estimate Std. Error z value Pr(>|z|) (Intercept) 1.42619600 0.23358664 6.105640 1.023894e-09 Diameter -2.18875484 0.51913830 -4.216131 2.485300e-05 Rings -0.02666163 0.01311026 -2.033647 4.198720e-02

Rings の p値は 0.042 で、5% 水準でかろうじて有意です。このときの AIC を見てみましょう。

AIC(model1)
AIC(model2)
[1] 3889.57 [1] 3887.425
モデルパラメータ数 k逸脱度（−2LL）ペナルティ 2kAIC
model1（Diameter）23885.5743889.57
model2（Diameter + Rings）33881.42563887.425

2つの AIC はほとんど同じ（3889.6 と 3887.4）で、差は 2.1 しかありません。理由は、Rings を足して逸脱度が 4.1 下がっても、ペナルティが 2 増えて、改善のほとんどが相殺されるからです。ペナルティがなく、逸脱度だけを見ていたら、この点は見えません。

⚠️ ペナルティ（予測変数を増やすことへのコスト）こそが AIC の要点です。これまでの講義でも考えてきたように、変数を増やすことには「複雑さ」というコストがあります。AIC は小さいほど良いモデルです。
🍎 かんたん説明

AIC = 点数（逸脱度）＋ 罰金（2k）。変数を足すと点数は少し良くなるけれど罰金も増える。差し引きで得をしたモデルが勝ちです。

💻 ミニ練習：2つのモデルの AIC を比べる

AB2 で、Type を Diameter と Rings で予測するロジスティック回帰 model2 を glm() で作り、AIC() で model1 と model2 の AIC を一度に比べる R コードを書いてください。

model2 <- glm(Type ~ Diameter + Rings, family = binomial, data = AB2)
AIC(model1, model2)

AIC(model1, model2) は、df（パラメータ数 2 と 3）と AIC（3889.570 と 3887.425）を表にして返します。差は約 2.1 です。

④

R の AIC() 関数と2つの k

TA 動画の補足

この動画は、TA（ティーチングアシスタント）のロバート・プレヴァ氏による補足で、R の AIC() 関数のちょっとした落とし穴を説明しています。まず式をおさらいします。

AIC = −2 × 対数尤度 ＋ 2k

  • 式の中の k = パラメータ（変数）の数。
  • 式の中の 2 = 1パラメータあたりのペナルティ。これが標準（classical）の AIC です。

ところが R の AIC(object, k = 2) では、引数の k は「ペナルティ」であって「パラメータの数」ではありません。式の k とまったく同じ名前なので、混乱のもとです。

意味値
式の kパラメータの数R が自動で数えてくれる
R の引数 k1パラメータあたりのペナルティ既定は 2（変えなくてよい）

パラメータの数は R が自動で数えるので気にしなくて大丈夫。ペナルティの既定値は 2 で、指示がない限り変えません。Part 2 の課題でも、「classical k を使う」と指示があるので、k を書かなくて構いません。

例：nycflights13 の flights データで、到着遅れ arr_delay を、出発遅れ・飛行時間・距離で予測する線形回帰です。

library(nycflights13)
delay_reg <- lm(arr_delay ~ dep_delay + air_time + distance, data = flights)
summary(delay_reg)    # 3つの予測変数はすべて有意

AIC(delay_reg)            # 何も指定しない（k = 2 が既定）
AIC(delay_reg, k = 2)     # ペナルティ 2 を明示：同じ値
AIC(delay_reg, k = 3)     # ペナルティを 3 にすると…
[1] 2728944 [1] 2728944 [1] 2728949

普通に実行しても k = 2 と書いても 2,728,944 で同じ。ペナルティを 3 にすると 2,728,949 と、わずかに高くなります（予測変数の数は変わらないまま、ペナルティだけが増えたため）。

💡 5 増える理由：この lm のパラメータ数は、切片 1 ＋ 係数 3 ＋ 誤差の標準偏差 σ 1 で 5 個です。ペナルティを 2 から 3 に 1 増やすと、5 × 1 = 5 だけ AIC が増えます。

参考：k = log(データの行数) にすると BIC になります。たとえば abalone では次のとおりです。

AIC(model1, k = log(nrow(AB2)))   # ペナルティ = log(2835)
[1] 3901.47
⚠️ 「R の k はペナルティ」。数値を自分で指定するのは、BIC のように別のペナルティを使うときだけです。ふだんは AIC(モデル) だけで十分です。
🍎 かんたん説明

式の k は「変数の数（R が数える）」、R の引数 k は「1変数あたりの罰（既定は2）」。同じ名前で別のものなので、普段は何も指定しないで AIC(モデル) と書きます。

💻 ミニ練習：ペナルティを BIC にする

model1 の AIC() を、ペナルティを log(nrow(AB2)) に変えて（BIC として）求める R コードを書いてください。

AIC(model1, k = log(nrow(AB2)))

結果は 3901.47。R の引数 k はペナルティなので、2 の代わりに log(2835) ≈ 7.95 を渡すと BIC になります（BIC(model1) と同じ値）。

⑤

z値と、存在しない R²

個々の予測変数の評価

モデル全体の当てはまりとは別に、個々の予測変数の有意性も知りたいことがあります。重回帰では t統計量（表の Pr(>|t|)）でした。ロジスティック回帰では、基礎統計の2週目から使ってきたのと同じ z統計量を使います。

z = b ÷ SE　（係数の推定値 ÷ 標準誤差）

係数表を取り出して、手で確かめてみましょう。

summary(model1)$coefficients[, 1]           # 推定値（1列目）の全部
summary(model1)$coefficients[, 2]           # 標準誤差（2列目）の全部

b  <- summary(model1)$coefficients[2, 1]    # Diameter の推定値
se <- summary(model1)$coefficients[2, 2]    # Diameter の標準誤差
b / se
(Intercept) Diameter 1.289130 -2.533227 (Intercept) Diameter 0.2229451 0.4901950 [1] -5.167795

−5.168 は、summary() の z value（−5.168）とまったく同じです。この z値が起こる確率（Pr(>|z|) = 2.37e-07）は、標準正規分布から求めます。何かをする必要はありませんが、「推定値 ÷ 標準誤差 → z値 → その確率」という仕組みは理解しておきましょう。

ここまでは線形回帰の考え方とほとんど同じです。では R² はどうでしょう？

⚠️ ロジスティック回帰には、R² の厳密な対応物がありません。重回帰ではとても大切でしたが、ここでは「ふつうの R²」は使えません。代わりに、これまでのAIC や逸脱度（deviance）などの適合度の指標でモデルを評価します。

補足（講義外）：「疑似R²」と呼ばれる指標を計算する流儀もあります。たとえば McFadden の疑似R² は 1 − LL(モデル) ÷ LL(定数項のみ) で、ここでは約 0.007 と、とても小さい値です。ふつうの R² のようには読めないので、この授業では AIC と逸脱度を使います。

m0 <- glm(Type ~ 1, family = binomial, data = AB2)   # 定数項だけ
1 - as.numeric(logLik(model1)) / as.numeric(logLik(m0))
[1] 0.006984326

💻 ミニ練習：z値を手で計算する

model1 の Diameter について、summary(model1)$coefficients から推定値と標準誤差を取り出し、z = 推定値 ÷ 標準誤差を求める R コードを書いてください。

coefs <- summary(model1)$coefficients
coefs[2, 1] / coefs[2, 2]

結果は −5.167795。summary() の z value（−5.168）と一致します。

全体は「逸脱度（小さいほど良い）と AIC」、個々の予測変数は「z値 = b ÷ SE」。R の AIC() の k はペナルティ（既定 2）で、パラメータ数ではありません。R² は使えません。

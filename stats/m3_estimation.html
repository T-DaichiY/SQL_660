①

標本のばらつきと標準誤差（SE）・中心極限定理（CLT）

標本平均はどれくらいゆれる？

データ分析では、母集団（population）のすべてを調べられないので標本（sample）を取ります。ところが、たとえ大学の学生名簿から乱数で選んでも、たまたま特定のグループの学生が多く選ばれることがあります。つまり標本は母集団を代表している（representative）かもしれないし、していないかもしれません。しかも同じ手順でもう一度抽出すれば、ほぼ確実に別の標本になります。

だからこそ「この標本は母集団をどれくらい代表しているのか」を数で知る必要があります。伝統的な道具の1つが標準誤差（standard error, SE）です。SE は標準偏差（standard deviation, SD）と別のものですが、深く関係しています。

標本のばらつき（sampling variation）と標本分布（sampling distribution）

母平均が 10 の母集団から何度も標本を取るとします。標本平均は 10 の近くに集まりますが、ときには 5・6・7 や 13・14・15 のような値も出ます。これが標本のばらつき（sampling variation）です。現実のデータで人を取り替えれば、必ず起こる自然な現象です。

たくさんの標本の平均を求めてそれを並べると、1つの分布ができます。これが標本分布（sampling distribution）、つまり「1つの母集団から取った標本平均の分布」です。1つの標本で平均とSDを求めたのと同じことを、今度は「標本平均たち」に対して行います。

📌 標準誤差（SE）の定義：標本分布（標本平均の分布）の標準偏差。「標本平均がどれくらいばらつくか」を表す。

実際には何度も標本を取らない：中心極限定理（CLT）

現実には同じ母集団から何百回も標本を取ることはできません（お金も時間もかかり非現実的）。しかし統計学者は、標本が十分に大きいとき標本分布には決まった性質があることを見つけました。これが中心極限定理（Central Limit Theorem, CLT）です。

CLT の3つの事実（標本が十分大きいとき）意味
① 標本分布は正規分布（normal）に近い母集団が歪んでいても、標本平均の山は左右対称の釣り鐘形になる
② 標本分布の平均 ＝ 母平均 μ標本平均は、母平均を中心にばらつく（かたよらない）
③ 標本分布のSD ＝ 標準誤差 SESE ＝ σ / √n。実際は σ の代わりに標本のSD s を使って SE ＝ s / √n
SE ＝ s / √n　（s：標本の標準偏差、n：標本サイズ）

実際にシミュレーションで確かめてみましょう。右に大きく歪んだ母集団（平均 10、SD ≈ 10）から、n = 25 の標本を1万回取って平均を調べます。

set.seed(1)
pop <- rexp(100000, rate = 1/10)
c(mean(pop), sd(pop))
means <- replicate(10000, mean(sample(pop, 25)))
c(mean(means), sd(means))
sd(pop) / sqrt(25)
means100 <- replicate(10000, mean(sample(pop, 100)))
c(mean(means100), sd(means100))
x <- sample(pop, 25)
c(mean(x), sd(x), sd(x) / sqrt(25))
[1] 10.02698 10.02038 [1] 10.035030 2.008706 [1] 2.004075 [1] 10.0263301 0.9999798 [1] 9.534888 8.951860 1.790372

標本平均の分布の平均は 10.04（≈ μ = 10）、SD は 2.01。SE の式 σ/√n = 10/√25 = 2.00 とほぼ一致します。n を 100 にすると SD は 1.00（= 10/√100）まで小さくなりました。最後の行は、現実の「1回だけ取った標本」の場合で、平均 9.53、s = 8.95 から SE = 8.95/√25 = 1.79 と推定しています（標本が1つでも SE は計算できる、という点がポイントです）。

同じ母集団から n = 25 の標本を1万回取り、平均を並べると…（R のシミュレーション結果をそのまま描画）
母集団（右に歪んだ分布）
μ ≈ 10, σ ≈ 10
標本平均の分布（sampling distribution）
平均 ≈ 10.04, SD ≈ 2.01
母集団は右に大きく歪んでいるのに、標本平均の分布はほぼ左右対称の山形になり、中心は母平均 10、広がり（SD）は SE = σ/√n = 10/5 = 2 にほぼ一致します。

標準偏差 SD (s)標準誤差 SE
何のばらつき？標本の個々のデータのばらつき標本平均のばらつき
n を増やすとほぼ変わらない小さくなる（1/√n）

⚠️ 講師が強調した「覚えること」：(1) SE と CLT の定義、(2) SE の式、(3) CLT の3つの事実。SE は信頼区間などでこれから何度も出てくるが、CLT は「CLT のおかげでこれができる」とときどき顔を出す程度。深い証明までは不要だが、後で説明なしに出てくるので、今のうちに意味を押さえておこう。
💡 補足：母集団そのものが正規分布なら、標本分布は n が小さくても正規分布になります。CLT が役に立つのは、母集団が歪んでいる（上の図のような）ときでも「n が十分大きければ標本平均は正規分布に近づく」という点です。「十分大きい」の目安は母集団の形によって変わります。
🍎 かんたん説明

標本平均は取るたびにゆれる。そのゆれの大きさ（標本平均のSD）が標準誤差 SE。式は s ÷ √n。人数が多いほどゆれは小さくなる。CLT は「n が大きければ、標本平均のゆれは正規分布の形で、中心は μ、広がりは SE」という約束。

💻 ミニ練習：標準誤差を計算する

8人の小テストの得点が x <- c(12, 9, 11, 14, 10, 8, 13, 11) です。標本平均の標準誤差（SE ＝ s/√n）を、sd()・sqrt()・length() を使って求めるRコードを書いてください。

x <- c(12, 9, 11, 14, 10, 8, 13, 11)
sd(x) / sqrt(length(x))

結果は 0.7071068（s = 2、n = 8 なので 2/√8 ≈ 0.707）。length(x) で n を数える点がコツ。

②

信頼区間（CI）

1.96 × SE で範囲を作る

標準誤差と並んで、標本の正確さを調べる方法が信頼区間（confidence interval, CI）です。論文ではこちらを目にする機会がずっと多く、統計の計算の途中では SE が使われる場面が多い、と覚えておきましょう。CI は標本平均のまわりに境界を作り、「母平均はこの範囲にありそうだ」という範囲で示します。

例：GPA の研究

母集団の GPA の平均は本当は 3.0（ただし研究者には未知）。取った標本の平均は 2.75 でした。SE を計算して代表性を見るのもよいですが、「母平均はおそらく ○ と △ の間」と範囲で言えたほうが役に立ちます。では境界をどう決めるか。

  • 適当に ±0.2 とすると 2.55〜2.95。理由がないうえに、（本当の平均 3.0 を外してしまう。）
  • ±1 とすると 1.75〜3.75。広すぎて無意味（標本平均が 1.75〜3.75 に入るのは当たり前）。

そこで、z スコアで学んだ1.96を使います。

なぜ 1.96 なのか

標準正規分布（平均0、SD1）では、真ん中の 95% が −1.96 から +1.96 の間に入ります（残り 5% は両端に 2.5% ずつ）。

qnorm(0.975)
pnorm(1.96) - pnorm(-1.96)
[1] 1.959964 [1] 0.9500042

標本分布は正規分布（CLT）で、平均は μ、SD は SE でした。そこで標本平均 x̄ を標準化した値 z ＝ (x̄ − μ) / SE は標準正規分布に従います。したがって

−1.96 ≤ (x̄ − μ) / SE ≤ 1.96 となる確率が約 95%
⇒ x̄ − 1.96 × SE ≤ μ ≤ x̄ + 1.96 × SE
95% CI ＝ x̄ ± 1.96 × SE

z スコアの式では分母が「個々のデータのSD」ですが、ここで見たいのは標本平均のばらつきなので、SD の代わりに SE を使います。これが CI の式のポイントです。

GPA の例で計算します。標本の n = 36、s = 0.6 とすると SE = 0.6/√36 = 0.1 なので、

qnorm(0.975)
pnorm(1.96) - pnorm(-1.96)
xbar <- 2.75; s <- 0.6; n <- 36
se <- s / sqrt(n)
se
xbar + c(-1, 1) * 1.96 * se
2 * 1.96 * 0.6 / sqrt(c(9, 36, 144))
set.seed(1)
mean(replicate(10000, {
  xb <- mean(rnorm(36, mean = 3, sd = 0.6))
  abs(xb - 3) <= 1.96 * 0.1
}))
[1] 1.959964 [1] 0.9500042 [1] 0.1 [1] 2.554 2.946 [1] 0.784 0.392 0.196 [1] 0.9506

95% CI は [2.554, 2.946]（上限 2.75 ＋ 0.196、下限 2.75 − 0.196）。この1回の標本では、区間が真の平均 3.0 を含んでいません。これは異常ではなく、95% の手順でも約 5% は外れる、ということです（次の図）。コードの最後の行は、「σ = 0.6, n = 36 の母集団から1万回標本を取って 95% CI を作ると、約 95% が μ を含む」ことの確認です（結果 0.9506）。

同じ母集団から20回標本を取って作った20本の95%信頼区間（n = 36, σ = 0.6, SE = 0.1）
点が各標本の平均、線が x̄ ± 1.96×SE。破線が本当の母平均 3.0。20本中19本が3.0を含み、赤い1本（10番目）だけが外れました。長い目で見ると約95%が含み、約5%が外れる——これが「95%信頼区間」の意味です。

95% 信頼区間の正しい読み方

正しい読み方よくある誤解
「同じ方法で標本を取って区間を作る作業を何度も繰り返すと、そのうち約 95% の区間が母平均を含む」。95% は手順の長期的な成功率。「この区間に母平均が入っている確率が 95%」「個々のデータの 95% がこの範囲に入る」「標本平均の 95% がこの範囲に入る」

母平均 μ は未知でも決まった1つの値です。手元の1本の区間は、μ を含むか含まないかのどちらか。ゆれているのは区間のほう（標本によって変わる）です。「95% の確信（confidence）」とは、この方法をうまく使えている自信と読みます。

区間の幅から何が分かるか

  • 区間が狭い → 標本平均が母平均の近くにあると期待でき、推定の精度が高い（標本が代表的）。
  • 区間が広い → 精度が低い、確信が持ちにくい。
  • 幅は 2 × 1.96 × s/√n。n を 4 倍にすると幅は半分になる。
📊 幅の例（s = 0.6）：n = 9 → 0.784、n = 36 → 0.392、n = 144 → 0.196（コードの 2 * 1.96 * 0.6 / sqrt(c(9, 36, 144)) の出力）。
⚠️ 注意：ここでは母集団のSDが分かっている（または n が十分大きい）として z = 1.96 を使いました。実際には s で σ を推定するので、n が小さいときは 1.96 より少し大きな t 値を使います（次のレッスン「t 分布」で扱います）。なお z = 1.96 は 95% の場合の値で、90% や 99% ならこの数は変わります。
🍎 かんたん説明

CI は「標本平均 ± 1.96 × SE」。1.96 は正規分布の真ん中 95% を囲む数。区間が狭いほどくわしく分かっている。「95%」は、同じやり方を何度も繰り返したとき約 95% の区間が本当の平均をつかまえる、という意味。

💻 ミニ練習：95%信頼区間を計算する

標本平均 xbar <- 3.10、標本のSD s <- 0.8、n <- 64 のとき、qnorm(0.975) を使って 95% 信頼区間（下限と上限）を求めるRコードを書いてください。

xbar <- 3.10; s <- 0.8; n <- 64
se <- s / sqrt(n)
xbar + c(-1, 1) * qnorm(0.975) * se

SE ＝ 0.8/8 ＝ 0.1。結果は 2.904 と 3.296（下限 2.904、上限 3.296）。c(-1, 1) で下限と上限を一度に出せる。

③

効果量（effect size）

p 値だけでは分からないこと

仮説検定でわかるのは「効果があるかどうか」だけです。効果がどれくらい大きいかや、それが重要かどうかは、p 値からはわかりません。さらに、p 値は標本サイズ nに強く左右されます。

n が大きいと「有意」になりやすい

2群の t 検定の式を見ると、n₁・n₂ は分母側にあります。

t ＝ (x̄₁ − x̄₂) / ( sp × √(1/n₁ + 1/n₂) )　（sp：2群をまとめた標準偏差）

平均の差とばらつきが同じでも、n が増えると分母が小さくなり、t が大きく（p が小さく）なります。実際に確かめてみましょう（1群あたり n、平均の差 2、SD 10）。

tt <- function(diff, sd, n) {
  t <- diff / (sd * sqrt(2 / n))
  df <- 2 * n - 2
  round(c(d = diff / sd, t = t, df = df, p = 2 * pt(-abs(t), df)), 4)
}
tt(2, 10, 20)
tt(2, 10, 80)
tt(2, 10, 500)
tt(8, 10, 12)
d <- c(0.2, 0.5, 0.8)
round(d / sqrt(d^2 + 4), 3)

どの行も「平均の差 2、SD 10」という同じ状況ですが、n を増やしただけで p が 0.66 から 0.0016 に変わりました。一方、右から2列目の効果の大きさ d は 0.2 のままです。

⚠️ p-hacking に注意：効果が見つからなかったときに、有意になるまで参加者を足し続けるのはやってはいけません。それは「重要だ」という幻想を作っているだけです。n に左右されにくい指標が必要で、それが効果量です。

効果量（effect size）とは

効果量は「効果の大きさ」を表す標準化された指標です。単位に依存しないので、研究どうしを比べられます。代表的なものは次の3つ。

  • Cohen's d：平均の差を SD で割った値（2群の比較）。d ＝ (x̄₁ − x̄₂) / sp。
  • Pearson's r：相関係数。
  • オッズ比（odds ratio）：2値の結果（あり／なし）の比較。

目安（ベンチマーク）：d と r は別のものさし

効果量small（小）medium（中）large（大）
Cohen's d0.20.50.8
Pearson's r0.10.30.5

d と r は同じ数字でも意味が違います。たとえば d ＝ 0.5（中）は、等しいサイズの2群なら r ≒ 0.24 に相当します（r ＝ d/√(d²＋4)）。

d <- c(0.2, 0.5, 0.8)
round(d / sqrt(d^2 + 4), 3)
[1] 0.100 0.243 0.371

つまり d ＝ 0.2, 0.5, 0.8 は r にすると約 0.10, 0.24, 0.37。「0.3 や 0.5」を d の目安として使うのは誤りです。なお、これらの目安自体にも疑問が出されています。講師の方針は「効果量の数値を報告して、判断は読む人に任せる」（効果量自身に語らせる）です。

p 値の大小は「重要度」ではない

  • p ＝ 0.01 は p ＝ 0.02 より「重要」とは限らない。
  • p ＝ 0.06（有意でない）でも、人数が足りないだけで効果量はむしろ大きいことがある。
tt(8, 10, 12)   # 平均の差8、SD10、1群n=12
d t df p 0.8000 1.9596 22.0000 0.0628

この研究は p ＝ 0.063 で有意ではありませんが、d ＝ 0.8（大）です。逆に先ほどの n ＝ 500 の研究は p ＝ 0.0016 で「高度に有意」ですが d ＝ 0.2（小）。「有意だから重要」と言われたら、「それで、効果量は？（What's the effect size?）」と返しましょう。

🍎 かんたん説明

p 値は「差があるかも？」の目安、効果量は「差はどれくらい大きい？」のものさし。p 値は人数を増やすと小さくなってしまうが、効果量は人数にあまり左右されない。d の目安は 0.2/0.5/0.8、r の目安は 0.1/0.3/0.5（別物！）。

💻 ミニ練習：t 値と p 値を計算する

1群あたり n <- 40、平均の差 5、SD 10 の2標本 t 検定について、t ＝ 差 / (SD × √(2/n))、自由度 df ＝ 2n − 2、両側 p 値（pt() を使う）を求めるRコードを書いてください。

n <- 40
t <- 5 / (10 * sqrt(2 / n))
df <- 2 * n - 2
t
2 * pt(-abs(t), df)

t ≈ 2.2361、df ＝ 78、両側 p ≈ 0.0282。このとき d ＝ 5/10 ＝ 0.5（中）。n を 10 にすると有意でなくなる点を、上の表と比べて確認しよう。

④

検出力（power）

見つけたい効果を見つけられる確率

効果量・標本サイズ・有意水準・検出力は、互いにつながっています。ここで重要になるのが検出力（statistical power）です。

検出力（power）とは

検出力は、「本当に効果があるとき、それを検出できる確率」です。前のレッスン（仮説検定の考え方）の言葉でいうと、検出力 ＝ 1 − β（β は第二種過誤、本当は効果があるのに見逃す確率）です。慣習としては 0.8（Cohen の推奨）が使われますが、この値には議論もあります。

4つの量：3つ決まれば残り1つが決まる

量意味
効果量（effect size）見つけたい効果の大きさ（例：d）
標本サイズ n集める人数
有意水準 α（alpha）本当は効果がないのに「ある」と言ってしまう確率の上限（慣習 0.05）
検出力（power）本当にある効果を見つける確率（慣習 0.8）

この4つのうち3つが分かれば、残り1つが計算できます。たとえば「効果量・α・検出力から必要な n」を求めるのが検出力分析（power analysis）です。R では power.t.test()（2標本 t 検定）を使います。調べたい量だけ省いて（NULL にして）渡します。

power.t.test(delta = 0.5, sd = 1, sig.level = 0.05, power = 0.8)
Two-sample t test power calculation n = 63.76576 delta = 0.5 sd = 1 sig.level = 0.05 power = 0.8 alternative = two.sided NOTE: n is number in *each* group

delta は平均の差、sd は SD なので、sd = 1 と置くと delta がそのまま Cohen's d になります。d ＝ 0.5 の効果を α ＝ 0.05 で 80% の確率で見つけるには、1群あたり 64 人（63.77 を切り上げ）必要です。

効果量が小さいほど、たくさんの人が必要

効果量 d目安必要な n（1群、α＝0.05、power＝0.8）
0.2small394（393.4）
0.5medium64（63.8）
0.8large26（25.5）
power.t.test(n = 20, delta = 0.5, sd = 1, sig.level = 0.05)$power

[1] 0.3377084 [1] 393.4067 [1] 25.52463 [1] 0.585251

n ＝ 20 では d ＝ 0.5 の効果を見つける確率は 34% にすぎず、「効果を見逃しやすい（underpowered）」状態です。同じ n ＝ 64 でも、α を 0.01 に厳しくすると検出力は 0.80 から 0.59 に下がります（α・検出力・n・効果量の関係の例）。

効果量 d = 0.5, α = 0.05（両側）の2標本 t 検定：n と検出力
n を増やすほど検出力は上がる。0.8 に届くのは n ≈ 64（1群あたり）あたり。数値は power.t.test(n = ..., delta = 0.5, sd = 1) の結果です。
⚠️ この回のまとめ（講師の主張）：(1) 有意性（significance）は、現代の統計ではささいな要素の1つ。(2) 効果量を、検出力・標本サイズとあわせて見る、成熟した理解が必要。「有意だから重要」と言うと、これから多くの間違いをする。
💡 検出力不足の研究で「有意でなかった」ことは、「効果がない」ことの証明にはなりません。n を決める前に検出力分析をしておく（後から n を足さない）のが、p-hacking を避ける正しい順番です。
🍎 かんたん説明

検出力は「本当にある効果を、ちゃんと見つけられる確率」。0.8 が目安。効果量・人数 n・α・検出力のうち3つが決まれば残り1つが決まる。小さな効果を見つけたいなら、たくさんの人が必要。

💻 ミニ練習：必要な標本サイズを求める

効果量 d ＝ 0.8（大）の差を、α ＝ 0.05・検出力 0.8 で検出するのに必要な1群あたりの人数を、power.t.test() で求めるRコードを書いてください（sd = 1 とする）。

power.t.test(delta = 0.8, sd = 1, sig.level = 0.05, power = 0.8)

結果は n ＝ 25.52463。人数は整数なので1群あたり 26 人に切り上げる（n ＝ 26 での検出力は 0.807）。

sampling variation
標本のばらつき
同じ母集団から標本を取るたびに、標本平均が変わる自然なゆれ。
sampling distribution
標本分布
1つの母集団から取った多数の標本平均の分布。
standard error (SE)
標準誤差
標本分布のSD。標本平均のゆれの大きさ。SE ＝ s/√n。
Central Limit Theorem (CLT)
中心極限定理
n が十分大きいとき、標本分布は正規分布・平均＝μ・SD＝SE。
confidence interval (CI)
信頼区間
標本平均 ± 1.96×SE（95%）。母平均がありそうな範囲を示す。
confidence level
信頼水準
手順の長期的な成功率（例：95%）。1本の区間が当たる確率ではない。
z = 1.96
臨界値
標準正規分布の真ん中95%を囲む境界（qnorm(0.975)）。
effect size
効果量
効果の大きさの標準化指標（Cohen's d, r, odds ratio）。nに左右されにくい。
Cohen's d
コーエンのd
平均の差÷SD。目安 0.2/0.5/0.8（小/中/大）。
Pearson's r
ピアソンの相関係数
効果量としての目安は 0.1/0.3/0.5（小/中/大）。d とは別。
statistical power
検出力
本当にある効果を検出する確率 ＝ 1 − β。慣習 0.8。
p-hacking
p値ハッキング
有意になるまでデータを足すなど、見かけの有意性を作る行為。

💡 学習のヒント

SE ＝ s/√n、95% CI ＝ x̄ ± 1.96×SE、CLT の3事実（正規・平均＝μ・SD＝SE）を暗記。効果量の目安は d：0.2/0.5/0.8、r：0.1/0.3/0.5 と別々に覚える。95% CI は「方法の成功率」と読む。

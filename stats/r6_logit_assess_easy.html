①

逸脱度（deviance）

予測のはずれ具合の点数

🎯 これだけ覚えればOK

逸脱度（deviance）= −2 × 対数尤度。小さいほど良い。Null deviance は「予測変数なし」、Residual deviance は「予測変数あり」の点数。

📉
逸脱度は「予測のはずれ具合」の点数。低いほど、予測が観測に近い。

summary(model1) の下のほうに、もう点数が出ています。

名前意味値
Null deviance定数項だけ（予測変数なし）3912.9
Residual devianceDiameter を入れたモデル3885.6

3912.9 → 3885.6 と点数が下がったので、Diameter を入れる意味がありそうです。中身は $ で取り出せます。

model1$null.deviance
model1$deviance
[1] 3912.899 [1] 3885.57
🍎 ひとことで

入れる前の点数（Null）より、入れたあとの点数（Residual）が低ければ、予測変数は役に立っています。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 逸脱度は何の何倍？A. 対数尤度の −2 倍（−2LL）。
Q2. 逸脱度は大きいほうが良い？小さいほうが良い？A. 小さいほうが良い。
Q3. Null deviance は何のモデル？A. 予測変数が1つもない（定数項だけの）モデル。
②

点数の差を検定する

カイ二乗検定

🎯 これだけ覚えればOK

逸脱度の差 = 27.3、自由度の差 = 1。pchisq(差, 自由度, lower.tail = FALSE) で p値 = 1.7e-7 → Diameter は有意に改善した。

🧪
「点数の下がり方」が偶然でないかをカイ二乗で調べる。
chi_diff <- model1$null.deviance - model1$deviance   # 27.32896
df_diff  <- model1$df.null - model1$df.residual      # 1
pchisq(chi_diff, df_diff, lower.tail = FALSE)
[1] 1.716213e-07
👍
p ≈ 1.7×10⁻⁷ とても小さい → Diameter を入れたモデルは、入れないモデルより有意によく当てはまる。

1つ足しても有意に良くならない予測変数は、かなりダメな予測変数です。

🍎 ひとことで

「点数が下がった差」が大きくて、p値が小さければ、入れた意味があった、ということです。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 差が大きいと p値はどうなる？A. 小さくなる（有意に改善した）。
Q2. 自由度の差はどう求める？A. df.null − df.residual（足した変数の数）。
Q3. この例の結論は？A. Diameter を入れたモデルは定数項だけのモデルより有意に良い。
③

AIC：点数＋罰金

変数を増やすコスト

🎯 これだけ覚えればOK

AIC = −2LL + 2k。変数を増やすとペナルティが増える。小さいほど良い。R の AIC() の引数 k は「ペナルティ」（既定 2）。

⚖️
AIC = 点数（逸脱度）＋ 罰金（2k）。変数を足すと点数は良くなるが、罰金も増える。
モデルk逸脱度罰金 2kAIC
model1（Diameter）23885.5743889.57
model2（+ Rings）33881.42563887.425
AIC(model1)
AIC(model2)
[1] 3889.57 [1] 3887.425

Rings はぎりぎり有意（p = 0.042）で、AIC はほとんど変わりません（差 2.1）。罰金が改善をほぼ打ち消すからです。

⚠️ 2つの k に注意：式の k は「パラメータの数」（R が自動で数える）。R の AIC(model, k = 2) の k は「1つあたりのペナルティ」で、既定は 2。普段は書かなくてOK。AIC(delay_reg, k = 3) にすると、2,728,944 が 2,728,949 になります。
🍎 ひとことで

AIC は「点数＋罰金」。小さいほど良いモデル。罰金のおかげで、役に立たない変数を入れすぎるのを防げます。

🤔 答えられるかな？（クリックで答えが開く）

Q1. AIC の式は？A. −2 × 対数尤度 ＋ 2k（k = パラメータの数）。
Q2. 変数を足すと AIC のペナルティはどうなる？A. 増える（2k が大きくなる）。
Q3. R の AIC(model, k = 2) の k は何？A. パラメータの数ではなく、1つあたりのペナルティ（既定は 2）。
④

z値と、無い R²

1つ1つの変数の評価

🎯 これだけ覚えればOK

個々の予測変数は z = 推定値 ÷ 標準誤差。ロジスティック回帰に R² は無いので、AIC と逸脱度を使う。

➗
z = b ÷ SE。Diameter なら −2.5332 ÷ 0.4902 = −5.168。
b  <- summary(model1)$coefficients[2, 1]
se <- summary(model1)$coefficients[2, 2]
b / se
[1] -5.167795

これは summary() の z value（−5.168）と同じです。p値（2.37e-07）は標準正規分布から求めます。

🚫
ロジスティック回帰には、ふつうの R² がありません。モデルの良さは、逸脱度と AIC で見ます。

R²（無い）
🍎 ひとことで

全体は「逸脱度とAIC」、1つ1つは「z値」。R² は使えません。

🤔 答えられるかな？（クリックで答えが開く）

Q1. z値の計算式は？A. 推定値 ÷ 標準誤差（b ÷ SE）。
Q2. Diameter の z値は？A. −2.5332 ÷ 0.4902 ≒ −5.168。
Q3. ロジスティック回帰で R² の代わりに何を使う？A. AIC と逸脱度（deviance）。

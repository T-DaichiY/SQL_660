切片と傾きの意味

予測の言葉で読む

🎯 これだけ覚えればOK

ŷ = 51.8 + 3.9x。傾き＝x が 1 増えると y は 3.9 増えると予測。切片＝x が 0 のときの予測値。

📈
傾き 3.91 → largest gift（いちばん大きい寄付）が $1 増えるごとに、total giving（寄付の合計）は $3.91 増えると予測する。
📍
切片 51.82 → largest gift が $0 の人の予測 total giving は $51.82。（この例では意味はあまりないけれど、直線に必要）
⚠️ 「予測する」と書くのを忘れずに。「増えます」と言い切ると満点にならない（直線はあくまで予測だから）。
⚠️ 外挿（extrapolation）：データは largest gift が約 $5〜$150 の範囲だけ。$5,000 を予測すると 19,599.86 と計算できるけれど、そんな遠くまで直線が続くかは分からないので信用できません。
🍎 かんたん説明

傾きは「1 増えたらどれだけ変わる？」、切片は「ゼロのときの値」。体重 0 ポンドで心拍数 −57 のように、切片が変な数になることもあります。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 傾き 3.91 を正しく言うと？A. largest gift が $1 増えるごとに total giving は $3.91 増えると予測する。
Q2. 切片が意味を持たないことがあるのはなぜ？A. x = 0 が現実にありえない（または観測範囲の外）ことがあるから。でも直線には必要。
Q3. データが $5〜$150 なのに $5,000 を予測すると？A. 外挿。計算はできるが、直線が続くとは限らないので気をつける。
②

残差プロットで見るモデルの妥当性

形を見るだけ

🎯 これだけ覚えればOK

残差プロットが「曲がっている」か「扇形」→ ダメ。「ランダム」→ OK。

🔍
残差プロット＝残差（実測 − 予測）を縦軸にした図。赤い線 0 が「回帰直線」の代わり。
形判断
曲線（U字など）× 線形モデルは不適切
扇形（fanning out / in）× 不適切（誤差が一定でない）
ランダム○ 適切

例1（検索順位 position とクリック率 rate の10点）は、左端が上・真ん中が下・右端が上のU字。曲線なので、直線では合っていません。例2（寄付者の total giving と largest gift）は扇形に広がるので、これも不適切。例3（年齢と largest gift）はランダムですが、外れ値は調べる必要があります。

rate_model <- lm(rate ~ position)
plot(position, rate_model$residuals, pch = 16)
abline(h = 0, col = "red", lwd = 2)
残差プロットの3つの見え方（すべて講義の実データ）
曲線パターン
→ 線形モデルは不適切
扇形（fanning out）
→ 不適切
ランダム散布
→ 適切（外れ値は要調査）
左：例1（position vs rate）。中：例2（largestGiftAmount vs totalGivingAmount）。右：例3（age → largestGiftAmount のモデル、横軸は予測値）。
🍎 かんたん説明

模様（パターン）が残っていたら、モデルが説明しきれていない証拠。別のモデル（二次モデルなど曲線のモデル）を試します。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 残差プロットが曲がっていたら？A. 線形モデルは不適切。曲線のモデルを検討する。
Q2. 良い残差プロットは？A. 曲がりも扇形もない、ランダムな散らばり。
Q3. 「fanning out」とは？A. xが大きくなるほど点が直線から遠く広がること。
③

R² = 説明できた変動の割合

0〜1、大きいほど良い

🎯 これだけ覚えればOK

R² = 1 − SSE / SST。「平均で予測するより、直線で予測すると誤差が何割減るか」。

🎯
donors の例：SST（平均で予測）＝ 1,407,256、SSE（直線で予測）＝ 925,380。
R² ＝ 1 − 925,380 / 1,407,256 ＝ 0.34（約34%）
誤差の二乗和：平均で予測（SST）と直線で予測（SSE）
緑の破線の部分が「直線を使ったことで減った誤差」。SST に対する割合が R² です。

言い方の型：「largest gift を使った最小二乗直線は、total giving の変動の 34% を説明する」。R² は 0〜1 で、大きいほど良いモデル。

⚠️ 単回帰（説明変数が1つ）では R² ＝ r²。r = 0.585 なので r² ≈ 0.34。でも意味は違う：r は関連の強さと向き、R² は減った誤差の割合です。
summary(model)$r.squared
cor(sampleDonors$largestGiftAmount, sampleDonors$totalGivingAmount)^2
[1] 0.3424222 [1] 0.3424222
🍎 かんたん説明

残差プロット＝「このモデルでいい？」／R² ＝「そのモデルはどれだけ当たる？」。例1の position モデルは R² ＝ 0.8144（81%）で、donors のモデル（34%）よりずっと当たります。

🤔 答えられるかな？（クリックで答えが開く）

Q1. R² = 0.34 の意味は？A. 直線を使うと、平均で予測するより誤差が約34%減る（変動の34%を説明する）。
Q2. r = 0.585 のとき、単回帰の R² は？A. 0.585² ≈ 0.34。
Q3. R² は負になる？A. ならない。二乗なので 0 以上 1 以下。

💡 まとめ

• 傾き：x が 1 増えると y は b₁ 増えると予測

• 切片：x = 0 のときの予測値

• 曲線・扇形の残差 → 不適切、ランダム → 適切

• R² ＝ 1 − SSE/SST（単回帰では r²）

🍎 超やさしい版：χ²①（適合度検定）

「数えた人数は、『こうなるはず』にちかい？」を、χ²という1つの数で調べます。

①

準備：何を比べる？

「こうなるはず」と「実際」

🎯 これだけ覚えればOK

カテゴリごとの人数を数えて、「こうなるはず」の人数（期待度数）と比べる。これが適合度検定（GOF）。

🏒
NHL選手80人の誕生日を四半期で数えたら、32, 20, 16, 12 人。
もし誕生日が均等なら、どの四半期も 80 ÷ 4 = 20人のはず。
言葉この例
H₀何も起きていない誕生日は4つの四半期で均等（各25%）
Hₐどれかがちがう均等ではない
期待度数 En × p80 × 0.25 = 20

使う条件は3つ：無作為抽出、期待度数がすべて5以上、独立（母集団が標本の10倍より多い）。

observed <- c(32, 20, 16, 12)
expected <- c(20, 20, 20, 20)
🍎 ひとことで

t検定やANOVAは「数値」用。人数を数えるカテゴリにはχ²適合度検定を使います。

🤔 答えられるかな？（クリックで答えが開く）

Q1. この例のH₀は？A. 誕生日は4つの四半期で均等（各25%）。
Q2. 期待度数20はどう計算した？A. 80人 × 0.25 = 20。
Q3. 期待度数の条件は？A. すべて5以上であること。
②

χ²を計算する

ズレを1つの数にまとめる

🎯 これだけ覚えればOK

χ² = Σ (観測 − 期待)² ÷ 期待　ズレが大きいほど χ² が大きくなる。

やることは4つ：引く → 2乗する → 期待で割る → 全部足す。

sum((observed - expected)^2 / expected)
[1] 11.2

🤔
なぜ期待で割る？
期待10で観測0は大事件。期待1000で観測990はほぼ誤差。同じ差10でも、驚きの大きさがちがうから。
🍎 ひとことで

11.2 が χ² 検定統計量。Q1（32人）のズレがいちばん大きい（7.2）。

🤔 答えられるかな？（クリックで答えが開く）

Q1. χ²を作る手順は？A. 引く → 2乗 → 期待で割る → 足す。
Q2. どの四半期がいちばんχ²を大きくした？A. Q1（寄与7.2）。
Q3. 期待どおりだとχ²は？A. 0に近い。
③

p値と結論

自由度 df = k − 1

🎯 これだけ覚えればOK

p値 = χ²分布の「右側」の面積。Rでは pchisq(..., lower.tail = FALSE)。

自由度はカテゴリ数 − 1。四半期は4つなので df = 3（標本サイズではない！）。

pchisq(q = 11.2, df = 3, lower.tail = FALSE)
[1] 0.01069213
📏
p ≈ 0.0107（約1%）。α = 0.05 より小さい → H₀を棄却。
「NHL選手の誕生日は均等ではないという証拠がある」
⚠️ lower.tail = FALSE を忘れない。「証明」とは言わず「証拠」と言う。

Rの関数にまかせるなら、度数ではなく元データを渡します（rep() で復元）。

nhl_data <- c(rep("Q1", 32), rep("Q2", 20), rep("Q3", 16), rep("Q4", 12))
lsr::goodnessOfFitTest(as.factor(nhl_data), p = rep(0.25, 4))
(出力の要点) X-squared statistic: 11.2 degrees of freedom: 3 p-value: 0.011
🍎 ひとことで

結論は3点：pとαの比較 → H₀を棄却するか → 対立仮説の証拠。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 12か月で比べるときの自由度は？A. 12 − 1 = 11。
Q2. p値が0.0107。どう解釈する？A. H₀が正しいなら、今回以上に極端なデータが偶然で出る確率が約1%。
Q3. 「証明された」と書いてよい？A. だめ。「説得力のある証拠がある」と書く。
④

例2：広告の人種の割合

国勢調査と同じ？（α = 0.01）

🎯 これだけ覚えればOK

確率が全部25%とは限らない。この例のH₀の確率は国勢調査の割合 0.177, 0.032, 0.734, 0.057。

observed <- c(57, 11, 330, 6)       # n = 404
null_p   <- c(0.177, 0.032, 0.734, 0.057)
expected <- sum(observed) * null_p
expected
sum((observed - expected)^2 / expected)
pchisq(19.599, df = 3, lower.tail = FALSE)
[1] 71.508 12.928 296.536 23.028 [1] 19.59872 [1] 0.0002055213
📺
χ² = 19.599、df = 3、p ≈ 0.0002 < 0.01 → H₀を棄却。
広告の人種の割合は国勢調査とちがうという証拠がある。

🍎 ひとことで

いちばんχ²に効いたのはヒスパニック。期待23人なのに観測は6人しかいなかった。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 期待度数はどう出す？A. 404 × 各確率（例：404 × 0.177 = 71.5）。
Q2. どの人種の寄与が最大？A. ヒスパニック（12.59）。期待より少ない。
Q3. 10%ルールで母集団は何人より多いと仮定する？A. 4,040人（10 × 404）。

💡 まとめ

• E = n × p、条件は「無作為・E≥5・独立」

• χ² = Σ (O − E)² / E

• df = カテゴリ数 − 1

• p値は右側：lower.tail = FALSE

• 「証明」ではなく「証拠」

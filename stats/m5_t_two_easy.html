2標本の区間と自由度

差 ± t*×SE

🎯 これだけ覚えればOK

2つのグループの平均の差は「差 ± t* × SE」。自由度は Welch が一番正確。データがあれば t.test() が全部やってくれる。

👶
男の子と女の子の平均の長さに差はある？→ 知りたいのは μ₁ − μ₂。引く順番はどちらでもOK、そろえればいい。
自由度の考え方値の例 (n=10, 20)
lower（小さい方 −1）9
upper（n₁+n₂−2）28
Welch（いちばん正確）この間のどこか
welch_df(10, 15, 4.5, 3.2)
[1] 14.99542
🍎 かんたん説明

自由度が小さいと t* は大きくなる（慎重になる）。Welch はちょうどよい値。生データがあれば t.test()、要約値だけのときだけ手計算。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 2標本の SE の式は？A. √( s₁²/n₁ + s₂²/n₂ )
Q2. n₁=10, n₂=15 の lower と upper は？A. lower 9、upper 23。Welch は 14.995。
Q3. 手計算が必要なのはいつ？A. 生データがなく、n・x̄・s の要約しかないとき。

小麦価格の区間

9月 − 7月

🎯 これだけ覚えればOK

小麦の例：9月 − 7月 の 99% 信頼区間は (0.56, 0.76) ドル。0 が入っていないので「差がある」。

月n平均s
9月453.610.19
7月902.950.22
wheat_stat <- 3.61 - 2.95
wheat_df   <- welch_df(45, 90, 0.19, 0.22)
wheat_SE   <- sqrt(0.19^2 / 45 + 0.22^2 / 90)
t_crit     <- qt(1 - 0.01 / 2, df = wheat_df)
wheat_ME   <- t_crit * wheat_SE
c(wheat_stat - wheat_ME, wheat_stat + wheat_ME)
[1] 0.5638849 0.7561151
✅
差 0.66 ± 0.096 ＝ (0.56, 0.76) → 0 を含まない → 9月の方が高いという証拠あり
⚠️ 区間が (−0.20, 0.30) のように 0 を含むなら「差があるとは言えない」。順序を逆にすると符号がひっくり返るだけです。
🍎 かんたん説明

手順は ①差 ②df ③SE ④t* ⑤ME ⑥差 ± ME。99% のときは qt(1 - 0.01/2, df)。

🤔 答えられるかな？（クリックで答えが開く）

Q1. この区間は何と何の差？A. 9月 − 7月 の母平均価格の差。
Q2. 0 が区間に入っていなければ？A. 差がある（説得力のある証拠）。
Q3. 99% の臨界値は qt の中身をどうする？A. 1 − 0.01/2 = 0.995。

2標本の検定

出生体重と喫煙

🎯 これだけ覚えればOK

喫煙／非喫煙の母親の出生体重：p = 0.0002075 < 0.05 → H₀ を棄却 → 差がある証拠あり。

weights_non   <- subset(births$weight, births$habit == "nonsmoker")
weights_smoke <- subset(births$weight, births$habit == "smoker")
t.test(weights_non, weights_smoke)
Welch Two Sample t-test data: weights_non and weights_smoke t = 3.8166, df = 131.31, p-value = 0.0002075 alternative hypothesis: true difference in means is not equal to 0 95 percent confidence interval: 0.2854852 0.8998751 sample estimates: mean of x mean of y 7.269873 6.677193
🔍
差は約 0.59 ポンド。「差がない」と仮定して、こんな差が偶然出る確率は 約 0.02%。ほぼありえない → 本当に差がありそう。
結論の3点このデータでは
① p と α を比べる0.0002075 < 0.05
② H₀ をどうする棄却する
③ 文脈つきで言う母平均の出生体重に差があるという説得力のある証拠
numerator   <- 7.27 - 6.68        # 0.59
denominator <- sqrt(1.23^2 / 867 + 1.60^2 / 114)
numerator / denominator            # t はおよそ 3.8
[1] 3.792576
🍎 かんたん説明

手計算の t は丸めのせいで少しずれるが、どちらも約 3.8。p は 2 * pt(t, df, lower.tail = FALSE)（両側なので ×2）。qt は臨界値、pt は確率。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 分子はいくつ？A. 7.27 − 6.68 = 0.59。
Q2. 両側 p 値はなぜ ×2？A. 両側（どちらの向きの差も数える）だから。
Q3. 起こりうる誤りは？A. Type I error（本当は差がないのに棄却した場合）。
④

対応あり

同じ人を2回測る

🎯 これだけ覚えればOK

同じ人を2回測ったら「対応あり」。差を作って、1標本の t にする。df = 人数 − 1。

☕
カフェイン vs プラセボを同じ11人が両方体験。差 = placebo − caffeine を作る。
xdiffs <- placebo - caff
t.test(xdiffs, conf.level = 0.95, alt = "two.sided")
One Sample t-test data: xdiffs t = 3.5304, df = 10, p-value = 0.005443 alternative hypothesis: true mean is not equal to 0 95 percent confidence interval: 2.716264 12.011009 sample estimates: mean of x 7.363636
✅
平均の差 7.36、95% CI は (2.72, 12.01)。0 が入っていない & p = 0.005443 < 0.05 → 差がある証拠あり。
⚠️ ペアなのに2標本 t（独立を仮定）を使うと、差の SE を過大評価してしまいます。ペアだと分かったら paired！
🍎 かんたん説明

「差を作る → 1標本 t」。t.test(placebo, caff, paired = TRUE) と書いても同じ結果になる。

🤔 答えられるかな？（クリックで答えが開く）

Q1. パラメータは？A. 差の母平均 μ_diff（1つ）。
Q2. df は？A. n − 1 = 11 − 1 = 10。
Q3. 区間に 0 がなければ？A. 差がある証拠あり。

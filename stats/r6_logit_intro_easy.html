🍎 超やさしい版：ロジスティック回帰の基本

「どっちになる？」の確率を予測するのが、ロジスティック回帰。カギは確率 ⇄ 対数オッズの行き来です。

ロジスティック回帰とは確率・オッズカギAge の係数📊 本編はこちら

ロジスティック回帰とは

結果が2択のとき

🎯 これだけ覚えればOK

結果が「2択」なら glm(…, family = binomial)。係数の読み方は線形回帰とは別物。

🐚
線形回帰：収入のように「いくらか」を予測。
ロジスティック回帰：スパム or 普通のメール、のように「どっちか」の確率を予測。

2択の片方を 0、もう片方を 1 にします。アワビの Type（オス M／メス F）を殻の直径 Diameter から予測してみましょう（R は文字の順で F=0、M=1 にします。だから「オスの確率」を予測します）。

model <- glm(Type ~ Diameter, family = binomial, data = AB2)
summary(model)
Call: glm(formula = Type ~ Diameter, family = binomial, data = AB2) Coefficients: Estimate Std. Error z value Pr(>|z|) (Intercept) 1.2891 0.2229 5.782 7.37e-09 *** Diameter -2.5332 0.4902 -5.168 2.37e-07 *** --- Signif. codes: 0 ‘***’ 0.001 ‘**’ 0.01 ‘*’ 0.05 ‘.’ 0.1 ‘ ’ 1 ...
⚠️ 表の見た目は線形回帰とそっくりですが、「回帰は回帰だから同じ読み方」は間違い。今は「Diameter は有意（p = 2.37e-07）」が読めればOK。Deviance residuals と Fisher scoring は今は気にしなくて大丈夫です。
🍎 ひとことで

lmではなくglm、そしてfamily = binomial。3つ以上の選択肢なら「多項」（multinomial）という別の回帰で、今は扱いません。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 結果が「卒業する／しない」のとき、使うのはlmとglmのどっち？A. glm(…, family = binomial)。2択の結果だから。
Q2. アワビのTypeで、1にあたるのはM？F？A. M（オス）。Rは文字の順で最初のFを0、次のMを1にするから。
②

確率・オッズ・対数オッズ

3つの言い方

🎯 これだけ覚えればOK

確率 → オッズ → 対数オッズ。係数がわかったら、P = 1/(1+e−式) で確率にもどす。

🎰
オッズ ＝ 起こる ÷ 起こらない。確率 0.8 なら 0.8÷0.2＝4（「4対1」）。
対数オッズ ＝ オッズの自然対数。ln(4)＝1.3863。
p <- c(0.1, 0.5, 0.7, 0.9)
data.frame(p, odds = p / (1 - p), log_odds = log(p / (1 - p)))
p odds log_odds 1 0.1 0.1111111 -2.1972246 2 0.5 1.0000000 0.0000000 3 0.7 2.3333333 0.8472979 4 0.9 9.0000000 2.1972246

2択なので、片方の確率がわかればもう片方は 1 − P。たとえば直径 0.4 のアワビがオスの確率は 0.5685、メスは 0.4315 です。

eta <- 0.2758                 # 回帰式の値 b0 + b1 × 0.4
1 / (1 + exp(-eta))
[1] 0.5685
📌 ここは濃い内容です。全部わからなくても、次に進んで大丈夫。あとで戻ると意味が見えてきます。
🍎 ひとことで

流れが先、数学は後。「確率 → オッズ → 対数オッズ」で係数を理解し、その係数を式に入れて確率を出します。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 確率が 0.5 のとき、オッズと対数オッズは？A. オッズ＝1、対数オッズ＝0。
Q2. P(M)＝0.6 なら P(F)は？A. 1 − 0.6 ＝ 0.4。
Q3. 確率が0.1のとき、対数オッズは正？負？A. 負（−2.1972）。起こりにくい → マイナス。
③

カギ：logit と逆 logit

0〜1に折り返す

🎯 これだけ覚えればOK

logit は「確率 → 対数オッズ」、逆 logit は「どんな数 → 0〜1の確率」。これがロジスティック回帰のカギ。

🔁
回帰式の値はどんな実数にもなるのに、確率は0〜1だけ。
その橋渡しをするのが逆 logit（シグモイド）。

p = 0.5 で一周してみましょう。

p <- 0.5
(odds <- p / (1 - p))         # 0.5 / 0.5 = 1
(logit <- log(odds))          # log(1) = 0
1 / (1 + exp(-logit))         # 逆変換: 1 / (1 + e^0) = 1/2
[1] 1 [1] 0 [1] 0.5
ステップp = 0.5 の場合
確率0.5
オッズ ＝ p/(1−p)1
対数オッズ ＝ ln(オッズ)0
逆 logit ＝ 1/(1+e0)0.5（元にもどる）
🍎 ひとことで

p = 0.5 は「オッズ1・対数オッズ0」の基準点。確率を変えても、同じ道を通って元にもどれます（p = 0.7 → 0.8473 → 0.7）。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 対数オッズ 0 を確率にもどすといくつ？A. 0.5（1/(1+e⁰) ＝ 1/2）。
Q2. 逆 logit はどんな範囲の数を出す？A. いつでも 0 より大きく 1 より小さい数（確率）。
④

連続の予測変数 Age

係数の意味を確かめる

🎯 これだけ覚えればOK

係数 ＝ 予測変数が1増えたときの「対数オッズの変化」。オッズの変化は「割り算」。

German credit（1000人）で、信用 Good（良い）の確率を年齢 Age から予測します。Good は 700人、Bad は 300人。Good の人のほうが少し年上（平均 36.22 歳 対 33.96 歳）です。

mod_age <- glm(Class ~ Age, family = binomial, data = gc2)
coef(summary(mod_age))
Estimate Std. Error z value Pr(>|z|) (Intercept) 0.20091865 0.232852767 0.862857 0.388216070 Age 0.01843994 0.006434155 2.865946 0.004157657

Age の係数は 0.01844。「1歳ふえると対数オッズが 0.018 ふえる」という意味です。確かめてみましょう。

ステップAge = 0Age = 1
確率0.55010.5546
オッズ1.22251.2453
➗
オッズの比 ＝ 1.2453 ÷ 1.2225 ＝ 1.0186
その自然対数 ln(1.0186) ＝ 0.0184 ＝ 係数 🎉

これは Age = 55 → 56 でも 33 → 34 でも同じ 1.0186 になります。

⚠️ オッズの変化は引き算ではなく割り算（新 ÷ 旧）。確率そのものの増え方は一定ではありません（33→34歳で +0.0039、55→56歳で +0.0032）。
📝 暗記はいりませんが、知っていると試験で楽。手順：回帰 → 式に代入 → x=0 の確率とオッズ → x=1 の確率とオッズ → オッズの比 → 自然対数 → 係数。
🍎 ひとことで

Age の係数 0.0184 ＝ 「1歳ふえるとオッズが約 1.0186 倍」。確率が 0.0184 ふえるという意味ではありません。

🤔 答えられるかな？（クリックで答えが開く）

Q1. Age の係数 0.01844 は何の変化を表す？A. Age が1つ増えたときの対数オッズの変化。
Q2. オッズが 1.2225 から 1.2453 に変わった。変化の求め方は？A. 割り算：1.2453 ÷ 1.2225 ＝ 1.0186。（その自然対数が 0.0184）
Q3. Good の確率が 0.55 のとき、Bad は？A. 1 − 0.55 ＝ 0.45。

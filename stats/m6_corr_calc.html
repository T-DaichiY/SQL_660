M6 · Correlation ② — How r is calculated, and its cautions

🧮 相関②：手計算と注意点

相関係数 r はどう計算されるのか。共分散（covariance）を標準化したものが r です。電卓でも手計算できる小さな例を通して意味をつかみ、そのあとで r の性質と、使うときの注意点（因果・曲線・外れ値・カテゴリ変数）を学びます。

①

共分散 covariance と r の手計算

「平均からのズレ」を掛けて足す

相関 r の土台は共分散（covariance）です。散布図の 1 つの点は順序対 (xi, yi)。それぞれの平均からのズレ（偏差 deviation）を掛け合わせ、全部の点で足し合わせ、n − 1 で割ります。

📐 共分散の式： cov(x, y) = Σ (xi − x̄)(yi − ȳ) ／ (n − 1)　（x̄, ȳ は x と y の平均、n は順序対の数、Σ は「全部足す」）

符号の読み方は直感的です。

  • cov > 0（正の相関）：平均的に、x と y がそろって平均より大きい／そろって小さい。
  • cov < 0（負の相関）：平均的に、片方が平均より大きいとき、もう片方は小さい。

講義の例：検索結果の「位置」とクリック率

検索結果の掲載順位（position：1 が最上位）と、そのクリック率（click-through rate, %）の 10 組です。まず平均と、各値の平均からのズレを求めます。

position <- 1:10
rate <- c(23.53, 14.94, 11.19, 7.47, 5.29, 3.8, 2.79, 2.11, 1.57, 1.18)

mean(position)
mean(rate)

deviation_positions <- position - mean(position)
deviation_rates <- rate - mean(rate)

⚠️ 共分散があまり使われない理由（講義の 3 点）
  1. 上限・下限がない：値が大きければ数百・数千・数百万にもなる。
  2. 単位が変：x が年（years）、y がドル（dollars）なら、共分散の単位は「年・ドル（year-dollars）」。引き算してから掛けるので、単位も掛け算になる。
  3. 単位が変数ごとに違うので、別々の 2 組の変数の「関連の強さ」を比べられない。

標準化して相関係数 r にする

そこで共分散を標準化（standardize）します。標準化とは「ズレを標準偏差で割る」こと（z スコアを求めるのと同じ考え方）。共分散を x の標準偏差と y の標準偏差の積で割ると、単位が全部約分されて単位のない（unitless）指標になります。

📐 ピアソンの相関係数（Pearson's correlation coefficient）： r = cov(x, y) ／ (sx · sy)　（sx, sy は標本標準偏差）
sd_position <- sd(position)
sd_rate <- sd(rate)
sd_position
sd_rate
my_covariance / (sd_position * sd_rate)
cor(rate, position)
[1] 3.02765 [1] 7.232038 [1] -0.9024191 [1] -0.9024191

sx = 3.0277、sy = 7.2320 なので r = −19.759 ÷ (3.0277 × 7.2320) = −0.9024 ≈ −0.90。cor()の答えと一致しました。

10 個の点（講義の位置×クリック率データ）。右下がりで、点は直線ではなく下に曲がるカーブに沿っています。この曲がり具合は③で扱います。

−8.1218 ÷ 9 = −0.9024。どちらの道で計算しても同じです。この式は、②で見る r の性質（単位が変わっても変わらない、など）を理解するのに役立つ、と講師は説明しています。

📜 コンピュータ以前の公式： 検索すると別の式もたくさん出てきます。たとえば r = Σ(xi − x̄)(yi − ȳ) ／ [√Σ(xi − x̄)² · √Σ(yi − ȳ)²]。講師は「怖がらせるために載せた。これを手計算させたりはしない」と言っています。
dx <- position - mean(position)
dy <- rate - mean(rate)
sum(dx * dy) / sqrt(sum(dx^2) * sum(dy^2))
[1] -0.9024191
⚠️ 実務では手計算しません。 現場ではcor()を一発で使います。手計算は「記号が何を意味するか」を理解するための練習です（講義の課題は「共分散のときのように、z スコアの式で r を一歩ずつ計算してみよう」）。
❓ なぜ n ではなく n − 1 で割る？ 標本共分散は標本平均を使い、n − 1 で割ります。母集団共分散なら母平均 μ を使い、母集団の大きさ N で割ります。標本は母集団と完全には一致しないので、n − 1 で割ると母集団共分散の不偏推定量（unbiased estimator）になります。
🍎 かんたん説明

共分散＝「x と y が一緒に平均から離れる度合い」。単位つきで大きさも決まらないので、標準偏差で割って −1〜+1 の単位なしの数（r）にします。r = −0.90 は「位置が下がるとクリック率は強く下がる」。

💻 ミニ練習：z スコアの式で r を求める

上のpositionとrateを使い、z スコアの式（Σ zxzy ／ (n − 1)）で相関係数を計算するRコードを書いてください。答えは −0.9024 になります。

z_x <- (position - mean(position)) / sd(position)
z_y <- (rate - mean(rate)) / sd(rate)
sum(z_x * z_y) / (length(position) - 1)
[1] -0.9024191

結果は −0.9024191。cor(position, rate)と一致します。scale()で z スコアを作っても構いません。

②

相関係数 r の性質

r = Σ zxzy ／ (n − 1) から分かること

r の性質の多くは、①の z スコアの式から説明できます。講義では次のデータを使います。paste()は文字と値をつなげる関数で、グラフの題名に r を直接表示するのに便利です。

x <- 1:10
y <- c(2, 5, 13, 7, 8, 10, 12, 14, 17, 25)
my_cor <- round(cor(x, y), 3)
my_cor
plot(x, y,
     main = paste("r =", my_cor),   # paste() でタイトルに r を表示
     pch = 16, las = 1)
[1] 0.875
1️⃣ 性質1：r には量的変数（quantitative variables）が必要。 カテゴリ変数をそのまま入れるとエラーになります。
z <- c(rep("yes", 4), rep("no", 6))
z
cor(x, z)
[1] "yes" "yes" "yes" "yes" "no" "no" "no" "no" "no" "no" Error in cor(x, z) : 'y' must be numeric Execution halted

カテゴリを数に置き換える（encode）ことはできますが、種類で扱いが違います。

種類例数値化
binary（2 値）yes / no0 と 1 にしてよい
ordinal（順序あり）XS, S, M, L, XL順序のある数（1〜5 など）にしてよい
nominal（順序なし）好きな色：青・緑・赤数にしない方がよい（青 = 1、緑 = 2 にすると「緑の方が上・強い」という意味のない大小が生まれる）
z01 <- ifelse(z == "yes", 1, 0)   # 2つのカテゴリ(binary)を 0/1 に
cor(x, z01)
[1] -0.8528029
2️⃣ 性質2：explanatory（説明）変数と response（応答）変数を区別しない。 x と y を入れ替えると散布図は反転したように見えますが、r はまったく同じです（相関行列でも見ました）。
cor(x, y)   # もとのデータ
cor(y, x)   # x と y を入れ替える
[1] 0.8746122 [1] 0.8746122
3️⃣ 性質3：単位を変えても（定数を足したり掛けたりしても）r は変わらない。 センチ → フィート、ドル → 百万ドルのような単位変換です。r は「標準化した共分散」なので、定数の足し算・掛け算は標準化で打ち消されます。
x2 <- 2 * x        # x を 2 倍
y2 <- y / 10       # y を 10 で割る
cor(x2, y2)
cov(x, y)          # 共分散は単位で変わる
cov(x2, y2)
[1] 0.8746122 [1] 17.38889 [1] 3.477778

x を 2 倍、y を 10 分の 1 にしても r は 0.8746 のまま。いっぽう共分散は 17.39 から 3.48 に変わりました（共分散は単位に依存する）。

4️⃣ 性質4：r には単位がない。 パーセントでもありません。r = 0.875 を「87.5%」と書いてはいけません。単位なしの 0.875 です。
5️⃣ 性質5：r の符号は、直線的な関係の向きと必ず一致する。 例：donors データの贈与回数（numberGifts）と総寄付額（totalGivingAmount）。外れ値があって直線関係ははっきりしませんが、符号は正（r ≈ +0.6）で、右上がりの傾向と合っています。
donors <- read.csv("donors.csv")
my_x <- donors$numberGifts
my_y <- donors$totalGivingAmount
round(cor(my_x, my_y), 4)
[1] 0.5998
6️⃣ 性質6：r は外れ値に強くない（not resistant to extreme values）。 1 点だけで r は大きく動きます。
x <- 1:6
y <- c(2, 3, 4, 4.5, 6, 7)
cor(x, y)

y_out <- y
y_out[6] <- 20     # 最後の 1 点だけ極端な値にする
cor(x, y_out)
[1] 0.9940327 [1] 0.7924682
点が直線に沿っている
最後の 1 点だけ 7 → 20 に変更
同じ 6 点のうち、最後の y を 7 から 20 に変えただけで r は 0.994 から 0.79 まで下がります（赤い点が外れ値）。
🔬 講義の課題（アプレットで実験）： 講師のリンク先のアプレットでマウスクリックで点を足したり消したりして、r の変化を観察します。観察のあとで、次の空欄に「強まる（strengthen）／弱まる（weaken）／ほぼ変わらない（keep about the same）」を入れます。
  • トレンドの外に点を足すと、相関は ＿＿。
  • トレンドに沿う点を足すと、相関は ＿＿。
  • トレンドの外の点を取り除くと、相関は ＿＿。
  • トレンドに沿う点を取り除くと、相関は ＿＿。
考えてから開く：目安の答え

外に足す → 弱まる／沿うものを足す → 強まる（ほぼ変わらないこともある）／外れた点を取り除く → 強まる／沿う点を取り除く → 弱まる。上のデータ（r = 0.8746）で試すと、外れた点 (5.5, 30) を足すと 0.648、直線上の点 (11, 21.7) を足すと 0.902、外れた点 (3, 13) を取り除くと 0.945 になります。

🍎 かんたん説明

r は「単位なしの −1〜+1 の数」。x と y を入れ替えても、単位を変えても同じ。でも外れ値 1 個で大きく変わるので要注意。r = 0.875 に「%」は付けない。

💻 ミニ練習：外れ値で r はどう変わる？

x <- 1:6、y <- c(2, 3, 4, 4.5, 6, 7)のとき、最後の y を 7 から 20 に置き換えたうえで相関係数を求めるRコードを書いてください（約 0.79 になります）。

x <- 1:6
y <- c(2, 3, 4, 4.5, 6, 7)
y[6] <- 20
cor(x, y)
[1] 0.7924682

結果は 0.7924682。もとの 0.9940327 から、1 点の外れ値だけで大きく下がりました。

③

相関を使うときの注意点

因果・曲線・外れ値・カテゴリ変数

講師が挙げる注意点を順番に整理します（番号は講義の「注意 1〜6」に対応）。

⚠️ 注意1：相関は因果を意味しない（Correlation does not imply causation）。 2 つの変数が強く関連していても、一方が他方の原因とは限りません。

x と y が一緒に動くとき、考えられる説明は 3 つ以上あります。

考えられる説明図式例
x が y の原因？x → y勉強時間が増えるとテスト点が上がる
逆に y が x の原因？y → x（逆向きの可能性も常に検討する）
第三の変数 z が両方の原因？
（lurking variable／交絡 confounder）		z → x, z → y気温 → アイスの売上、気温 → 水難事故。アイスと事故は連動するが、アイスが事故の原因ではない
  • 講義資料の例：チョコレートの消費量とノーベル賞受賞者数の国別の相関（NEJM の論文と、それへの反論）。「相関があるから原因だ」とは言えない典型例です。
  • spurious correlations（見かけ上の相関）：無関係なものが偶然に強く相関する例が集められたサイトがあります。
  • 因果を調べる方法：ランダム化実験（randomized experiment）（A/B テストなど）や、観察研究と因果の基準（Bradford Hill の基準など）。
  • 講義資料の締めくくり：Correlation does not imply causation… but it might!（因果を示さないが、因果かもしれない）。
⚠️ 注意2：|r| が 1 に近くても、関係が直線とは限らない。 ①の位置×クリック率は r = −0.90 ですが、散布図は曲線でした。
⚠️ 注意3：r が 0 に近くても、関連が全くないとは限らない。 r = 0 は「直線的な関連がない」だけ。曲線（放物線・二次関数）の関連は残っていることがあります。
x <- -5:5
y <- x^2
round(cor(x, y), 4)
[1] 0
r は −1 に近いのに、直線ではない
r = 0 でも、はっきりした放物線の関係
左：r が −1 に近くても直線とは限らない。右：r がちょうど 0 でも関連がないとは限らない。どちらも散布図を描かないと分からない例です。
⚠️ ピアソンの相関係数は、非線形（nonlinear）の関係の説明に使わない。 だから必ずデータを散布図に描いて、関係が直線的かどうかを見ます。直線的なら Pearson、そうでなければ別の相関統計量を検討します（④で扱う）。
外れ値（性質6）にも注意：1 点で r が大きく動くので、散布図で外れ値の有無も確認しましょう。
⚠️ 注意6：カテゴリ変数に「相関（correlation）」という言葉を使わない。 講師の「こだわり」です。「髪の色と目の色は相関しているか？」のような言い方は、統計では不適切。correlation は量的変数どうしにしか計算できない、とても限定された意味の言葉だからです。カテゴリ変数には「関連（association）」や「関係（relationship）」を使います。

例：donors データの urbanicity（居住地域）と socioeconomic status（社会経済的地位）の 2 元表。2 つともカテゴリなのでcor()は計算できず、エラーになります。

donors <- read.csv("donors.csv")
table(donors$urbanicity, donors$socioEconomicStatus)
cor(donors$urbanicity, donors$socioEconomicStatus)
average highest lowest city 8264 6145 5280 rural 13623 1358 4809 suburb 8530 11503 1891 town 12369 4982 2176 urban 5852 4510 1804 Error in cor(donors$urbanicity, donors$socioEconomicStatus) : 'x' must be numeric
🍎 かんたん説明

r は直線の強さだけを測る道具。①「相関＝原因」ではない　②r が −1 に近くても曲線かも　③r が 0 でも曲線の関連があるかも　④カテゴリ変数には「相関」と言わず「関連」。とにかく先に散布図！

💻 ミニ練習：r = 0 の放物線を作る

xを −5 から 5 の整数とし、yをその 2 乗（y = x²）としたとき、corで相関係数を求めるRコードを書いてください。結果は 0 です。

x <- -5:5
cor(x, x^2)
[1] 0

結果は 0。y は x から完全に決まる（放物線）のに、直線的な関連がないので r = 0 になります。散布図を描く習慣の大切さが分かる例です。

Spearman・Kendall、そして Anscombe と Datasaurus

別の相関統計量と、「必ずプロットする」教訓

注意4：非線形なら別の相関統計量を

相関にはピアソン以外にも種類があります：Spearman の順位相関（Spearman's rank）、Kendall のτ（Kendall's tau）、ほか多数。ピアソンが最も一般的です。cor()のmethodで選べます（既定は"pearson"。use = "everything"という既定値は、欠損値 NA がある場合の扱いの話です）。

cor(position, rate)                          # 既定は method = "pearson"
cor(position, rate, method = "spearman")
cor(position, rate, method = "kendall")
[1] -0.9024191 [1] -1 [1] -1

位置×クリック率（曲線）では、Pearson は −0.90、Spearman は −1。Kendall も −1 です。順位でみると「位置が下がるとクリック率は必ず下がる」ので完全な単調関係、というわけです。曲線なのでピアソンは使うべきではありません。

もう一つの曲線の例（y = x²、x は 0〜10）：

x <- 0:10
y <- x^2
cor(x, y)
cor(x, y, method = "spearman")
[1] 0.9631427 [1] 1

Pearson は 0.963 と非常に強い値を出しますが、Spearman は 1。どちらも「強い正の関係」を示しますが、直線的ではないことをピアソンだけでは見落とします。

⚠️ 注意5：いつでもデータをプロットする（Always plot your data）。

💻 ミニ練習：Anscombe の 2 組目を計算する

anscombeの x2 と y2 の相関係数をピアソン（既定）とスピアマンの両方で求めるRコードを書いてください。

cor(anscombe$x2, anscombe$y2)
cor(anscombe$x2, anscombe$y2, method = "spearman")
[1] 0.8162365 [1] 0.6909091

ピアソンは 0.8162365。スピアマンは 0.6909091。ピアソンの値は他の 3 組とほぼ同じ（約 0.816）ですが、散布図は放物線のような曲線です。

cor(anscombe$x1, anscombe$y1)
cor(anscombe$x2, anscombe$y2)
cor(anscombe$x3, anscombe$y3)
cor(anscombe$x4, anscombe$y4)
[1] 0.8164205 [1] 0.8162365 [1] 0.8162867 [1] 0.8165214
Anscombe の 4 組。どれも平均・ばらつき・r（約 0.816）・回帰直線（赤）がほぼ同じですが、点の並びはまったく別物です。（左上は直線的、右上は曲線、左下は外れ値が 1 つ、右下は 1 点だけ x が離れている）
📌 教訓： 4 組とも r ≈ 0.816（さらに x の平均 9、y の平均 7.5 なども同じ）。数値の要約だけでは、データの姿が全く違うことに気づけません。必ずプロットしましょう。
🦖 Datasaurus（より新しいデータセット）： 講師が紹介している、アンスコムの考え方の現代版です。恐竜（dinosaur）の形などの、見た目が全く違う多くのデータが、平均・標準偏差・相関はほぼ同じ。講義のリンク（CRAN の datasauRus パッケージ）を開いて、何が起きているのか・このデータセットの要点は何かを自分で考えてみましょう。

💡 学習のヒント

r の計算は「平均からのズレを掛けて足し、標準偏差で割る」。試験や実務では、まず散布図、次に r の順に。r の値だけを見て「直線的」「因果がある」と決めつけないこと。

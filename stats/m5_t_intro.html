M5 · T Procedures ① — Inference for One Mean

🧪 t手順①：1標本の平均の推測

①

推測統計の全体像

記述から推測へ、区間と検定

統計には2つの枝があります。記述統計（descriptive statistics）は手元のデータを説明すること（中心＝平均、ばらつき＝標準偏差、グラフ）。推測統計（inferential statistics）は、その平均から未知の母集団・未知の母数（parameter）について何が言えるかを考えることです。このモジュールは推測統計です。

推測が必要なのは、全数調査（census）が現実的でないことが多いからです。米国全人口を調べるのは大変ですし、小さな工場のPCなら全数調査できるかもしれません。多くの場合は時間もお金もかかりすぎるので、代表的な標本（representative sample）を取ります。ただし標本を取る以上、標本のばらつき（sampling variability）があります。「この標本をどこまで信頼できるか」が問題です。

2本柱：信頼区間と有意性検定

confidence interval 信頼区間significance test 有意性検定（hypothesis test 仮説検定）
目的未知の平均を範囲で推定するある仮説を検証する（結果は偶然か、別の何かか）
航空券の例1つの値「$300」より、「$250〜$450」という区間のほうが情報が多い去年の平均 $300 に対し今年 $350。これは有意か、たまたまの標本か
仮説なし（未知の母数を推定）帰無仮説（null）と対立仮説（alternative）
点推定と区間推定（航空券の例）
点推定は1つの値。区間推定は「この範囲にありそう」という幅を持つので、情報が多い。
📌 このモジュールの前提
  • 解釈は頻度論（frequentist）の立場で、ベイズ（Bayesian）ではありません。
  • 扱うのは量的データ（quantitative）（航空券の価格など）。航空会社名のような質的データ（categorical）は別の章です。量的か質的かの区別は、この章と後の章の検定・区間を取り違えないために大切です。
  • 公式がたくさん出ますが、暗記よりも「数字がどこから来るか」を理解すること。実務ではデータを入力すればRが区間も検定結果も出してくれますが、公式を見る価値は教育上とても大きいです。
🍎 かんたん説明

「標本の平均」は1つの数字にすぎません。そこで、①幅をつけて真の平均を当てにいく（信頼区間）、②「変わった」と言ってよいかを確かめる（有意性検定）の2つを学びます。

💻 ミニ練習：標本の平均・標準偏差・標準誤差

mtcarsのmpg（32台の燃費）を標本とみなし、標本平均 xbar、標準偏差 s、標準誤差 se = s/√n を求めてください（nはlength()で）。

x <- mtcars$mpg
xbar <- mean(x)           # 20.09062
s    <- sd(x)             # 6.026948
n    <- length(x)         # 32
se   <- s / sqrt(n)       # 1.065424
se

平均 20.09、標準偏差 6.03、n = 32 なので SE = 6.026948/√32 ≈ 1.065。この SE が、後で区間の幅や検定統計量の分母になります。

②

1標本のt区間

estimate ± ME と臨界値 qt()

名前を分解すると、one-sample t interval for a population mean。1標本（one sample。2標本は後で）、t（別の分布を使う手法と区別するための名前）、interval（検定ではなく区間）、母平均（比率ではなく平均）です。

一般形：推定値 ± 誤差の幅

どんな信頼区間も形は同じです。

estimate ± margin of error　（ME ＝ critical value × standard error）
  • estimate（推定値）：統計量。多くの場合、標本平均 x̄。
  • standard error（標準誤差）：その統計量が標本ごとにどれだけ変わるか。
  • critical value（臨界値）：区間が望みの幅になるようにする倍率。

「±」は短縮表記です。(統計量 − 臨界値 × SE, 統計量 ＋ 臨界値 × SE) の、左が下限（lower bound）、右が上限（upper bound）。区間は角括弧ではなく丸括弧 ( , ) で書きます。最初の例では、点推定 $300、ME $10 なら ($290, $310) です。

1標本のt区間

x̄ ± t*(1−α/2, df) · s/√n　　df ＝ n − 1
  • x̄：標本平均（統計量）　s/√n：標準誤差（s は変数 x の標本標準偏差、n は標本サイズ）
  • t*：臨界値（分位点 quantile ともいう）。t* × SE ＝ ME。

参考書では単に「x̄ ± t × SE」と書かれることもありますが、t* を求めるには分位点（1 − α/2）と自由度 df の両方が必要です。

t* の決め方：qt()

信頼水準が95%なら 1 − 0.95 ＝ α ＝ 0.05、その半分 α/2 ＝ 0.025。中央の95%を塗った曲線の左右に2.5%ずつ残るので、必要なのは 0.95 ＋ 0.025 ＝ 0.975 番目の分位点（97.5th quantile）です。

中央95%と、左右の2.5%（イメージ）
t* は「右側に2.5%残る点」＝ 0.975 の分位点。左右対称なので −t* と +t* で挟む。

練習問題：n ＝ 10 の標本で90%信頼区間を作るときの t*。1 − 0.90 ＝ 0.10、半分で 0.05。必要な分位点は 0.90 ＋ 0.05 ＝ 0.95。df ＝ 10 − 1 ＝ 9。Rでは q（quantile）＋ t（分布）＝ qt() です。

qt(p = 0.9 + 0.05, df = 10 - 1)   # p = 0.95, df = 9
qt(0.95, df = 9)                 # 同じ
qt(1 - 0.10/2, 9)                # 同じ（引数名は省略してよい）
[1] 1.833113 [1] 1.833113 [1] 1.833113

どの書き方でも答えは同じ 1.833113 です。p =、df = は省略可（Rが数の位置で判断できるとき）で、足し算を使わず 1 - 0.10/2 と書いても構いません。

t表（Table B）との対応

表を使う人もいます。表の下側で信頼水準（90%）、左側で df（9）を選ぶと 1.833。Rと同じ値ですが、表は小数の桁が少ないだけです。表の最上段の t に付いた添字 t0.95 が、Rで使った 0.95 に対応します。90%なら t0.95、よく使う95%なら t0.975 です。

信頼水準αqt に入れる pn = 10 (df = 9) の t*
90%0.100.951.833
95%0.050.9752.262

df が大きいほど t* は小さくなり、正規分布の1.96に近づきます。

qt(0.975, df = c(4, 9, 19, 29, 49, 99))
[1] 2.776445 2.262157 2.093024 2.045230 2.009575 1.984217
⚠️ 講師の注意：実務で「この臨界値は？」と聞かれることはまずありません。求められるのは区間を作り、解釈し、前提（条件）を確認し、結論を述べることです。ここで臨界値を丁寧にやるのは、ME と区間の数字がどこから来るかを理解するためです。
🍎 かんたん説明

信頼区間 ＝ 平均 ± （倍率 t*）×（ぶれの大きさ SE）。倍率は qt(1 - α/2, df = n - 1)。95%なら qt(0.975, ...)、90%なら qt(0.95, ...)。

💻 ミニ練習：臨界値 t*

標本サイズ n = 25 の標本で95%信頼区間を作るときの臨界値 t* を、qt() で求めてください（df は n - 1）。

n <- 25
qt(0.975, df = n - 1)

95%なので p = 0.975、df = 24。結果は 2.063899。

③

例：コールセンターの応答時間

平均18.353秒、s = 11.761、n = 50

状況：銀行のマネージャーは、コールセンターの担当者が電話に30秒以内で出ているかを知りたい。アナリストが無作為に50件の通話を調べたところ、標本平均 x̄ ＝ 18.353 秒、標本標準偏差 s ＝ 11.761 秒でした。95%信頼区間を作ります。

質問に順に答える

質問答え
推定したい母数は？未知の母平均＝担当者が電話に出るまでの平均時間（秒）
母集団は？担当者が受けるすべての通話（母集団は「～のすべて」であることが多い）
標本は？無作為に選んだ50件の通話（問題文で与えられる部分）
母数の推定に使う統計量は？標本平均 18.353 秒
標本平均は母平均の不偏推定（unbiased）といえる？無作為抽出なので標本は母集団を代表すると考えられ、yes。全数調査は難しいので標本を取る
どの区間？なぜ？1標本のt区間：標本が1つ、量的データ、母標準偏差は不明で標本の s だけ分かる
🎯 実務で一番大事なこと：計算の手順よりも、データを見て「ここは1標本のt区間が必要」と正しい区間を選べることです。この先、区間の種類が増えると選ぶのが難しくなります。

標準誤差・臨界値・誤差の幅・区間

「標本平均は標本ごとにどれくらい変わるか」とは、標準誤差（SE, SEM）のことです。SE ＝ s/√n ＝ 11.761/√50 ≈ 1.66 秒。別の50件を取れば平均は同じにならず、1.66秒ほどのばらつきがあります（18秒の次に17分が出たら驚きますよね）。

xbar <- 18.353
s    <- 11.761
n    <- 50

se <- s / sqrt(n)                 # 標準誤差
se
t_star <- qt(0.975, df = n - 1)   # 95%の臨界値
t_star
me <- t_star * se                 # 誤差の幅
me
c(xbar - me, xbar + me)           # 95%信頼区間
[1] 1.663257 [1] 2.009575 [1] 3.342439 [1] 15.01056 21.69544
  • ME ＝ 3.34 秒。定義：「推定値が真の母集団の値から、高々どれだけ離れうるか」。
  • 区間 ＝ x̄ ± ME ＝ (15.0, 21.7) 秒（小数第1位に丸め。丸括弧）。
  • 解釈（文脈つき）：We are 95% confident that the interval (15.0, 21.7) seconds captures the unknown mean time that agents take to answer calls.
95%区間と99%区間（目標の30秒との比較）
白丸が標本平均 18.353。区間全体が30秒の左にあるので、目標を満たしているという説得力のある証拠。99%のほうが幅が広い。
⚠️ R の落とし穴（講義）：qt(0.975, df = 49) は、引数名を省いて qt(0.975, 49) と書いても動きます。しかし順番を逆にした qt(49, 0.975) は、最初の数（49）をパーセンタイルとして扱い、パーセンタイルは1以下のはずなので NaN になります。
また、ここまでの書き方は「数字の出どころを見せる」ための学習用。実務ではやりません。
qt(49, 0.975)
[1] NaN Warning message: In qt(49, 0.975) : NaNs produced

目標（30秒以内）を満たしているか？

区間 (15.0, 21.7) は全体が30秒を下回っているので、yes、説得力のある証拠（convincing evidence）がある。マネージャーは、担当者が推奨の30秒以内で応答していると自信を持てます。

もし99%信頼区間にすると、臨界値（倍率）が大きくなるので区間は広がりますが、それでも30秒未満です。

t99 <- qt(0.995, df = n - 1)
t99
me99 <- t99 * se
me99
c(xbar - me99, xbar + me99)
[1] 2.679952 [1] 4.457448 [1] 13.89555 22.81045
📌 補足（講義）：区間や検定には満たすべき条件（conditions）があり、ここでは扱っていません（後の動画で学習）。もし生データがあれば、Rのショートカット t.test() で区間が出せます（次のユニットで使う）。今回は要約統計量（平均と標準偏差）しかないので使えませんでした。
🍎 かんたん説明

① SE ＝ s/√n（ぶれの大きさ）→ ② t* ＝ qt(0.975, n−1)（倍率）→ ③ ME ＝ t* × SE → ④ 区間 ＝ x̄ ± ME。「18秒ぐらいだけど、15〜21.7秒の間に真の平均がありそう（95%）。全部30秒より下！」

💻 ミニ練習：95%信頼区間を作る

要約統計量 xbar = 18.353、s = 11.761、ただし標本サイズが n = 100 のとき、95%信頼区間の下限・上限を c(下限, 上限) で求めてください。

xbar <- 18.353
s <- 11.761
n <- 100
me <- qt(0.975, df = n - 1) * s / sqrt(n)
c(xbar - me, xbar + me)

ME = 2.333638、区間は (16.01936, 20.68664) ≈ (16.0, 20.7)。n が増えると SE が小さくなり、n = 50 のときの (15.0, 21.7) より狭くなります。

④

「95%信頼」とは何か

アプレットとシミュレーション

(15.0, 21.7) を「95%信頼」と解釈しました。この「95%」は何を意味するのでしょう。講義では Rossman-Chance の「Simulating confidence intervals」アプレットで、頻度論（frequentist）の意味を確かめました（ベイズ派はこの解釈に同意しませんが、このモジュールは頻度論です）。

アプレットの設定

統計量：mean、分布：normal、方法：t。母平均 μ ＝ 25、母標準偏差 σ ＝ 4、標本サイズ n ＝ 30、信頼水準 95%。本物の調査では μ は未知ですが、ここでは既知なので区間が当たったか確認できます（黒い縦線が μ ＝ 25）。

  • 1回目：標本平均 24.8、区間は 25 を含む（緑）。
  • 2回目：標本平均 25.9、これも含む（緑）。
  • 何度も標本を取ると、赤の区間が出る。例：標本平均 27、幅4 → 約 (25, 29) となり、区間全体が25より大きく、含まない。

回数を増やすとどうなるか

設定回数25 を含んだ区間捕捉率
95%50回（途中経過）—約90%
95%10094（赤は6本）94%
95%100095595.5%
70%（区間は狭くなる）100—62%
70%1000—68.3%

捕捉率（capture rate）は信頼水準に近づきます。回数を増やすほど近づく――これが頻度論的と呼ばれる理由です。70%にすると臨界値が小さくなるため区間は狭くなり、捕捉率も下がります。アプレットで標本サイズ・平均・標準偏差・回数・信頼水準を変えて、区間と捕捉率の変化を体感することが勧められています。

Rでも区間をシミュレートできる

講師は「おもしろいから」と、Rで区間を作る例も紹介しました（授業で使う教科書から）。同じ設定（μ ＝ 25, σ ＝ 4, n ＝ 30）で自分でも書いてみましょう。

set.seed(2024)
mu <- 25; sigma <- 4; n <- 30

captured <- replicate(1000, {
  x  <- rnorm(n, mu, sigma)                       # 標本を1つ取る
  ci <- mean(x) + c(-1, 1) * qt(0.975, n - 1) * sd(x) / sqrt(n)
  ci[1] <= mu & mu <= ci[2]                       # μ を含んだか？
})
sum(captured)
mean(captured)
[1] 954 [1] 0.954

1000本の区間のうち954本がμを含みました（95.4%、95%に近い）。次の図は、最初の40本です（緑＝含む、赤＝外れ）。

シミュレーションした40本の95%信頼区間（上のコードの最初の40回）
黒線が μ＝25。40本中37本が含み、3本（赤）が外れた。長く繰り返すと含む割合が95%に近づく。

信頼水準の正しい解釈

✅ 多数回標本を取れば、約 C%（95%や90%など、信頼水準）の区間が未知の母数（平均でも比率でも）を捕捉する。
⚠️ level（水準）と interval（個別の区間）を混同しない。interval は端点のある特定の区間。「95%信頼水準」は、区間を作る前の手続きについての話で、多数の区間のうち何割が捕捉するかを指します。ある1本の区間について述べるときは「We are 95% confident that this interval captures …」と言います。

誤差の幅（ME）に関する3つの質問

質問答え理由
標本サイズ n を増やすと ME は？小さくなるSE ＝ s/√n の分母が大きくなる。標本が大きいほど母集団について多く知っている
信頼水準を上げると ME は？大きくなる臨界値 t* が大きくなり、SE にかける倍率が増える
ME は標本の偏りや質問文の悪さを補正する？しないME は標本ごとのばらつき（sampling variability）だけを扱う。non-sampling の問題は別の方法で直す

最初の2つは「他の条件を一定として（holding everything else constant）」成り立ちます。複数を同時に変えると簡単には言えません。「error」は「間違い」という意味ではなく、標本ごとのばらつきから生じる幅のことです。

コールセンターの例（s ＝ 11.761 のままと仮定）で数字を確かめましょう。

s <- 11.761
# 信頼水準だけを変える（n = 50）
cl <- c(0.70, 0.90, 0.95, 0.99)
round(qt(1 - (1 - cl) / 2, df = 49) * s / sqrt(50), 2)

# 標本サイズだけを変える（95%）
n <- c(25, 50, 100, 200)
round(qt(0.975, df = n - 1) * s / sqrt(n), 2)
[1] 1.74 2.79 3.34 4.46 [1] 4.85 3.34 2.33 1.64

信頼水準が上がるほど ME は増え（1.74 → 4.46）、n が増えるほど減ります（4.85 → 1.64）。なお n を4倍にしても ME は半分程度にしかなりません（√n の効果）。

🍎 かんたん説明

「95%信頼」＝ 同じやり方で区間を何回も作ると、約95回（100回中）は本当の平均を捕まえる。1本の区間について「95%の確率で入っている」というより、やり方が95%の割合で成功するという意味。n を増やすと狭く、自信を上げると広くなる。

💻 ミニ練習：区間を1本シミュレートする

set.seed(1) のあと、rnorm(30, 25, 4) で標本 x を取り、95%信頼区間 c(下限, 上限) を作って、μ = 25 を含むか確かめてください。

set.seed(1)
x  <- rnorm(30, 25, 4)
me <- qt(0.975, df = 29) * sd(x) / sqrt(30)
c(mean(x) - me, mean(x) + me)

区間は約 (23.95, 26.71) で、25 を含みます（x̄ = 25.33, s = 3.70, ME = 1.38）。

⑤

母平均の有意性検定

マイアミ空港の評価

信頼区間の次は有意性検定（significance test）です。公式を先に並べず、例を通して部品を学びます。

状況：マイアミ国際空港（MIA）について、無作為に選んだ50人の出張客に0〜10で評価（rating）してもらいました。前年の調査の平均は 5.1。空港が改善策を導入し、FAAは平均評価が上がったと考えています。有意水準 α ＝ 0.05。

ratings <- c(6, 4, 6, 8, 7, 7, 6, 3, 3, 8, 10, 4, 8, 7, 8, 7, 5, 9, 5, 8,
             4, 3, 8, 5, 5, 4, 4, 4, 8, 4, 5, 6, 2, 5, 9, 9, 8, 4, 8, 9,
             9, 5, 9, 7, 8, 3, 10, 8, 9, 6)
mean(ratings)
sd(ratings)
hist(ratings)
boxplot(ratings, horizontal = TRUE)
[1] 6.34 [1] 2.162859

平均 6.34、標準偏差 2.16。この検定でも信頼区間と同じく平均と標準偏差が必要です。グラフはヒストグラム・箱ひげ図・ドットプロット・茎葉図が適切。棒グラフ（bar graph）と円グラフ（pie chart）は質的データ用なので不適切です。

ratings のヒストグラム（上のデータ）
目立つ歪み（skew）も外れ値もない。これは後で検定の前提を確認するときに大事になる。

仮説を立てる

ここまでは記述統計。ここから検定です（significance test ＝ hypothesis test、同じもの）。

  • 帰無仮説 H0：μ ＝ 5.1（null：現状のまま、特に面白いことは起きていない）
  • 対立仮説 HA：μ > 5.1（alternative：本当に知りたい主張。「上がった」だけでなく値（5.1）を明記する）
  • μ は、標本の旅行者だけでなく空港を使うすべての旅行者の未知の母平均評価。

2つの説明（教えるための道具）

標本平均 6.34 は5.1より大きく、対立仮説の証拠にはなっています。ただし全数調査ではないので、標本のばらつきがあります。この証拠には2つの説明があります。

説明内容対応
① 偶然母平均は今も5.1。たまたま標本の人が高く評価しただけ（sampling variability）H0
② 本当に上がった人々が本当に空港をよく思っているHA

※この「2つの説明」は理解のための道具で、実務や他の授業ではこの言い方をしないかもしれません。

検定が答える問いは、「説明①（H0が真）のもとで、6.34以上の平均が偶然出る確率は？」。それが p値です。

検定統計量とp値

6.34 が帰無値 5.1 から標準誤差いくつ分離れているか、標準化します。z得点（観測値 − 平均）/標準偏差 と形がそっくりです。

t ＝ (x̄ − μ0) / (s/√n)　　df ＝ n − 1 ＝ 49
xbar <- mean(ratings)
s    <- sd(ratings)
n    <- length(ratings)
se   <- s / sqrt(n)                  # 標準誤差
se
t_stat <- (xbar - 5.1) / se          # 検定統計量
t_stat
pt(t_stat, df = n - 1, lower.tail = FALSE)   # 右片側のp値
[1] 0.3058745 [1] 4.053951 [1] 8.986953e-05

t ≈ 4.05（4標準誤差ほども離れていて、とても多い）。p値 ＝ 8.99 × 10−5 ≈ 0.00009（df = n − 1 = 50 − 1 = 49）。

⚠️ lower.tail の使い分け（講義）：対立仮説が 「より大きい」（右側）→ lower.tail = FALSE、「より小さい」（左側）→ lower.tail = TRUE（左が下側）。

p値の定義：帰無仮説のもとで、標本のばらつきだけで、この検定統計量と同じかそれ以上に極端な値が出る確率。

結論の書き方（3点セット）

  1. p値とαの比較：p ≈ 0.00009 ＜ α ＝ 0.05
  2. H0 を reject（棄却）する
  3. 対立仮説の証拠がある（文脈で）：MIAの母平均評価は5.1より大きいという証拠がある（「ちょうど6.34」とは限らない）。

解釈文：「H0（母平均 5.1）のもとで、標本のばらつきだけで6.34以上（t ＝ 4.05以上）になる確率は約0.00009（0.009%）と極めて小さい」→ 説明①を捨て、説明②（対立仮説）の証拠があると結論します。

⚠️ 言葉づかい：p値がαより大きいときは「H0を棄却しない（do not reject）」で、対立仮説の証拠は見つからない。H0を「受け入れる（accept）」とは言わないし、H0の証拠を見つけるとも言わない。見つけるのは対立仮説の証拠だけ。「棄却する／しない」の2通りだけです。

ショートカット：t.test()

t.test(ratings, mu = 5.1, alternative = "greater")
One Sample t-test data: ratings t = 4.054, df = 49, p-value = 8.987e-05 alternative hypothesis: true mean is greater than 5.1 95 percent confidence interval: 5.827186 Inf sample estimates: mean of x 6.34
  • データ、帰無値 mu、対立仮説の向き alternative（"greater"）を渡すと、検定統計量・自由度・p値が出ます。
  • p値だけ欲しいときは t.test(...)$p.value。他の引数は ?t.test で確認。
  • 出力の信頼区間は片側（one-sided）の区間（上限が Inf）。通常は両側の区間を使います。

両側の対立仮説（alternativeを指定しない）にすると、p値は2倍の 0.0001797、区間は両側の (5.725322, 6.954678) です。

🎯 講師のまとめ：一番大事なのは、「p値とは何か」と「検定をどう結論づけるか（3つの部品）」をまず理解すること。計算はRが助けてくれます。
🍎 かんたん説明

「本当は変わっていない（H0）のに、こんなに高い平均がたまたま出る確率」がp値。それが0.00009とめちゃくちゃ小さいので、「たまたま」とは考えにくく、「本当に上がった」と言ってよい。

💻 ミニ練習：両側検定とその区間

ratings を使い、両側の検定（H0：μ ＝ 5.1）を t.test() で行ってください。出力の p値と95%信頼区間を読み取ります。

t.test(ratings, mu = 5.1)

t = 4.054、df = 49、p = 0.0001797（片側の2倍）。95%信頼区間は (5.725, 6.955) で、5.1 を含まないので、検定の結果（H0棄却）と一致します。

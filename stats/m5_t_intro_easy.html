🍎 超やさしい版：t手順①（1標本の平均）

「標本の平均から、本当の平均を幅つきで当てる／変わったかを確かめる」を、やさしく。

全体像区間95%の意味検定🧪 本編はこちら
①

全体像

区間と検定

🎯 これだけ覚えればOK

標本の平均は1つの数字。だから「幅」をつけて推定する（信頼区間）か、「変わった？」を確かめる（検定）。

✈️
航空券の平均が $300（点）より、$250〜$450（区間）のほうが「だいたいこの範囲」と分かって便利。
道具やること
信頼区間未知の平均を範囲で当てる
有意性検定「去年 $300 → 今年 $350」はたまたま？本当？
🍎 ひとことで

全員を調べる（全数調査）のは大変なので、一部（標本）で調べる。標本は毎回ちがうので、そのぶんの「ぶれ」を考えるのが推測統計です。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 全員を調べることを何という？A. 全数調査（census）。
Q2. 信頼区間と検定の違いは？A. 区間は未知の平均を範囲で推定。検定は仮説が正しいかを確かめる。
②

信頼区間を作る

平均 ± t* × SE

🎯 これだけ覚えればOK

区間 ＝ 平均 ± t* × SE。　SE ＝ s/√n。　t* ＝ qt(0.975, n−1)（95%のとき）。

🏦
コールセンター：50件、平均 18.353秒、s ＝ 11.761。目標は30秒以内。
xbar <- 18.353; s <- 11.761; n <- 50
se <- s / sqrt(n)                 # 1.663257
t_star <- qt(0.975, df = n - 1)   # 2.009575
me <- t_star * se                 # 3.342439
c(xbar - me, xbar + me)
[1] 15.01056 21.69544
✅
(15.0, 21.7) 秒。全部30秒より下なので、目標は達成できていそう！
信頼水準t*（df = 49）区間
95%2.0096(15.0, 21.7)
99%2.6800(13.9, 22.8)
⚠️ 区間は 丸括弧 ( , ) で書く。qt(49, 0.975) のように順番を逆にすると NaN になる。qt(0.975, 49) が正しい。
🍎 ひとことで

「18秒ぐらい。でも本当の平均は15〜21.7秒のどこかにありそう（95%）」。自信を99%に上げると、範囲は広くなります。

🤔 答えられるかな？（クリックで答えが開く）

Q1. SEは？A. s/√n ＝ 11.761/√50 ≈ 1.66 秒。
Q2. 95%信頼のt*を出すRの式は？A. qt(0.975, df = 49)（≈ 2.0096）。
Q3. 99%にすると区間は？A. 広くなる（13.9〜22.8 秒）。それでも30秒未満。
③

95%信頼ってなに？

手続きの成功率

🎯 これだけ覚えればOK

「95%信頼」＝ 同じやり方で何回も区間を作ると、約95%が本当の平均を捕まえる。

🎯
アプレットで μ ＝ 25 の母集団から標本を取り続けると、100回で94本、1000回で955本が25を含んだ。
40回区間を作ってみた（緑＝μ=25を含む／赤＝外れ）
40本中37本が含み、3本が外れた。
変えると誤差の幅 ME は
標本サイズ n を増やす小さくなる
信頼水準を上げる大きくなる

（どちらも「他は一定」のとき）

⚠️ 「ME」は標本のばらつきだけを扱う。聞き方が悪い質問や、偏った標本までは直してくれない。
🍎 ひとことで

95%は「1本の区間に入っている確率」ではなく、やり方の成功率。

🤔 答えられるかな？（クリックで答えが開く）

Q1. アプレットで赤い区間とは？A. 母平均（25）を含まなかった区間。
Q2. 区間を何回も作ると、含む割合は？A. 信頼水準（95%）に近づく。
④

平均の検定

マイアミ空港

🎯 これだけ覚えればOK

検定の流れ：仮説 → t ＝ (x̄ − μ0)/SE → p値 → 3点で結論。

🛬
マイアミ空港：50人の評価の平均 6.34、s ＝ 2.16。去年は 5.1。上がった？
H0（現状）μ ＝ 5.1
HA（知りたいこと）μ ＞ 5.1
se <- sd(ratings) / sqrt(50)               # 0.3058745
t_stat <- (mean(ratings) - 5.1) / se      # 4.053951
pt(t_stat, df = 49, lower.tail = FALSE)   # 8.986953e-05
🔎
t ≈ 4.05（SEの約4つ分も離れている）、p ≈ 0.00009。とても小さい！

結論の3点セット

① p ＜ α（0.05）　② H0を棄却　③ 母平均は5.1より大きいという証拠がある

⚠️ p値がαより大きいときは「棄却しない」。H0を「受け入れる」とは言わない。右側の対立仮説は lower.tail = FALSE。
🍎 ひとことで

p値は「本当は変わっていないのに、こんなに高い平均がたまたま出る確率」。小さければ「たまたま」ではなさそう。t.test(ratings, mu = 5.1, alternative = "greater") で一発。

🤔 答えられるかな？（クリックで答えが開く）

Q1. p値とは？A. H0が真のとき、この検定統計量以上に極端な値が出る確率。
Q2. p ＝ 0.00009、α ＝ 0.05 のときの結論は？A. H0を棄却。平均評価は5.1より大きいという証拠がある。
Q3. p値が大きいときは？A. H0を棄却しない（受け入れるとは言わない）。

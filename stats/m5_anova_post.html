M5 · ANOVA ③ — Post Hoc Tests: Tukey HSD & Bonferroni

🔍 ANOVA③：事後検定（Tukey HSD・Bonferroni）

ANOVA で「どこかに差がある」と分かったら、次は「どのグループとどのグループが違うのか」。それを調べるのが事後検定（post hoc test）です。

①

事後検定とは何か

ANOVA は「どこか」しか教えてくれない

前回までで、3つのダイエットプランの体重減少（weight loss）をANOVAで比べ、p = 0.0058という小さな p値を得ました。これは 5% の有意水準（α）よりずっと小さいので、「少なくとも2つのグループの母平均が違う」という証拠があります。

データ：3プランの体重減少（赤線＝各グループの平均）
Plan 1 = 7, 9, 5, 7（平均7）／ Plan 2 = 9, 11, 7（平均9）／ Plan 3 = 15, 12, 18（平均15）
weight_loss <- c(7, 9, 5, 7,  9, 11, 7,  15, 12, 18)
group <- factor(rep(c(1, 2, 3), times = c(4, 3, 3)))
summary(aov(weight_loss ~ group))
Df Sum Sq Mean Sq F value Pr(>F) group 2 114 57.00 11.73 0.00581 ** Residuals 7 34 4.86 --- Signif. codes: 0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

ところが ANOVA は「どのペアが違うのか」を教えてくれません。グループ1と2が違うのか？ 2と3が違うのか？ 全部違うのか？ ANOVA は「どこかに有意な差がある」と言うだけの omnibus test（総括的な検定）です。違いの場所を探すには、別の検定 post hoc test（事後検定）が必要です。

⚠️ 講師の強調：ANOVA が有意でも、「どのグループ同士が違うか」は分かりません。そこで ANOVA のあと（post hoc）に、ペアごとの比較をやり直します。ただし単純に t検定を何本も繰り返すと Type I error が膨らむので、「補正した」やり方を使います。

この講座で学ぶ2つの事後検定

方法考え方特徴
Bonferroni correction
（ボンフェローニ補正）		有意水準 α を厳しく（小さく）して、多重比較の誤りを抑えるANOVA 以外のどんな検定にも使える。いちばん厳格（stringent）
Tukey's HSD
（Honestly Significant Difference）		ペアごとの比較（pairwise comparisons）を、多重比較用の式で行うpower が高く、比較の数が多い（たとえば10グループ）ときに有効。より一般的で推奨

ほかに Scheffé's test や Fisher's LSD（Least Significant Difference）などの事後検定もあります（詳しくは講義ノート参照。LSD は薬物の LSD とは無関係）。Tukey は John Tukey にちなんだ名前です。

比較の数はどれくらい？

k 個のグループから2つ選ぶペアの数は k(k − 1) / 2 です。

🍎 かんたん説明

ANOVA は「どこかが違うよ」という火災報知器。どの部屋が火事かは教えてくれません。事後検定は、部屋を1つずつ調べる作業です。

💻 ミニ練習：比較の数

グループが6つあるとき、ペアでの比較は何通りになりますか。R の関数で計算してください（答えは15）。

choose(6, 2)

6 × 5 / 2 = 15 通り。順序は区別しない（1-2 と 2-1 は同じ）ので 2 で割ります。

②

Tukey's HSD

結果の読み方と信頼区間

Tukey's HSD は最も一般的な事後検定です。計算の中身（adjusted standard error の式）は手計算しませんが、「事後検定とは何か」と「結果の読み方」が大切です。通常の two-sample t区間と違って、多重比較に対応した調整済みの標準誤差の式を使い、全部のペアをまとめて 95% の信頼度にしたfamily-wise confidence intervalを作ります。

手順

  1. 実験結果を data frame にする。順序が大事：先に応答変数（weight_loss）、次にグループ（group）。
  2. ANOVA を実行して結果を保存（aov(lm(...))）。
  3. TukeyHSD() を実行。base R の関数で、追加パッケージは不要。結果は後でプロットできるよう、オブジェクト（tukey_test）に保存する。
results_df <- data.frame(weight_loss, group)
results_aov <- aov(lm(weight_loss ~ group, data = results_df))
tukey_test <- TukeyHSD(results_aov)
tukey_test
Tukey multiple comparisons of means 95% family-wise confidence level Fit: aov(formula = lm(weight_loss ~ group, data = results_df)) $group diff lwr upr p adj 2-1 2 -2.9572719 6.957272 0.4961594 3-1 8 3.0427281 12.957272 0.0051155 3-2 6 0.7004534 11.299547 0.0296150

結果の読み方

各行は1つのペアで、列は diff（平均の差）・lwr/upr（信頼区間の下限・上限）・p adj（調整済み p値）です。2-1 は「グループ2 − グループ1」の意味です。

ペア差95% CIp adj判断（α = 0.05）
2-12[−2.96, 6.96]0.496有意でない。CI が 0 を含む。Plan 1 と 2 の差の証拠なし
3-18[3.04, 12.96]0.0051有意。Plan 3 のほうが体重減少が大きい（約3〜13 lb）
3-26[0.70, 11.30]0.030有意。Plan 3 のほうが大きい（約0.7〜11.3 lb）
💡 p値と信頼区間は一致します：p adj < 0.05 ⇔ 95% CI が 0 を含まない。p adj が約 0.50 と大きいときは、区間が 0 を大きくまたぎます。

CI をプロットする

plot(tukey_test)
plot(tukey_test) のイメージ（点＝差、線＝95% CI）
2-1 は区間が 0 をまたぐ（証拠なし）。3-1 と 3-2 は区間全体が 0 より右（Plan 3 の方が高い）。

結論：ANOVA だけでは分からなかった「差の場所」が分かりました。Plan 3 は Plan 1 とも Plan 2 とも有意に違い（体重減少が大きい）、Plan 1 と Plan 2 の間には差の証拠がない。Tukey の HSD は、母平均に小さな p値の ANOVA 結果が出たあとに、その差がどこにあるかを調べる定番の方法です。

⚠️ data.frame(weight_loss, group) は応答変数が先。順序を逆にすると、モデルの式やグループの扱いがずれてしまいます。
🍎 かんたん説明

Tukey は「全員をまとめて比べる安全な比べ方」。区間が 0 をまたいだら『差があるとは言えない』、またがなければ『差がある』。これだけで読めます。

💻 ミニ練習：Tukey HSD を実行する

weight_loss と group から results_df を作り、aov(lm(...)) の結果に TukeyHSD() を適用して tukey_test に保存し、CI をプロットしてください。

results_df <- data.frame(weight_loss, group)
results_aov <- aov(lm(weight_loss ~ group, data = results_df))
tukey_test <- TukeyHSD(results_aov)
plot(tukey_test)

3-1 と 3-2 の区間が 0 を含まないので、Plan 3 が Plan 1・Plan 2 より有意に大きい。

③

Bonferroni correction

α を検定の回数で割る

多重検定をするとType I error（偽陽性）の確率が増えます。Bonferroni correction は、有意水準を検定の回数で割って厳しくする方法です。

調整後の有意水準 = α ÷ 検定の回数　　検定の回数 = k(k − 1) / 2

3グループなら検定は 3 × 2 / 2 = 3 回（たまたまグループ数と同じ）。4グループなら 4 × 3 / 2 = 6 回（1-2, 1-3, 1-4, 2-3, 2-4, 3-4）。順序を区別すると 12 通りですが、1-2 と 2-1 は同じなので 2 で割ります。

0.05 / 3
[1] 0.01666667

新しい有意水準は0.0167（Type I error の確率は 2% 未満）。2標本 t検定のそれぞれの p値が 0.0167 より小さいときだけ帰無仮説を棄却します。

例：t検定を3本やってみる（本当は避けたいやり方）

plan1 <- c(7, 9, 5, 7)
plan2 <- c(9, 11, 7)
plan3 <- c(15, 12, 18)
t.test(plan1, plan2)
t.test(plan1, plan3)
t.test(plan2, plan3)
Welch Two Sample t-test data: plan1 and plan2 t = -1.4142, df = 3.8571, p-value = 0.2327 alternative hypothesis: true difference in means is not equal to 0 95 percent confidence interval: -5.98451 1.98451 sample estimates: mean of x mean of y 7 9
Welch Two Sample t-test data: plan1 and plan3 t = -4.1779, df = 2.8924, p-value = 0.02682 alternative hypothesis: true difference in means is not equal to 0 95 percent confidence interval: -14.22416 -1.77584 sample estimates: mean of x mean of y 7 15
Welch Two Sample t-test data: plan2 and plan3 t = -2.8823, df = 3.4845, p-value = 0.05298 alternative hypothesis: true difference in means is not equal to 0 95 percent confidence interval: -12.1329472 0.1329472 sample estimates: mean of x mean of y 9 15

t.test() の既定値は var.equal = FALSE（等分散を仮定しない Welch 検定）と alternative = "two.sided"（両側）。書かなくても同じ結果です。

3本の p値と有意水準
通常の α = 0.05 なら 1 vs 3（p = 0.027）が有意。でも Bonferroni の 0.0167 では3本とも有意でない。
ペアp値α = 0.05Bonferroni（0.0167）
Plan 1 vs 20.233有意でない有意でない
Plan 1 vs 30.027有意有意でない
Plan 2 vs 30.053有意でない有意でない
⚠️ Tukey と結論が違う！前の単元では Tukey HSD で 3-1 と 3-2 が有意でした。Bonferroni + 個別 t検定では何も見つかりません。ANOVA と Tukey HSD の組み合わせのほうが、差を検出できます。

Bonferroni の代償

  • 有意水準を小さくすると Type I error は減るが、Type II error（偽陰性）が増える。帰無仮説を棄却しにくくなる。
  • 検出力（statistical power）が下がる。「棄却すべきときに棄却できる確率」が下がり、Plan 3 が本当に効くことを見逃すかもしれない。
  • Bonferroni は最も厳格（stringent）な方法の1つ。
🍎 かんたん説明

検定を3回やるなら、1回あたりの合格ラインを 0.05 から 0.0167 にきびしくします。そのぶん『差がある』と言いにくくなります。

💻 ミニ練習：調整後の α

4グループを総当たりで比べるとき、Bonferroni 補正後の有意水準（α = 0.05）を R で計算してください（比較は6回。答えは約 0.00833）。

m <- choose(4, 2)   # 6 回
0.05 / m

0.05 / 6 = 0.008333…。グループが増えると比較の数が増え、基準がどんどん厳しくなります。

④

使い分けとまとめ

ANOVA → Tukey を基本に

2つの事後検定の使い分けを、同じデータで整理しましょう。

t検定を3本 + BonferroniANOVA → Tukey HSD
基準各 p値 < 0.0167p adj < 0.05（family-wise）
Plan 3 vs Plan 1p = 0.027 → 有意でないp adj = 0.0051 → 有意
Plan 3 vs Plan 2p = 0.053 → 有意でないp adj = 0.030 → 有意
Plan 1 vs Plan 2p = 0.233 → 有意でないp adj = 0.496 → 有意でない
Type II error多い（保守的）比較的少ない（power が高い）
💡 講師のまとめ：多重検定は避ける。やるなら Bonferroni correction を使って Type I error を不必要に増やさない。ただし Type I error を下げると Type II error が上がる。おすすめは「ANOVA を実行 → 有意なら Tukey HSD」。

判断フロー

  1. 3グループ以上の平均を比べたい → まず aov() で ANOVA。
  2. p値が小さい → 「少なくとも2つの母平均が違う」。
  3. 「どのペア？」を調べるため TukeyHSD()。p adj と CI（0 を含むか）で読む。
  4. CI が 0 を含まないペア → そのペアの母平均に差の証拠あり。

おまけ：pairwise.t.test()

R には、補正付きのペアごと t検定をまとめて出す pairwise.t.test() があります。既定は全グループの共通の SD（pooled SD）を使うので、前の単元の Welch の t検定とは数値が変わります（p値は Bonferroni 補正後）。

pairwise.t.test(weight_loss, group, p.adjust.method = "bonferroni")
pairwise.t.test(weight_loss, group, p.adjust.method = "bonferroni", pool.sd = FALSE)
Pairwise comparisons using t tests with pooled SD data: weight_loss and group 1 2 2 0.8205 - 3 0.0062 0.0376 P value adjustment method: bonferroni
Pairwise comparisons using t tests with non-pooled SD data: weight_loss and group 1 2 2 0.70 - 3 0.08 0.16 P value adjustment method: bonferroni
⚠️ 講義の「3本とも有意でない」は、グループごとの SD を使う Welch の t検定（t.test()）を3本やって 0.0167 と比べた場合の話です。pooled SD では 1 vs 3 と 2 vs 3 が有意になります。pooled SD は「3グループの分散が等しい」という仮定を使うぶん、情報を多く使えるためです。
🍎 かんたん説明

ANOVA → Tukey が基本の流れ。Bonferroni は『検定を何本もやってしまったとき』の安全ベルト。ただし安全ベルトは強すぎて、本当の差も見逃しがちです。

💻 ミニ練習：p値と信頼区間

Tukey の結果で 3-1 の信頼区間は [3.04, 12.96] でした。tukey_test の中身を数値の行列として取り出して表示する R コードを書いてください（$group を使う）。

tukey_test$group

$group は diff / lwr / upr / p adj の4列の行列です。

🍎 超やさしい版：予測と区間

「70°Fの日、自転車は何台？」を、1つの数だけでなく幅つきで答える練習です。

予測する平均の幅 CI1日の幅 PIくらべる📊 本編はこちら
📖 講義動画：「Making a prediction with linear regression」「Confidence interval for Y」「Prediction Interval for Y」。データは bikes.csv（731日分）、モデルは temp_model <- lm(rentals ~ temperature, data = bikes)。
①

予測する

気温を直線に入れるだけ

🎯 これだけ覚えればOK

ŷ = −166.88 + 78.50 × 気温。新しい気温には predict() を使う。

📈
気温が1°F上がるごとに、レンタルは平均で約78.5台ふえる。15番目の日（37.3°F）は、予測 2764 台・実測 1248 台で、残差は −1516（予測しすぎ）。
new.data <- data.frame(temperature = c(50, 70))
predict(temp_model, newdata = new.data)
1 2 3757.893 5327.801
⚠️ fitted.values は、データにある行だけ。predict() は新しい気温でもOK（新しいデータはデータフレームで渡す）。
🍎 ひとことで

予測は「気温を式に入れる」だけ。ただし出てくるのは当たる保証のない1つの数です。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 残差 e はどうやって求める？A. 実測 − 予測。15番目の日は 1248 − 2764 = −1516。
Q2. データにない気温の予測に使うのは？A. predict()。fitted.values はデータの行だけ。
②

平均の幅 CI

信頼区間（confidence interval）

🎯 これだけ覚えればOK

CI は「70°Fの日の平均はこの範囲」。幅はせまい。

new.data <- data.frame(temperature = c(70))
predict(temp_model, newdata = new.data,
        interval = "confidence", level = 0.95)
fit lwr upr 1 5327.801 5195.392 5460.209
🎯
5195 〜 5460 台 → 気温70°Fの日の平均レンタル数は、95%の確信でこの範囲。

気温を使わずに平均だけで作った区間は (4363.684, 4645.014)。70°Fの日の需要をかなり少なく見積もってしまいます。

🍎 ひとことで

クラスの平均点は当てやすい。だから CI の幅はせまい。

🤔 答えられるかな？（クリックで答えが開く）

Q1. CI の interval には何と書く？A. "confidence"。
Q2. 気温を無視した平均の区間はなぜダメ？A. 70°Fの日の需要を大きく少なく見積もってしまうから。
③

1日の幅 PI

予測区間（prediction interval）

🎯 これだけ覚えればOK

PI は「70°Fのある1日はこの範囲」。CI よりずっと広い。

new.data <- data.frame(temperature = 70)
predict(temp_model, newdata = new.data,
        interval = "prediction", level = 0.95)
fit lwr upr 1 5327.801 2361.577 8294.024
📏
2362 〜 8294 台 → ある1日のレンタル数は、95%の確信でこの範囲。fit は同じ 5327.801。
🍎 ひとことで

あなた1人の点数は当てにくい。だから PI の幅は広い。「個々は平均よりばらつく」。

🤔 答えられるかな？（クリックで答えが開く）

Q1. CI から PI に変えるとき、書きかえるのは？A. interval の1か所だけ（"prediction"）。
Q2. 70°Fで PI が広いのはなぜ？A. 1日ごとのレンタル数は、平均よりずっとばらつくから。
④

くらべる

同じ気温で並べる
70°Fの日区間誤差の幅
CI（平均）5195.392 〜 5460.209±132.4
PI（1日）2361.577 〜 8294.024±2966.2
⚠️
平均を知りたい → CI。ある1日を知りたい → PI。どちらも、データの端のほうで広がる。
青＝CI、黄＝PI
🍎 ひとことで

点（predict）→ 平均の幅（"confidence"）→ 1日の幅（"prediction"）。同じ fit、幅だけちがう。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 90°Fの日、CI と PI はどちらが広い？A. PI（CI は 6655.548〜7139.869、PI は 3924.563〜9870.853）。
Q2. 在庫不足を避けたい会社は、どちらの端に注目する？A. 上限（upper）。たとえば70°Fの平均なら 5460 台。

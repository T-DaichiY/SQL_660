①

標本の傾きは推定値

標本分布・標準誤差・t 分布（df = n − 2）

これまで学んだ推測の考え方を思い出しましょう。標本から計算した統計量（statistic）で、わからない母集団の母数（parameter）を推し量るのでした。標本平均 x̄ で母平均 μ を、標本比率 p̂ で母比率 p を推定したのと同じように、今回は標本の傾き b（b₁、β̂₁ とも書く）で、母集団の回帰直線の傾き β（ベータ）を推定します。

標本（わかっている）母集団（わからない）
平均x̄μ
比率p̂p
回帰直線の傾きb（b₁, β̂₁）β
💡 傾きは量的データ（quantitative）から作る統計量です。平均と同じ仲間（t 分布を使う）で、比率のようなカテゴリカルデータの仲間（z を使う）ではありません。

この講義では、これまで何度も使ってきた寄付者データで、最大寄付額 largestGiftAmount（x）から総寄付額 totalGivingAmount（y）を予測する回帰を扱います。母集団は95,412人（9万人を超える寄付者）で、そこから無作為に50人（n = 50）を取り出したのが標本です。

donors <- read.csv('donors.csv')

set.seed(1)
# 母集団の行番号から50個を無作為に選ぶ
sampleIDs <- sample(1:95412, size = 50, replace = FALSE)
myColumns <- c("age", "incomeRating", "totalGivingAmount", "largestGiftAmount",
               "isHomeowner", "gender", "urbanicity", "respondedMailing")
sampleDonors <- donors[sampleIDs, myColumns]

model <- lm(sampleDonors$totalGivingAmount ~ sampleDonors$largestGiftAmount)
summary(model)

set.seed(1) を付けると乱数が固定され、誰が実行しても同じ50人が選ばれて同じ結果になります。標本の傾きは b = 3.910 です。

標本の50人（点）と最小二乗直線（赤）
点は寄付者1人ずつ（データは R の donors から）。右上に飛び抜けた点や、x が大きい点があり、傾きを引っ張っている可能性があります。

標本が変わると傾きも変わる（sampling variability）

講師は4つの異なる無作為標本（各 n = 50）でそれぞれ最小二乗直線を引いて見せました。散布図が違えば傾き b も相関 r も違います。たとえばある標本では相関が低く（0.35）、別の標本では高い（0.78、飛び抜けた点が2つあるため）という具合です。別の標本を取れば別の統計量が出る。これが標本変動です。

知りたいのは「母集団の傾き β の真の値」ですが、b は標本ごとにゆれます。そこで、どれくらいゆれるかを数にしたものが傾きの標準誤差 SE(b)（standard error of the slope）です。

  • SE(b) が小さい → 標本が変わっても b はあまりゆれない → 推定がしっかりしている。
  • SE(b) が大きい → b が大きくゆれる → 推定があいまい。
  • 標本の傾き b を SE(b) で割ると、t 分布（自由度 df = n − 2）に従う統計量になる。
⚠️ 自由度は n − 2 = 50 − 2 = 48 です。n − 1 ではありません。直線を決めるために切片と傾きの2つをデータから推定しているからです（講師が「あとの計算で大事」と強調した点）。
🍎 かんたん説明

50人を選び直すたびに、引ける直線は少しずつ違います。「本当の傾き β」は1つだけなのに、手元の b は毎回ゆれる。だから b をゆれの大きさ SE(b)と一緒に読む、というのが傾きの推測です。

💻 ミニ練習：標本を取って回帰する

set.seed(1) で乱数を固定し、1〜95412 から50個を重複なしで選んで sampleIDs に入れてください。そのあと sampleDonors を使って、totalGivingAmount を largestGiftAmount で予測する線形モデルを model に作り、summary() で表示します（sampleDonors は作成済みとしてかまいません）。

set.seed(1)
sampleIDs <- sample(1:95412, size = 50, replace = FALSE)

model <- lm(sampleDonors$totalGivingAmount ~ sampleDonors$largestGiftAmount)
summary(model)

lm(y ~ x) は「y を x で説明する」モデル。summary() の係数表で傾きの行を見ると、Estimate = 3.910、Std. Error = 0.782 です。

②

傾きの信頼区間

b ± t* × SE(b)、qt() と confint()

未知の母集団の傾き β を区間で推定するのが信頼区間（confidence interval, CI）です。作り方は、これまでの信頼区間とそっくりです。

何の信頼区間か式
母平均 μx̄ ± t* × SE(x̄)
母集団の傾き βb ± t* × SE(b)（t* は自由度 df = n − 2 の t 分布の臨界値）

「統計量 ± 臨界値 × 標準誤差」という形は同じで、b を中心に、前後に誤差の幅（margin of error）を取ります。必要な数字は summary(model) の係数表（傾きの行）にあります：Estimate = 3.910（b）、Std. Error = 0.782（SE(b)）。

t 分布（df = 48）と臨界値 t* = 2.01
中央 95% をはさむ境目が ±2.01。95% の信頼区間では、両端の赤い部分（合計5%、片側2.5%ずつ）を除いた中央の幅を使います。

手順1：臨界値 t* を求める

95% 信頼 → 両側に 2.5% ずつ残す → 0.975 のパーセンタイル、自由度は 50 − 2 = 48。

tcrit <- qt(p = 0.975, df = 50 - 2)
tcrit
[1] 2.010635

手順2：下限と上限を計算する

# 下限 (lower bound)
3.910 - tcrit * 0.782

# 上限 (upper bound)
3.910 + tcrit * 0.782
[1] 2.337292 [1] 5.481925

誤差の幅（margin of error）は t* × SE(b) = 2.01 × 0.782 ≈ 1.57。つまり 3.91 ± 1.57 で、区間は (2.34, 5.48) です（講義の画面では 2.33 〜 5.48 と表示。下限 2.337… の表示の違いです）。

手順3：confint() で確認する

R には、モデルとレベルを渡すだけで区間を返す関数 confint() があります。パーセンタイルを自分で考える必要はなく、level に信頼水準をそのまま書きます。

confint(model, level = 0.95)
2.5 % 97.5 % (Intercept) -3.056523 106.690339 sampleDonors$largestGiftAmount 2.337298 5.481919

2行目が傾きの区間です。手計算との小さな差は、手計算で b と SE を丸めた値（3.910、0.782）を使ったためです。

💡 信頼水準を変えると幅が変わります（同じ標本で）：90% は (2.60, 5.22)、95% は (2.34, 5.48)、99% は (1.81, 6.01)。「より確実に」と望むほど、区間は広くなります。

解釈：区間は母集団の傾きを捕まえたか？

通常、母集団の傾きは未知です。でもこの例では、95,412人全員のデータ（母集団）があるので、答え合わせができます。母集団全体で回帰直線を引くと、母集団の傾き β = 2.64（黒い線）。標本の傾きは b = 3.91（赤い線）です。標本の直線は、標本変動のぶんだけ母集団の直線とずれています。

popLine <- lm(donors$totalGivingAmount ~ donors$largestGiftAmount)
popLine$coefficients[2]
donors$largestGiftAmount 2.636853
標本の直線（赤）と母集団の直線（黒）
点は標本の50人のみ。黒の線は95,412人全員の回帰直線で、標本の赤い線よりゆるやかです。
傾きの95%信頼区間（数直線）
区間 (2.34, 5.48) の中に母集団の傾き 2.64 が入っています。0 は区間の外です。

結論の書き方：「私たちは、最大寄付額で総寄付額を予測する、この団体の全寄付者の回帰直線の母集団の傾きを、区間 2.3 〜 5.5 が捕まえていると 95% 確信している。」

そして実際、母集団の傾きは 2.64 なので、この区間は母数を捕まえました（captured）。

⚠️ 「95%」の意味：この1本の区間が当たる確率が95%ではなく、別々の標本から同じ手順で何度も区間を作ると、その約95%が母数を含むということです。現実では母集団の傾きは未知なので、「捕まえたかどうか」は確かめられません。だからこそ、区間の意味と捕まえたかどうかの確かめ方（この例では母集団の β と比べる）を理解しておきましょう。
⚠️ この区間は信頼できるか？ 散布図には怪しい点（右上の飛び抜けた点や、x が大きい点）があります。極端な値が傾きを動かしているかもしれないので、区間を使うときは慎重に。
🍎 かんたん説明

信頼区間は「真の傾きはこのあたりにあるはず」という幅つきの推測です。b = 3.91 を中心に前後 1.57 → 2.34 〜 5.48。真の値 2.64 はちゃんとその中にありました。

💻 ミニ練習：t* を求める

自由度 48 の t 分布で、95% 信頼区間に使う臨界値 t* を qt() で求め、tcrit に入れてください。

tcrit <- qt(p = 0.975, df = 50 - 2)
tcrit

結果は 2.010635。qt(0.975, 48) と書いても同じです。0.975 は「両側 5% → 片側 2.5% を除いた」下から 97.5% の位置です。

💻 ミニ練習：confint で区間を出す

モデル model に対し、傾きの 90% 信頼区間を confint() で求めてください。95% の区間と比べて、広がりますか、狭まりますか。

confint(model, level = 0.90)

傾きの行は 2.598 〜 5.221。95% の (2.337, 5.482) より狭くなります（確信の度合いを下げると区間は狭くなる）。

③

傾きの有意性検定

H₀: β = 0、t 統計量、p 値、結論の書き方

信頼区間が「未知の傾き β はいくつ？」を推定するのに対し、有意性検定（significance test = 仮説検定 hypothesis test）は「この標本の傾きは、2つの変数に関連があるという証拠になるか？」に答えます。

標本ごとに傾きは違うので、b ≠ 0 でも、(a) 標本がたまたまそうなっただけ、(b) 母集団に本当に関連がある、のどちらかです。検定は「(a) だとしたらこんな傾きがどれくらい起こりうるか」を調べます。

回帰モデルの目標は、各説明変数（predictor）の p 値が小さいこと、そしてモデル全体の R² が高い（1 に近い）ことです。

ステップ1：仮説を立てる（α = 0.05）

帰無仮説 H₀（null）β = 0（2つの変数に関連はない。母集団の回帰直線の傾きは 0）
対立仮説 Hₐ（alternative）β ≠ 0（関連がある。傾きは 0 ではない）

β は母集団の回帰直線の傾きです（標本の b ではありません）。

💡 統計的に有意（statistically significant）とは、慣例として p 値が 5% より小さいこと。p 値は「帰無仮説が正しいと仮定したとき、今回の標本傾き以上に極端な値が、標本変動だけで起こる確率」です。

ステップ2：summary(model) から読む

先ほどの出力の傾きの行に注目します。

summary(model)$coefficients[2, ]
Estimate Std. Error t value Pr(>|t|) 3.909609e+00 7.819973e-01 4.999517e+00 8.074946e-06
  • t value = 5.000（検定統計量）
  • Pr(>|t|) = 8.07e-06。e-06 は ×10⁻⁶ のこと。つまり 約 8 × 10⁻⁶（0.000008）で、8 の前にゼロがたくさん並ぶ非常に小さい数です。
  • 右端の *** は「p 値は実質 0 に近い」という目印で、統計的に有意と数えます。

ステップ3：判断する

p 値 ≈ 8 × 10⁻⁶ ＜ α = 0.05 → 帰無仮説 H₀ を棄却（reject）します。偶然では起こりにくい。

結論の書き方：「p 値が α = 0.05 より小さいので、この団体の全寄付者について、最大寄付額で総寄付額を予測する母集団の回帰直線の傾きは 0 ではないという説得力のある証拠（convincing evidence）がある。言いかえると、最大寄付額と総寄付額の間に関連（association）がある。」

💡 前の動画で、母集団の傾きは 2.64（≠ 0）でした。検定の結論と合っています。ただし現実では母集団の傾きは知らないので、検定で判断します。
⚠️ p ≥ 0.05 のときは「H₀ を棄却できない（fail to reject）」と言います。「H₀ が正しい」とは言いません。

t と p を手計算で確かめる

検定統計量の式は、これまでの検定と同じ形です：（統計量 − 帰無仮説の値）÷ 標準誤差。

t = (b − 0) ÷ SE(b) = 3.910 ÷ 0.782 = 5.00　（df = n − 2 = 48）

(3.910 - 0) / 0.782
[1] 5

表の t value と一致します。p 値は、右側の面積を pt() で求めます。t = +5 と正なので、lower.tail = FALSE（右側が欲しい）。対立仮説が両側（β ≠ 0）なので、2 倍します。

pt(5, df = 50 - 2, lower.tail = FALSE)
2 * pt(5, df = 50 - 2, lower.tail = FALSE)
2 * pt(-5, df = 48)   # 左側の面積を2倍しても同じ
[1] 4.030833e-06 [1] 8.061665e-06 [1] 8.061665e-06

右側だけだと 4.03 × 10⁻⁶（表の値の半分）なので、2 倍して 8.06 × 10⁻⁶。これが回帰出力の p 値（約 8 × 10⁻⁶）と一致します。（出力の 8.07e-06 は、丸める前の t = 4.9995 から計算した値のため、わずかに違います。）

💡 信頼区間との関係：95% の信頼区間 (2.34, 5.48) は 0 を含みません。α = 0.05 の検定で H₀: β = 0 を棄却したことと一致します。

統計的有意と実質的有意は別物

p 値が小さくても、効果の大きさ（effect size）が小さければ実務上は重要でないことがあります。たとえば「欠席数が説明変数、授業の成績が応答変数」で p 値が極端に小さくても、欠席1回あたり成績が 1% 下がるだけなら、成績に目立つ差が出るほど何日も休まなければなりません。p 値が小さい ≠ 実質的に重要。「p 値が小さいから論文になる！」と喜ぶ前に、効果の大きさを考えましょう。もっと役に立つのはモデルがどれくらい当てはまるか（R²）です。

💡 この例の R² は 0.3424（総寄付額の変動の約34%を最大寄付額で説明）。p 値は極めて小さいのに、説明できているのは約3分の1です。
🍎 かんたん説明

H₀ は「本当は傾き 0（関係なし）」という仮説。そう仮定すると、b = 3.91 のような傾きが偶然出る確率（p 値）は約 0.0008%。ほぼあり得ないので「関係なし」は疑わしい、と判断します。

🎯 課題（講師から）：同じ個体について2つの量的変数を選び、傾きの信頼区間と有意性検定を行ってみましょう。donors データには今回使っていない量的データがたくさんあります。興味のあるデータを探して、データの出どころを書き、検定と区間を解釈するポートフォリオ作品にするのもおすすめです。
💻 ミニ練習：検定統計量 t を計算する

傾きの検定統計量 t を、b = 3.910、帰無仮説の値 0、SE(b) = 0.782 から R で計算してください。

(3.910 - 0) / 0.782

結果は 5（t = 5.00）。summary(model) の t value と一致します。

💻 ミニ練習：両側の p 値を求める

t = 5、自由度 n − 2（n = 50）の t 分布で、両側検定の p 値を pt() で求めてください。右側の面積を取り、両側なので 2 倍します。

2 * pt(5, df = 50 - 2, lower.tail = FALSE)

結果は 8.061665e-06。2 を掛け忘れると 4.03e-06 になってしまいます。

💡 傾きの行を3ステップで使う：
① Estimate が b、Std. Error が SE(b)。これで信頼区間 b ± t* × SE(b)。
② t value ＝ b ÷ SE(b)、Pr(>|t|) が両側 p 値。これで H₀: β = 0 の検定。
③ Multiple R-squared で、モデルの当てはまり（実質的な意味）を確認する。

切片の行の p 値（0.0636）は、「切片 = 0 か」の検定です。この例では 5% より大きいですが、今回の主役は傾きです。

数値だけを取り出して使うこともできます。

summary(model)$coefficients[2, 3]   # 傾きの t value
summary(model)$coefficients[2, 4]   # 傾きの p 値
summary(model)$r.squared            # R-squared
[1] 4.999517 [1] 8.074946e-06 [1] 0.3424222
📌 補足（講義外）：出力の最後の行 F-statistic: 25 on 1 and 48 DF, p-value: 8.075e-06 は、モデル全体の検定です。説明変数が1つだけの単回帰では、F = t² = 5² = 25 で p 値も傾きの p 値と同じになります。
🍎 かんたん説明

出力の傾きの行を横に読むと「推定 3.91、ゆれ 0.78、だから 3.91 ÷ 0.78 = 5、それが偶然で起こる確率は約 8×10⁻⁶」。この1行から、区間と検定の両方が作れます。

💻 ミニ練習：傾きの p 値を取り出す

summary(model) の係数表から、傾きの行（2行目）の Pr(>|t|)（4列目）だけを取り出す R コードを書いてください。

summary(model)$coefficients[2, 4]

結果は 8.074946e-06。[2, 3] なら t value（4.999517）、[2, 2] なら SE(b)（0.7819973）になります。

📖 用語集

slope (b, β̂₁)
標本の傾き
標本の回帰直線の傾き。母集団の傾き β を推定する統計量。
population slope (β)
母集団の傾き
母集団全体の回帰直線の傾き（母数）。通常は未知。
standard error of the slope SE(b)
傾きの標準誤差
標本が変わったときの b のゆれの大きさ。summary の Std. Error。
sampling variability
標本変動
標本が変わるたびに統計量の値が変わること。
degrees of freedom (df)
自由度
傾きの推測では n − 2（切片と傾きを推定するため）。
critical value (t*)
臨界値
信頼水準で決まる t 分布の値。95% なら qt(0.975, 48) = 2.01。
confidence interval
信頼区間
b ± t* × SE(b)。母数を捕まえる区間を作る手順。
margin of error
誤差の幅
t* × SE(b)。この例では約 1.57。
null / alternative hypothesis
帰無仮説／対立仮説
H₀: β = 0（関連なし）／Hₐ: β ≠ 0（関連あり）。
test statistic
検定統計量
t = (b − 0) ÷ SE(b)。この例では 5.00。
p-value
p 値
H₀ のもとで、今回以上に極端な傾きが偶然起こる確率。この例は約 8 × 10⁻⁶。
practical significance
実質的有意性
効果の大きさが現実に意味を持つか。p 値が小さくても別問題。

💡 学習のヒント

傾きの行を読む順番：Estimate（b）→ Std. Error（SE）→ t value（= b ÷ SE）→ Pr(>|t|)（p 値）。区間は b ± t* × SE、検定は H₀: β = 0。df はいつも n − 2。p 値が小さいだけでなく、効果の大きさと R² も見ること。

カテゴリでも予測できる

ダミー変数と基準カテゴリ

🎯 これだけ覚えればOK

カテゴリは「0 か 1 のスイッチ」にして使う。切片は基準の人の予測値、係数は「基準とのちがい」。

寄付者データ（50 人）で、総寄付額 totalGivingAmount を性別 gender で予測します。標本は女性 27 人、男性 22 人。

model_gender <- lm(totalGivingAmount ~ gender, data = sampleDonors)
summary(model_gender)
Coefficients: Estimate Std. Error t value Pr(>|t|) (Intercept) 139.17 33.05 4.211 0.000114 *** gendermale 22.08 49.32 0.448 0.656465
🔘
ŷ = 139.17 + 22.08 × male
男性でないとき male = 0 → 139.17（女性）
男性のとき male = 1 → 161.25（男性）
しくみ意味
基準カテゴリ（reference group）スイッチが 0 の人たち（ここでは女性）。その予測値が切片 139.17。
係数 22.08男性は女性より 22.08 多いと予測、という「差」。
予測のコードpredict(model_gender, data.frame(gender = "male")) → 約 $161
⚠️ p 値は 0.656 でとても高い。この男女差は偶然かもしれません。「男性のほうが多く寄付する」とは言えません（標本が限られているので）。
🍎 ひとことで

カテゴリは「基準」を 1 つ決めて、他は「基準よりいくつ多い？」で表す。係数が「差」。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 切片 139.17 はだれの予測値？A. 基準カテゴリ（女性）の予測値。
Q2. 男性の予測値は？A. 139.17 + 22.08 = 161.25（約 $161）。
Q3. gender の p 値が高いと何が言える？A. 男女差が偶然かもしれないので、一般化してはいけない。

水準がたくさんあるとき

urbanicity の 5 水準

🎯 これだけ覚えればOK

水準が 5 つなら、基準を除いた 4 つのスイッチ。基準の予測値は切片そのもの。

居住地域 urbanicity は city・rural・suburb・town・urban の 5 つ（人数は 9・14・7・8・11）。基準は city です。

🏘️
ŷ = 199.28 − 113.63 (rural) + 18.72 (suburb) − 84.47 (town) − 60.47 (urban)
地域計算予測
city（基準）切片だけ$199.28
rural199.28 − 113.63約 $85
suburb199.28 + 18.72$218
🍎 ひとことで

0 と 1 を入れる項が増えるだけ。予測したい地域の項に 1、あとは全部 0 を入れて足し算。

🤔 答えられるかな？（クリックで答えが開く）

Q1. city の項が式にないのはなぜ？A. city が基準カテゴリなので、切片に含まれているから。
Q2. rural の予測は？A. 199.28 − 113.63 ≈ 85.65、約 $85。

重回帰：理由がいくつもあるとき

調整済み R² と「他を一定に」

🎯 これだけ覚えればOK

説明変数は + でつなぐ。評価は調整済み R²。係数は「他を一定にしたとき」と言う。

米国西部の公立大学 9 校で、卒業率 rate を支出 expend と SAT の中央値 SAT で予測します。

モデルR²調整済み R²
支出のみ0.6180.564
SAT のみ0.8350.811
両方（重回帰）0.8410.788
model_mult <- lm(rate ~ expend + SAT)
summary(model_mult)
Coefficients: Estimate Std. Error t value Pr(>|t|) (Intercept) -37.777476 16.503961 -2.289 0.0620 . expend 0.002011 0.004115 0.489 0.6425 SAT 0.080646 0.027766 2.905 0.0272 * Multiple R-squared: 0.8413, Adjusted R-squared: 0.7884
🎓
SAT だけのほうがよいモデル。調整済み R² は 0.811 → 0.788 に下がった。役に立たない支出を入れたからです。「ただお金を投入すればよいわけではない」。
🔑 係数の言い方：「median SAT が 100 点増えるごとに、卒業率は 8.1% 増えると予測される、expenditure を一定にしたとき」（0.081% × 100 = 8.1%）。
🍎 ひとことで

調整済み R² は「入れすぎたら減点」の採点。係数は「ほかの条件をそろえたら、この変数が 1 増えると予測がいくつ変わる？」。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 重回帰のコードは？A. lm(rate ~ expend + SAT)（説明変数を + でつなぐ）。
Q2. なぜ調整済み R² を使う？A. 役に立たない変数を入れても R² は上がってしまうので、その分を減点するため。
Q3. 「holding expenditure constant」とは？A. 支出が同じ大学どうしで比べたとき、という意味。

まとめ：M6 の全体像

相関 → 回帰 → 推測 → 拡張

🎯 これだけ覚えればOK

相関で「見る」→ 回帰で「式にする」→ 推測で「偶然か確かめる」→ 拡張で「カテゴリ・複数の変数」。

ステップ使うもの一言
① 相関散布図、r強さと向き。相関 ≠ 原因
② 回帰lm(y ~ x)、残差、R²ŷ = b₀ + b₁x で予測
③ 推測信頼区間、t 検定、p 値傾きは偶然ではない？（donors：傾き 3.910、p = 8.07e-06）
④ 拡張ダミー変数、重回帰カテゴリや複数の変数も OK
⚠️ 回帰の結果は 3 点セットで読もう：①p 値は低い？ ②R²（重回帰は調整済み R²）は高い？ ③ 係数を単位つきで言える？（重回帰なら「他を一定にして」）
📝 課題：自分のデータで重回帰モデルを作り、R² と調整済み R²、各変数の有意性を確かめて portfolio に入れましょう。
🍎 ひとことで

M6 の流れは「見る → 式にする → 確かめる → 広げる」。p 値と R² と単位をいつもセットで確認しよう。

🤔 答えられるかな？（クリックで答えが開く）

Q1. M6 の 4 つのステップは？A. 相関 → 回帰 → 推測 → 拡張（カテゴリ・重回帰）。
Q2. カテゴリ変数の係数は何を表す？A. そのカテゴリと基準カテゴリの差。

回帰とは

予測と関連、説明変数と応答変数

これまで学んだ相関 rは、2つの量的変数の関係を1つの数で表しました。このモジュールの主役は回帰（regression）です。じつは相関の記号 r は、regression（回帰）の頭文字から来ています。それくらい両者は近い関係です。

回帰でできることは大きく2つです。

  • 予測（prediction）：ある値 x を決めたとき、それに対応する y を予測する。データから予測できることは、多くの企業やビジネスで役に立ちます。
  • 関連（association）の確認：2つの変数に関連があるか。「一方が増えると他方も増える（または減る）か」を調べる。確率の単元の二元表（two-way table）ではカテゴリ変数の独立・関連を扱いましたが、ここでは量的変数（quantitative variable）どうしを調べます。

散布図と time series

散布図（scatterplot）は、同じ個体の2つの量的変数の関係を見せる図です。講義では、ビジネス分析の教科書のデータ（バスの年数 age と年間維持費 cost）を使いました。なお、time series（時系列）とは、x軸に時間（秒・月・年・十年など）をとった散布図のことで、このバスの図もそうです。

age <- c(1, 2, 2, 2, 2, 3, 4, 4, 5, 5)
cost <- c(350, 370, 480, 520, 590, 550, 750, 800, 790, 950)

plot(age, cost, pch = 16, las = 1, cex = 1,
     xlab = "Age of Bus (years)", ylab = "Annual Maintenance Cost ($)")
バスの年数と年間維持費（左：傾向をとらえた直線 / 右：点を全部つなぐ「過学習」）
左は「全体として右上がり」という傾向（trend）を表す直線。右の「connect-the-dots」は点にぴったり合わせた線で、新しいバスのデータが来ると合いません。

x軸は年数（1〜5）、y軸は維持費（400未満〜900超）。説明変数（explanatory variable）= バスの年数、応答変数（response variable）= 年間維持費で、どちらも量的変数です。このバスの例で、年数が増えるほど維持費も増える右上がりの傾向があり、関連があると言えます。車を持ったことがあれば納得ですね。古い車ほど維持にお金がかかります。

講師はここで、こんな場面を例に挙げました。たとえば2.5年のバスの維持費を、この関係から予測できるでしょうか。この関係がなければ、どれくらいが妥当か見当もつきません。また、もし3.5年のバスの費用が傾向よりずっと上にあったら、他のバスの傾向から外れているので「ちょっと気になる（concerning）」点になります。

Outcome = Model + Error と過学習

図を見ると、点は右上がりの傾向のまわりにばらついています。このばらつき（variability）は悪いことではなく、そういうものです。同じ年数のバスでも維持費はバスごとに違います。

⚠️ 統計の「error」は「間違い」ではありません。期待（モデル）からのずれ（deviation）、つまりばらつきのことです。
回帰の基本の考え方は Outcome = Model + Error（結果 = モデル + 誤差）です。

機械学習でよく聞く過学習（overfitting）とは、点を全部つなぐ「connect-the-dots」のように、モデルをデータにぴったり合わせすぎることです。2つの変数の間に完全な関係があるとは限らないのに「完全な関係」を無理に作ってしまうので、新しいデータはそのモデルに合いません。過学習はerrorの存在を認めたがらない考え方で、私たちは「errorがあってよい」と割り切って、傾向（trend）をとらえるモデルを作ります。

🍎 かんたん説明

回帰は「x から y を予想する」道具。点は直線の周りにばらつくけれど、それは間違いではなく自然なばらつき。点を全部つなぐのではなく、全体の傾向をとらえます。

回帰の種類

回帰モデルにはいろいろな種類があります。このモジュールで学ぶのは線形回帰と重回帰です。ほかの種類は今後の授業で出てきます。選び方はデータの型しだいで、結果が二値（binary）ならロジスティック、連続（continuous）なら線形・重回帰を使います。

モデル（Model）データ（Data）
Linear regression（線形回帰）予測変数 1 つ、結果は連続
Multiple regression（重回帰）予測変数が複数、結果は連続（例：バスの年数に加えて走行距離）
Logistic regression（ロジスティック回帰）予測変数 1 つ、結果は二値
Multiple logistic regression予測変数が複数、結果は二値
Polynomial regression（多項式回帰）予測変数と連続の結果の関係が直線ではない

用語を整理する

役割英語の別名バスの例
応答変数 response variable（y）dependent variable（従属変数）、outcome（結果）年間維持費
説明変数 explanatory variable（x）independent variable（独立変数）、predictor（予測変数）、feature（特徴量）バスの年数

※ feature は機械学習の文脈でよく使う言い方で、predictor と同じ意味です。

関連（association）：一方の変数の値を知ると他方の値を予測しやすくなるとき、2つの変数には関連があると言います。また、「年間維持費を年数に回帰する」を英語では “regressing Y on X”（y を x に回帰する）と言います。

最良の直線 ŷ = b₀ + b₁x

lm() で直線の式を求める

いちばん基本的な回帰モデルが線形回帰モデル、別名「最良の直線（line of best fit）」です。これまで同様、結果 = モデル + 誤差で、誤差は間違いではなく「完全な関係はなく、ばらつきがある」ことを表しています。

使うのは donors の標本50人の最高寄付額 largestGiftAmount（説明変数 x）と総寄付額 totalGivingAmount（応答変数 y）です。この2つの相関は0.59（上で計算した 0.5851685 を丸めた値）。散布図を見て、関係を言葉で説明してみましょう（右上がりで、最高寄付額が大きい人ほど総額も多い）。点を全部つなぐ過学習は避け、ざっくり1本の直線で表します。

直線のいろいろな名前

この直線にはたくさんの名前があります。略称が出てくるので、何の略か必ず覚えておきましょう。

英語日本語
trend line傾向線
line of best fit最良の直線
least squares regression line（LSRL）最小二乗回帰直線
ordinary least squares regression（OLSR）通常の最小二乗回帰

Rで直線の式を求める：lm()

Rではlm()（linear model）を使います。書き方はlm(y ~ x)で、応答変数 y が先、説明変数 x が後。~（チルダ）は「〜に回帰する／given」と読みます。

⚠️ 順番に注意：グラフを見るときはx軸（横）を先に見がちですが、lm()では予測したい y が先、予測に使う x（グラフの横軸の変数）が2番目です。
model <- lm(sampleDonors$totalGivingAmount ~ sampleDonors$largestGiftAmount)
model
Call: lm(formula = sampleDonors$totalGivingAmount ~ sampleDonors$largestGiftAmount) Coefficients: (Intercept) sampleDonors$largestGiftAmount 51.82 3.91

係数（coefficients）は 51.82 と 3.91。最初がy切片（intercept、直線がy軸と交わるところ）、次が傾き（slope、直線の急さ）です。

💡 modelという名前は実はあまりよくありません。何のモデルかが分かるもっと具体的な名前を付けるのが望ましいと講師は述べています（ここでは簡単のため model としています）。

式の書き方：y = mx + b から ŷ = b₀ + b₁x へ

中学・高校の数学ではy = mx + b（m = 傾き、b = y切片）の形を習いました。統計では文字も順番も少し違い、次のように書きます。

書き方y切片傾き
数学：y = mx + bbm
統計：ŷ = a + bxab
統計（添字版）：ŷ = b₀ + b₁xb₀b₁

講師は「数学の y = mx + b は忘れて、a + bx（aが切片、bが傾き）と考えるとよい」と話しています。x の位置が違うことに注意してください。a + bxのbxはb·x（かけ算）で、括弧は特に必要ありません。

添字のb₀・b₁の形が最も便利です。重回帰になると係数がいくつも出てくるので、a, b, c, d, e…とアルファベットを使い切らないよう、1, 2, 3, 4…と番号を増やせるからです。b₀, b₁はパラメータ（parameters）と呼び、教科書やサイトによっては θ₀, θ₁ や β₀, β₁ と書かれることもあります。

ŷ の「ハット」の意味

なぜ y ではなくŷ（y-hat）と書くのでしょうか。教科書やサイトによっては y = a + bx + ε（ε＝イプシロン、error の頭文字）と、誤差の項を付けて書きます。この講義では誤差をハット（^）の中に含めて表します。ハットは「誤差と同じ考え方」です。

⚠️ ε かハットを必ず付ける理由：これは「直線は傾向（trend）にすぎず、保証ではない」と伝えるためです。点が直線の上にぴったり並ぶわけではなく、直線は決定論的（deterministic）ではありません。「最高寄付額がちょうどこの額の人は、総額が必ずこの額になる」とは言っていません。人にはばらつきがあります。言えるのは「最高寄付額が大きい人ほど、総額も大きくなる傾向がある」ことだけです。

係数の取り出しと、直線を描く

係数はmodel$coefficientsで取り出せます。1番目がy切片、2番目が傾きです。

model$coefficients
model$coefficients[1]   # y切片
model$coefficients[2]   # 傾き
(Intercept) sampleDonors$largestGiftAmount 51.816908 3.909609 (Intercept) 51.81691 sampleDonors$largestGiftAmount 3.909609

講義のプロットのコードは、係数を丸めて保存し、散布図を描いて、abline()で直線（太さ2、赤）を重ねるものでした。タイトルにはpaste()で式そのものを入れています。

b0 <- round(model$coefficients[1], 1)
b1 <- round(model$coefficients[2], 1)
plot(sampleDonors$largestGiftAmount, sampleDonors$totalGivingAmount,
     pch = 16, las = 1, cex = 1,
     xlab = "Largest Gift Amount ($)", ylab = "Total Giving ($)",
     main = paste("y-hat =", b0, "+", b1, "x"))
abline(model, lwd = 2, col = "red")
donors の標本50人：最高寄付額 x と総寄付額 y（赤線が最小二乗直線）
赤い線が最良の直線 ŷ = 51.8 + 3.9x。これは donors のデータが示す「最高寄付額と総寄付額の関連」を表すモデルです。

求まった式は ŷ = 51.8 + 3.9x。赤い線がこのデータの「最良の直線」で、y切片 51.8 は x = 0 のときの予測 ŷ です。このモデルは完璧ではなく、すべての点を通りません。直線と点の間にはずれ（error）があり、それで構いません。新しいデータが加わったときにうまくいかない過学習モデルより、傾向をとらえる良いモデルのほうがよいからです。

🍎 かんたん説明

lm(y ~ x)は「x から y を予想する直線」を作る呪文。yが先、xが後。出てきた2つの数は、1つ目がy切片（b₀）、2つ目が傾き（b₁）。式は ŷ = b₀ + b₁x で、ŷ は「予測値」です。

💻 ミニ練習：標本データで直線を求める

sampleDonorsを使い、総寄付額totalGivingAmountを最高寄付額largestGiftAmountに回帰する線形モデルをlm()で作ってください。data =引数を使って構いません。

donorModel <- lm(totalGivingAmount ~ largestGiftAmount, data = sampleDonors)
donorModel

結果は (Intercept) 51.82、largestGiftAmount 3.91。$を使った書き方と同じ係数になります。応答 y（totalGivingAmount）が~の左、説明 x（largestGiftAmount）が右です。

③

残差 residual

実際の y − 予測された y

最小二乗法がなぜ最良なのかを理解する前に、まず残差（residual）を理解します。次の散布図（直線付き）で考えましょう。

  • 質問①：この直線にもとづくと、最高寄付額から予想されるより多く寄付した人は？ 直線の上にいる人は全員そうです。たとえば最高寄付額 $100 の人を、直線は総額およそ $400 と予測します。ところが実際は約 $900寄付しています。この人は直線からの縦の距離（上向き）が最大です。
  • 質問②：予想より少なく寄付した人は？ 直線の下にいる人です。最高寄付額 $150 の人は、直線の予測ではここまでに約 $600 になるはずなのに、実際はずっと少なく、直線は総額を過大に予測（over-predict）しました。この人が下向きの縦距離が最大です。

こうした上向き・下向きの縦の距離が残差です。

📌 残差（residual）＝ 実際の y − 予測された y ＝ y − ŷ
実際の y は「黒い点」、予測された y は「直線上の点」の高さです。
⚠️ 引き算の順番がとても重要：「実際 − 予測」です。順番を逆にすると、正負の符号が逆になってしまいます。
残差点の位置直線の予測
正（＋）直線の上under-predict（過小予測）
負（−）直線の下over-predict（過大予測）
0直線のちょうど上ぴったり当たり（予測 6、実際 6：6 − 6 = 0）

また、最小二乗直線（最良の直線）では残差の合計は必ず 0 になります。正の残差と負の残差が打ち消し合うからです（理由は後の動画で出てきます）。

最小二乗直線と全部の残差（青い縦線）
縦線の長さが残差。オレンジの2点が、最大の正の残差（＋478.2）と最大の負の残差（−448.3）です。

手計算：$150 の人の残差を求める

最高寄付額が $150 の寄付者の残差を計算してみましょう（点が直線の下なので、負の答えになるはずです）。まず標本の中から探します。

sampleDonors[sampleDonors$largestGiftAmount == 150, ]
age incomeRating totalGivingAmount largestGiftAmount isHomeowner gender 13602 37 7 190 150 NA male urbanicity respondedMailing 13602 urban FALSE

この人は元の donors データの 13,602 行目（95,412 行中。講義では約13,600番目）です。標本の中で何番目かはwhich()で調べられます。

which(sampleDonors$largestGiftAmount == 150)
sampleDonors[46, c("largestGiftAmount", "totalGivingAmount")]
[1] 46 largestGiftAmount totalGivingAmount 13602 150 190

標本の46番目で、実際の総寄付額（actual y）は $190。予測は直線の式 ŷ = 51.8 + 3.9 × 150 に x = 150 を入れて求めます（x は説明変数、横軸の最高寄付額 $150）。

190 - (51.8 + 3.9 * 150)    # 実際 - 予測
[1] -446.8

残差は −446.8。点が直線の下にあるので負です（予測 ŷ = 51.8 + 585 = 636.8、実際 190）。

✍️ 残差の解釈の書き方：「最高寄付額が $150 のこの寄付者について、最小二乗直線は総寄付額を $446.80 だけ過大に予測した（over-predicted）」。または短く「この寄付者は予測より $446 少なく寄付した」。どちらも「−」は書きません。over-predicted や「より少ない」という言葉が、すでに残差の向き（負）を表しているからです。

Rに残差を計算させる

モデルを作れば、Rが残差を全部保存しています。model$residualsで全員の残差が見られます。46番目の人は次のようになります。

model$residuals[46]
sum(model$residuals)
round(sum(model$residuals), 6)
46 -448.2582 [1] -4.334311e-13 [1] 0

手計算の −446.8 とRの −448.26 が少し違うのは、手計算で係数を 51.8・3.9 に丸めたからです（丸めない係数なら −448.26）。残差の合計は、コンピュータの計算誤差を除けば 0 です。

⚠️ 講義では、この図の残差を青い線で描いたあと、残差プロット（residual plot）の予告もありました。残差を別のグラフ（説明変数、または予測値に対して）にしたものです。詳しくは後の動画で扱います。Rではplot(model)とすると標準の残差プロット（赤い水平線付き）が最初の図として出ます。今は、「残差とは何か」「正負の違い」「計算のしかた」「解釈のしかた」を理解すれば十分です。
🍎 かんたん説明

残差 = 実際 − 予測。点が線の上なら＋（線が低く見積もった）、下なら−（線が高く見積もった）。説明は「$○○過大に予測した／$○○少なかった」と、マイナス記号は書かずに言葉で向きを表します。

💻 ミニ練習：残差を計算する

最高寄付額 $100、総寄付額 $921 の寄付者がいます。丸めた式 ŷ = 51.8 + 3.9x を使い、残差（実際 − 予測）を返すRコードを1行で書いてください（数値の計算式でOK）。

921 - (51.8 + 3.9 * 100)

結果は [1] 479.2（丸めない係数なら 478.2582）。正の残差なので、この人は直線の上にいて、直線は総額を$479.20 だけ過小に予測（under-predict）した、または「予測より約$479 多く寄付した」と解釈します。

④

なぜ最小二乗法か

残差の二乗和を最小にする直線

では、なぜ最小二乗回帰直線が「最良」の直線なのでしょうか。講義では、GeoGebra のアプリ（squared residuals）で、散布図に手で直線を合わせてみました。明らかに傾向に合っていない直線は、点から遠く、残差が大きい。傾向に近い直線は、正負の残差はあっても点に近く、残差が小さいのです。

ここで残差を二乗します。残差（縦の距離）が1単位なら1×1の正方形、距離が大きければ大きな正方形を作ります。直線が点から遠いほど正方形は巨大に、近いほど小さくなります。

📌 最良の直線 ＝ これらの正方形の面積の合計（残差の二乗和）が最小になる直線
この合計を SSE（sum of squared errors：誤差の二乗和）と呼びます。

講義のアプリでは、手で引いた直線がほぼ平行で、残差の二乗和は 3.23（ほとんど最小）でした。講義のこの例で、最小二乗直線の傾きは 0.66、手で引いた直線は 0.50 でした。講師は「傾きが 0.66 でした（アプリの別データ）。偶然、同じ数字が並んだだけで、いつもそうなるわけではない」と述べています。

小さな例で確かめる（4点）

講義のアプリと同じ考え方を、4点 (1, 2), (2, 4), (3, 3), (4, 6) で確かめます。最小二乗直線は ŷ = 1.0 + 1.1x で、各残差は −0.1, 0.8, −1.3, 0.6（合計 0）、二乗の合計は 0.01 + 0.64 + 1.69 + 0.36 = 2.7 です。別の直線 ŷ = 0.5 + 1.5x を引くと、残差は 0, 0.5, −2, −0.5 で、二乗和は 0 + 0.25 + 4 + 0.25 = 4.5。最小二乗直線のほうが小さくなります。

残差の二乗を「正方形」で表す（オレンジの正方形の面積の合計 = SSE）
どんな直線を引いても、最小二乗直線より SSE を小さくすることはできません。
x <- c(1, 2, 3, 4)
y <- c(2, 4, 3, 6)
toy <- lm(y ~ x)
toy
residuals(toy)
sum(residuals(toy)^2)
sum((y - (0.5 + 1.5 * x))^2)   # 別の直線のSSE
Call: lm(formula = y ~ x) Coefficients: (Intercept) x 1.0 1.1 1 2 3 4 -0.1 0.8 -1.3 0.6 [1] 2.7 [1] 4.5

式で書くと

講義のまとめです。最小二乗直線は残差の二乗の合計が最小になる直線です。残差を d₁, d₂, … と書くと、d₁² + d₂² + … が最小になってほしい（d の代わりに error と書いても同じ）。長い和を書くのは大変なので、数学者は和の記号 Σ（シグマ）を使い、y切片 b₀ と傾き b₁ の両方に関して最小にする、と表します。

📌 最小化する量：Σ (y − ŷ)² ＝ Σ (y − b₀ − b₁x)²
残差は y − ŷ で、予測 ŷ = b₀ + b₁x を代入すると、引き算の括弧が分配されて y − b₀ − b₁x になります。b₀ と b₁ の2つの変数について最小化します。

では b₀ と b₁ はどう計算されるのでしょうか。公式は複数あります（各点から平均を引いて割る形、和だけで書く形など）。ただし、導出には多変数の微積分と線形代数が必要で、この授業では重視しません。講師が強調するのは、計算はR（technology）に任せ、値の意味を解釈できることです。ただし、次の2つの関係式は知っておくと便利です。

求めるもの式意味
傾き b₁b₁ = r × (sy / sx)相関 r に、y の標準偏差と x の標準偏差の比をかける。相関が分かれば傾きが計算できる（覚えやすい式）
y切片 b₀b₀ = ȳ − b₁x̄重心（centroid）(x̄, ȳ) は、いつも直線の上にある

y切片の式の導き方：「平均の x を入れると、平均の y が出てくる」はずなので、ŷ = a + bx に x̄ と ȳ を代入すると ȳ = a + b·x̄。両辺から b·x̄ を引けば、a = ȳ − b·x̄。b は上の式のいずれかで計算した傾きです。ここでは a の代わりに b₀ と書いても同じです。

donors の標本で確認しましょう。

x <- sampleDonors$largestGiftAmount
y <- sampleDonors$totalGivingAmount

cor(x, y) * sd(y) / sd(x)    # 傾き b1 = r * (sy / sx)
mean(y) - 3.909609 * mean(x) # 切片 b0 = ybar - b1 * xbar
[1] 3.909609 [1] 51.81691

r = 0.5851685、sy = 169.4683、sx = 25.36508、x̄ = 24.238、ȳ = 146.578 から、b₁ = 0.5851685 × (169.4683 / 25.36508) = 3.91、b₀ = 146.578 − 3.9096 × 24.238 = 51.82 となり、lm()の結果と一致します。

Rで求める：summary()

講義では最後にdata =引数を使う書き方でlm()を実行しました（応答変数を~の左、説明変数を右に書き、データフレームをdata =で指定）。

model <- lm(totalGivingAmount ~ largestGiftAmount, data = sampleDonors)

「最良の直線」とは、残差を二乗して全部足した値（SSE）がいちばん小さくなる直線のこと。二乗は「正方形の面積」と考えるとイメージしやすいです。傾きは b₁ = r × (sy/sx)、切片は b₀ = ȳ − b₁x̄。

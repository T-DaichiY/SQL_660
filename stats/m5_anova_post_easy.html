①

事後検定ってなに？

ANOVA のあとにやること

🎯 これだけ覚えればOK

ANOVA は「どこかが違う」と言うだけ。どのペアが違うかは「事後検定」で調べる。

🔥
ANOVA = 火災報知器（ピーッ！）。
事後検定 = どの部屋が火事か、1つずつ調べる作業。

3つのダイエットプランで ANOVA をしたら p = 0.0058（5% よりずっと小さい）。だから「少なくとも2つのプランに差がある」。でもどの2つ？は分かりません。

事後検定ひとこと
Bonferroni合格ラインを厳しくする。いちばん厳しい
Tukey HSDペアを全部まとめて比べる。定番でおすすめ
🍎 かんたん説明

3グループなら比べるペアは 3 つ（1-2, 1-3, 2-3）。4グループなら 6 つ、10グループなら 45 こ。グループが増えるとペアはすぐ増えます。

🤔 答えられるかな？（クリックで答えが開く）

Q1. ANOVA が有意なとき、分かることは？A. 少なくとも2つのグループの平均が違うこと。どのペアかは分からない。
Q2. 5グループのペアの数は？A. 5 × 4 ÷ 2 = 10 通り。
②

Tukey HSD

区間が 0 をまたぐか見る

🎯 これだけ覚えればOK

TukeyHSD() の結果は「区間が 0 をまたぐか」で読む。またがなければ差がある。

results_df <- data.frame(weight_loss, group)
results_aov <- aov(lm(weight_loss ~ group, data = results_df))
tukey_test <- TukeyHSD(results_aov)
tukey_test

2-12−2.96 〜 6.96（0 をまたぐ）0.496ない

🏆
Plan 3 は Plan 1 よりも Plan 2 よりも、体重がたくさん減る！ Plan 1 と Plan 2 は差があると言えない。
⚠️ data.frame(weight_loss, group) は結果（weight_loss）を先に書くこと。
🍎 かんたん説明

p adj が 0.05 より小さい ＝ 範囲が 0 をまたがない。どちらで見ても同じ答えです。plot(tukey_test) で絵にもできます。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 3-1 の範囲 [3.04, 12.96] は 0 を含む？A. 含まない。だから Plan 3 と Plan 1 には差がある。
Q2. 2-1 の p adj = 0.496 のとき結論は？A. 差があるとは言えない（0.05 より大きい）。
③

Bonferroni

α を厳しくする

🎯 これだけ覚えればOK

Bonferroni：新しい α = 0.05 ÷ 検定の回数。厳しいぶん、見逃しも増える。

🎯
3グループ → 検定は 3 回 → 0.05 ÷ 3 = 0.0167。各 p値が 0.0167 より小さいときだけ『差がある』。
0.05 / 3
[1] 0.01666667

weight-loss データで t検定を3本やると、p値は 0.233（1 vs 2）、0.027（1 vs 3）、0.053（2 vs 3）。どれも 0.0167 より大きいので、差は見つかりません。

ペアp値0.0167 より小さい？
1 vs 20.233いいえ
1 vs 30.027いいえ
2 vs 30.053いいえ
⚠️ Tukey HSD では 3-1 と 3-2 が有意でした。Bonferroni + t検定だと見つからない。厳しすぎると本当の差を見逃す（Type II error が増え、検出力 power が下がる）のです。
🍎 かんたん説明

検定をたくさんするほど、まぐれ当たりが増えます。だから合格ラインを厳しくするのが Bonferroni。でも厳しすぎると、本当に当たりのものまで落としてしまいます。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 4グループのとき検定は何回？A. 4 × 3 ÷ 2 = 6 回。
Q2. Bonferroni の弱点は？A. 厳しすぎて、本当の差を見逃しやすい（Type II error が増える）。
④

まとめ

ANOVA → Tukey が基本

🎯 これだけ覚えればOK

基本の流れ：ANOVA → 有意なら TukeyHSD()。t検定を何本もやるのは避ける。

t検定3本 + BonferroniANOVA → Tukey
Plan 3 vs 1見つからない（p = 0.027）見つかる（p adj = 0.0051）
Plan 3 vs 2見つからない（p = 0.053）見つかる（p adj = 0.030）
Plan 1 vs 2見つからない見つからない
🍎 かんたん説明

① ANOVA で『どこか違う』 → ② Tukey で『どこ？』。これが定番の2ステップです。

🤔 答えられるかな？（クリックで答えが開く）

Q1. おすすめの流れは？A. ANOVA を実行し、有意なら Tukey HSD でどのペアが違うかを調べる。
Q2. 多重検定をしてしまったらどうする？A. Bonferroni correction で α を厳しくする（ただし見逃しは増える）。

M6 · Inference for the Slope 🍎

🍎 超やさしい版：回帰③（傾きの推測）

「手元の傾きから、本当の傾きについて何が言える？」を、信頼区間と検定で答えます。

傾きはゆれる信頼区間検定summaryの読み方📊 本編はこちら
📖 講義動画：Linear Regression 8（Inference for Slope - CI）と 9（Inference for Slope - ST）。データは寄付者 donors（母集団 95,412 人、標本 n = 50）。
①

傾きはゆれる

b は推定値、本当の値は β

🎯 これだけ覚えればOK

手元の傾き b は「推定値」。標本を取り直すと b は変わる。本当の傾きは β（ベータ）。

🎲
寄付者 95,412 人から50人を選んで直線を引くと、傾きは b = 3.91。
別の50人を選ぶと、別の傾きになります（相関も 0.35 になったり 0.78 になったり）。
標本（手元にある）母集団（本当の値）
傾きbβ
平均x̄μ
🍎 ひとことで

b は毎回ゆれる。どれくらいゆれるかが 標準誤差 SE(b)。今回の例は b = 3.91、SE = 0.782、自由度は n − 2 = 48（切片と傾きの2つを推定したから）です。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 手元の傾きは b と β のどっち？A. b（標本の傾き）。β は母集団の本当の傾きで、普通はわからない。
Q2. 自由度は？A. n − 2 = 50 − 2 = 48。
②

信頼区間

β のありかを区間で推測

🎯 これだけ覚えればOK

信頼区間 = b ± t* × SE(b)。今回は 3.91 ± 1.57 = (2.34, 5.48)。

📏
b を真ん中に、前後に「ゆれの幅」を取った区間で、本当の傾き β をはさみにいきます。
tcrit <- qt(p = 0.975, df = 48)   # 2.01
3.910 - tcrit * 0.782
3.910 + tcrit * 0.782
confint(model, level = 0.95)   # 一発で出す
[1] 2.337292 [1] 5.481925 2.5 % 97.5 % sampleDonors$largestGiftAmount 2.337298 5.481919
✅
本当の傾きは β = 2.64。区間 (2.34, 5.48) の中に入っている → 区間は β を捕まえた！
⚠️ 「95%」は、「同じやり方で何回も区間を作ると、そのうち約95%がβを含む」という意味です。現実では β は知らないので、捕まえたかは確かめられません。
🍎 ひとことで

「95% 確信：最大寄付額で総寄付額を予測する傾きは 2.3〜5.5 のあたり」と書きます。確信度を上げると（99%）区間は広く、下げると（90%）狭くなります。

🤔 答えられるかな？（クリックで答えが開く）

Q1. t* を出す R の式は？A. qt(0.975, 48)（= 2.01）。
Q2. 区間は β = 2.64 を含む？A. 含む（2.34 ≤ 2.64 ≤ 5.48）。だから捕まえた。
Q3. 99% にすると区間は広い？狭い？A. 広い（1.81〜6.01）。
③

有意性検定

関係はあるといえる？

🎯 これだけ覚えればOK

H₀: β = 0（関係なし）。t = b ÷ SE = 5、p ≈ 8×10⁻⁶ ＜ 0.05 → H₀ を棄却。

⚖️
「本当は傾き 0（関係なし）」と仮定して、b = 3.91 が偶然出る確率（p 値）を調べます。小さければ、その仮定はあやしい。
手順内容
① 仮説H₀: β = 0　／　Hₐ: β ≠ 0（α = 0.05）
② tt = (3.910 − 0) ÷ 0.782 = 5
③ p 値2 × pt(5, 48, lower.tail = FALSE) = 8.06×10⁻⁶（出力は 8.07e-06）
④ 判断p ＜ 0.05 → H₀ を棄却
🍎 結論の書き方

「最大寄付額と総寄付額の間に関連がある、という説得力のある証拠がある（母集団の傾きは 0 ではない）。」

⚠️ 2 を掛け忘れない（両側だから）。p ≥ 0.05 なら「棄却できない」であって「関係ないと証明」ではありません。
⚠️ p 値が小さい ≠ 重要。「欠席1回で成績 1% 減」は、p が小さくても実質的にはほぼ意味がない。効果の大きさと R²（この例は 0.3424）も見ましょう。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 帰無仮説は？A. β = 0（母集団の傾きが 0 ＝ 関連なし）。
Q2. t と p の手計算は？A. t = b ÷ SE = 3.910 ÷ 0.782 = 5。p = 2 * pt(5, 48, lower.tail = FALSE) ≈ 8×10⁻⁶。
Q3. p 値が小さければ、必ず重要？A. いいえ。効果の大きさ（傾き）と R² も見る。
④

summary の読み方

傾きの行を横に読む

🎯 これだけ覚えればOK

summary(model) の「傾きの行」を横に読む：Estimate → Std. Error → t value → Pr(>|t|)。

                               Estimate Std. Error t value Pr(>|t|)

下のほうの Multiple R-squared: 0.3424 は、y の変動の約 34% を x で説明できるという意味です。

🍎 ひとことで

1行で 区間（Estimate ± t* × Std. Error）も、検定（t と p）もできる。summary(model)$coefficients[2, 4] で p 値だけ取り出せます。

🤔 答えられるかな？（クリックで答えが開く）

Q1. p 値はどの列？A. Pr(>|t|) の列（傾きの行は 8.07e-06）。
Q2. *** の意味は？A. p 値が 0.001 より小さい（実質 0 に近い）。統計的に有意。

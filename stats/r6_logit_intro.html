①

ロジスティック回帰とは

二値の結果を予測する回帰

これまでの線形回帰（lm）は、収入のように連続的な量を予測しました。収入は数十万円にも0円にも、極端にはマイナスにすらなりえます。ここからのモジュールは、結果（outcome）が二値（binary）の場合のロジスティック回帰（logistic regression）です。「2つのカテゴリのうちどちらに入るか（その確率）」を予測します。

  • 腫瘍が悪性かどうか
  • 妊娠しているかどうか
  • メールがスパムかどうか
  • 卒業できるかどうか

確率を扱うので、片方のカテゴリを 0、もう片方を 1 とコード化します。これは重回帰で学んだダミー変数（dummy coding）とそっくりですが、今回は結果の側をダミーにする点が違います。カテゴリが3つ以上の結果を予測する場合は多項ロジスティック回帰（multinomial logistic regression）と呼びますが、今は扱いません。単に「ロジスティック回帰」と言えば二値ロジスティック回帰（binary logistic regression）のことです。

💡 数学の新しい種類が出てきます。重回帰のときと同じで、時間をかけてゆっくり進めましょう。

例：アワビ（abalone）のデータ

モデルの仕組み

確率・オッズ・対数オッズと確率の式

この動画の最初のメッセージは「まず流れ（process）をつかみ、数学の理解は後でよい」です。数学は見慣れないものなので、学習を2段階に分けて考えましょう。

ロジスティック回帰の係数を得るには、次の3つの概念が必要です（重回帰に係数があったのと同じです）。

概念英語意味
確率probabilityすでに学習済み。0〜1。
オッズodds思い出せるはず。確率 ÷ (1 − 確率)。
対数オッズlog oddsおそらく初めて。オッズの自然対数（natural log）にすぎないので難しくない。

係数が得られたら、その係数を式に代入して最終的な確率を計算します。流れをまとめると次のとおりです。

全体の流れ
確率 p→オッズ p/(1−p)→対数オッズ ln(odds)→係数 b₀, b₁, …→式に代入して確率 P(Y)
「確率・オッズ・対数オッズ」で係数を理解し、得られた係数を使って最終的な確率を出す。
📌 あとで「対数オッズの変化（change in log odds）」の計算も必要になります。単なる対数オッズより少し難しいので、ここでは予告だけにして先へ進みます。

確率を出す式

線形回帰では回帰式 b₀ + b₁X₁ + … で点推定（たとえば学歴と職歴から収入を1つの値で推定）をしました。ロジスティック回帰では、点推定ではなく「どちらのグループに入るかの確率」を計算します。

P(Y) = 1 / ( 1 + e−(b₀ + b₁X₁ + b₂X₂ + …) )
  • P(Y)：Y（成功＝コード1のグループ）が起こる確率。
  • e：自然対数の底（base of natural logarithms、約 2.718）。今は詳しく知らなくても大丈夫です。
  • 括弧の中：線形回帰・重回帰の回帰式とまったく同じもの。つまり「1 ÷ (1 + e のマイナス回帰式乗)」です。

二択なので、片方の確率がわかればもう片方もわかります：P(もう一方) = 1 − P(Y) です。

abalone のモデルで確かめましょう。係数は b₀ = 1.2891、b₁ = −2.5332 でした。直径 0.4 のアワビがオスである確率は次のように計算できます。

b <- coef(model)                               # b[1] = b0, b[2] = b1
eta <- unname(b[1] + b[2] * 0.4)               # 回帰式の値(Diameter = 0.4)
eta
1 / (1 + exp(-eta))                            # P(Type = M)
plogis(eta)                                    # 同じ計算をする組み込み関数
1 - 1 / (1 + exp(-eta))                        # P(Type = F) = 1 - P(M)
[1] 0.2758388 [1] 0.5685258 [1] 0.5685258 [1] 0.4314742

回帰式の値は 0.2758（正）なので、確率は 0.5 より少し大きい 0.5685。メスである確率は 1 − 0.5685 = 0.4315 です。plogis() は式 1/(1+e−x) をそのまま計算してくれる R の関数です。

確率 → オッズ → 対数オッズ

確率 p が 0.8 のとき、オッズは 0.8 / 0.2 = 4、対数オッズは ln(4) = 1.3863 です。

p <- 0.8
odds <- p / (1 - p)       # オッズ
log_odds <- log(odds)     # 対数オッズ(自然対数)
c(p = p, odds = odds, log_odds = log_odds)
p odds log_odds 0.800000 4.000000 1.386294

いくつかの確率で並べると、対応関係が見やすくなります。

🍎 かんたん説明

係数を理解するための道具は3つ：確率 → オッズ → 対数オッズ。係数がわかったら、P = 1 / (1 + e−回帰式) に代入して確率を出します。片方の確率が決まれば、もう片方は 1 − P。

💻 ミニ練習：係数から確率を計算する

abalone のモデルの係数は b₀ = 1.2891、b₁ = −2.5332 です。直径 Diameter = 0.2 のアワビがオス（M）である確率を、式 1/(1+e−(b₀+b₁x)) を使って R で計算してください。

b0 <- 1.2891; b1 <- -2.5332
1 / (1 + exp(-(b0 + b1 * 0.2)))
[1] 0.6862101

回帰式の値は 1.2891 − 2.5332×0.2 = 0.7825 で、確率は約 0.6862。直径が 0.4 のとき（0.5685）より大きい＝直径が小さいほどオスの確率が高い、という係数が負のモデルの傾向と合っています。

ロジスティック回帰のカギ

logit と逆 logit

この動画の目的は、理論から少し具体的な話へ進むことです。3枚のグラフを使います。ねらいは次のとおりです。

🔑 目標：確率（0〜1）を入力にして、出力として 0〜1 の値を得ること。もっと正確には、連続的な回帰式の値（どんな実数にもなる）を、0〜1 の確率に折り返す（flip する）こと。これがロジスティック回帰のカギです。
3枚のグラフで見る「確率 → odds → logit → 確率」の流れ
① odds（縦軸は20で切断）
② logit（odds の自然対数）
③ 逆 logit（シグモイド）
グラフ①②は x（確率）を 0〜1 に切り取って描いています（確率は負にも1超にもならないため）。グラフ③は逆に、どんな実数を入れても出力が 0〜1 に収まります。3つとも p = 0.5 を通ります：odds = 1、logit = 0、シグモイド(0) = 0.5。
  1. グラフ①：オッズ。確率は 0〜1 の値で、オッズ = x / (1 − x) です。確率は負にならず 1 を超えないので、グラフは 0〜1 の範囲で切り取って描いています（自分で x/(1−x) を描くと見た目が少し違います）。x が 1 に近づくと、オッズは「とても大きな値」になります。これはよいのですが、欲しいのは 0〜1 の出力でした。
  2. グラフ②：logit（ロジット）。オッズの自然対数を取ります。この対数が logit（logit link：リンク関数）で、オッズから対数オッズへ変換します。縦軸の目盛りが変わっていることに注意してください。入力 x は 0〜1 で、出力は −∞〜+∞ の実数になります。
  3. グラフ③：逆 logit（inverse logit、logit⁻¹）。最後に logit の逆関数を取ります。すると、どんな x を入れても 0〜1 の y が出てくるグラフになります。これこそ欲しかったものです。

具体例：p = 0.5 で往復する

簡単のため確率を 0.5 としましょう。確率 → オッズ → 対数オッズ → 逆変換、と一周して元に戻るかを確かめます。

p <- 0.5
(odds <- p / (1 - p))         # 0.5 / 0.5 = 1
(logit <- log(odds))          # log(1) = 0
1 / (1 + exp(-logit))         # 逆変換: 1 / (1 + e^0) = 1/2
[1] 1 [1] 0 [1] 0.5
  1. オッズ：0.5 ÷ (1 − 0.5) = 0.5 ÷ 0.5 = 1
  2. 対数：ln(1) = 0（自分で確かめてみてください）
  3. 逆変換：1 / (1 + e⁰) = 1 / (1 + 1) = 1/2 = 0.5

入力 0.5 から出発して、出力も 0.5。当然の結果ですが、これで確率をいったん別の尺度に移し、数学的に元へ戻せる（可逆である）ことが見えました。実際のモデルはもっと複雑ですが、この「折り返し」が logit link であり、ロジスティック回帰のカギです。

他の確率でも同じように往復できます（qlogis() は logit、plogis() は逆 logit を直接計算する関数）。

p <- c(0.1, 0.7, 0.9)
logit <- log(p / (1 - p))
data.frame(p, odds = p / (1 - p), logit, back = 1 / (1 + exp(-logit)))
qlogis(0.7)        # logit を直接計算する関数
plogis(0.8473)     # 逆 logit(シグモイド)を直接計算する関数
p odds logit back 1 0.1 0.1111111 -2.1972246 0.1 2 0.7 2.3333333 0.8472979 0.7 3 0.9 9.0000000 2.1972246 0.9 [1] 0.8472979 [1] 0.7000004
📖 補足：logit が 0.8473 のとき逆変換して 0.7 に戻る（表示は丸め）ように、変換は可逆です。次の動画からは、実際のデータで「基本の確率 → オッズ → 対数オッズ」を順に計算し、ロジスティック回帰の出力と比べていきます。
🍎 かんたん説明

回帰式の値はどんな実数にもなりますが、確率は 0〜1 にしか入りません。そこでlogit（確率→対数オッズ）と、その逆の逆 logit（回帰式の値→確率）で橋渡しします。p = 0.5 ⇄ odds 1 ⇄ logit 0 が覚える基準点です。

💻 ミニ練習：確率 0.9 を往復する

確率 p = 0.9 について、オッズ、対数オッズ（自然対数）を求め、その対数オッズを逆変換して元の確率に戻ることを R で確かめてください。

p <- 0.9
odds <- p / (1 - p)
log(odds)
1 / (1 + exp(-log(odds)))
[1] 2.197225 [1] 0.9

オッズは 9、対数オッズは 2.197225、逆変換すると 0.9 に戻ります。p = 0.1 のときは符号が反対（−2.1972）になる、という対称性にも注目しましょう。

連続予測変数：Age の係数の意味

German credit で「対数オッズの変化」を確かめる

ここからは別のデータ、German Credit（caret パッケージ、1000人分）を使います。結果 Class は信用が Good（良い）／Bad（悪い）の二値です。分析しやすいよう、Class・Age・Amount・ForeignWorker の4列だけの gc2 を作りました。

library(caret)                                          # GermanCredit データ
data(GermanCredit)
gc2 <- GermanCredit[, c("Class", "Age", "Amount", "ForeignWorker")]
table(gc2$Class)
contrasts(gc2$Class)                                    # Good = 1 になっている
aggregate(Age ~ Class, data = gc2, FUN = mean)
Bad Good 300 700 Good Bad 0 Good 1 Class Age 1 Bad 33.96333 2 Good 36.22429

Good が 700人、Bad が 300人。contrasts() の表から Good = 1 と読めるので、モデルは「Good（良い信用）である確率」を予測します。まず Age でグループ別の平均年齢を見ると、信用が良い人のほうがやや年上（36.22 歳 対 33.96 歳）です。

🔎 予測変数なしのモデル glm(Class ~ 1, family = binomial) の切片は 0.8473 で、全体の対数オッズ ln(0.7/0.3) = ln(2.3333) と一致します（0.7 → オッズ 2.33 → 対数オッズ 0.847）。予測変数を足すと、切片の意味は変わります。

連続予測変数 Age を加える

それ以外は今までと同じです。モデル名は mod_age（age のモデル）とします。出力は二値予測変数の場合と似ています。

mod_age <- glm(Class ~ Age, family = binomial, data = gc2)

なぜ 0.0184 が「対数オッズの変化」なのか：実際に計算する

講師は、係数がどこから出てくるかを手順で確かめました。わざと Age = 0（現実ではありえない値）を入れますが、仕組みを見せるためです。

b <- coef(mod_age)
p0 <- unname(plogis(b[1] + b[2] * 0))   # Age = 0 のときの確率
o0 <- p0 / (1 - p0)                 # そのオッズ
p1 <- unname(plogis(b[1] + b[2] * 1))   # Age = 1 のときの確率
o1 <- p1 / (1 - p1)                 # そのオッズ
round(c(p0 = p0, odds0 = o0, p1 = p1, odds1 = o1), 4)
o1 / o0                             # オッズの比(割り算!)
log(o1 / o0)                        # その自然対数 -> 係数 0.01844
unname(b[2])
p0 odds0 p1 odds1 0.5501 1.2225 0.5546 1.2453 [1] 1.018611 [1] 0.01843994 [1] 0.01843994
  1. 回帰を実行し、係数（b₀ = 0.2009、b₁ = 0.01844）を確認する。
  2. 式に代入して Age = 0 の確率を計算：0.5501（約 0.55）。
  3. そのオッズ：0.5501 / 0.4499 = 1.2225（約 1.22）。
  4. 式に代入して Age = 1 の確率を計算：0.5546。
  5. そのオッズ：1.2453（約 1.25）。
  6. オッズの変化 ＝ 割り算：1.2453 / 1.2225 = 1.0186。
  7. その自然対数：ln(1.0186) = 0.01844 ＝ Age の係数。
⚠️ オッズの変化は引き算ではなく割り算（新しいオッズ ÷ 古いオッズ）。講師もこの順に計算しています。丸めた 1.22 や 1.25 で割ると誤差が出るので、丸めない値で計算しましょう。

これは二値予測変数で「0 → 1」に変えたときと同じ考え方です。連続変数の「1単位の増加」も、二値の「0から1」に変わるのと同じように扱えます。しかもどの2つの値でも同じです。55 → 56 歳でも 33 → 34 歳でも、オッズの比は同じ 1.0186 になります。

odds_ratio <- function(age) {
  pa <- plogis(b[1] + b[2] * age)
  pb <- plogis(b[1] + b[2] * (age + 1))
  unname((pb / (1 - pb)) / (pa / (1 - pa)))
}
sapply(c(0, 33, 55), odds_ratio)
exp(unname(b[2]))
[1] 1.018611 1.018611 1.018611 [1] 1.018611

オッズの比（= exp(係数) = 1.0186）は一定でも、確率そのものの増え方は一定ではありません。

plogis(b[1] + b[2] * c(33, 34, 55, 56))
[1] 0.6919894 0.6959057 0.7712028 0.7744402

33 → 34 歳では 0.6920 → 0.6959（+0.0039）、55 → 56 歳では 0.7712 → 0.7744（+0.0032）と、確率の増加幅は違います。一定なのは対数オッズの増加（= 係数）です。

🧾 8ステップのレシピ（講義のまとめ）
回帰を実行 → 式に代入 → x = 0 の確率 → オッズ → x = 1 の確率 → オッズ → オッズの比（÷）→ その自然対数 ＝ 係数。
📝 試験への心構え：これを暗記している必要はありません（実務でも覚えていません）。ただし、知っていると試験でずっと楽になるので、何問か自分で計算して慣れておきましょう。「確率 → オッズ → 対数オッズ」の変換を流れるようにできるのが目標です。
🍎 かんたん説明

係数 = 予測変数が1増えたときの「対数オッズの変化」。Age の係数 0.0184 は、Age が1歳増えるとオッズが 1.0186 倍（ln 1.0186 = 0.0184）になる、という意味です。

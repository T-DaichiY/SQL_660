650 M4 · Regression — Prediction, Confidence Interval & Prediction Interval

🔮 予測区間・信頼区間・予測

回帰直線ができたら、次は「気温が70°Fの日、自転車は何台借りられるか」を予測します。ただし予測はただ1つの数（点推定）。そこで平均の幅（信頼区間）と1日の幅（予測区間）をつけて、「どれくらい外れうるか」まで言えるようにするのがこの回です。

📺 講義動画: 「Making a prediction with linear regression」／「Confidence interval for Y」／「Prediction Interval for Y」（SU1 Data Analytics M4）

📦 データ: bikes.csv（ワシントンD.C.のレンタル自転車、731日分、列は date, season, holiday, weekday, weather, temperature, realfeel, humidity, windspeed, rentals）。モデルは temp_model <- lm(rentals ~ temperature, data = bikes)（気温だけの単回帰）。

①

回帰直線で予測する

手計算 → fitted.values → predict()

モデルを作るのは、データを理解するためだけでなく予測（prediction）のためでもあります。単回帰の一般形は次のとおりです。

y = b₀ + b₁x + e　（b₀＝切片 intercept、b₁＝傾き slope、x＝説明変数 explanatory variable、e＝誤差 error。ギリシャ文字 ε で書くこともあります）

e は「このモデルはあくまでモデルであり、確定的な（deterministic）関係ではない。ばらつき（ノイズ）がある」ことを表します。この授業では e を使わず、予測値 ŷ（y-hat）で書きます：ŷ = b₀ + b₁x。

まず係数を確認しましょう（講義では ggplot の geom_smooth(method = "lm") で赤い直線を描き、base R の plot() と abline() でも同じ図が描けると紹介されました）。

ggplot(bikes, aes(x = temperature, y = rentals)) +
  geom_point() +
  geom_smooth(method = "lm", formula = y ~ x, se = FALSE,
              color = "red", linewidth = 1.5) +
  theme_minimal()

bikes <- read.csv("bikes.csv")
temp_model <- lm(rentals ~ temperature, data = bikes)
temp_model$coefficients
(Intercept) temperature -166.87675 78.49539

b₀ ＝ −166.88、b₁ ＝ 78.50。つまり気温が1°F上がるごとに、レンタル数は平均で約78.5台増えます。切片 b₀ は「気温0°Fの日」という意味のある解釈がありませんが、予測が直線の上に乗るために必要です。

気温とレンタル数の散布図、回帰直線（赤）、15行目の予測と残差
731日分のデータ（青）。15番目の日は気温37.3°F・実測1248台ですが、直線は2764台と予測し、1516台の過大予測になっています。

方法1：手計算（ブラックボックスの中身）

データの15番目の観測を例にします。bikes[15, ] の 15 が行、カンマの後ろを空にすると「全部の列」。ここでは必要な列だけ取り出します。

bikes[15, c("rentals", "temperature")]
rentals temperature 15 1248 37.33997

実測は 1248 台、気温は 37.34°F。この気温を直線に代入して予測値 ŷ を求めます。残差 e は実測 − 予測です。

b0 <- temp_model$coefficients[1]
b1 <- temp_model$coefficients[2]
temp <- bikes$temperature[15]
y_hat <- b0 + b1 * temp
y_hat
e1 <- bikes$rentals[15] - y_hat
e1
(Intercept) 2764.139 (Intercept) -1516.139

ŷ = −166.88 + 78.50 × 37.34 ≈ 2764（小数の違いは丸めのせい）。実測 1248 − 予測 2764 ＝ −1516。マイナスの残差は、このモデルが寒い日を過大予測（over-predict）していることを意味します。寒い日はレンタルが直線よりずっと少ない傾向があるのです。

💡 講義のポイント：予測値は「保証」ではなく推定値です。だから「predicted rentals」と書き、記号も ŷ（y-hat）を使います。

方法2：fitted.values（データ内の行だけ）

モデルは同じ計算結果を fitted.values に保存しています。

temp_model$fitted.values[15]
15 2764.139
⚠️ fitted.values はデータに実在する行にしか使えません。「その気温の行がデータにある」ことが前提です。

方法3：predict()（新しい値でもOK）

データにない気温の予測には predict() を使います。ポイントは新しいデータをデータフレーム（data frame）で渡すこと、列名を説明変数の名前（temperature）と一致させること。行を探す必要もありません。

new.data <- data.frame(temperature = 37.34)
predict(temp_model, newdata = new.data)
1 2764.141

方法1・2と同じ値（2764.141 と 2764.139 の差は 37.34 に丸めたため）。c() で複数の気温を一度に渡すこともできます。

new.data <- data.frame(temperature = c(50, 70))
predict(temp_model, newdata = new.data)
1 2 3757.893 5327.801
⚠️ 講義では「10°Fの日にはデータがないが、predict() なら予測できる」と紹介されました。ただし実際のデータの気温は range(bikes$temperature) ＝ 22.6〜90.5°F の範囲です。データの範囲外（extrapolation）での予測は、直線がそこまで続く保証がないので信頼できません。
例：predict(temp_model, newdata = data.frame(temperature = 10)) ＝ 618.0772（R の出力）。範囲外の値です。
🍎 かんたん説明

予測は「気温を直線の式に入れるだけ」。手で計算しても、predict() に任せても同じです。predict() は新しい気温でも使えるのが強み。ただしこの1つの数は当たる保証のない推定値。次から「どれくらいの幅で外れるか」をつけていきます。

💻 ミニ練習：気温50°Fの日を予測する

temp_model を使い、気温が 50°F の日の予測レンタル数を predict() で求めてください（新しいデータはデータフレームで渡す）。

new.data <- data.frame(temperature = 50)
predict(temp_model, newdata = new.data)

結果は 3757.893（約3758台）。fitted.values は実在する行にしか使えませんが、predict() なら 50°F のような値でも予測できます。

②

信頼区間 CI：平均の幅

Confidence interval for the mean response

予測値 ŷ は点推定（point estimate）、つまり1つの数です。「70°Fの日は2400台必要」と言っても、ぴったり2400とは限らず、プラスマイナスの誤差の幅があります。そこで区間推定（interval estimate）を使います。上限と下限が、ある確信度（confidence）つきで分かるので、点推定よりずっと多くの情報を与えてくれます。

この単元で求めるのは期待値（expected value、平均のこと）E[Ys]の区間です。Ys は「説明変数が s のときの Y」。つまり気温が70°Fのとき、レンタル数の平均はいくつか？という問いです。

まずグラフで見ましょう。geom_smooth() で se = TRUE（これまでは FALSE）、level = 0.95 とすると、直線のまわりに95%信頼帯（confidence band）が描かれます。

ggplot(bikes, aes(x = temperature, y = rentals)) +
  geom_point() +
  geom_smooth(method = "lm", formula = y ~ x,
              se = TRUE, level = 0.95) +
  labs(title = "95% Confidence Band") +
  geom_vline(xintercept = 70, color = "red", size = 2)

帯は散布図の中央では細く、両端で広くなっています。中央にはデータがたくさんあるので平均をしっかり推定でき、端はデータが少なく自信が持てないからです（ばらつきが大きい）。70°Fでは、点推定は5000を少し超えたあたりです。数値は predict() で求めます。

new.data <- data.frame(temperature = c(70))
predict(temp_model, newdata = new.data,
        interval = "confidence", level = 0.95)
fit lwr upr 1 5327.801 5195.392 5460.209
  • fit ＝ 点推定（回帰直線上の点）：5327.801
  • lwr ＝ 下限（lower）：5195.392
  • upr ＝ 上限（upper）：5460.209
📝 解釈の書き方（試験でよく問われる形）：
「気温が70°Fの日の平均レンタル数は、95%の確信で 5195 〜 5460 台の間にある」

在庫不足（undersupply）を避けたい会社なら、上限の 5460 を選ぶ判断もあります（点推定より約130台多い）。区間はビジネスの意思決定に使えるのです。

気温を無視した平均の区間と比べる

気温を使わず、レンタル数の平均だけで作ったt区間（t interval）と比べてみます。

t.test(bikes$rentals, level = 0.95)$conf[1:2]
[1] 4363.684 4645.014
モデル95%区間
平均レンタル数のt区間（気温を使わない）(4363.684, 4645.014)
気温70°Fの日の平均レンタル数のCI(5195.392, 5460.209)

気温70°Fという情報を使うと、区間の下限も上限もずっと高くなります。気温を無視して全体の平均だけを使うモデルは、暑くないが快適な日の需要を大幅に過小評価（severely underestimate）してしまいます。

公式（参考）

ŷs ± t* · S · √( 1/n + (xs − x̄)² / ssx )
ŷs ＝ x = s での予測値（点推定）／ t* ＝ t分布（自由度 df = n − 2）の臨界値／ S ＝ 残差の標準偏差／ n ＝ 標本サイズ／ x̄ ＝ 説明変数の平均／ ssx ＝ Σ(xi − x̄)²

講義では「この公式を計算させる問題は出さない。いつ使うか・どう使うか・どう解釈するか・モデルを比べられるかが大切」と強調されました。

🍎 かんたん説明

信頼区間は「平均がこの範囲にあるはず」という幅。70°Fの日がたくさんあったとして、その平均は 5195〜5460 台。1つの数（5328）より、幅つきのほうが正直な答えです。

💻 ミニ練習：気温50°Fの平均を信頼区間で言う

temp_model を使い、気温が 50°F の日の平均レンタル数の 95%信頼区間を predict() で求めてください。

new.data <- data.frame(temperature = 50)
predict(temp_model, newdata = new.data,
        interval = "confidence", level = 0.95)

fit = 3757.893、下限 3629.254、上限 3886.532。解釈：「気温50°Fの日の平均レンタル数は、95%の確信で約3629〜3887台」。

③

予測区間 PI：1日の幅

Prediction interval for a particular Y

次の2つの質問は似ていますが、違います。

  1. 気温が70°Fの日が何日もあるとき、レンタル数の平均はいくつか？ → 平均 Y の信頼区間（CI）
  2. 気温が70°Fの特定の1日のレンタル数はいくつか？ → Y の予測区間（prediction interval, PI）

講義の核心はこの一文です。「個々の観測値は、平均よりもばらつく（Individual observations vary more than averages）」。だから1日を予測する区間（PI）は、平均を予測する区間（CI）より広いのです。

🍎 かんたん説明（講義のたとえ）

クラスの平均点を当てるのは、80点か85点か90点かと考えれば、かなり近くを言えます。でもあなた1人の点数を当てるのは難しい。とても高いかもしれないし低いかもしれません。クラス全体なら高い人も低い人も「打ち消し合って」80点台になります。

R のコードは、CI のときから変えるのは interval の1か所だけです（"confidence" → "prediction"）。

new.data <- data.frame(temperature = 70)
predict(temp_model, newdata = new.data,
        interval = "prediction", level = 0.95)
fit lwr upr 1 5327.801 2361.577 8294.024

fit は CI と同じ 5327.801（70°Fの予測値は変わりません）。しかし下限は 2361.577 と大きく下がり、上限は 8294.024 と大きく上がりました。CI のほうは (5195.392, 5460.209) で、前後約±130台と、とても狭い区間でした。

📝 解釈の書き方：「気温が70°Fの特定の1日のレンタル数は、95%の確信で 2362 〜 8294 台の間にある」

公式（参考）

ŷs ± t* · S · √( 1 + 1/n + (xs − x̄)² / ssx )

CI の公式との違いは、根号の中の「1 +」だけ。この 1 が「1日ごとのばらつき」を足しています。講義では「式を暗記させる問題は出さない」とのことです。

この公式を R で計算して、predict() の結果と一致するか確かめてみましょう。S ＝ 残差の標準偏差（summary(temp_model)$sigma）です。

n    <- nrow(bikes)
S    <- summary(temp_model)$sigma
xbar <- mean(bikes$temperature)
ssx  <- sum((bikes$temperature - xbar)^2)
t_star <- qt(0.975, df = n - 2)
xs <- 70
me_ci <- t_star * S * sqrt(1/n + (xs - xbar)^2 / ssx)
me_pi <- t_star * S * sqrt(1 + 1/n + (xs - xbar)^2 / ssx)
c(S = S, t_star = t_star, me_ci = me_ci, me_pi = me_pi)
S t_star me_ci me_pi 1509.388455 1.963223 132.408546 2966.223555

誤差の幅（margin of error）は CI が ±132.4、PI が ±2966.2。5327.801 ± 132.409 ＝ (5195.392, 5460.209)、5327.801 ± 2966.224 ＝ (2361.577, 8294.024) となって、predict() の出力と一致します。

🍎 かんたん説明

予測区間は「特定の1日」の幅。平均の幅（CI）より、ずっと広くなります。「個々は平均よりばらつく」と覚えましょう。

💻 ミニ練習：気温50°Fの1日を予測区間で言う

temp_model を使い、気温が 50°F の特定の1日のレンタル数の 95%予測区間を predict() で求めてください。

new.data <- data.frame(temperature = 50)
predict(temp_model, newdata = new.data,
        interval = "prediction", level = 0.95)

fit = 3757.893、下限 791.8351、上限 6723.950。同じ50°Fの CI（3629〜3887）よりずっと広い区間です。

④

CIとPIを比べる

数値と図で見る

気温を変えて、CI と PI を並べてみます（講義では一番暑い日の 90.5°F でも同じことを確認しました）。

new.data <- data.frame(temperature = c(32, 50, 70, 90.5))
predict(temp_model, newdata = new.data, interval = "confidence")
predict(temp_model, newdata = new.data, interval = "prediction")
fit lwr upr 1 2344.976 2121.436 2568.515 2 3757.893 3629.254 3886.532 3 5327.801 5195.392 5460.209 4 6936.956 6691.632 7182.280 fit lwr upr 1 2344.976 -626.7107 5316.662 2 3757.893 791.8351 6723.950 3 5327.801 2361.5770 8294.024 4 6936.956 3963.5516 9910.360

どの気温でも PI は CI より広いことが分かります。表は退屈なので、全部の気温について帯を描いたものが次の図です（geom_ribbon() で作ります）。

CI（青）と PI（黄）の帯
黒い線がモデル、青い帯が95%CI（線にぴったり張りつく）、黄色の帯が95%PI（ずっと広い）。赤い縦線が70°F。回帰直線のまわりに実際のデータ点が散らばる幅が、PIの帯です。

黄色の帯は、実際の1日ごとのレンタル数の散らばりを表しています。70°F付近（67.5〜72.5°F）の日は70日ありますが、そのうち66日が70°FのPI（2361.577〜8294.024）に入っています。

near70 <- subset(bikes, temperature >= 67.5 & temperature <= 72.5)
nrow(near70)
sum(near70$rentals >= 2361.577 & near70$rentals <= 8294.024)
[1] 70 [1] 66
⚠️ 32°Fの PI の下限は −626.7（マイナスのレンタル数）。区間は数式の結果なので、現実にありえない値が出ることがあります。数値は鵜呑みにせず、意味を考えて読みましょう。

① predict() で点を出す。② interval = "confidence" で平均の幅。③ interval = "prediction" で1日の幅（より広い）。違いは1語だけ。

💻 ミニ練習：90°FのCIとPIを両方出す

temp_model を使い、気温が 90°F のとき、95%の信頼区間と予測区間を、それぞれ predict() で求めてください。どちらが広いかも確かめましょう。

new.data <- data.frame(temperature = 90)
predict(temp_model, newdata = new.data, interval = "confidence")
predict(temp_model, newdata = new.data, interval = "prediction")

どちらも fit = 6897.708。CI は (6655.548, 7139.869)、PI は (3924.563, 9870.853)。PI のほうがずっと広い区間です。

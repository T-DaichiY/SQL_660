M7 · Transactions, Splitting & Dropping 🍎

🍎 超やさしい版：トランザクション・分割・削除

データを書き換える前の「お試しモード」と、1つの列を2つに分ける実例、そして不要な列や表の消し方を学びます。

お試しモード給与を2つに分ける消す🔒 本編はこちら
①

トランザクション＝お試しモード

START TRANSACTION → 確認 → COMMIT か ROLLBACK

🎯 これだけ覚えればOK

たとえば「元に戻す」ボタンがある下書きのようなものです。COMMITで確定、ROLLBACKで取り消し。エラーが出たらROLLBACKします。

▶ 全員の評価を0にしてみる（でも取り消す）

START TRANSACTION;
UPDATE ds_jobs SET rating = 0;
SELECT ROUND(AVG(rating), 2) AS avg_rating FROM ds_jobs;
ROLLBACK;
avg_rating 0

ROLLBACKのあとで平均を調べると、元の 3.05 に戻っています。

🍎 ひとことで

トランザクションは、確定する前の安全確認です。ただしバックアップの代わりにはならないので、バックアップとセットで使いましょう。

②

給与を「下限」と「上限」に分ける

'$110K-$163K (Glassdoor est.)' → 110000 と 163000
🧺
洗濯物の仕分けと同じ：まずカゴを2つ用意（列を追加）→ 分ける（SPLIT_PART）→ ゴミを取る（$とK）→ 千を足す（||'000'）→ 数として登録（INTに変換）。

▶ 分けて、きれいにして、数値にする

START TRANSACTION;
ALTER TABLE ds_jobs ADD COLUMN low_range TEXT, ADD COLUMN high_range TEXT;
UPDATE ds_jobs
SET low_range  = SPLIT_PART(REPLACE(SPLIT_PART(salary_est, '-', 1), '$', ''), 'K', 1) || '000',
    high_range = SPLIT_PART(REPLACE(SPLIT_PART(salary_est, '-', 2), '$', ''), 'K', 1) || '000';
ALTER TABLE ds_jobs ALTER COLUMN low_range SET DATA TYPE INT USING low_range::INT;
ALTER TABLE ds_jobs ALTER COLUMN high_range SET DATA TYPE INT USING high_range::INT;
SELECT post_id, low_range, high_range FROM ds_jobs WHERE post_id IN (1, 3, 8);
COMMIT;
post_id | low_range | high_range 1 | 110000 | 163000 3 | 45000 | 79000 8 | 52000 | 87000 (3 rows)

本編では、この長い式を1ステップずつに分けて説明しています。数字以外の文字（たとえば 110K）が残っているとINTへの変換はエラーになります。そのときは ROLLBACK です。

🤔 答えられるかな？（クリックで答えが開く）

Q1. SPLIT_PART(salary_est, '-', 2) は何を返す？A. 「-」で分けた2番目、つまり上限側（'$163K (Glassdoor est.)'）。
Q2. INTに変換するときにエラーになる原因は？A. 「$」や「K」など、数字以外の文字が残っているから。
🍎 ひとことで

「列を追加 → 分ける → きれいにする → 型を変える」の順番です。全部トランザクションの中でやれば、失敗しても安心です。

③

列や表を消す

DROP COLUMN と DROP TABLE
🗑️
列を消す＝ALTER TABLE … DROP COLUMN。表ごと消す＝DROP TABLE。行だけ消すのはDELETEです。消す前にバックアップのコピーを作りましょう。

▶ コピーの表から列を消し、最後に表ごと消す

CREATE TABLE ds_jobs_backup2 AS SELECT * FROM ds_jobs;
ALTER TABLE ds_jobs_backup2 ADD COLUMN low_range INT;
ALTER TABLE ds_jobs_backup2 DROP COLUMN low_range;
SELECT COUNT(*) AS n_cols FROM pragma_table_info('ds_jobs_backup2');
DROP TABLE IF EXISTS ds_jobs_backup2;
n_cols 15

low_range を追加してから消したので、列数は元の15列に戻りました。IF EXISTS を付けると、表が無くてもエラーになりません。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 列を消すコマンドは？A. ALTER TABLE 表 DROP COLUMN 列。
Q2. DROP TABLE と DELETE FROM のちがいは？A. DROP TABLEは表ごと消す。DELETE FROMは行だけ消して、表は残る。
🍎 ひとことで

消す前にバックアップ。列ならDROP COLUMN、表ならDROP TABLE、行ならDELETE。

M9 · Python and SQL — Part 2 🍎

🍎 超やさしい版：接続する

1ファイル版の接続の書き方です。

1ファイル版3ファイル版
①

1ファイル版の中身

4ステップ

🎯 これだけ覚えればOK

import → connect → cursor → execute。最後に commit と close。

import psycopg2

conn = psycopg2.connect(
    dbname="module9",
    user="postgres",
    password="your_password"
)
cur = conn.cursor()

cur.execute("SELECT version();")   # ← ここにコマンドを書く（何回でも）

conn.commit()
cur.close()
conn.close()
🍎 かんたん説明

変えるのは dbname・user・password の3つだけ。ホストを書かなければ自分のPC（localhost）につなぎます。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 自分で変える3つは？A. dbname、user、password。
Q2. executeは何回呼べる？A. 何回でも。
②

3ファイル版は見るだけ

本番向け

🎯 これだけ覚えればOK

課題で必要なのは1ファイル版だけ。3ファイル版は「設定を.iniに分ける」本番向けの書き方。

[postgres]
host=localhost
database=module9
user=postgres
password=your_password

設定（host・database・user・password）を.iniにまとめるので、変えるときはこのファイルだけ直せば済みます。

🍎 かんたん説明

1ファイル版は1人で作るキッチン、3ファイル版は分業する厨房。まずは1人でOK。

🤔 答えられるかな？（クリックで答えが開く）

Q1. .iniファイルに書くものは？A. 接続の設定（host・database・user・password）。

①

Series：名札つきの1列

値（values）と索引（index）と名前（name）

Seriesは、1次元の値の並びにラベル（索引）がセットになったデータです。NumPy配列は「何番目」でしか呼べませんが、Seriesは「'Tokyo'」のように自分で付けた名前でも呼べます。

import pandas as pd

obj = pd.Series([4, 7, -5, 3])
obj
0 4 1 7 2 -5 3 3 dtype: int64
print(obj.array)    # 値の部分
print(obj.index)    # 索引の部分（省略すると 0,1,2,…）
<NumpyExtensionArray> [4, 7, -5, 3] Length: 4, dtype: int64 RangeIndex(start=0, stop=4, step=1)

索引は自分で決められます。辞書から作ると、キーが索引になります。

pop = pd.Series({'Tokyo': 37.4, 'Delhi': 31.0, 'Shanghai': 27.1, 'Osaka': 19.2})
print(pop)
print(pop['Delhi'])
pop[['Osaka', 'Tokyo']]    # 複数ラベルはリストで
Tokyo 37.4 Delhi 31.0 Shanghai 27.1 Osaka 19.2 dtype: float64 31.0 Osaka 19.2 Tokyo 37.4 dtype: float64

値の部分は条件で絞ったり、計算したりできます。ラベルは計算してもそのまま付いてきます。

print(pop[pop > 25])       # 条件で絞る
print(pop * 1000)          # 全部に掛ける
print('Osaka' in pop)       # 索引にあるか
Tokyo 37.4 Delhi 31.0 Shanghai 27.1 dtype: float64 Tokyo 37400.0 Delhi 31000.0 Shanghai 27100.0 Osaka 19200.0 dtype: float64 True
pop.name = 'population'          # Series自身の名前
pop.index.name = 'city'         # 索引の名前
pop
city Tokyo 37.4 Delhi 31.0 Shanghai 27.1 Osaka 19.2 Name: population, dtype: float64
🍎 かんたん説明

Seriesは「名札つきのNumPy配列」。計算しても名札が付いたままなので、どの値が何だったか迷いません。

💻 ミニ練習：Seriesを作る

果物の価格 apple: 120, banana: 80, orange: 100 を辞書から Series にして、変数 price に入れてください。

price = pd.Series({'apple': 120, 'banana': 80, 'orange': 100})

辞書のキーが索引、値がデータになります。

②

DataFrame：表を作る

同じ索引を共有するSeriesの束

DataFrameは、行と列をもつ表です。各列がSeriesで、すべての列が同じ行ラベル（索引）を共有します。いちばん基本の作り方は「列名 → 値のリストの辞書」です。

data = {'city': ['Tokyo', 'Delhi', 'Shanghai'],
        'pop': [37.4, 31.0, 27.1],
        'country': ['Japan', 'India', 'China']}
frame = pd.DataFrame(data)
frame
city pop country 0 Tokyo 37.4 Japan 1 Delhi 31.0 India 2 Shanghai 27.1 China

列の並び順や行ラベルは、引数で指定できます。無い列名を指定すると、その列は欠損値（NaN）になります。

pd.DataFrame(data, columns=['country', 'city', 'pop', 'area'], index=['a', 'b', 'c'])
country city pop area a Japan Tokyo 37.4 NaN b India Delhi 31.0 NaN c China Shanghai 27.1 NaN
# 辞書のリスト（1行＝1つの辞書）。足りない所は NaN
pd.DataFrame([{'a': 1, 'b': 2}, {'b': 3, 'c': 4}])
a b c 0 1.0 2 NaN 1 NaN 3 4.0
# 入れ子の辞書：外側のキー＝列、内側のキー＝行
nested = {'Tokyo': {2020: 37.3, 2021: 37.4}, 'Delhi': {2020: 30.3, 2021: 31.0}}
frame2 = pd.DataFrame(nested)
print(frame2)
frame2.T    # 転置（行と列を入れ替え）
Tokyo Delhi 2020 37.3 30.3 2021 37.4 31.0 2020 2021 Tokyo 37.3 37.4 Delhi 30.3 31.0
print(frame.to_numpy())     # 値だけをNumPy配列として取り出す
print(frame.dtypes)           # 列ごとに型が違ってよい
[['Tokyo' 37.4 'Japan'] ['Delhi' 31.0 'India'] ['Shanghai' 27.1 'China']] city object pop float64 country object dtype: object
⚠️ 列ごとに型が違うDataFrameを to_numpy() すると、全体が object型（なんでも入る型）になります。数値だけの表なら数値型のままです。
🍎 かんたん説明

DataFrameは「列ごとに型を持てる表」。表計算ソフトの1シートのようなものと考えてOKです。

💻 ミニ練習：DataFrameを作る

name列（Ann, Bob）とscore列（80, 90）のDataFrameを辞書から作り、df に入れてください。

df = pd.DataFrame({'name': ['Ann', 'Bob'], 'score': [80, 90]})

辞書のキーが列名になります。

③

列と行を取り出す・足す・消す

[ ] と loc / iloc

本物のCSV（本の examples/tips.csv）で試します。まず読み込んで、head()で先頭を眺めます。

tips = pd.read_csv('examples/tips.csv')
tips.head()
total_bill tip smoker day time size 0 16.99 1.01 No Sun Dinner 2 1 10.34 1.66 No Sun Dinner 3 2 21.01 3.50 No Sun Dinner 3 3 23.68 3.31 No Sun Dinner 2 4 24.59 3.61 No Sun Dinner 4

列は [ ] に列名を入れて取り出します（1列ならSeries、複数列ならリストで渡してDataFrame）。

print(tips['tip'].head(3))               # 1列 → Series
tips[['total_bill', 'tip']].head(3)    # 2列 → DataFrame
0 1.01 1 1.66 2 3.50 Name: tip, dtype: float64 total_bill tip 0 16.99 1.01 1 10.34 1.66 2 21.01 3.50

行は loc（ラベルで）か iloc（位置で）で取り出します。

print(tips.loc[0])          # ラベル0の行 → Series
print(tips.iloc[2])         # 3番目の行（位置は0から）
tips.loc[0:2, ['tip', 'day']]    # ラベル0〜2（終点を含む）、列も指定
total_bill 16.99 tip 1.01 smoker No day Sun time Dinner size 2 Name: 0, dtype: object total_bill 21.01 tip 3.5 smoker No day Sun time Dinner size 3 Name: 2, dtype: object tip day 0 1.01 Sun 1 1.66 Sun 2 3.50 Sun

新しい列は、代入するだけで足せます。スカラー・リスト・Series（索引でそろえて入る）が使えます。消すときは drop（元は変えない）か del（元を変える）です。

tips['tip_pct'] = tips['tip'] / tips['total_bill']      # 計算した列を追加
tips['is_big'] = tips['size'] >= 4                          # 真偽値の列
tips[['tip_pct', 'is_big']].head(3)
tip_pct is_big 0 0.059447 False 1 0.160542 False 2 0.166587 False
small = tips.drop(columns=['is_big'])    # 新しいDataFrameを返す
print('is_big' in small.columns, 'is_big' in tips.columns)
del tips['is_big']                          # tips自身から消す
'is_big' in tips.columns
False True False
⚠️ tips[0] のように数字を [ ] に入れると「0という名前の列」を探します。行を取りたいときは必ず loc[0] / iloc[0] を使います。
🍎 かんたん説明

列は [ ]、行は loc（名前）か iloc（番号）。迷ったらこの3つだけ覚えればOKです。

💻 ミニ練習：列を足す

tipsに、total_billとtipの合計を入れたgrand列を追加してください。

tips['grand'] = tips['total_bill'] + tips['tip']

右辺の計算結果が、新しい列になります。

④

Index：変えられない名札

集合のように使える・重複もOK

索引（Index）はあとから1か所だけ書き換えられない（イミュータブルな）配列です。複数のデータで同じ索引を安全に共有するための仕組みです。

idx = pd.Index(['a', 'b', 'c'])
print(idx[1:])
Index(['b', 'c'], dtype='object')
idx[1] = 'z'
TypeError: Index does not support mutable operations

Indexは集合のように使えます。2つの索引の共通部分や、どちらかにある要素を調べられます。

a = pd.Index([1, 3, 5, 7, 9])
b = pd.Index([2, 3, 5, 7, 11])
print(a.intersection(b))    # 共通
print(a.union(b))           # どちらか
print(a.difference(b))      # aにだけある
Index([3, 5, 7], dtype='int64') Index([1, 2, 3, 5, 7, 9, 11], dtype='int64') Index([1, 9], dtype='int64')

NumPy配列の索引と違って、重複したラベルを持てます。重複があると、そのラベルを指定したときに複数行がまとめて返ります。

dup = pd.Series([10, 20, 30], index=['x', 'x', 'y'])
print(dup.index.is_unique)
dup['x']
False x 10 x 20 dtype: int64
frame3 = pd.DataFrame({'a': [1, 2]}, index=['r1', 'r2'])
print('a' in frame3.columns)    # 列に名前があるか
print('r1' in frame3.index)     # 行ラベルがあるか
True True
🍎 かんたん説明

名札の途中を書き換えられないのは、データと名札がずれる事故を防ぐため。同じ名札を何個ものSeriesで使い回しても安心です。

💻 ミニ練習：共通の索引

aとbの共通部分を求めてください。

a.intersection(b)

結果は [2, 3] です。

📖 用語集

Series（シリーズ）
Series
索引つきの1次元データ。値と索引と名前をもつ。
DataFrame（データフレーム）
DataFrame
行と列をもつ表。各列がSeriesで、索引を共有する。
索引・インデックス
index
行につけるラベル。重複もでき、途中の書き換えはできない。
ラベルによる選択
loc
行・列の名前で選ぶ。範囲指定の終点は含まれる。
位置による選択
iloc
0から数えた位置で選ぶ。範囲指定の終点は含まれない。
欠損値
NaN
値がないことを表す特別な値。存在しない列を指定すると入る。
転置
transpose (.T)
行と列を入れ替えること。

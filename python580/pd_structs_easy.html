SeriesとDataFrame

名札つきの列と表

🎯 これだけ覚えればOK

Seriesは名札つきの1列、DataFrameは表（列がSeriesの束）。

s = pd.Series({'a': 1, 'b': 2})
print(s)
df = pd.DataFrame({'name': ['Ann', 'Bob'], 'score': [80, 90]})
df
a 1 b 2 dtype: int64 name score 0 Ann 80 1 Bob 90
🍎 ひとことで

辞書から作ると、キーが名札（索引）や列名になります。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 辞書からSeriesを作ると、索引は何になる？A. キーになる。
Q2. DataFrameの列は何？A. Series。

取り出す・足す

[ ] と loc

🎯 これだけ覚えればOK

列は [ ]、行は loc（名前）／iloc（番号）。

tips = pd.read_csv('examples/tips.csv')
print(tips['tip'].head(2))
tips.loc[0, ['tip', 'day']]
0 1.01 1 1.66 Name: tip, dtype: float64 tip 1.01 day Sun Name: 0, dtype: object
🍎 ひとことで

新しい列は tips['新しい名前'] = 計算式 で足せます。tips[0] は行ではなく「0という列」なので注意！

🤔 答えられるかな？（クリックで答えが開く）

Q1. 1行目（ラベル0）を取るには？A. tips.loc[0]
Q2. tips[0]が取りにいくのは？A. 「0」という名前の列。

🏗️ M5 演習アリーナ — テーブル設計と制約

命名規則・主キー・複合キー・外部キー・ON DELETE CASCADE・制約（NOT NULL / UNIQUE / CHECK）・ERD・インデックスを、実際に CREATE TABLE を書いて練習します。基礎5問・中級5問・上級5問の計15問。テーブルを作る問題は、できあがった構造（と削除後のデータ）で自動採点します。

🟢 基礎🟡 中級🔴 上級🔑 レッスンへ

▶ 実行：書いたSQLを実際に動かして結果を見ます。✅ 採点：模範解答と結果を比較して正解／不正解を判定します。💡 答えを見る：模範解答のSQLを表示します。

⚠️ 採点は結果の「値」を比較します。問題文で指定された列と順番でSELECTしてください。列の順番や別名が異なると不一致と判定されることがあります。

🏗️ このブラウザ版の SQLite は PostgreSQL ではないので、GENERATED ALWAYS AS IDENTITY や SERIAL は使いません（主キーは INTEGER PRIMARY KEY）。構造の確認には pragma_table_info・pragma_foreign_key_list・sqlite_master を使います。

⚠️ 外部キーの動作確認（ON DELETE CASCADE）：SQLite は初期状態で外部キー制約がオフです（PostgreSQL では常にオン）。カスケード削除を試す問題では、スクリプトの先頭に PRAGMA foreign_keys = ON; を書いてください。

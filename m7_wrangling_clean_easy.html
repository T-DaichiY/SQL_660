🍎 超やさしい版：ALTER・UPDATEでクリーニング

散らかったデータを、バックアップを取ってからそうじします。使うのはALTERとUPDATEだけ。練習用の30行のデータで見てみましょう。

ALTERとUPDATEバックアップと置換会社名の評価を消す-1をNULLに🧹 本編はこちら
①

ALTERとUPDATEのちがい

入れ物を変える？ 中身を変える？

🎯 これだけ覚えればOK

ALTER＝表の「形」を変える。UPDATE＝表の「中身」を変える。

🗄️
たとえば、引き出し付きの棚を考えます。棚に引き出しを1つ足すのがALTER、引き出しの中の物を入れ替えるのがUPDATEです。

▶ 列（引き出し）を足す

ALTER TABLE ds_jobs ADD COLUMN note TEXT;

▶ 中身を書き換える

UPDATE ds_jobs SET rating = 0 WHERE post_id = 1;
⚠️
WHEREを書き忘れると、30行ぜんぶが書き換わります。「どの行？」を必ず書きましょう。
🍎 ひとことで

SET＝何にするか。WHERE＝どの行か。この2つをセットで考えます。

🤔 答えられるかな？（クリックで答えが開く）

Q1. ALTERは何を変える？A. 表の構造（列を足す・型を変えるなど）。
Q2. UPDATEでWHEREを忘れると？A. 全行（この教材では30行）が書き換わる。
②

バックアップをとってから直す

コピーを作ってから、宿題を書き直す

🎯 これだけ覚えればOK

直す前にコピーを取る。失敗しても、コピーから戻せます。

📋
大事な宿題を書き直す前に、コピー機でコピーを取るのと同じです。SQLではCREATE TABLE ... AS SELECTを使います。

▶ ds_jobsのコピーを作る

CREATE TABLE ds_jobs_backup AS
SELECT * FROM ds_jobs;

▶ 'Sr.'を'Senior'に置き換える（REPLACE）

UPDATE ds_jobs
SET job_title = REPLACE(job_title, 'Sr.', 'Senior');
UPDATE 2 （post_id 5 と 19 が 'Senior Data Scientist' に）
⚠️
順番が大事。先に'Sr.'（ピリオド付き）、あとで'Sr'。逆にすると'Senior.'のようにピリオドが残ります。
🍎 ひとことで

最後にGROUP BY job_titleで数えると、'Senior Data Scientist'が9行にそろいます。

🤔 答えられるかな？（クリックで答えが開く）

Q1. なぜ先にバックアップを取るの？A. UPDATEを間違えたとき、コピーから元のデータに戻せるから。
Q2. 'Sr'を先に置き換えるとどうなる？A. 'Sr.'が'Senior.'になり、ピリオドが残ってしまう。
③

会社名の後ろの「評価」を消す

名前にくっついた数字をはさみで切る

🎯 これだけ覚えればOK

後ろの3文字（例：4.4）を切り落とす。ただし評価がついている行だけ。

✂️
Bluepeak Studios4.4の後ろの4.4は、評価がくっついたゴミです。全体の長さ−3文字だけ残せば消えます。
UPDATE ds_jobs
SET company_name = SUBSTRING(company_name, 1, LENGTH(company_name) - 3)
WHERE RIGHT(company_name, 3) LIKE '_._';
UPDATE 25 （'Bluepeak Studios4.4' → 'Bluepeak Studios'）
⚠️
WHEREがないと、きれいな名前まで削れます。たとえばOpen Door HealthがOpen Door Heaになってしまいます。
🍎 ひとことで

'_._'は「何か1文字・ドット・何か1文字」。評価の形（4.4など）の行だけを選ぶ目印です。実行前に同じWHEREでSELECTして、25行だと確認しましょう。

🤔 答えられるかな？（クリックで答えが開く）

Q1. SUBSTRINGの位置は0から？1から？A. 1から数える。
Q2. WHEREで何をしているの？A. 評価がついた25行だけを選び、きれいな5行を守っている。
④

-1 を本物の NULL にする

「わからない」を、ちゃんと「空っぽ」にする

🎯 これだけ覚えればOK

-1は「わからない」の代わりに入っただけ。NULLに直すと、計算が正しくなります。

🕳️
テストの「未受験」を0点と書くと、平均が下がりますよね。-1も同じ。本物の「空っぽ」＝NULLにします。
UPDATE ds_jobs SET competitors = NULL
WHERE competitors = '-1';
UPDATE 13
⚠️
文字の列は'-1'（引用符あり）、数字の列は-1（引用符なし）。competitorsは文字の列、ratingは数字の列です。

▶ COUNT(rating)の変化

直す前： COUNT(rating) = 30 直した後： COUNT(rating) = 25 （COUNT(*)は30のまま）
🍎 ひとことで

COUNT(列)はNULLを数えません。数が減れば、-1がNULLに変わった証拠です。

🤔 答えられるかな？（クリックで答えが開く）

Q1. competitorsの'-1'に引用符が必要なのはなぜ？A. competitorsがTEXT（文字）の列だから。
Q2. 直した後、COUNT(rating)は？A. 25。NULLの5行が数えられなくなるから。

💡 まとめ

• ALTER＝形を変える、UPDATE＝中身を変える

• 直す前にCREATE TABLE ... AS SELECTでバックアップ

• WHEREを忘れると全行が変わる

• -1はSET 列 = NULL WHERE 列 = '-1'でNULLに

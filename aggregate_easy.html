M4 · Aggregate function 🍎

🍎 超やさしい版：集計関数

たくさんの行を1つの値にまとめる関数。使ったらGROUP BYもセットで書きます。

一言でいうとGROUP BY必須できないこと📊 本編はこちら
⚡

一言でいうと

行をまとめて1つの値に

🎯 これだけ覚えればOK

前のレッスンは「1行の中の計算」でした。集計関数は複数の行をまたいでまとめる計算です。平均・合計・件数・最大・最小がその代表。

関数意味
AVG()平均
SUM()合計
COUNT()件数
MAX() / MIN()最大 / 最小
🍎 ひとことで

平均は1行だけ見ても出せません（何行あるか分からないから）。だから専用の関数が必要なのです。

①

GROUP BY がセット

「何ごとに」まとめるか

▶ 銘柄ごとの平均終値

SELECT s_index, AVG(s_close)
FROM stocks
GROUP BY s_index;
s_index | avg --------+----------- AAPL | 128.43... AMZN | 1702.99...
⚠️
GROUP BYを忘れるとエラー。
column "s_index" must appear in the GROUP BY clause
——集計していない列は、必ずGROUP BYに書きます。
ExcelSQL
平均=AVERAGE(A1:A58)AVG(s_close)
範囲自分でセルを選ぶGROUP BYが範囲を決める
14銘柄なら数式14個クエリ1本
🍎 ひとことで

GROUP BYはExcelの「範囲選択」の代わり。同じ値ごとに勝手にまとめてくれます。

②

できること・できないこと

別名は◯、WHEREは✗

⭕ 別名＋ORDER BY

SUM(volume) AS total
ORDER BY total DESC

❌ WHEREで使う

WHERE AVG(x) > 10
→ 集計より前に走るのでNG

▶ 全部入りの例（銘柄ごとの平均パーセント変化）

SELECT s_index,
       CAST(AVG(((s_close - s_open) / s_open) * 100)
            AS numeric(10,2)) AS percent_change
FROM stocks
WHERE s_close IS NOT NULL
GROUP BY s_index;

①WHEREでNULLを除く → ②銘柄ごとに分ける → ③平均を計算 → ④CASTで整形。NULLを先に除くのは、平均が引っ張られないようにするためです。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 集計関数を使ったら何が必要？A. GROUP BY（非集計の列を並べる場合）。
Q2. WHEREにAVG()は書ける？A. 書けない。WHEREは集計より前に走るため。絞りたいならHAVING。
Q3. 集計結果で並べ替えたいときは？A. 別名を付けてORDER BY 別名。

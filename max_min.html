M4 · Max and min

📈 MAX と MIN

列の最大値と最小値。単純な関数ですが、「データが取りうる範囲」を知る強力な調査ツールになります。

① 構文と使い方② 範囲を知る価値📝 Quiz
①

MAX と MIN — 期待どおりの動き

列の最大値・最小値を返す

MAX()は列の最大値、MIN()は最小値を返します。他の集計関数とまったく同じ形で使えます。

例1：未払い金額が最も大きい顧客はいくらか

SELECT MAX(outstanding_amt)
FROM customers;
max ------- 12000

「誰が一番お金を払っていないか」を調べる第一歩です。最大の未払い額は12,000だと分かりました。

例2：最小値に変えるだけ

SELECT MIN(outstanding_amt)
FROM customers;
min ------ 3000
📌 MAX＝largest／biggest、MIN＝smallest。名前のとおりで、特別なルールはありません。
🍎 かんたん説明

MAX(列)で一番大きい値、MIN(列)で一番小さい値。それだけです。

②

「値の範囲」が分かることの価値

外れ値と異常の検出

例3：顧客の格付け（grade）の範囲

SELECT MAX(grade) FROM customers;
max ----- 3
SELECT MIN(grade) FROM customers;
min ----- 0

ここから分かることは、単なる「3」と「0」以上のものです——顧客の格付けは0から3の範囲で付けられているという、データの仕様そのものが読み取れます。同様に、未払い金額は3,000〜12,000の範囲に収まっていることも分かりました。

MAX / MIN から読み取れること
MIN = 0
下限
←
値の範囲
0 〜 3
→
MAX = 3
上限
範囲が分かれば、そこから外れた値は「おかしい」と判断できる。
📌 外れ値（outlier）の発見に使えます。格付けが0〜3の範囲だと分かっていれば、後の分析で7や-1といった値が出てきたときに「何かがおかしい」とすぐ気付けます。データの入力ミス、変換の失敗、想定外のケース——いずれも早く見つけるほど傷が浅くて済みます。
📊 MAX・MINはごく基本的な統計分析ツールです。しかし「このデータはどんな値を取るのか」を最短で把握できるという点で、新しいテーブルに触れたときの偵察手段として非常に有効です。DISTINCTが「値の種類」を教えてくれたのに対し、MAX/MINは「値の幅」を教えてくれます。
🍎 かんたん説明

MAXとMINをセットで見ると「このデータは○○から○○まで」が分かります。範囲から外れた値は要注意サインです。

📖 用語集

MAX()
最大値
列に含まれる最も大きい値を返す集計関数。
MIN()
最小値
列に含まれる最も小さい値を返す集計関数。
range
値の範囲
MINからMAXまでの幅。データがどんな値を取りうるかを示す。
outlier
外れ値
想定される範囲から外れた値。入力ミスや異常のサインになる。

💡 学習のヒント

新しい数値列に出会ったら、MAXとMINを1回ずつ実行しておきましょう。30秒で「このデータの常識」が手に入ります。

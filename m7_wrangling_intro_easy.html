🍎 超やさしい版：データ整形①（準備・取込・探索）

汚れたデータをきれいにする「大掃除」の、最初の3ステップです。まずやり方を知り、取り込んで、汚れを探します。

データ整形とは取り込みと件数チェックGROUP BYで汚れ探し🔎 本編はこちら
①

データ整形とは？

散らかった部屋を片づける前の心がまえ

🎯 これだけ覚えればOK

データ整形＝汚れたデータを使える形に直すこと。いきなり直さず、メモ → 確認 → バックアップ → 少しずつ直す、の順で進める。

🧹
部屋の片づけと同じです。先に写真を撮って（バックアップ）から、簡単な所から片づけます。

▶ SQLのコメント（実行されないメモ）

-- 1行だけのメモ
/* 何行にもわたる
   メモ。理由を書く */
SELECT COUNT(*) FROM ds_jobs;
⚠️
/*を閉じ忘れると、その後ろが全部メモ扱いになって、何も実行されません。
🍎 ひとことで

直す前にメモとバックアップ。コメントには「何をしたか」より「なぜそうしたか」を書きます。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 直す前に必ずやることは？A. バックアップ（控えのテーブル）を作ること。失敗しても戻れる。
Q2. /*を閉じ忘れるとどうなる？A. その後ろのSQLが全部コメントになり、実行されない。
②

取り込みと件数チェック

入れたら、数えて確かめる

🎯 これだけ覚えればOK

取り込んだら、まずCOUNT(*)で行数を数える。元のファイルと同じ数ならOK。

▶ 行数と、ratingの件数を数える

SELECT COUNT(*), COUNT(rating) FROM ds_jobs;
count(*) | count(rating) ---------+-------------- 30 | 30
🤔
「評価なし」は5行あるのに、ratingの件数も30。-1はNULLではなく、ただの数字として入っているからです。
⚠️ 本物のCSV取り込み（COPY ... FROM）はこの練習サイトでは動きません。ds_jobsは最初から読み込み済みです。
🍎 ひとことで

宿題のプリントを配ったら、枚数を数えますよね。それと同じです。「-1」のような「不明」の代わりの数字を番兵値と呼びます。

🤔 答えられるかな？（クリックで答えが開く）

Q1. なぜ取り込み後に件数を数える？A. 取りこぼしがないか、元のファイルの行数と比べて確かめるため。
Q2. COUNT(rating)が25でなく30なのはなぜ？A. -1がNULLではなく本物の数値として入っていて、COUNTが数えるから。
③

GROUP BYで汚れ探し

数えて、並べて、変な値を見つける
🔍
SELECT 列, COUNT(列) FROM ds_jobs GROUP BY 列 ORDER BY 列;
並べると、似た値が隣に並んで見つけやすい！

▶ ratingで試す（先頭の3行）

SELECT rating, COUNT(rating)
FROM ds_jobs GROUP BY rating ORDER BY rating;
rating | count -------+------ -1 | 5 2.9 | 1 3.2 | 1 ...

▶ job_titleで試す（下の4行がぜんぶ同じ意味）

Senior Data Scientist | 3 Senior. Data Scientist - | 2 Sr Data Scientist | 2 Sr. Data Scientist | 2
🍎 ひとことで

クローゼットの服を色別に並べると、同じ服が何枚もあると分かります。見つけた汚れはチェックリストにメモしておきます（-1が5行、Srの表記ゆれ、社名の末尾にくっついた評価など）。

🤔 答えられるかな？（クリックで答えが開く）

Q1. ORDER BYを付ける理由は？A. 似た値が隣に並び、繰り返しのパターンや変な値が見つけやすくなるから。
Q2. ratingで見つかった変な値は？A. -1（5行）。「不明」を表す番兵値。

💡 まとめ

• 整形の順番：メモ → 確認 → 取り込み → 探索 → バックアップ → 修正

• コメント：--は1行、/* */は複数行

• 取り込んだらCOUNT(*)で件数チェック

• GROUP BY + COUNT + ORDER BYで汚れ探し

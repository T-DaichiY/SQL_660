M6 演習アリーナ

🏋️ M6 演習アリーナ — SQLをIDEで書いて実行

レッスンで学んだ内容を、実際にSQLを書いて body に染み込ませましょう。本物のSQLite（sql.js）がブラウザ内で動き、書いたSQLはその場で実行され、模範解答と自動で比較採点されます。8つのスキルカテゴリ × 基礎5問・中級5問・上級5問 ＝ 合計120問。

💻 使い方： 各カードのエディタにSQLを書く → ▶ 実行で結果を確認 → ✅ 採点で模範解答と自動比較 → 分からなければ💡 答えを見る。エディタは打った瞬間にSQLキーワードが色付けされます（IDEと同じ体験）。

🗄️ 使うデータは、レッスンでもおなじみの University DB（student / instructor / course / takes / teaches / prereq / section / advisor / department）と Banking DB（customer / account / branch / depositor / loan / borrower）です。

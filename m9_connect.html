🔗 Python×SQL②：データベースに接続する

1ファイル版の接続（import→connect→cursor）と、変える3か所、本番向けの3ファイル版（.ini）を学びます。

🎥 講義動画「Python and SQL」part 2 ・ 講義で使う接続用のサンプルは、講師が配るファイルです。このページのコードは講義の説明に沿った標準的な形で、講師のファイルそのものではありません。

① 2つの書き方② 4ステップ③ 変える3か所④ 3ファイル版📝 Quiz
①

2つの書き方

1ファイル版（これで十分）と、3ファイル版（本番向け）

講師は接続の書き方を2つ見せます。

  • full file（1ファイル版）：接続・カーソル・コマンドを1つのファイルに全部書く。いちばん簡単で、始めやすい。
  • 3ファイル版：設定ファイル（.ini）・設定を読むファイル・接続のファイルに分け、try/exceptでエラー処理もする。本番向け。
📌 講師は「必須なのは full file だけ。3ファイル版は見せるだけ」と明言しています。課題では full file を書き換えて、自分のコマンドを入れて使います。
🍎 かんたん説明

お店で言うと、1ファイル版は「全部ひとりで作るキッチン」、3ファイル版は「分業する大きな厨房」。まずは1人で十分です。

②

1ファイル版の4ステップ

import → connect → cursor → execute

講師が示すのは、psycopg2の公式ドキュメントにある基本の使い方の例とほぼ同じです。流れは4ステップ＋締めです。

import psycopg2

conn = psycopg2.connect(
    dbname="module9",
    user="postgres",
    password="your_password"
)
cur = conn.cursor()

cur.execute("SELECT version();")   # ← ここにコマンドを書く（何回でも）

conn.commit()
cur.close()
conn.close()
  1. import：このファイルでpsycopg2を使うと宣言する（インストールしただけでは足りません）。
  2. connect：データベース名・ユーザー・パスワードを渡して、接続を作る。
  3. cursor：接続の上でカーソルを開く。「接続を開いて、データベースにアクセスさせて」の意味。
  4. execute：カーソルに対してコマンドを実行。何回呼んでもよい。
  5. 最後にcommit（変更を確定）→ カーソルを閉じる → 接続を閉じる。
📝 変数名（conn・cur など）は自由です。講義の音声では名前が聞き取りにくいため、ここでは公式ドキュメントで一般的な名前にしています。
💻 ミニ練習：接続を作る

データベース名module9、ユーザーpostgres、パスワードpw123で接続を作り、カーソルを開く2行以上を書いてください（importも含める）。

import psycopg2

conn = psycopg2.connect(dbname="module9", user="postgres", password="pw123")
cur = conn.cursor()

接続はpsycopg2.connect(...)、カーソルはconn.cursor()で作ります。

③

自分で変える3か所

dbname・user・password

講師が「変えるのはここだけ」と強調した部分です。

変える変えない
dbname（自分のデータベース名）conn = ...connect(...) の形
user（データベースのユーザー）cur = conn.cursor()
password（そのパスワード）executeの呼び方（引用符の中のSQLだけ変わる）
  • =の右側の文字列を、自分のデータベースに合わせて書き換えます。
  • ホストを指定しなければ、localhost（自分のPC）につなぎます。別のサーバーなら、URLまたはIPアドレスを指定します。
🍎 かんたん説明

住所（データベース名）、名前（ユーザー）、鍵（パスワード）の3つを自分用に変えれば、あとはそのままです。

④

3ファイル版を見てみよう

.ini と config と connect

見せるだけの例ですが、仕組みを知っておくと読めます。設定は.iniファイルに集めるので、ユーザー名やホストを変えるときは、このファイルだけを直せば済みます。

▶ ① database.ini（設定ファイル）

[postgres]
host=localhost
database=module9
user=postgres
password=your_password

[postgres]はセクション名。講師の説明では、ここでhost（localhost）が増えるだけで、あとはdbname・user・passwordと同じ3つです。

▶ ② config.py（設定を読む）

from configparser import ConfigParser

def config(filename="database.ini", section="postgres"):
    parser = ConfigParser()
    parser.read(filename)
    db = {}
    if parser.has_section(section):
        for param in parser.items(section):
            db[param[0]] = param[1]
    else:
        raise Exception("Section " + section + " not found in " + filename)
    return db

ファイル名とセクション名を受け取り、そのセクションのパラメータを辞書に読み込みます。ファイル名はdatabase.ini、セクション名はpostgresと、.iniの中身と一致している必要があります。

▶ ③ connect.py（接続）

import psycopg2
from config import config

def connect():
    conn = None
    try:
        params = config()
        conn = psycopg2.connect(**params)
        cur = conn.cursor()
        cur.execute("SELECT version();")
        print(cur.fetchone())
        cur.close()
    except (Exception, psycopg2.DatabaseError) as error:
        print(error)
    finally:
        if conn is not None:
            conn.close()

if __name__ == "__main__":
    connect()
  • try / except / finallyがエラー処理（講師の言う「try-catch」）。
  • if __name__ == "__main__":は、このファイルを直接実行したときだけconnect()を呼ぶ決まり文句。
  • バージョンをprintしているのは、接続できたかどうかを確かめるためのおまけです。
📝 このコードは、講義の説明（config→connectの流れ）に沿った典型的な形です。講師が配る実際のファイルとは細部が違う場合があります。配布ファイルがあればそちらを優先してください。
🔑 まとめ：full file でも3ファイル版でも、やることは同じ。import → 接続 → カーソル → execute（何回でも）→ commit → カーソルと接続を閉じる。
💻 ミニ練習：iniファイルを書く

localhostのデータベースmodule9に、ユーザーpostgres、パスワードpw123でつなぐ設定を、[postgres]セクションで書いてください。

[postgres]
host=localhost
database=module9
user=postgres
password=pw123

セクション名[postgres]の下に、4つのキーを書きます。

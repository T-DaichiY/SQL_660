📈 回帰の評価：RMSE・MAE・R²

数値を予測するモデルの「当たり具合」を表す 3 つの指標を、式から自作します。R² がマイナスになる理由も確かめます。

①

説明する：何のため？

3文で言えるようにする

回帰モデルは「どれくらい外したか」を1つの数字にして比べます。

指標意味単位特徴
RMSE平均的なズレの大きさy と同じ大きな外れを重く罰する
MAEズレの絶対値の平均y と同じ外れ値に強い
R²ばらつきのうち説明できた割合なし（0〜1）平均だけ予測すると 0、それより悪いとマイナス
📝 3文のお手本
RMSE は誤差を二乗して平均し平方根を取った値で、y と同じ単位の「平均的なズレ」を表す。R² は平均だけを予測する場合と比べてどれだけ誤差が減ったかの割合で、0 なら平均予測と同じ。訓練データだけで R² が高くても過学習かもしれないので、必ずテストデータで見る。

自分で作る

NumPy で書いて、scikit-learn と一致させる

3 つの関数を書き、糖尿病データ（442 人）の線形回帰の予測で、sklearn と並べます。

def rmse(y, p):
    y, p = np.asarray(y, float), np.asarray(p, float)
    return float(np.sqrt(np.mean((y - p) ** 2)))

def mae(y, p):
    y, p = np.asarray(y, float), np.asarray(p, float)
    return float(np.mean(np.abs(y - p)))

def r2(y, p):
    y, p = np.asarray(y, float), np.asarray(p, float)
    return float(1 - np.sum((y - p) ** 2) / np.sum((y - y.mean()) ** 2))

print('RMSE 自作:', round(rmse(yr_te, pred), 4), ' sklearn:', round(mean_squared_error(yr_te, pred) ** 0.5, 4))
print('MAE  自作:', round(mae(yr_te, pred), 4), ' sklearn:', round(mean_absolute_error(yr_te, pred), 4))
print('R2   自作:', round(r2(yr_te, pred), 4), ' sklearn:', round(r2_score(yr_te, pred), 4))

R² の意味を確かめる

baseline = np.full(len(yr_te), np.mean(yr_te))      # 平均だけを予測
print('平均だけを予測したときの R²:', round(r2(yr_te, baseline), 6))
print('平均より悪い予測の R²:', r2([1, 2, 3], [3, 2, 1]))
平均だけを予測したときの R²: 0.0 平均より悪い予測の R²: -3.0
RMSE ≈ 56 は「予測は平均して約 56 ズレる」という意味です（y の単位は糖尿病の進行指標）。R² ≈ 0.36 は、ばらつきの約 36% を説明できたという意味。R² は平均より悪い予測ならマイナスになります。

⚠️ よくある間違い
  • RMSE を「％」だと思う（y と同じ単位）
  • 訓練データの R² だけ見て満足する（テストで見る）
  • R² は常に 0〜1 だと思う（テストではマイナスになる）
  • RMSE と MAE を単位の違う y で比べる
❓ 確認：RMSE が MAE よりずっと大きいとき、何が起きている？
少数の大きな誤差がある。RMSE は誤差を二乗するので、大きな外れに強く反応する。
❓ 確認：R² = 0 は、どんなモデル？
平均だけを予測するモデルと同じ当たり具合（何も説明できていない）。

📖 用語集

RMSE
二乗平均平方根誤差
誤差を二乗して平均し、平方根を取る。y と同じ単位。大きな誤差を重く見る。
MAE
平均絶対誤差
誤差の絶対値の平均。外れ値に強い。
R²
決定係数
1 − (誤差の二乗和) ÷ (平均からの差の二乗和)。1 に近いほど良い。

💡 学習のヒント

RMSE はy と同じ単位の「平均的なズレ」。R² は「平均だけを予測するより、どれだけ良いか」。

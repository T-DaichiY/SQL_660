⚖️ 標準化（z スコア）

単位の違う列を同じものさしに揃える標準化。z スコアを自作して、StandardScaler と pandas の .std() がなぜ少しずれるかまで確かめます。

①

説明する：何のため？

3文で言えるようにする

身長（cm）と年収（円）のように単位や大きさが違う列は、そのまま使うと、数字の大きい列がモデルを支配してしまいます。距離を使うモデル（KNN・SVM・K-Means）や、正則化つきの回帰では特に問題です。標準化は各列を「平均から何 SD 離れているか」に置き換えることです。

木のモデル（決定木・ランダムフォレスト）は大小関係しか見ないので、標準化は不要です。
📝 3文のお手本
標準化は各列から平均を引いて SD で割り、平均 0・SD 1 に揃える変換。単位の違う列を公平に扱うため、距離や正則化を使うモデルで必要になる。標準化した列の平均は 0、SD は 1 になる。
②

手で計算する

小さなデータを紙と電卓で

平均 10・SD 2 のとき、x = 14 の z スコアは (14 − 10) ÷ 2 ＝ 2（平均より 2 SD 上）。x = 7 なら (7 − 10) ÷ 2 ＝ −1.5。逆に z = −1 を元の値に戻すと 10 + (−1)×2 ＝ 8。

mu, sd = 10, 2
print((14 - mu) / sd, (7 - mu) / sd, mu + (-1) * sd)
2.0 -1.5 8
③

自分で作る

NumPy で書いて、scikit-learn と一致させる

zscore(x, ddof) と、訓練データだけから平均・SD を求める fit_transform_train_test を自作します。

def zscore(x, ddof=0):
    x = np.asarray(x, dtype=float)
    return (x - x.mean()) / x.std(ddof=ddof)

def fit_transform_train_test(X_tr, X_te):
    mu, sd = X_tr.mean(axis=0), X_tr.std(axis=0)      # 平均・SD は訓練データだけから
    return (X_tr - mu) / sd, (X_te - mu) / sd

z = zscore(col)
print('自作 z の平均・SD:', round(z.mean(), 6), round(z.std(), 6))
print('StandardScaler と一致:', np.allclose(z, StandardScaler().fit_transform(col.reshape(-1, 1)).ravel()))
自作 z の平均・SD: -0.0 1.0 StandardScaler と一致: True

なぜ pandas とずれる？

5 個のデータ [1,2,3,4,5] で、2 つの SD を比べます。

data = np.array([1., 2., 3., 4., 5.])
sc_sd = StandardScaler().fit(data.reshape(-1, 1)).scale_[0]
pd_sd = pd.Series(data).std()
print('StandardScaler の SD:', round(sc_sd, 4), ' pandas .std():', round(pd_sd, 4))
print('比:', round(sc_sd / pd_sd, 4), ' = sqrt(4/5) =', round(np.sqrt(4 / 5), 4))
StandardScaler の SD: 1.4142 pandas .std(): 1.5811 比: 0.8944 = sqrt(4/5) = 0.8944
StandardScaler は n で、pandas の .std() は n−1 で割ります。比は √((n−1)/n)。n が大きいほど差は小さくなりますが、小さいデータでは見えるずれです。

訓練データだけで fit する

a, b = fit_transform_train_test(Xa, Xb)
print('訓練の平均（ほぼ 0）:', np.abs(a.mean(axis=0)).max().round(8))
print('テストの平均（0 にはならない）:', np.abs(b.mean(axis=0)).max().round(3))
訓練の平均（ほぼ 0）: 0.0 テストの平均（0 にはならない）: 0.194
テストデータの平均が 0 にならないのは正しい動きです。テストの情報を使って平均を求めたら、それがデータ漏れになります（→ T3）。

⚠️ よくある間違い
  • 全データで fit してから分割する（データ漏れ）。正しくは分割 → 訓練で fit → 訓練とテストを transform
  • テストデータを別に fit_transform する（訓練と違うものさしになる）
  • 木のモデルに標準化をかけて安心する（効果なし。無害だが不要）
❓ 確認：標準化した列の平均と SD は？
平均 0・SD 1（訓練データについて）。
❓ 確認：なぜテストデータは、訓練の平均と SD で変換する？
本番では未来のデータの平均は分からない。訓練で決めたものさしで測るのが、本番と同じ条件になるから。

📖 用語集

z-score
z スコア
(x − 平均) ÷ SD。平均から何 SD 離れているか。
standardization
標準化
平均 0・SD 1 に揃える変換。
ddof
自由度の補正
SD を割る数を n − ddof にする。pandas は 1、NumPy・StandardScaler は 0。

💡 学習のヒント

標準化は「平均 0・SD 1 にする」だけ。ただし平均と SD は訓練データだけから求める、が試験の定番です。

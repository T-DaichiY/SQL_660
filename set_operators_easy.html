M6 · Set Operators 🍎

🍎 超やさしい版：集合演算子

JOINは列を横に並べる。UNION・INTERSECT・EXCEPTは2つのクエリの行を縦に重ねたり比べたりする仕組みです。

UNION・INTERSECT・EXCEPTEXCEPTの順序ルールとALL➕ 本編はこちら
⚡

3つの演算子を1枚で見る

同じ2つのクエリ、結果はこう変わる

🎯 これだけ覚えればOK

UNIONは「どちらかにあれば全部」、INTERSECTは「両方にあるものだけ」、EXCEPTは「Aにあって、Bには無いもの」。JOINと違って、列ではなく行を重ねたり比べたりします。

UNION

A ∪ B
どちらかにあれば含める（重複は消える）

INTERSECT

A ∩ B
両方にある行だけ残す

EXCEPT

A − B
Aから、Bにもある行を引く

▶ 教えられている または 受講されているコース（UNION）

SELECT course_id FROM teaches
UNION
SELECT course_id FROM takes;
85 rows（重複なしの一覧）
🍎 ひとことで

UNIONは2つのクエリを1つのリストに合体。重複は自動で消えます。

①

EXCEPTは順番が命

A EXCEPT B ≠ B EXCEPT A
⚠️
UNIONとINTERSECTは順番を変えても結果は同じですが、EXCEPTだけは順番で結果が変わります。「A引くB」と「B引くA」は別物です。

▶ 前提科目が無いコース（course − prereq）

SELECT course_id FROM course
EXCEPT
SELECT course_id FROM prereq;
121 rows

▶ 順番を逆にすると…（prereq − course）

SELECT course_id FROM prereq
EXCEPT
SELECT course_id FROM course;
0 rows
🍎 ひとことで

EXCEPTは「1つ目から2つ目を引く」。1つ目と2つ目を入れ替えると答えも変わります。

②

ルールとALL

列数・型を揃える／重複を残すALL
守ること理由
2つのクエリの列数を揃える1本の列にまとめるので数が合わないと比較できない
対応する列の型を揃える型が違うと「同じ値か」を判定できない
🔁
UNION ALL・INTERSECT ALL・EXCEPT ALLは重複を消さずに残します。ふつうのUNION/INTERSECT/EXCEPTは重複を自動で除きますが、ALLを付けると元の重複がそのまま残ります。

🤔 答えられるかな？（クリックで答えが開く）

Q1. UNIONとINTERSECTの違いは？A. UNIONはどちらかにあれば含める。INTERSECTは両方にある行だけ残す。
Q2. EXCEPTで注意すべき点は？A. 順番が結果を左右する。A EXCEPT BとB EXCEPT Aは別の結果になる。
Q3. ALLを付けるとどうなる？A. 重複行を消さずに、そのまま全部残す。

文字を整える道具箱

upper・trim・char_length・initcap

🎯 これだけ覚えればOK

文字列関数は、文字をそろえたり測ったりする道具。大文字にするupper()、余計な文字を削るtrim()、長さを数えるchar_length()が基本です。

たとえるなら散らかったクローゼットの整理。服（文字）を同じ向きにそろえて、余計なタグ（記号）を取って、数を数えます。

▶ 職種名を大文字にして、長さも数える

SELECT post_id, UPPER(job_title) AS up,
       CHAR_LENGTH(job_title) AS len,
       TRIM(job_title, ' -') AS t
FROM ds_jobs WHERE post_id = 15;
post_id | up | len | t 15 | SENIOR. DATA SCIENTIST - | 24 | Senior. Data Scientist
⚠️
initcap()は単語の先頭だけ大文字にしますが、略語は苦手。ETLがEtlになります。
🔠
PostgreSQLのLIKEは大文字小文字を区別します。区別しないのはILIKE。（アリーナのSQLiteはLIKEでも区別しません）
🍎 ひとことで

trimの2つ目の引数は「削っていい文字のセット」。前後から、セット以外の文字にぶつかるまで削ります。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 文字数を数える関数は？A. char_length()（またはlength()）。空白も1文字として数える。
Q2. PostgreSQLで大文字小文字を無視して探すには？A. LIKEではなくILIKEを使う。

文字の「あみ」で探して置き換える

正規表現 ~ ~* / regexp_replace

🎯 これだけ覚えればOK

正規表現は、文字のパターンを書く「あみ」。~*であみにかかる行を探し、regexp_replaceでかかった部分を置き換えます。

たとえるなら魚をすくうあみ。あみの目（パターン）が細かいほど、決まった形の文字だけがかかります。

▶ Sr でも Senior でも、シニアの行を全部探す

SELECT COUNT(*) FROM ds_jobs
WHERE job_title ~* 'sr\.?|senior';
count 9

▶ 会社名の最後にくっついた評価値を消す

SELECT REGEXP_REPLACE(company_name,
       '[0-9]\.[0-9]$', '') AS clean
FROM ds_jobs WHERE post_id = 1;
clean Bluepeak Studios
✨
~は大文字小文字を区別、~*は区別しない。頭に!を付けると「かからない行」。
🍎 ひとことで

regexp_replaceは、あみにかかったときだけ置き換えます。評価の付いていない会社名は、そのまま残ります。UPDATEの前に必ずSELECTで確認しましょう。

🤔 答えられるかな？（クリックで答えが開く）

Q1. ~ と ~* の違いは？A. ~は大文字小文字を区別し、~*は区別しない。
Q2. regexp_replaceで全部のマッチを置き換えるには？A. 第4引数に'g'を付ける。付けないと最初の1か所だけ。

全文検索（読んで理解）

tsvector・tsquery・@@

🎯 これだけ覚えればOK

全文検索は、文章を「語の索引」にして探す仕組み。PostgreSQL専用で、このサイトのアリーナでは動かないので、読んで理解する単元です。

たとえるなら本の後ろの索引。本文を全部読み直さなくても、索引を見れば単語のあるページがすぐ分かります。

📖
walkingもwalkも同じ語として扱う（語幹にそろえる）。theのような意味の薄い語は捨てる。

▶ PostgreSQLで（アリーナでは実行できません）

SELECT post_id, job_description
FROM ds_jobs
WHERE to_tsvector('english', job_description)
      @@ to_tsquery('english', 'model & data');

読み方：説明文を索引にして（tsvector）、検索語（tsquery）と@@で照合。&は「かつ」です。

🍎 ひとことで

LIKE '%word%'は語形の違いに弱く、順位も付けられません。全文検索ならts_rank()で「一番それらしい順」に並べられます。

🤔 答えられるかな？（クリックで答えが開く）

Q1. tsvectorは何をした文章？A. ストップワードを除き、語幹にそろえて、位置も記録した検索用の文章。
Q2. @@ は何をする？A. tsvectorとtsqueryを照合して、true/falseを返す。

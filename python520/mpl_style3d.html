①

見た目を一括で変える：スタイルシート

plt.style.use

色やフォントなど見た目の設定をまとめて変えるのがスタイルシートです。

print(plt.style.available[:6])
['Solarize_Light2', 'bmh', 'classic', 'dark_background', 'fast', 'fivethirtyeight']
x = np.linspace(0, 10, 100)
with plt.style.context('ggplot'):
    plt.plot(x, np.sin(x))
    plt.plot(x, np.cos(x))

plt.style.use('名前')はそれ以降すべてに、with plt.style.context('名前'):はそのブロックの中だけに適用されます。

個別の設定はplt.rcParamsで変えられます。

plt.rcParams['lines.linewidth'] = 2
plt.rcParams['axes.grid'] = True
plt.rcParams['lines.linewidth']
2.0
🍎 かんたん説明

「全体の見た目」はスタイルシート、「1か所だけ」は引数、というふうに使い分けます。

💻 ミニ練習：スタイル

with文で'seaborn-v0_8'スタイルを一時的に使って、線を1本描くコードを書いてください。

with plt.style.context('seaborn-v0_8'):
    plt.plot([1, 2, 3])

withを抜けると元の設定に戻ります。

②

棒グラフ・円グラフ

bar と pie

カテゴリごとの大きさを比べるには棒グラフ（plt.bar）、割合を見るには円グラフ（plt.pie）です。

cats = ['A', 'B', 'C', 'D']
vals = [23, 17, 35, 29]
fig, ax = plt.subplots()
ax.bar(cats, vals, color='steelblue')
ax.set_ylabel('count')

fig, ax = plt.subplots()
ax.barh(cats, vals, color='tomato')     # 横向き
ax.set_xlabel('count')

fig, ax = plt.subplots(figsize=(4, 4))
ax.pie(vals, labels=cats, autopct='%1.0f%%', startangle=90)
⚠️ 円グラフは、項目が多い・値が近いときには比べにくくなります。迷ったら棒グラフです。
🍎 かんたん説明

大きさの比較は棒、全体の中の割合は円。

💻 ミニ練習：棒グラフ

catsとvalsの棒グラフを描き、y軸ラベルを count にしてください。

ax.bar(cats, vals)
ax.set_ylabel('count')

barにカテゴリと値を渡します。

③

3Dのグラフ

projection='3d'

3次元の図は、projection='3d'を指定して軸を作ります。

fig = plt.figure()
ax = fig.add_subplot(projection='3d')
z = np.linspace(0, 15, 200)
ax.plot3D(np.sin(z), np.cos(z), z, 'gray')
ax.scatter3D(np.sin(z[::10]), np.cos(z[::10]), z[::10], c=z[::10], cmap='viridis')

X, Y = np.meshgrid(np.linspace(-3, 3, 30), np.linspace(-3, 3, 30))
Z = np.sin(np.sqrt(X ** 2 + Y ** 2))
fig = plt.figure()
ax = fig.add_subplot(projection='3d')
ax.plot_surface(X, Y, Z, cmap='viridis')
ax.view_init(elev=40, azim=30)
🍎 かんたん説明

3Dは、見る角度（view_init）で印象が変わります。読み取りやすさのため、使いすぎないのも大事です。

💻 ミニ練習：3D

3D用の軸を作ってください（axに入れる）。

ax = fig.add_subplot(projection='3d')

projectionを指定します。

📖 用語集

style
スタイルシート
見た目の設定をまとめて変える。plt.style.use / context。
rcParams
個別設定
plt.rcParamsで線の太さなどの既定値を変える。
bar / barh
棒グラフ
縦／横の棒グラフ。カテゴリの比較に。
pie
円グラフ
割合を表す。項目が多いと読みにくい。
projection="3d"
3D軸
3次元のグラフを描くための指定。
view_init
視点
3Dグラフの見る角度（elev・azim）を指定する。

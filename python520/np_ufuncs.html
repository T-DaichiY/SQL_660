①

配列まるごと計算する（ベクトル化）

forループを書かない

NumPyでは、配列に対して+や*を書くと、全要素にまとめて計算されます。これをベクトル化と呼びます。

values = np.array([1, 2, 5])

# ループで書くと
out = []
for v in values:
    out.append(1.0 / v)
print(out)

# ベクトル化すると
1.0 / values
[1.0, 0.5, 0.2] array([1. , 0.5, 0.2])

結果は同じですが、2つ目のほうが短く、データが大きいほどはるかに速くなります。計算の中身が、Pythonではなく速いC言語のコードで行われるからです。

🍎 かんたん説明

1人ずつ手でハンコを押すのがforループ。ハンコの列をまとめて押せる大きなスタンプがNumPy。

💻 ミニ練習：まとめて計算

配列 a = np.array([1, 2, 3, 4]) の全要素を2乗した配列を、ループを使わずに作ってください。

a ** 2

**は累乗。配列全体に一度に作用します。

②

ユニバーサル関数（ufunc）

演算子の正体と、よく使う関数

配列にかけられる速い関数をufunc（ユニバーサル関数）と呼びます。実は+などの演算子も、ufuncの別名です。

演算子ufunc
a + bnp.add
a - bnp.subtract
a * bnp.multiply
a / bnp.divide
a // bnp.floor_divide
a ** bnp.power
a % bnp.mod
x = np.arange(4)
print(x + 5)
print(x * 2)
print(x ** 2)
print(-x)
x // 2
[5 6 7 8] [0 2 4 6] [0 1 4 9] [ 0 -1 -2 -3] array([0, 0, 1, 1])

数学の関数も、そのまま配列に使えます。

t = np.array([-2, -1, 0, 1, 2])
print(np.abs(t))
print(np.exp([0, 1, 2]))
np.log([1, 10, 100])
[2 1 0 1 2] [1. 2.71828183 7.3890561 ] array([0. , 2.30258509, 4.60517019])
np.log10([1, 10, 100, 1000])
array([0., 1., 2., 3.])
⚠️ np.logは自然対数（底がe）です。10を底にしたいときはnp.log10、2ならnp.log2です。
💻 ミニ練習：ufunc

配列 t = np.array([-3, 4, -5]) の絶対値を、np.absで求めてください。

np.abs(t)

np.absは各要素の絶対値を返します。

③

集計：合計・最小・最大・平均

sum / min / max / mean / std

配列を1つの数にまとめる関数が集計（aggregate）です。

d = np.array([4, 8, 15, 16, 23, 42])
print(d.sum())
print(d.min(), d.max())
print(d.mean())
print(d.std())
d.argmax()   # 最大値の「位置」
108 4 42 18.0 12.315302134607444 5

np.sum(d)とd.sum()は同じ意味です。Pythonの組み込みsum()より、NumPyのsumのほうが速いので、配列にはこちらを使います。

2次元の配列では、axisで「どの方向に集計するか」を指定します。

m = np.array([[1, 2, 3],
              [4, 5, 6]])
print(m.sum())          # 全体
print(m.sum(axis=0))    # 列ごと（縦方向に潰す）
m.sum(axis=1)           # 行ごと（横方向に潰す）
21 [5 7 9] array([ 6, 15])
📌 axisの覚え方：axis=0は「0番目の軸（行方向）を潰す」ので、結果は列ごとの値になります。axis=1は列方向を潰すので、行ごとの値です。
💻 ミニ練習：列ごとの平均

上の2次元配列 m の列ごとの平均を求めてください。

m.mean(axis=0)

列ごと＝行方向を潰す＝axis=0。結果は[2.5, 3.5, 4.5]です。

④

欠損値（NaN）に注意

nan付きの関数

データに欠損値（np.nan）が混ざると、普通のsumやmeanはnanになってしまいます。

e = np.array([1.0, 2.0, np.nan, 4.0])
print(e.sum())
print(np.nansum(e))
np.nanmean(e)
nan 7.0 2.3333333333333335

nanを無視して計算したいときは、nansum・nanmean・nanmaxのように頭にnanが付く関数を使います。

🍎 かんたん説明

nanは「分からない」。分からない数が混ざった足し算の答えも「分からない」になります。無視してよいならnan付きの関数を。

💻 ミニ練習：nanを無視

配列 e = np.array([2.0, np.nan, 4.0]) の平均を、nanを無視して求めてください。

np.nanmean(e)

結果は3.0です。通常のnp.meanだとnanになります。

📖 用語集

ufunc
ユニバーサル関数
配列の全要素に速く作用する関数。+や*も実体はufunc。
vectorization
ベクトル化
forループを書かず、配列まるごとに計算すること。
aggregate
集計
sum・min・max・mean・stdなど、配列を1つの値にまとめる関数。
axis
軸
集計する方向。axis=0は行方向を潰して列ごとの結果、axis=1は行ごと。
nan
欠損値
数値ではない値。普通の集計に混ざると結果もnanになる。nansum等で無視できる。
argmax
最大値の位置
最大値そのものではなく、そのインデックスを返す。

💡 学習のヒント

axisで迷ったら、「どの軸を潰すか」を考えます。出力の形（shape）を必ず確認しましょう。

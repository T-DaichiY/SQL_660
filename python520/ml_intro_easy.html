①

機械学習の2種類

教師あり・教師なし

🎯 これだけ覚えればOK

正解つきで学ぶのが教師あり（分類・回帰）、正解なしで仲間分けするのが教師なし。

X = np.array([[1.0], [2.0], [3.0]])   # 特徴量：2次元
y = np.array([2.0, 4.0, 6.0])        # 正解：1次元
print(X.shape, y.shape)
(3, 1) (3,)
🍎 ひとことで

Xは「表」、yは「正解の列」。Xは必ず2次元です。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 正解が数値なら？A. 回帰。
Q2. Xの形は？A. [サンプル数, 特徴量数]。
②

fit と predict

5つの手順

🎯 これだけ覚えればOK

モデルを選ぶ → 作る → X,yを整える → fit → predict。どのモデルでも同じ。

from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(X, y)
model.predict([[4.0]])
array([8.])
🍎 ひとことで

fitで覚えさせ、predictで答えさせます。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 学習するメソッドは？A. fit。
Q2. 末尾が _ の属性は？A. fitで学習された結果。

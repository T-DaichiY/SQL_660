📐 NumPy③：ブロードキャスト

形の違う配列を計算する仕組みと、3つのルール、データの中心化を学びます。

①

ブロードキャストとは

形が違う配列でも計算できる

これまでは同じ形の配列どうしを計算してきました。NumPyは、形が違っていても小さいほうを自動で引き伸ばして計算してくれます。これがブロードキャストです。

a = np.array([1, 2, 3])
a + 5        # 数1つが [5, 5, 5] に引き伸ばされる
array([6, 7, 8])
M = np.ones((3, 3))
M + a        # a が3行ぶんに引き伸ばされる
array([[2., 3., 4.], [2., 3., 4.], [2., 3., 4.]])

実際にコピーが作られるわけではなく、「そう見なして」計算します。だからメモリも節約できます。

col = np.arange(3).reshape(3, 1)   # 縦ベクトル
row = np.arange(3)                      # 横ベクトル
col + row                               # 両方が引き伸ばされて 3×3
array([[0, 1, 2], [1, 2, 3], [2, 3, 4]])
🍎 かんたん説明

九九の表のように、縦の列と横の行を組み合わせて、一気に表を作れます。

💻 ミニ練習：九九の表

np.arange(1, 4) を縦ベクトルと横ベクトルにして掛け合わせ、3×3の掛け算表を作ってください。

r.reshape(3, 1) * r

縦（3×1）と横（3,）を掛けると3×3になります。結果は[[1,2,3],[2,4,6],[3,6,9]]。

②

3つのルール

右から揃えて、1か同じなら通る

ブロードキャストが成立するかは、次の3つのルールで決まります。

  1. 次元の数が違うときは、少ないほうの左側に1を足して次元数を揃える。
  2. ある次元の大きさが1なら、もう片方の大きさに引き伸ばす。
  3. どちらの大きさも1でなく、かつ違う値ならエラー。
📌 形を右端から比べて、各位置で「同じ」か「どちらかが1」ならOK、と覚えると速く判断できます。
M = np.ones((3, 3))
print(M.shape, np.arange(3).shape)   # (3, 3) と (3,)
(M + np.arange(3)).shape         # (3,) は (1, 3) とみなされ、行方向に引き伸ばされる
(3, 3) (3,) (3, 3)
A = np.ones((3, 2))
B = np.arange(3)
A.shape, B.shape
((3, 2), (3,))
np.ones((3, 2)) + np.arange(3)
ValueError: operands could not be broadcast together with shapes (3,2) (3,)

この失敗は、右端の2と3が「同じでも1でもない」からです。np.newaxis（またはreshape）で縦ベクトルにすれば通ります。

(np.ones((3, 2)) + np.arange(3)[:, np.newaxis]).shape
(3, 2)
⚠️ 形のエラーはValueError: operands could not be broadcast togetherと出ます。まず.shapeを印字して、右端から見比べましょう。
💻 ミニ練習：形を判断

形 (4, 1) の配列と、形 (3,) の配列を足すと、結果の形は何になりますか？ 実際にnp.onesで作って.shapeを確かめるコードを書いてください。

(np.ones((4, 1)) + np.ones(3)).shape   # (4, 3)

右端：1と3 → 3。次：4と（補われた1）→ 4。結果は(4, 3)です。

③

使いどころ：データのセンタリング

列ごとの平均を引く

ブロードキャストの代表的な使い方は、各列からその列の平均を引く（中心化）です。統計や機械学習の前処理でよく使います。

np.random.seed(0)
X = np.random.randint(0, 10, size=(4, 3))
print(X)
mean = X.mean(axis=0)     # 形(3,)  列ごとの平均
print(mean)
X - mean                  # 形(4,3) - 形(3,) → 各行から引かれる
[[5 0 3] [3 7 9] [3 5 2] [4 7 6]] [3.75 4.75 5. ] array([[ 1.25, -4.75, -2. ], [-0.75, 2.25, 4. ], [-0.75, 0.25, -3. ], [ 0.25, 2.25, 1. ]])
(X - mean).mean(axis=0)    # 中心化後の列ごとの平均は 0
array([0., 0., 0.])

行ごとに引きたいときは、keepdims=Trueで形を保つと、ブロードキャストの形が揃います。

row_mean = X.mean(axis=1, keepdims=True)   # 形(4,1)
X - row_mean
array([[ 2.33333333, -2.66666667, 0.33333333], [-3.33333333, 0.66666667, 2.66666667], [-0.33333333, 1.66666667, -1.33333333], [-1.66666667, 1.33333333, 0.33333333]])
🍎 かんたん説明

平均を引いたあとは、データの「真ん中」が0になります。値の大小を比べやすくするための下ごしらえです。

💻 ミニ練習：行ごとの中心化

配列 X の各行から、その行の平均を引いた配列を作ってください。

X - X.mean(axis=1, keepdims=True)

keepdims=Trueで平均の形が(2, 1)になり、各行に正しく引かれます。

📖 用語集

broadcasting
ブロードキャスト
形の違う配列を、小さいほうを自動で引き伸ばして計算する仕組み。
newaxis
軸の追加
x[:, np.newaxis]のように、大きさ1の軸を足して縦ベクトルなどにする。
keepdims
次元を保つ
集計のあとも、潰した軸を大きさ1で残す。ブロードキャストの形が揃う。
centering
中心化
各列から平均を引いて、平均を0にする前処理。
ValueError
形のエラー
形が合わないときのエラー。.shapeを右端から比べて原因を探す。
stretch
引き伸ばし
コピーではなく、同じ値を繰り返したように見なして計算する。

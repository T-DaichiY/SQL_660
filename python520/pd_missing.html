🕳️ Pandas④：欠損値

NaNの意味、isnull、dropna、fillnaを学びます。

①

欠損値とは

NaN と None

実データには値が入っていない箇所がよくあります（欠損値）。Pandasでは、数値の欠損はNaN、文字列などの欠損はNoneやNaNで表されます。

vals = pd.Series([1, np.nan, 3, None])
vals
0 1.0 1 NaN 2 3.0 3 NaN dtype: float64

数値の列にNoneを入れると、自動でNaNに変換され、型はfloat64になります（整数のまま欠損を持てないため）。

⚠️ NaNを含む計算の結果はNaNです。ただし、Pandasのsum・meanはデフォルトでNaNを無視して計算します（NumPyとは違う点）。
print(vals.sum())
print(vals.mean())
np.nan + 1
4.0 2.0 nan
🍎 かんたん説明

欠損値は「空欄」。足し算に空欄が混ざると答えも不明になりますが、Pandasの集計は空欄を飛ばして計算してくれます。

💻 ミニ練習：欠損を含むSeries

値 1, 2, NaN の Series を作り、s に入れてください。

s = pd.Series([1, 2, np.nan])

np.nanが欠損値です。

②

見つける：isnull / notnull

欠損の数を数える

欠損かどうかは、isnull()（またはisna()）とnotnull()で判定します。結果はTrue/Falseです。

df = pd.DataFrame({'a': [1, np.nan, 3, 4], 'b': [np.nan, 2, 3, 4], 'c': [1, 2, np.nan, np.nan]})

df.isnull()
a b c 0 False True False 1 True False False 2 False False True 3 False False True
print(df.isnull().sum())          # 列ごとの欠損数
df.isnull().sum().sum()        # 全体の欠損数
a 1 b 1 c 2 dtype: int64 4
df[df["a"].notnull()]          # a列が欠損でない行だけ
a b c 0 1.0 NaN 1.0 2 3.0 3.0 NaN 3 4.0 4.0 NaN
🍎 かんたん説明

isnull().sum()は、「各列に空欄がいくつあるか」を数える定番のコードです。

💻 ミニ練習：欠損の数

dfの列ごとの欠損数を求めてください。

df.isnull().sum()

isnull()でTrue/Falseにし、sum()で列ごとのTrueの個数を数えます。

③

取り除く：dropna

行ごと・列ごと

dropna()は、欠損のある行を取り除きます（元のdfは変わらず、新しいDataFrameが返ります）。

df.dropna()
Empty DataFrame Columns: [a, b, c] Index: []
df.dropna(axis=1)           # 欠損のある「列」を取り除く
Empty DataFrame Columns: [] Index: [0, 1, 2, 3]
df.dropna(how="all")        # すべてが欠損の行だけ除く
a b c 0 1.0 NaN 1.0 1 NaN 2.0 2.0 2 3.0 3.0 NaN 3 4.0 4.0 NaN
df.dropna(thresh=2)         # 欠損でない値が2個以上ある行だけ残す
a b c 0 1.0 NaN 1.0 1 NaN 2.0 2.0 2 3.0 3.0 NaN 3 4.0 4.0 NaN
⚠️ dropna()は初期設定で1つでも欠損がある行を丸ごと消します。データが大幅に減ることがあるので、減った行数を確認しましょう。
🍎 かんたん説明

how='all'は「全部空欄なら消す」、thresh=nは「n個以上埋まっていれば残す」。

💻 ミニ練習：dropna

dfから、欠損でない値が2個以上ある行だけを残してください。

df.dropna(thresh=2)

threshは「残すために必要な欠損でない値の数」です。

④

埋める：fillna

値・直前の値・直後の値

fillnaは欠損を別の値で埋めます。

df.fillna(0)
a b c 0 1.0 0.0 1.0 1 0.0 2.0 2.0 2 3.0 3.0 0.0 3 4.0 4.0 0.0
df.fillna(df.mean())      # 列ごとの平均で埋める
a b c 0 1.000000 3.0 1.0 1 2.666667 2.0 2.0 2 3.000000 3.0 1.5 3 4.000000 4.0 1.5
s = pd.Series([1, np.nan, 2, None, 3], index=list('abcde'))
print(s.ffill())    # 直前の値で埋める
s.bfill()           # 直後の値で埋める
a 1.0 b 1.0 c 2.0 d 2.0 e 3.0 dtype: float64 a 1.0 b 2.0 c 2.0 d 3.0 e 3.0 dtype: float64
⚠️ 欠損をどう処理するかで分析結果が変わります。0で埋めるのが正しいとは限りません（例：気温が欠損のとき0℃とは限らない）。意味を考えて選びましょう。
🍎 かんたん説明

ffillは「前の値をそのまま持ち越す」、bfillは「次の値を前に持ってくる」。

💻 ミニ練習：fillna

dfの欠損を、列ごとの平均で埋めてください。

df.fillna(df.mean())

df.mean()は列ごとの平均で、列名が対応する欠損を埋めます。

📖 用語集

NaN
欠損値
数値の欠けた値。入ると列の型はfloat64になる。
isnull / notnull
欠損の判定
欠損ならTrue（isnull）／欠損でないならTrue（notnull）。
dropna
欠損を除く
欠損のある行（や列）を取り除く。how・thresh・axisで調整。
fillna
欠損を埋める
指定した値や平均などで埋める。
ffill / bfill
前／後ろの値で埋める
直前の値を持ち越す／直後の値を前に持ってくる。
thresh
しきい値
残すために必要な、欠損でない値の最小数。

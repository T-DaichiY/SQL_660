①

間違ったやり方と、ホールドアウト法

学習に使ったデータで評価してはいけない

モデルを学習に使ったデータそのもので評価すると、点数が不当に高くなります。最近傍法（1-NN）は訓練データを丸暗記するので、その極端な例です。

from sklearn.datasets import load_iris
from sklearn.neighbors import KNeighborsClassifier
from sklearn.metrics import accuracy_score
iris = load_iris()
X, y = iris.data, iris.target

model = KNeighborsClassifier(n_neighbors=1).fit(X, y)
print(accuracy_score(y, model.predict(X)))   # 同じデータで評価
1.0

正解率100%…ですが、これは答えを見ながらテストを受けたようなものです。そこで、データを2つに分けるのがホールドアウト法です。

from sklearn.model_selection import train_test_split
Xtr, Xte, ytr, yte = train_test_split(X, y, random_state=0, train_size=0.5)
model.fit(Xtr, ytr)
print(Xtr.shape, Xte.shape)
print(accuracy_score(yte, model.predict(Xte)))
(75, 4) (75, 4) 0.9066666666666666
🍎 かんたん説明

「勉強に使った問題」ではなく「初めて見る問題」で点数をつける。それがテスト用データです。

💻 ミニ練習：分割

X, y を7:3に分けて（テスト用が30%）、random_state=0 で Xtr, Xte, ytr, yte に入れてください。

Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=0)

test_sizeかtrain_sizeのどちらかを指定します。

②

交差検証：cross_val_score

分け方に左右されない評価

1回の分割だと、たまたまの偶然に左右されます。交差検証は、データをk個に分け、順番にテスト役を交代して、k回の点数を平均します。

from sklearn.datasets import load_iris
from sklearn.neighbors import KNeighborsClassifier
iris = load_iris()
X, y = iris.data, iris.target

from sklearn.model_selection import cross_val_score
model = KNeighborsClassifier(n_neighbors=1)
scores = cross_val_score(model, X, y, cv=5)
print(scores)
print(scores.mean().round(3))
[0.96666667 0.96666667 0.93333333 0.93333333 1. ] 0.96

5回の点数のばらつきも見えます。平均を代表値にします。

🍎 かんたん説明

5分割なら、「5回テスト」して平均。どのデータも1回ずつテスト役になります。

💻 ミニ練習：5分割で平均

KNeighborsClassifier(n_neighbors=3) を5分割の交差検証で評価し、点数の平均を m に入れてください。

m = cross_val_score(KNeighborsClassifier(n_neighbors=3), X, y, cv=5).mean()

約0.967です。

③

過学習と未学習

モデルの複雑さを動かして見る

モデルが単純すぎると未学習（高バイアス）、複雑すぎて訓練データのノイズまで覚えると過学習（高バリアンス）になります。多項式の次数を動かして、訓練点数と検証点数を並べてみましょう。

from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import validation_curve

rng = np.random.RandomState(1)
Xd = rng.rand(40, 1) * 6 - 3
yd = np.sin(Xd).ravel() + 0.3 * rng.randn(40)

model = make_pipeline(PolynomialFeatures(), LinearRegression())
degree = np.arange(0, 16)
train, val = validation_curve(model, Xd, yd, param_name='polynomialfeatures__degree', param_range=degree, cv=5)
plt.plot(degree, train.mean(axis=1), label='training')
plt.plot(degree, val.mean(axis=1), label='validation')
plt.ylim(-1, 1)
plt.xlabel('degree')
plt.ylabel('R^2 score')
plt.legend()

訓練の点数は次数とともに上がり続けますが、検証の点数はある次数でピークになり、その後下がります。このピークがちょうどよい複雑さです。

🍎 かんたん説明

訓練点数だけ高い→過学習、両方低い→未学習。検証点数で選びます。

📈 学習曲線（learning curve）：訓練データの量を増やしたときの点数の変化を見る方法です。データを増やせば良くなるのか、モデルを変えるべきかの判断材料になります。
from sklearn.model_selection import learning_curve
sizes, tr, va = learning_curve(make_pipeline(PolynomialFeatures(3), LinearRegression()), Xd, yd, cv=5, train_sizes=[0.3, 0.6, 1.0])
print(sizes)
[ 9 19 32]
💻 ミニ練習：過学習の判定

訓練点数が 0.99、検証点数が 0.55 のとき、過学習か未学習か。変数 state に "overfitting" か "underfitting" を入れてください。

state = "overfitting"

訓練だけ高いので過学習です。

④

グリッドサーチ：GridSearchCV

最良の組み合わせを自動で探す

ハイパーパラメータの候補を全部の組み合わせで試し、交差検証で一番良いものを選ぶ道具がGridSearchCVです。

from sklearn.model_selection import GridSearchCV
param_grid = {'polynomialfeatures__degree': np.arange(0, 9),
              'linearregression__fit_intercept': [True, False]}
grid = GridSearchCV(make_pipeline(PolynomialFeatures(), LinearRegression()), param_grid, cv=5)
grid.fit(Xd, yd)
print(grid.best_params_)
{'linearregression__fit_intercept': False, 'polynomialfeatures__degree': 3}

最良のモデルで予測するにはgrid.best_estimator_を使います。

best = grid.best_estimator_
print(best.predict([[0.0]]).round(3))
[-0.006]
🍎 かんたん説明

「次数は0〜8、切片あり／なし」の全パターンを交差検証して、一番良い設定を教えてくれます。

💻 ミニ練習：候補の辞書

KNNの n_neighbors を 1, 3, 5 で試すための param_grid 辞書を作ってください。

param_grid = {'n_neighbors': [1, 3, 5]}

キーはパラメータ名、値は候補のリストです。

📖 用語集

Hold-out set
ホールドアウト
学習に使わず取っておく、評価専用のデータ。
Cross-validation
交差検証
テスト役を交代しながら複数回評価して平均する方法。
Overfitting
過学習
訓練データに合わせすぎて、新データで性能が落ちる。
Underfitting
未学習
モデルが単純すぎて、訓練データにも合わない。
Validation curve
検証曲線
1つのハイパーパラメータを動かしたときの点数のグラフ。
GridSearchCV
グリッドサーチ

①

つなぐ：concat

縦・横

🎯 これだけ覚えればOK

pd.concat([df1, df2])は縦につなぐ。axis=1で横に。

df1 = pd.DataFrame({'A': [1, 2]})
df2 = pd.DataFrame({'A': [3, 4]})
pd.concat([df1, df2], ignore_index=True)
A 0 1 1 2 2 3 3 4
🍎 ひとことで

ignore_index=Trueで索引を振り直します。

②

結びつける：merge

SQLのJOIN

🎯 これだけ覚えればOK

pd.mergeは共通の列が同じ行を結びつける。howで残す行を選ぶ。

a = pd.DataFrame({'name': ['Peter', 'Mary'], 'food': ['fish', 'bread']})
b = pd.DataFrame({'name': ['Mary', 'Joe'], 'drink': ['wine', 'beer']})
print(pd.merge(a, b))
pd.merge(a, b, how='outer')
name food drink 0 Mary bread wine name food drink 0 Joe NaN beer 1 Mary bread wine 2 Peter fish NaN
🍎 ひとことで

inner＝両方にある、outer＝どちらかにある、left/right＝片側を全部。

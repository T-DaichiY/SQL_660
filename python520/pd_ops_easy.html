計算はラベルが同じ者どうし。片方にしかないラベルはNaN。

a = pd.Series([1, 2], index=[0, 1])
b = pd.Series([10, 20], index=[1, 2])
print(a + b)
a.add(b, fill_value=0)
0 NaN 1 12.0 2 NaN dtype: float64 0 1.0 1 12.0 2 20.0 dtype: float64
🍎 ひとことで

NaNにしたくないときはadd(…, fill_value=0)。

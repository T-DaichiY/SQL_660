並べ替える：sort と argsort

元の配列は変えない？変える？

配列を小さい順に並べるにはnp.sortを使います。元の配列は変わらず、並べ替えた新しい配列が返ります。

x = np.array([2, 1, 4, 3, 5])
print(np.sort(x))
x          # 元はそのまま
[1 2 3 4 5] array([2, 1, 4, 3, 5])

配列自身を並べ替えたいときは、メソッドx.sort()です（その場で変更）。

x.sort()
x
array([1, 2, 3, 4, 5])

np.argsortは、並べ替えたあとの順番を表す「位置」を返します。「何番目の要素が一番小さいか」を知りたいときに使います。

y = np.array([2, 1, 4, 3, 5])
i = np.argsort(y)
print(i)
y[i]       # この位置で取り出すと並べ替え済み
[1 0 3 2 4] array([1, 2, 3, 4, 5])
🍎 かんたん説明

sortは「並べ替えた結果」、argsortは「並べ替えるための番号」。番号があれば、別の配列も同じ順に並べ替えられます。

💻 ミニ練習：argsort

配列 y = np.array([30, 10, 20]) を小さい順に並べたときの「位置」の配列を求めてください。

np.argsort(y)   # array([1, 2, 0])

10は位置1、20は位置2、30は位置0にあるので[1, 2, 0]です。

②

行・列ごとに並べ替える

axis で方向を指定

2次元配列では、axisで「どの方向に」並べ替えるかを選びます。

np.random.seed(42)
R = np.random.randint(0, 10, (3, 4))
print(R)
print(np.sort(R, axis=0))   # 各列を縦に並べ替え
np.sort(R, axis=1)          # 各行を横に並べ替え
[[6 3 7 4] [6 9 2 6] [7 4 3 7]] [[6 3 2 4] [6 4 3 6] [7 9 7 7]] array([[3, 4, 6, 7], [2, 6, 6, 9], [3, 4, 7, 7]])
⚠️ 行どうしの関係は崩れます。axis=1で各行を別々に並べ替えると、元の「行の組み合わせ」は保たれません。

「小さいほうからk個だけ」知りたいときはnp.partitionが速いです（順序は保証されません）。

z = np.array([7, 2, 3, 1, 6, 5, 4])
np.partition(z, 3)    # 小さい3個が左側に集まる（左側内の順序は不定）
array([2, 1, 3, 4, 6, 5, 7])
💻 ミニ練習：行ごとに並べ替え

2次元配列 R の各行を小さい順に並べ替えてください。

np.sort(R, axis=1)

各行を横方向に並べ替えるのでaxis=1です。

③

構造化配列（名前付きの列を持つ配列）

Pandasにつながる考え方

NumPyの普通の配列は1種類の型しか持てません。構造化配列は、名前と型が違う列を1つの配列に持てます。表のようなデータが扱えます。

data = np.zeros(3, dtype={'names': ('name', 'age', 'weight'),
                              'formats': ('U10', 'i4', 'f8')})
print(data.dtype)
data['name'] = ['Alice', 'Bob', 'Cathy']
data['age'] = [25, 45, 37]
data['weight'] = [55.0, 85.5, 68.0]
data
[('name', '<U10'), ('age', '<i4'), ('weight', '<f8')] array([('Alice', 25, 55. ), ('Bob', 45, 85.5), ('Cathy', 37, 68. )], dtype=[('name', '<U10'), ('age', '<i4'), ('weight', '<f8')])
print(data['name'])
print(data[0])
data[data['age'] < 40]['name']
['Alice' 'Bob' 'Cathy'] ('Alice', 25, 55.) array(['Alice', 'Cathy'], dtype='<U10')

名前で列を取り出し、条件で行を選べます。これはPandasのデータフレームとよく似ています。実際の分析ではPandasのほうが便利で、構造化配列は「Pandasの原型」として知っておけば十分です。

📌 型コード：U10＝最大10文字の文字列、i4＝4バイト整数、f8＝8バイト小数。
🍎 かんたん説明

構造化配列は「列に名前と型を付けられる配列」。次の章のPandasがそれをもっと使いやすくしたものです。

💻 ミニ練習：構造化配列

dataからage列だけを取り出してください。

data['age']

列名を文字列で指定して取り出します。

📖 用語集

np.sort
並べ替え
並べ替えたコピーを返す。元は変わらない。x.sort()はその場で変更。
argsort
並べ替えの位置
並べ替えたときの順番を表すインデックスを返す。
partition
部分的な並べ替え
k個の小さい値を左に集める。完全な並べ替えより速い。
structured array
構造化配列
名前と型を持つ列からなる配列。Pandasの原型。
dtype names/formats
型の定義
{'names': …, 'formats': …}で列名と型を指定する。
axis
軸
axis=0は列ごと、axis=1は行ごとに処理する。

💡 学習のヒント

sortは「コピーを返す」、x.sort()は「その場で並べ替える」。

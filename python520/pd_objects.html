①

Series：名前付きの1列

値（values）と索引（index）

PandasのSeriesは、「値」と「それに付けた名札（インデックス）」がセットになった1次元のデータです。NumPy配列との違いは、位置の番号ではなく自分で決めたラベルでも取り出せる点です。

import pandas as pd

data = pd.Series([0.25, 0.5, 0.75, 1.0])
data
0 0.25 1 0.50 2 0.75 3 1.00 dtype: float64
print(data.values)    # 中身はNumPy配列
print(data.index)     # 0, 1, 2, 3 の連番
[0.25 0.5 0.75 1. ] RangeIndex(start=0, stop=4, step=1)

インデックスは自分で決められます。辞書から作ると、キーがインデックスになります。

pop = pd.Series({'California': 39.5, 'Texas': 29.1, 'New York': 20.2})
print(pop)
pop['Texas']
California 39.5 Texas 29.1 New York 20.2 dtype: float64 29.1
🍎 かんたん説明

Seriesは「名札付きのNumPy配列」。名札で取り出せるので、位置を覚えなくて済みます。

💻 ミニ練習：Seriesを作る

果物の価格 apple: 120, banana: 80, orange: 100 を、辞書から Series にして変数 price に入れてください。

price = pd.Series({'apple': 120, 'banana': 80, 'orange': 100})

辞書のキーが索引、値がデータになります。

②

DataFrame：表

列ごとに型があり、行・列に名前がある

DataFrameは、Excelの表のような2次元データです。各列がSeriesで、同じ行ラベル（インデックス）を共有します。

area = pd.Series({'California': 424, 'Texas': 696, 'New York': 141})
pop = pd.Series({'California': 39.5, 'Texas': 29.1, 'New York': 20.2})
states = pd.DataFrame({'population': pop, 'area': area})
states
population area California 39.5 424 Texas 29.1 696 New York 20.2 141
print(states.index)
print(states.columns)
print(states.shape)
states.dtypes
Index(['California', 'Texas', 'New York'], dtype='object') Index(['population', 'area'], dtype='object') (3, 2) population float64 area int64 dtype: object

辞書のリスト（1行＝1つの辞書）や、NumPy配列＋列名からも作れます。

pd.DataFrame([{'a': 1, 'b': 2}, {'b': 3, 'c': 4}])    # 無い所は NaN
a b c 0 1.0 2 NaN 1 NaN 3 4.0
pd.DataFrame(np.arange(6).reshape(3, 2), columns=['foo', 'bar'], index=['a', 'b', 'c'])
foo bar a 0 1 b 2 3 c 4 5
🍎 かんたん説明

DataFrameは「同じ行ラベルを共有するSeriesの束」。列はキーで、行はラベルや位置で取り出します。

💻 ミニ練習：DataFrameを作る

name列（Ann, Bob）とscore列（80, 90）の DataFrame を辞書から作り、df に入れてください。

df = pd.DataFrame({'name': ['Ann', 'Bob'], 'score': [80, 90]})

辞書のキーが列名になります。

④

Index：変更できない名札

集合のように使える

インデックスは変更できない（immutable）配列で、集合の演算もできます。

a = pd.Index([1, 3, 5, 7, 9])
b = pd.Index([2, 3, 5, 7, 11])
print(a.intersection(b))
print(a.union(b))
a.symmetric_difference(b)
Index([3, 5, 7], dtype='int64') Index([1, 2, 3, 5, 7, 9, 11], dtype='int64') Index([1, 2, 9, 11], dtype='int64')
a[1] = 0
TypeError: Index does not support mutable operations
🍎 かんたん説明

名札の途中を書き換えられないのは、データと名札がずれる事故を防ぐためです。

💻 ミニ練習：共通の索引

aとbの共通部分を求めてください。

a.intersection(b)

結果は[2, 3]。

📖 用語集

Series
シリーズ
索引（index）付きの1次元データ。DataFrameの1列。
DataFrame
データフレーム
行ラベルを共有するSeriesの束。表形式のデータ。
Index
索引
行（や列）の名札。変更できない。集合演算ができる。
read_csv
CSV読み込み
CSVファイルをDataFrameに読み込む。
head / info / describe
眺める3点セット
先頭の行／型と欠損の概要／数値列の要約統計。

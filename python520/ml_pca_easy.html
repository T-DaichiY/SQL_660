①

一番ばらつく向き

PCA

🎯 これだけ覚えればOK

データが一番ばらつく向き（主成分）を見つけ、そこへ圧縮する。

from sklearn.decomposition import PCA
x = np.array([[1, 2], [2, 4.1], [3, 5.9], [4, 8.2]])
p = PCA(1).fit(x)
print(p.explained_variance_ratio_.round(3))
[1.]
🍎 ひとことで

寄与率が1に近いほど、1次元でほぼ表せるということです。

成分の数

累積寄与率

🎯 これだけ覚えればOK

累積寄与率が90%などになる最小の個数を選ぶ。

from sklearn.datasets import load_digits
d = load_digits()
PCA(0.9).fit(d.data).n_components_
21
🍎 ひとことで

64次元が約20次元で、情報の9割を保てます。

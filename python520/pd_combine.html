①

縦に・横につなぐ：concat

pd.concat

pd.concatは、複数のSeriesやDataFrameをつなげる関数です。初期設定では縦（行を追加）につなぎます。

df1 = pd.DataFrame({'A': ['A1', 'A2'], 'B': ['B1', 'B2']}, index=[1, 2])
df2 = pd.DataFrame({'A': ['A3', 'A4'], 'B': ['B3', 'B4']}, index=[3, 4])

pd.concat([df1, df2])
A B 1 A1 B1 2 A2 B2 3 A3 B3 4 A4 B4
pd.concat([df1, df2], ignore_index=True)    # 索引を振り直す
A B 0 A1 B1 1 A2 B2 2 A3 B3 3 A4 B4

索引がかぶっていても、そのままつながります（重複した索引になる点に注意）。振り直すにはignore_index=Trueです。

df3 = pd.DataFrame({'C': ['C1', 'C2']}, index=[1, 2])
pd.concat([df1, df3], axis=1)    # 横につなぐ（索引でそろう）
A B C 1 A1 B1 C1 2 A2 B2 C2
df4 = pd.DataFrame({'A': ['A9'], 'C': ['C9']})
print(pd.concat([df1, df4]))                # 無い列はNaN（outer）
pd.concat([df1, df4], join='inner')           # 共通の列だけ
A B C 1 A1 B1 NaN 2 A2 B2 NaN 0 A9 NaN C9 A 1 A1 2 A2 0 A9
🍎 かんたん説明

concatは「積み木を縦または横に積む」道具。列や索引がそろわない部分はNaNで埋まります。

💻 ミニ練習：縦に連結

df1とdf2を縦につなぎ、索引を0から振り直してください。

pd.concat([df1, df2], ignore_index=True)

ignore_indexで連番になります。

②

共通の列で結びつける：merge

データベースのJOINと同じ

pd.mergeは、共通の列（キー）の値が同じ行どうしを結びつけます。SQLのJOINとほぼ同じです。

emp = pd.DataFrame({'employee': ['Bob', 'Jake', 'Lisa', 'Sue'], 'group': ['Accounting', 'Engineering', 'Engineering', 'HR']})
hired = pd.DataFrame({'employee': ['Lisa', 'Bob', 'Jake', 'Sue'], 'hire_date': [2004, 2008, 2012, 2014]})

df3 = pd.merge(emp, hired)    # 共通の列 employee が自動でキーになる
df3
employee group hire_date 0 Bob Accounting 2008 1 Jake Engineering 2012 2 Lisa Engineering 2004 3 Sue HR 2014

キーの値が重複している場合（多対一）は、片側の値が複製されてつきます。

boss = pd.DataFrame({'group': ['Accounting', 'Engineering', 'HR'], 'supervisor': ['Carly', 'Guido', 'Steve']})
pd.merge(df3, boss)
employee group hire_date supervisor 0 Bob Accounting 2008 Carly 1 Jake Engineering 2012 Guido 2 Lisa Engineering 2004 Guido 3 Sue HR 2014 Steve

キーの列名が違うときはleft_on・right_onで指定します。

salary = pd.DataFrame({'name': ['Bob', 'Jake', 'Lisa', 'Sue'], 'salary': [70000, 80000, 120000, 90000]})
pd.merge(emp, salary, left_on='employee', right_on='name').drop('name', axis=1)
employee group salary 0 Bob Accounting 70000 1 Jake Engineering 80000 2 Lisa Engineering 120000 3 Sue HR 90000
🍎 かんたん説明

名簿AとBを「名前」でつなぎ合わせて、1枚の表にする作業です。

💻 ミニ練習：merge

empとhiredを、共通の列で結びつけてください。

pd.merge(emp, hired, on='employee')

on='employee'とキーを明示するのが安全です。

③

どの行を残す？：how

inner / outer / left / right

片方にしかないキーがあるとき、どの行を残すかをhowで決めます。

a = pd.DataFrame({'name': ['Peter', 'Paul', 'Mary'], 'food': ['fish', 'beans', 'bread']})
b = pd.DataFrame({'name': ['Mary', 'Joseph'], 'drink': ['wine', 'beer']})

pd.merge(a, b)                    # 初期設定 inner：両方にあるキーだけ
name food drink 0 Mary bread wine
pd.merge(a, b, how='outer')       # どちらかにあれば残す（無い所はNaN）
name food drink 0 Joseph NaN beer 1 Mary bread wine 2 Paul beans NaN 3 Peter fish NaN
pd.merge(a, b, how='left')        # 左（a）の行は全部残す
name food drink 0 Peter fish NaN 1 Paul beans NaN 2 Mary bread wine
pd.merge(a, b, how='right')       # 右（b）の行は全部残す
name food drink 0 Mary bread wine 1 Joseph NaN beer
how残る行
inner（初期）両方にあるキー
outerどちらかにあるキー
left左のキー全部
right右のキー全部
🍎 かんたん説明

SQLの INNER / FULL OUTER / LEFT / RIGHT JOIN と1対1で対応します。

💻 ミニ練習：left

aの行をすべて残して、bを結びつけてください。

pd.merge(a, b, how='left')

Peter、Paulの drink は NaN になります。

④

列名がかぶったとき・join

suffixes と DataFrame.join

キー以外に同じ名前の列があると、_x・_yが付きます。suffixesで分かりやすい名前にできます。

l = pd.DataFrame({'name': ['Bob', 'Jake'], 'rank': [1, 2]})
r = pd.DataFrame({'name': ['Bob', 'Jake'], 'rank': [3, 1]})
pd.merge(l, r, on='name', suffixes=['_L', '_R'])
name rank_L rank_R 0 Bob 1 3 1 Jake 2 1

索引どうしで結びつけるなら、joinが簡単です。

l2 = l.set_index('name')
r2 = r.set_index('name')
l2.join(r2, lsuffix='_L', rsuffix='_R')
rank_L rank_R name Bob 1 3 Jake 2 1
🍎 かんたん説明

キーを列で結びつけるならmerge、索引で結びつけるならjoin。

💻 ミニ練習：suffixes

同名の列 rank に _L・_R を付けて name でmergeしてください。

pd.merge(l, r, on='name', suffixes=['_L', '_R'])

列は rank_L と rank_R になります。

📖 用語集

concat
連結
複数のDataFrameを縦（axis=0）または横（axis=1）につなぐ。
merge
結合
共通の列（キー）の値が同じ行どうしを結びつける。SQLのJOIN。
how
結合の種類
inner／outer／left／right。残す行が変わる。
left_on / right_on
キーの指定
左右でキーの列名が違うときに使う。
suffixes
接尾辞
同名の列に付ける目印（例：_L、_R）。
join
索引で結合
索引どうしを結びつける、mergeの簡易版。

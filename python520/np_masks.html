①

比較演算は、真偽の配列を作る

< > == != と、数え方

配列に比較演算子を使うと、各要素のTrue/Falseの配列が返ります。

x = np.array([1, 2, 3, 4, 5])
x < 3
array([ True, True, False, False, False])
print(x == 3)
print(x != 3)
print(x >= 4)
[False False True False False] [ True True False True True] [False False False True True]

この真偽の配列は、数えたり調べたりできます。Trueは1、Falseは0として扱われます。

print(np.sum(x < 4))         # 4未満の個数
print(np.count_nonzero(x < 4))
print(np.any(x > 4))       # 1つでもTrue?
np.all(x > 0)              # 全部True?
3 3 True True
m = np.array([[1, 5, 2], [7, 3, 9]])
np.sum(m > 2, axis=1)     # 行ごとに「2より大きい」の個数
array([1, 3])
🍎 かんたん説明

「条件に合うものは何個?」は、np.sum(条件)で一発。TrueがそのまんまNの個数になります。

💻 ミニ練習：個数を数える

配列 x = np.array([3, 8, 1, 9, 5]) のうち、5より大きい要素の個数を求めてください。

np.sum(x > 5)

8と9で2個です。

②

マスクで取り出す・複数条件

x[x < 3]、& | ~

真偽の配列を[ ]に入れると、Trueの位置の値だけが取り出せます。この真偽の配列をマスクと呼びます。

x = np.array([1, 2, 3, 4, 5])
mask = x > 2
print(mask)
x[mask]            # 2より大きいものだけ
[False False True True True] array([3, 4, 5])
x[x % 2 == 0]       # 偶数だけ
array([2, 4])

複数の条件は、andやorではなく、&（かつ）、|（または）、~（否定）を使い、各条件を括弧で囲みます。

x[(x > 1) & (x < 5)]     # 1より大きく5未満
array([2, 3, 4])
x[(x < 2) | (x > 4)]     # 2未満 または 4より大きい
array([1, 5])
x[~(x > 2)]              # 2より大きく「ない」もの
array([1, 2])
⚠️ x[x > 1 and x < 5]はエラーになります（ValueError: The truth value of an array...）。配列の要素ごとの判定には&・|を使い、括弧を忘れないこと。

マスクで値を書き換えることもできます。

y = np.array([5, -3, 8, -1])
y[y < 0] = 0       # 負の値を0に
y
array([5, 0, 8, 0])
💻 ミニ練習：複数条件

配列 x = np.arange(10) から、3以上かつ7以下の要素を取り出してください。

x[(x >= 3) & (x <= 7)]

結果は[3, 4, 5, 6, 7]。andではなく&、括弧が必要です。

③

ファンシーインデックス

位置のリストで取り出す

インデックスに位置のリスト（配列）を渡すと、好きな順番で・好きな要素を取り出せます。これがファンシーインデックスです。

x = np.array([51, 92, 14, 71, 60, 20])
x[[0, 3, 4]]
array([51, 71, 60])
ind = np.array([[3, 7], [4, 5]])
z = np.arange(10, 20)
z[ind]      # 結果の形は、インデックスの形
array([[13, 17], [14, 15]])

2次元では、行のリストと列のリストを組み合わせて(行, 列)のペアを取り出します。

X = np.arange(12).reshape(3, 4)
row = np.array([0, 1, 2])
col = np.array([2, 1, 3])
X[row, col]      # (0,2), (1,1), (2,3) の3点
array([ 2, 5, 11])
X[2, [2, 0, 1]]     # 単純なインデックスと組み合わせる
array([10, 8, 9])

代入にも使えます。

w = np.arange(10)
w[[2, 4, 6]] = 99
w
array([ 0, 1, 99, 3, 99, 5, 99, 7, 8, 9])
⚠️ スライスはビューですが、ファンシーインデックスはコピーを返します（元の配列とは別物）。
📌 マスク（真偽）とファンシー（位置）の違い：マスクは「条件に合うものを選ぶ」、ファンシーは「番地を指定して選ぶ」。
💻 ミニ練習：番地を指定

配列 x = np.array([10, 20, 30, 40, 50]) から、位置 4, 0, 2 の要素をこの順番で取り出してください。

x[[4, 0, 2]]

結果は[50, 10, 30]。リストの順番どおりに並びます。

📖 用語集

mask
マスク
True/Falseの配列。x[mask]でTrueの位置の値だけを取り出す。
&, |, ~
論理演算子
かつ／または／否定。配列ではand・or・notの代わりに使い、各条件を括弧で囲む。
count_nonzero
個数を数える
条件のTrueの個数。np.sum(条件)でも同じ。
any / all
1つでも／全部
どれかTrueか、全部Trueかを調べる。
fancy indexing
ファンシーインデックス
位置のリストで要素を選ぶ。結果はコピー。
copy vs view
コピーとビュー
スライスはビュー、ファンシーインデックスやマスクはコピー。

①

索引を2段にする：MultiIndex

「都道府県 × 年」のようなデータ

1つの行を2つ以上のラベル（例：州と年）で指定したいとき、MultiIndex（階層索引）を使います。

index = pd.MultiIndex.from_tuples([('CA', 2000), ('CA', 2010), ('TX', 2000), ('TX', 2010)], names=['state', 'year'])
pop = pd.Series([34.0, 37.3, 20.9, 25.1], index=index)
pop
state year CA 2000 34.0 2010 37.3 TX 2000 20.9 2010 25.1 dtype: float64

これで2段のラベルで取り出せます。

print(pop['CA'])              # 州だけ指定
print(pop['CA', 2010])         # 州と年
pop.loc[:, 2010]               # 全州の2010年
year 2000 34.0 2010 37.3 dtype: float64 37.3 state CA 37.3 TX 25.1 dtype: float64
🍎 かんたん説明

「州」というフォルダの中に「年」のファイルがある、という階層構造です。

💻 ミニ練習：2段索引

popから、TXの2000年の値を取り出してください。

pop['TX', 2000]

結果は20.9です。

②

stack と unstack

縦長 ↔ 横長

2段索引のSeriesは、unstack()で内側のラベルを列に移して、表にできます。逆はstack()です。

index = pd.MultiIndex.from_tuples([('CA', 2000), ('CA', 2010), ('TX', 2000), ('TX', 2010)], names=['state', 'year'])
pop = pd.Series([34.0, 37.3, 20.9, 25.1], index=index)

table = pop.unstack()
table
year 2000 2010 state CA 34.0 37.3 TX 20.9 25.1
table.stack()
state year CA 2000 34.0 2010 37.3 TX 2000 20.9 2010 25.1 dtype: float64
🍎 かんたん説明

unstackは縦長（ロング）から横長（ワイド）へ、stackはその逆。データの形を変えるときに役立ちます。

💻 ミニ練習：unstack

popを unstack() して表にしてください。

pop.unstack()

年が列になり、州が行になります。

③

索引と列を行き来する

set_index / reset_index

普通の列を索引にするのがset_index、索引を普通の列に戻すのがreset_indexです。

df = pd.DataFrame({'state': ['CA', 'CA', 'TX', 'TX'], 'year': [2000, 2010, 2000, 2010], 'pop': [34.0, 37.3, 20.9, 25.1]})
idx = df.set_index(['state', 'year'])
idx
pop state year CA 2000 34.0 2010 37.3 TX 2000 20.9 2010 25.1
idx.reset_index()
state year pop 0 CA 2000 34.0 1 CA 2010 37.3 2 TX 2000 20.9 3 TX 2010 25.1
🍎 かんたん説明

set_indexは「列を名札にする」、reset_indexは「名札を列に戻す」。

💻 ミニ練習：set_index

dfのstate列を索引にしてください。

df.set_index('state')

列が索引（行の名札）になります。

④

レベルごとに集計

level を指定

集計関数にlevel（どの段で集計するか）を指定できます。groupby(level=...)も同じ考え方です。

data = pop.groupby(level='state').mean()   # 州ごとの平均
data
state CA 35.65 TX 23.00 dtype: float64
pop.groupby(level='year').sum()            # 年ごとの合計
year 2000 54.9 2010 62.4 dtype: float64
🍎 かんたん説明

2段のラベルのうち、「どの段でまとめるか」を指定して集計します。

💻 ミニ練習：レベルで集計

popを州ごとに合計してください。

pop.groupby(level='state').sum()

CA: 71.3、TX: 46.0です。

📖 用語集

MultiIndex
階層索引
2段以上のラベルで行を指定する索引。
unstack
横長にする
内側のレベルを列へ移して表にする。
stack
縦長にする
列を内側のレベルへ移す。unstackの逆。
set_index
索引にする
列を行の名札（索引）にする。
reset_index
索引を戻す
索引を普通の列に戻し、連番の索引にする。
level
レベル
MultiIndexの段。groupby(level=…)で段ごとに集計できる。

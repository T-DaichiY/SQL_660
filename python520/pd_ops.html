①

計算しても索引は保たれる

ufuncとの関係

PandasのSeriesやDataFrameにNumPyの関数や演算を使っても、行ラベル・列ラベルは残ります。

s = pd.Series([1, 2, 3, 4], index=['a', 'b', 'c', 'd'])
print(s * 10)
np.exp(s)
a 10 b 20 c 30 d 40 dtype: int64 a 2.718282 b 7.389056 c 20.085537 d 54.598150 dtype: float64
df = pd.DataFrame(np.arange(6).reshape(2, 3), columns=['A', 'B', 'C'])
df * 2
A B C 0 0 2 4 1 6 8 10
🍎 かんたん説明

NumPyの計算が、名札付きのまま使えます。結果にも名札が付いて返ってきます。

💻 ミニ練習：計算

Series s の全要素を2乗した Series を作ってください。

s ** 2

結果は a:1, b:4, c:9 で、索引は保たれます。

②

索引がそろう：アラインメント

同じラベル同士を足す

2つのSeriesやDataFrameを計算すると、同じラベルどうしが自動で対応づけられます（アラインメント）。片方にしかないラベルはNaNになります。

a = pd.Series([2, 4, 6], index=[0, 1, 2])
b = pd.Series([1, 3, 5], index=[1, 2, 3])
a + b
0 NaN 1 5.0 2 9.0 3 NaN dtype: float64

NaNにしたくないときは、addなどのメソッドでfill_value（無い所を何として扱うか）を指定します。

a.add(b, fill_value=0)
0 2.0 1 5.0 2 9.0 3 5.0 dtype: float64
A = pd.DataFrame([[1, 11], [5, 1]], columns=list('AB'))
B = pd.DataFrame(np.arange(9).reshape(3, 3), columns=list('BAC'))
A + B     # 列の順番が違っても、列名でそろう
A B C 0 2.0 11.0 NaN 1 9.0 4.0 NaN 2 NaN NaN NaN
⚠️ 位置ではなくラベルで対応づけられます。ラベルが違うと、期待しないNaNが出るので、結果にNaNがあったらまずラベルを疑いましょう。
🍎 かんたん説明

出席番号ではなく名前で点呼してから足し算するイメージ。名前が片方にしかいなければ「不明（NaN）」になります。

💻 ミニ練習：fill_value

aとbを、ない所を0として足してください。

a.add(b, fill_value=0)

結果は 0:1, 1:12, 2:20。

③

DataFrameとSeriesの計算

ブロードキャストが行われる

DataFrameからSeriesを引くと、Seriesのラベルと列名がそろえられ、NumPyのブロードキャストと同じように計算されます。

df = pd.DataFrame(np.array([[1, 2, 3], [4, 6, 9]]), columns=list('ABC'))
df - df.iloc[0]       # 各行から、0行目を引く
A B C 0 0 0 0 1 3 4 6
df.sub(df['A'], axis=0)    # 各列から、A列を引く（行方向にそろえる）
A B C 0 0 1 2 1 0 2 5
🍎 かんたん説明

「df - 行」は各行から引く。列方向に引きたいときは df.sub(列, axis=0) と書きます。

💻 ミニ練習：列ごとの平均を引く

dfの各列から、その列の平均を引いてください。

df - df.mean()

df.mean()は列ごとの平均のSeriesで、列名でそろえて引かれます。

④

並べ替えと集計の基本

sort_values・mean・sum

列の値で行を並べ替えるにはsort_valuesを使います。

tips = pd.read_csv('data/tips.csv')

tips.sort_values('tip', ascending=False).head(3)
total_bill tip sex smoker day time size 170 50.81 10.00 Male Yes Sat Dinner 3 212 48.33 9.00 Male No Sat Dinner 4 23 39.42 7.58 Male No Sat Dinner 4
print(tips['tip'].mean())
print(tips[['total_bill', 'tip']].sum())
tips['tip'].max()
2.99827868852459 total_bill 4827.77 tip 731.58 dtype: float64 10.0
tips['tip_rate'] = tips['tip'] / tips['total_bill']
tips[['total_bill', 'tip', 'tip_rate']].head(3)
total_bill tip tip_rate 0 16.99 1.01 0.059447 1 10.34 1.66 0.160542 2 21.01 3.50 0.166587
🍎 かんたん説明

sort_values(列名)は小さい順、ascending=Falseで大きい順。計算した結果は新しい列として追加できます。

💻 ミニ練習：並べ替え

tipsを total_bill の大きい順に並べ、先頭1行を取り出してください。

tips.sort_values('total_bill', ascending=False).head(1)

最大の会計金額の行が得られます。

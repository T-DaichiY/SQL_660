①

カテゴリ特徴：ワンホット表現

文字を数に変える

「地区名」のようなカテゴリ（文字）は、そのままでは計算できません。かといって Queen Anne=1, Fremont=2 と番号を振ると、「Fremont は Queen Anne の2倍」のような偽の大小関係が生まれます。そこで1カテゴリ＝1列にするワンホット表現を使います。

data = [
    {'price': 850000, 'rooms': 4, 'neighborhood': 'Queen Anne'},
    {'price': 700000, 'rooms': 3, 'neighborhood': 'Fremont'},
    {'price': 650000, 'rooms': 3, 'neighborhood': 'Wallingford'},
    {'price': 600000, 'rooms': 2, 'neighborhood': 'Fremont'},
]

from sklearn.feature_extraction import DictVectorizer
vec = DictVectorizer(sparse=False, dtype=int)
vec.fit_transform(data)
array([[ 0, 1, 0, 850000, 4], [ 1, 0, 0, 700000, 3], [ 0, 0, 1, 650000, 3], [ 1, 0, 0, 600000, 2]])
print(vec.get_feature_names_out())
['neighborhood=Fremont' 'neighborhood=Queen Anne' 'neighborhood=Wallingford' 'price' 'rooms']

数値の列はそのまま、neighborhoodは3つの0/1の列になりました。pandasならget_dummiesでも同じことができます。

pd.get_dummies(pd.DataFrame(data), columns=['neighborhood'], dtype=int)
price rooms neighborhood_Fremont neighborhood_Queen Anne \ 0 850000 4 0 1 1 700000 3 1 0 2 650000 3 0 0 3 600000 2 1 0 neighborhood_Wallingford 0 0 1 0 2 1 3 0
🍎 かんたん説明

「どの地区か」を、当てはまる列だけ1、他は0で表します。

💻 ミニ練習：get_dummies

Series s をワンホット表現にして d に入れてください（整数で）。

d = pd.get_dummies(s, dtype=int)

列は blue, red の2つです。

②

テキスト特徴：単語の数え上げ

CountVectorizer

文章は単語の出現回数に直すと、機械学習に使えます（Bag of Words）。

from sklearn.feature_extraction.text import CountVectorizer
sample = ['problem of evil', 'evil queen', 'horizon problem']
vec = CountVectorizer()
X = vec.fit_transform(sample)
print(vec.get_feature_names_out())
X.toarray()
['evil' 'horizon' 'of' 'problem' 'queen'] array([[1, 0, 1, 1, 0], [1, 0, 0, 0, 1], [0, 1, 0, 1, 0]])

各行が1つの文、各列が1つの単語です。表にすると見やすくなります。

pd.DataFrame(X.toarray(), columns=vec.get_feature_names_out())
evil horizon of problem queen 0 1 0 1 1 0 1 1 0 0 0 1 2 0 1 0 1 0
🍎 かんたん説明

文章を「単語の出席簿」にする。何回出たかを数えます。

🔎 よく出る単語の影響を弱めるTfidfVectorizerもあります。使い方はCountVectorizerと同じです。
💻 ミニ練習：単語の種類数

docs を CountVectorizer で変換し、単語の種類数（列数）を n に入れてください。

n = CountVectorizer().fit_transform(docs).shape[1]

cat, dog, bird の3種類です。

③

派生特徴と欠損の補完

特徴量を作る・埋める

直線では表せない関係も、特徴量を足すと直線モデルで扱えます。たとえば x から x², x³ を作るPolynomialFeaturesです。

from sklearn.preprocessing import PolynomialFeatures
x = np.array([1, 2, 3, 4, 5])
poly = PolynomialFeatures(degree=3, include_bias=False)
poly.fit_transform(x.reshape(-1, 1))
array([[ 1., 1., 1.], [ 2., 4., 8.], [ 3., 9., 27.], [ 4., 16., 64.], [ 5., 25., 125.]])

次に欠損値。多くのモデルはNaNを受け付けないので、平均などで埋めるSimpleImputerを使います。

from sklearn.impute import SimpleImputer
Xm = np.array([[1.0, 2.0], [np.nan, 3.0], [7.0, np.nan]])
imp = SimpleImputer(strategy='mean')
imp.fit_transform(Xm)
array([[1. , 2. ], [4. , 3. ], [7. , 2.5]])
🍎 かんたん説明

fitで「平均の値」を覚え、transformでNaNをその値に置き換えます。

平均などの値は訓練データだけから計算するのが原則です（テスト用の情報を漏らさないため）。パイプラインに入れると自動でそうなります。
💻 ミニ練習：中央値で埋める

Xm の欠損を中央値で埋めた配列を filled に入れてください。

filled = SimpleImputer(strategy='median').fit_transform(Xm)

列ごとの中央値（4.0と2.5）で埋まります。

④

パイプライン

前処理＋モデルを1つにまとめる

「欠損を埋める→特徴量を作る→回帰する」のような一連の手順を、make_pipelineで1つのモデルのように扱えます。

from sklearn.pipeline import make_pipeline
from sklearn.linear_model import LinearRegression

x = np.array([1, 2, 3, np.nan, 5])
y = np.array([14, 16, -1, 8, -5])
model = make_pipeline(SimpleImputer(strategy='mean'),
                      PolynomialFeatures(degree=2),
                      LinearRegression())
model.fit(x.reshape(-1, 1), y)
print(model.predict(x.reshape(-1, 1)).round(2))
[16.2 10.46 4.88 6.26 -5.79]

NaN入りのデータでも、そのままfitとpredictが使えます。各段の名前は小文字のクラス名になります。

print(list(model.named_steps))
['simpleimputer', 'polynomialfeatures', 'linearregression']
🍎 かんたん説明

パイプラインは「ベルトコンベア」。データが前処理を通ってからモデルに入ります。

💻 ミニ練習：パイプライン

StandardScaler と LinearRegression をこの順でつないだパイプラインを model に作ってください。

model = make_pipeline(StandardScaler(), LinearRegression())

最後の段だけがモデル、前は変換器です。

📖 用語集

One-hot encoding
ワンホット表現
カテゴリを「1カテゴリ＝1列」の0/1で表す。
Bag of words
単語の袋
語順を捨て、単語の出現回数だけを特徴にする。
Derived feature
派生特徴
元の特徴量から作った新しい特徴量（x²など）。
Imputation
補完
欠損値を平均などで埋めること。
Pipeline
パイプライン
前処理とモデルを順番につないで1つにしたもの。
Data leakage
データ漏洩
テスト用の情報が学習に混ざってしまうこと。

①

文字列を扱う：.str

まとめて加工する

Seriesの文字列は、.strを付けると、全要素にまとめて文字列メソッドが使えます。欠損値があってもエラーになりません。

names = pd.Series(['peter', 'Paul', None, 'MARY', 'gUIDO'])
print(names.str.capitalize())
names.str.lower()
0 Peter 1 Paul 2 None 3 Mary 4 Guido dtype: object 0 peter 1 paul 2 None 3 mary 4 guido dtype: object
s = pd.Series(['Graham Chapman', 'John Cleese', 'Terry Gilliam'])
print(s.str.split().str[0])    # 名
print(s.str.len())
s.str.contains('ll')
0 Graham 1 John 2 Terry dtype: object 0 14 1 11 2 13 dtype: int64 0 False 1 False 2 True dtype: bool
s.str.extract('([A-Za-z]+)')    # 正規表現で先頭の単語を取り出す
0 0 Graham 1 John 2 Terry
🍎 かんたん説明

.strは「文字列メソッドをSeries全体に使うためのスイッチ」。

💻 ミニ練習：.str

sの各要素を大文字にしてください。

s.str.upper()

結果は ABC と DEF です。

②

日付と時刻：datetime

to_datetime と .dt

日付は文字列のままだと計算できません。pd.to_datetimeで日付型に変えると、年・月・曜日を取り出せます。

dates = pd.to_datetime(['2024-07-03', '2024-07-04', '2024-12-25'])
dates
DatetimeIndex(['2024-07-03', '2024-07-04', '2024-12-25'], dtype='datetime64[ns]', freq=None)
s = pd.Series(dates)
print(s.dt.year.tolist())
print(s.dt.month.tolist())
s.dt.day_name().tolist()
[2024, 2024, 2024] [7, 7, 12] ['Wednesday', 'Thursday', 'Wednesday']
print(dates[1] - dates[0])
pd.date_range('2024-01-01', periods=4, freq='D')
1 days 00:00:00 DatetimeIndex(['2024-01-01', '2024-01-02', '2024-01-03', '2024-01-04'], dtype='datetime64[ns]', freq='D')
🍎 かんたん説明

日付型にすると「7月4日から3日後は？」のような計算ができます。まずto_datetime。

💻 ミニ練習：日付型

文字列の日付 d を日付型に変換してください。

pd.to_datetime(d)

変換後は.dtが使えます。

③

時系列の集計：resample と rolling

日別 → 月別、移動平均

日付を索引にすると、期間ごとの集計が簡単です。

idx = pd.date_range('2024-01-01', periods=60, freq='D')
ts = pd.Series(np.arange(60), index=idx)

ts.resample('MS').sum()     # 月ごとの合計（'MS'＝月初）
2024-01-01 465 2024-02-01 1305 Freq: MS, dtype: int64
ts.rolling(7).mean().tail(3)   # 直近7日間の移動平均
2024-02-27 54.0 2024-02-28 55.0 2024-02-29 56.0 Freq: D, dtype: float64
ts.shift(1).head(3)            # 1日ずらす
2024-01-01 NaN 2024-01-02 0.0 2024-01-03 1.0 Freq: D, dtype: float64
🍎 かんたん説明

resampleは「期間でまとめる」、rollingは「最近n個の窓をずらしながら平均」、shiftは「ずらす」。

💻 ミニ練習：resample

tsを月ごとの平均にしてください（'MS'）。

ts.resample('MS').mean()

1月と2月の2行になります。

④

query と eval：読みやすい書き方

条件を文字列で書く

queryは、条件を文字列で書けるので、行の絞り込みが読みやすくなります。

tips = pd.read_csv('data/tips.csv')

tips.query('tip > 6 and day == "Sat"')
total_bill tip sex smoker day time size 23 39.42 7.58 Male No Sat Dinner 4 59 48.27 6.73 Male No Sat Dinner 4 170 50.81 10.00 Male Yes Sat Dinner 3 212 48.33 9.00 Male No Sat Dinner 4 214 28.17 6.50 Female Yes Sat Dinner 3
lim = 8
tips.query('total_bill > @lim').shape    # 変数は @ で参照
(237, 7)
tips.eval('tip_rate = tip / total_bill').head(2)
total_bill tip sex smoker day time size tip_rate 0 16.99 1.01 Female No Sun Dinner 2 0.059447 1 10.34 1.66 Male No Sun Dinner 3 0.160542
🍎 かんたん説明

df[(df.tip > 6) & (df.day == "Sat")]と同じことを、括弧や&なしで書けます。

💻 ミニ練習：query

sizeが5以上の行を、queryで取り出してください。

tips.query('size >= 5')

5人以上のテーブルの行が得られます。

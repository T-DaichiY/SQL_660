①

Seriesの取り出し：ラベルと位置

loc と iloc

Seriesは「ラベル」でも「位置」でも取り出せるので、混乱しやすいところです。そこで、取り出し方をはっきり使い分ける2つの道具があります。

  • loc：ラベルで取り出す（スライスの終点も含む）
  • iloc：位置（0から数えた番号）で取り出す（終点は含まない）
data = pd.Series(['a', 'b', 'c'], index=[1, 3, 5])
print(data[1])          # 角括弧の整数は「ラベル」として扱われる
print(data.loc[1:3])    # ラベル1〜3（3を含む）
data.iloc[1:3]          # 位置1〜2（3番目は含まない）
a 1 a 3 b dtype: object 3 b 5 c dtype: object
⚠️ 索引が整数のとき、data[1]は「ラベル1」ですが、data[1:3]は「位置1〜2」になる、というややこしい決まりがあります。迷わないために常にlocかilocを使うのがおすすめです。
🍎 かんたん説明

loc＝Label（名前）、iloc＝integer（番号）。名前なら終点を含み、番号なら含みません。

💻 ミニ練習：loc と iloc

Series s から、ラベルが 3 の要素を loc で、先頭の要素を iloc で取り出す2行を書いてください。

s.loc[3]
s.iloc[0]

ラベル3は2番目の要素で、位置0は先頭です。

②

DataFrameの列と行を選ぶ

df['col']、loc、iloc

DataFrameでは、列は名前で、行は loc／ilocで選ぶのが基本です。

df = pd.DataFrame({'name': ['Ann', 'Bob', 'Cy', 'Di'], 'age': [23, 31, 27, 45], 'city': ['NY', 'LA', 'NY', 'SF']}, index=['a', 'b', 'c', 'd'])

df['age']              # 1列 → Series
a 23 b 31 c 27 d 45 Name: age, dtype: int64
df[['name', 'age']]    # 複数列 → DataFrame（リストで指定）
name age a Ann 23 b Bob 31 c Cy 27 d Di 45
print(df.loc['b'])             # 行ラベルで1行
df.loc['a':'c', ['name', 'age']]   # 行ラベルと列名
name Bob age 31 city LA Name: b, dtype: object name age a Ann 23 b Bob 31 c Cy 27
df.iloc[:2, :2]        # 上の2行・左の2列（位置）
name age a Ann 23 b Bob 31

新しい列は、代入するだけで追加できます。

df['age_next'] = df['age'] + 1
df
name age city age_next a Ann 23 NY 24 b Bob 31 LA 32 c Cy 27 NY 28 d Di 45 SF 46
🍎 かんたん説明

df.loc[行, 列]の書き方はNumPyのx[行, 列]と同じ。違いは、行・列を名前で指定できることです。

💻 ミニ練習：行と列を選ぶ

dfから、行ラベル b と c の name 列だけを取り出してください（locを使う）。

df.loc['b':'c', 'name']

locのスライスは終点を含むので、bとcの2行になります。

③

条件で絞り込む

ブール値のマスク

NumPyのマスクと同じ考え方で、条件に合う行を取り出せます。

df[df['age'] > 25]
name age city age_next b Bob 31 LA 32 c Cy 27 NY 28 d Di 45 SF 46
df[(df['age'] > 25) & (df['city'] == 'NY')]    # 複数条件は & と括弧
name age city age_next c Cy 27 NY 28
df.loc[df['city'].isin(['NY', 'SF']), ['name', 'city']]
name city a Ann NY c Cy NY d Di SF
⚠️ 複数条件は&（かつ）・|（または）で、条件ごとに括弧が必要です。and・orは使えません。
🍎 かんたん説明

「df[条件]」は「条件がTrueの行だけ残す」の意味。条件の結果は、行ごとのTrue/Falseです。

💻 ミニ練習：条件で絞る

ageが30以上の行だけを取り出してください。

df[df['age'] >= 30]

結果はBob（31）とDi（45）の2行です。

④

値の書き換えと、よくある落とし穴

loc で代入する

値の書き換えにはlocを使います。

df.loc['a', 'age'] = 24
df.loc[df['city'] == 'NY', 'city'] = 'New York'
df
name age city age_next a Ann 24 New York 24 b Bob 31 LA 32 c Cy 27 New York 28 d Di 45 SF 46
⚠️ df[条件]['col'] = 値のようにつなげて書くと、元のDataFrameが変わらないことがあります（SettingWithCopyWarning）。書き換えは必ずdf.loc[条件, 'col'] = 値の1回の指定で。
🍎 かんたん説明

「どこを」（行・列）と「何に」（値）を、1つのlocで指定するのがコツ。

💻 ミニ練習：書き換え

ageが40以上の人のcityを Senior に書き換えてください（locで）。

df.loc[df['age'] >= 40, 'city'] = 'Senior'

行の条件と列名を、1つのlocで指定します。

📖 用語集

loc
ラベルで選ぶ
行・列の名前で選ぶ。スライスの終点を含む。
iloc
位置で選ぶ
0からの番号で選ぶ。スライスの終点を含まない。
boolean mask
ブールマスク
条件の結果（True/False）で行を絞る。&、|を使い、括弧が必要。
isin
含まれるか
df['c'].isin([…])で、リストに含まれる行をTrueにする。
SettingWithCopyWarning
コピーの警告
つなげて代入すると元が変わらない恐れがある。locを1回で使う。
new column
列の追加
df['new'] = … で新しい列を作る。

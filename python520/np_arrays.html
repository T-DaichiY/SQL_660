①

なぜNumPyを使うのか

リストより速く、型がそろった配列

Pythonのリストは何でも入れられて便利ですが、中の要素は1つ1つが「Pythonのオブジェクト」で、型の情報も持ち歩いています。数値計算では、この柔軟さが遅さの原因になります。

NumPyの配列（ndarray）は、すべて同じ型の値を、メモリの中にぎっしり並べて持ちます。だから、まとめて計算するのが速く、型も1つだけ覚えておけば済みます。

import numpy as np

L = [1, 2, 3, 4, 5]
L2 = [1, "two", 3.0, True]     # リストは型が混ざってもよい
print(type(L2[1]))

a = np.array([1, 2, 3, 4, 5])
a.dtype
<class 'str'> dtype('int64')

配列には型（dtype）が1つだけあります。整数だけならint64などの整数型です（WindowsやPythonの古い環境ではint32と表示されることもあります）。

b = np.array([1, 2, 3.5])    # 小数が1つ混ざると、全体が float になる
b
array([1. , 2. , 3.5])
🍎 かんたん説明

リストは「何でも入る買い物袋」、NumPy配列は「同じサイズの卵がきれいに並んだパック」。パックのほうが、数えるのも運ぶのも速い。

💻 ミニ練習：配列を作る

整数 10, 20, 30 からなるNumPy配列を作り、変数 a に入れてください（import numpy as npも書く）。

import numpy as np

a = np.array([10, 20, 30])

np.array(リスト)でリストから配列を作ります。

②

配列を作る

リストから、ゼロから、連番から

配列の作り方は大きく3つです。

np.array([[1, 2, 3], [4, 5, 6]])   # リストのリスト → 2次元
array([[1, 2, 3], [4, 5, 6]])
関数できるもの
np.zeros(5)0が5個（float）
np.ones((2, 3))1が2行3列
np.full((2, 2), 7)7で埋めた2行2列
np.arange(0, 10, 2)0から10手前まで2ずつ（rangeと同じ感覚）
np.linspace(0, 1, 5)0から1まで終点を含めて5等分
np.zeros(5)
array([0., 0., 0., 0., 0.])
np.arange(0, 10, 2)
array([0, 2, 4, 6, 8])
np.linspace(0, 1, 5)
array([0. , 0.25, 0.5 , 0.75, 1. ])
⚠️ arangeは終点を含みません（rangeと同じ）。linspaceは終点を含みます。間違えやすいので、並べて覚えましょう。

乱数の配列もよく使います。np.random.seedで種を固定すると、毎回同じ結果になります。

np.random.seed(0)
np.random.randint(0, 10, size=(2, 3))
array([[5, 0, 3], [3, 7, 9]])

dtype=で型を指定することもできます。

np.zeros(3, dtype=int)
array([0, 0, 0])
💻 ミニ練習：連番と等分

0, 5, 10, 15, 20の配列を、arangeとlinspaceの両方で作ってください（linspaceは5個）。

np.arange(0, 21, 5)
np.linspace(0, 20, 5)

arangeは終点を含まないので21（20より大きい値）にします。linspaceは終点20を含みます。

③

配列の属性と、インデックス・スライス

形（shape）と、取り出し方

配列は次の属性を持ちます。

x = np.array([[3, 1, 4, 1], [5, 9, 2, 6], [5, 3, 5, 8]])
print(x.ndim)     # 次元の数
print(x.shape)    # 形（行, 列）
print(x.size)     # 要素の総数
print(x.dtype)    # 型
2 (3, 4) 12 int64

取り出しは、リストと同じ[ ]です。2次元ではカンマで区切って（行, 列）と書きます。

print(x[0, 0])     # 1行目・1列目
print(x[-1, -1])   # 最後の行・最後の列
x[1, 2]
3 8 2

スライスは開始:終了:ステップで、終了は含みません。

y = np.arange(10)
print(y[2:5])      # 2, 3, 4
print(y[::2])      # 1つおき
print(y[::-1])     # 逆順
[2 3 4] [0 2 4 6 8] [9 8 7 6 5 4 3 2 1 0]
x[:2, :3]      # 上の2行、左の3列
array([[3, 1, 4], [5, 9, 2]])
print(x[:, 0])     # 0列目だけ（すべての行）
x[1]             # 1行目だけ
[3 5 5] array([5, 9, 2, 6])
🍎 かんたん説明

x[行, 列]。:は「全部」。x[:, 0]は「全部の行の、0列目」と読みます。

💻 ミニ練習：スライス

上の配列 x から、2行目（行番号1）の全体と、最後の列のすべての行を取り出すコードを2行で書いてください。

x[1]
x[:, -1]

行は0から数えるので2行目はx[1]。最後の列は-1です。

④

スライスは「コピー」ではなく「ビュー」

reshape と copy

NumPyのスライスは、元の配列と同じデータを見ているだけ（ビュー）です。ここがリストと違う大事な点です。

a = np.arange(5)
b = a[:3]       # ビュー
b[0] = 99       # b を変更すると…
a               # a も変わる！
array([99, 1, 2, 3, 4])

コピーが欲しいときは.copy()を使います。

a = np.arange(5)
c = a[:3].copy()
c[0] = 99
a               # a は変わらない
array([0, 1, 2, 3, 4])

形を変えるにはreshape。要素の数が合っている必要があります。

np.arange(1, 7).reshape(2, 3)
array([[1, 2, 3], [4, 5, 6]])
v = np.array([1, 2, 3])
v.reshape(1, 3)      # 行ベクトル（1行3列）
array([[1, 2, 3]])
np.arange(5).reshape(2, 3)
ValueError: cannot reshape array of size 5 into shape (2,3)
⚠️ 5個の要素は2×3=6個の形には並べられません。reshapeは「要素の総数が同じ」ときだけ使えます。
🍎 かんたん説明

スライスは「窓から元の部屋をのぞいている」状態。窓の中を変えると部屋が変わります。別の部屋が欲しければcopy。

💻 ミニ練習：コピーする

配列 a = np.arange(5) の先頭3つをコピーして変数 c に入れ、c[0]を100にしてもaが変わらないようにしてください。

a = np.arange(5)
c = a[:3].copy()
c[0] = 100

.copy()を付けると別のデータになります。付けないとaも100になります。

📖 用語集

ndarray
NumPyの配列
同じ型の値を並べた、NumPyの基本のデータ構造。
dtype
データ型
配列の中身の型（int64、float64など）。配列に1つだけ。
shape
形
(行, 列)のタプル。reshapeで変えられる。
view
ビュー
スライスで得られる、元データを共有した配列。変更が元に伝わる。
arange / linspace
連番／等分
arangeは終点を含まず、linspaceは含む。

乱数の種

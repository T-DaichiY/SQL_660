①

分けて測る

train_test_split

🎯 これだけ覚えればOK

データを学習用とテスト用に分け、テスト用で点数を測る。

from sklearn.datasets import load_iris
iris = load_iris()
X, y = iris.data, iris.target
from sklearn.model_selection import train_test_split
Xtr, Xte, ytr, yte = train_test_split(X, y, random_state=0)
print(Xtr.shape, Xte.shape)
(112, 4) (38, 4)
🍎 ひとことで

random_stateを決めると、毎回同じ分け方になります。

②

交差検証

cross_val_score

🎯 これだけ覚えればOK

データをcv個に分けて、テスト役を交代しながら平均する。

from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import cross_val_score
cross_val_score(KNeighborsClassifier(3), X, y, cv=5).mean().round(3)
0.967
🍎 ひとことで

1回の分割より、安定した評価になります。

🤔 答えられるかな？（クリックで答えが開く）

Q1. cv=5なら何回評価する？A. 5回。

M8 · Common Table Expressions — Part 2 🍎

🍎 超やさしい版：CTE②（複数のCTE）

CTEを2つ以上つなげる方法です。ルールは3つだけ。そのあと、講義の例題を一緒に見ましょう。

カンマでつなぐ例題 2つのCTECTEの中でCTE🧱 本編はこちら
①

カンマでつなぐ

WITHは1回、あとはカンマ

🎯 これだけ覚えればOK

CTEを2つ以上作るときは、最初の1つだけWITH。あとはカンマ,でつなぐ。

▶ 2つのCTEのかたち

WITH first_cte AS (
    SELECT ...
),                         -- ← ここにカンマ！
second_cte AS (            -- ← 2つ目にWITHは書かない
    SELECT ...
)                          -- ← 最後のCTEの後ろにカンマは付けない
SELECT ...
FROM first_cte
JOIN second_cte ON ...;
🔑
3つのルール
① WITHは1回だけ　② CTEの間はカンマ（最後の後ろには付けない）　③ 名前はぜんぶ別々
🍎 ひとことで

CTEを「表のリスト」だと思いましょう。リストの項目はカンマで区切り、最後には付けません。

🤔 答えられるかな？（クリックで答えが開く）

Q1. 2つ目のCTEの前にWITHは必要？A. いらない。WITHは最初の1回だけ。
Q2. 同じ名前のCTEを2つ作れる？A. 作れない。名前はユニーク（重複なし）でなければならない。
②

例題：2つのCTE

部署の条件を2つとも満たすのは？

🎯 これだけ覚えればOK

2つの条件があるときは、条件ごとにCTEを1つずつ作って、最後に結びつける。

お題：(1) 1つのプロジェクトで、どの社員よりも長く働いた人（最長の160時間）がいる部署で、かつ (2) 部署の給与の合計が200,000を超える部署の「部署名と給与合計」。（会社のデータは架空のものです）

  • CTE① top_project_workers：最長時間の社員とその部署ID（結果：部署2と部署4）
  • CTE② high_salary_departments：給与合計が200,000を超える部署（結果：部署1、2、3）

両方に出てくる部署は部署2（Marketing）だけです。

▶ 全体のSQL

WITH top_project_workers AS (
    SELECT ep.employee_id, e.department_id
    FROM employee_projects ep
    JOIN employees e ON ep.employee_id = e.employee_id
    WHERE ep.hours_worked = (SELECT MAX(hours_worked) FROM employee_projects)
),
high_salary_departments AS (
    SELECT department_id, SUM(salary) AS total_salary
    FROM employees
    GROUP BY department_id
    HAVING SUM(salary) > 200000
)
SELECT d.department_name, hsd.total_salary
FROM high_salary_departments hsd
JOIN top_project_workers tpw ON hsd.department_id = tpw.department_id
JOIN departments d ON d.department_id = hsd.department_id
GROUP BY d.department_name, hsd.total_salary;
department_name | total_salary ----------------+------------- Marketing | 245000
🤝
2つのCTEをJOINすると、両方に出てくる部署だけが残ります。これが「かつ（AND）」の働きです。
🍎 ひとことで

CTEが2つなので、GROUP BYやHAVINGの置き場所で悩まずに済みます。Marketingだけが両方の条件を満たすので、答えは1行です。

🤔 答えられるかな？（クリックで答えが開く）

Q1. なぜ2つのCTEをJOINすると「かつ」になる？A. 両方の部署IDに出てくる部署だけが結びつき、どちらかにしかない部署は消えるから。
Q2. 給与合計の200,000のチェックはどこに書いた？A. CTE②のHAVING（集計と一緒にCTEの中で絞った）。
③

CTEの中でCTEを使う

3つ目のCTEを足してみよう

🎯 これだけ覚えればOK

CTEは、前に作ったCTEをあとのCTEから使える。何個でも作れる。

🧩
「最長時間」を調べる部分を、max_hoursという3つ目のCTEにしても同じ答えになります（講師も説明）。
WITH max_hours AS (
    SELECT MAX(hours_worked) AS mh FROM employee_projects
),
top_project_workers AS (
    SELECT ep.employee_id, e.department_id
    FROM employee_projects ep
    JOIN employees e ON ep.employee_id = e.employee_id
    JOIN max_hours m ON ep.hours_worked = m.mh
)
SELECT * FROM top_project_workers;
employee_id | department_id ------------+-------------- 5 | 2 14 | 4
🍎 ひとことで

小さく分けるほど、1つ1つが簡単になります。ただし、分けすぎると逆に読みにくいので、ほどほどに。

🤔 答えられるかな？（クリックで答えが開く）

Q1. CTEは最大何個まで作れる？A. 決まりはない。必要なだけ作れる（講師も「もっと増やせる」と説明）。
Q2. あとのCTEは前のCTEを使える？A. 使える。上から順に定義し、名前で呼ぶ。

💡 まとめ

• WITHは1回だけ

• CTEの間はカンマ、最後の後ろには付けない

• 名前はぜんぶ別々

• 2つの条件 → 2つのCTE → JOINで「かつ」

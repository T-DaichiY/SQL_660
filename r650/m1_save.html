①

ggsave：グラフを保存する

直前のグラフが保存される

ggsave() は最後に作ったグラフを作業フォルダ（working directory）に保存します。

ggplot(mpg, aes(x = class)) + geom_bar()ggplot(mpg, aes(x = cty, y = hwy)) + geom_point()ggsave("mpg-plot.png") # 保存されるのは2枚目（直前のグラフ）ggsave("mpg-plot.pdf") # 拡張子を変えれば PDFgetwd() # 今どこに保存される？?ggsave # 使える形式を調べる
📌 保存先は getwd() で確認。setwd() を使うより、Quarto ファイルを置いたフォルダに保存される運用が楽です。
②

エラーのとき見るところ

R は融通がきかない

エラーは出て当たり前。経験者でも一発では動きません。落ち着いて次を確認します。

  • + は正しい位置？（行の最後に置く）
  • 括弧 ) は閉じている？ 引用符 " は対になっている？
  • コンソールが > でなく + のまま止まっていたら、式が未完成。Esc で抜ける。
  • エラーメッセージをよく読む。答えが書いてあることが多い。
  • ?関数名 で公式ヘルプ。英語のエラー文をそのまま検索（"ggplot2" も添える）。
# よくある綴りミスggplot(diamonds, aes(x = cut, color = clarity)) + geom_bar(fill = NA, potion = "identity") # position のつづり間違い！# 割合表示：位置の指定は geom の中geom_bar(aes(x = cut, fill = clarity), position = "fill")
③

読みやすいコード

短く・揃えて・パイプ

引数名を省いた短い書き方、パイプ、そして整った改行が読みやすさの基本です。

# 学習中はていねいにggplot(data = penguins, mapping = aes(x = flipper_length_mm, y = body_mass_g)) + geom_point()# 慣れたら簡潔に（課題ではこちら）ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) + geom_point()
  • 短いと①タイプが減る ②読みやすい ③違いが目立つ。
  • 関数の引数が1行に入らないときは、1引数1行にする。
🍎 かんたん説明

コードは「あとで読む自分」への手紙。短く、整えて、誰が見てもわかるように✍️

🔀 2変数以上の関係と facet

変数の組み合わせでグラフを選びます。数値×カテゴリは箱ひげ図、カテゴリ×カテゴリは積み上げ棒、数値×数値は散布図。さらに facet で分割して見ます。

① 数値 × カテゴリ：箱ひげ図② カテゴリ × カテゴリ：棒の積み上げ方③ 数値 × 数値：散布図と3変数以上④ facet で分割して見る📝 Quiz

①

数値 × カテゴリ：箱ひげ図

geom_boxplot と jitter

箱ひげ図は位置の指標（パーセンタイル）を図にしたものです。

  • 箱の両端：Q1（25%）と Q3（75%）。この距離が IQR = Q3 − Q1。
  • 箱の中の線：中央値（50%）。
  • ひげ：外れ値でない最も遠い点まで。
  • 外れ値：Q1 − 1.5×IQR より小さい、または Q3 + 1.5×IQR より大きい点（点で表示）。
ggplot(penguins, aes(x = species, y = body_mass_g)) + geom_boxplot()# 横向きにする（2通り）... + coord_flip()ggplot(penguins, aes(y = species, x = body_mass_g)) + geom_boxplot()# 生データの点も重ねる（jitter＝少しずらして重なり防止）ggplot(penguins, aes(x = species, y = body_mass_g)) + geom_boxplot() + geom_jitter(width = 0.15, color = "blue", shape = 17, size = 0.75)# 外れ値の点だけ消すgeom_boxplot(outlier.shape = NA)
📌 Chinstrap の体重には高い外れ値と低い外れ値が1つずつあります。
②

カテゴリ × カテゴリ：棒の積み上げ方

position = dodge / fill

2つのカテゴリは、片方を fill に割り当てた棒グラフで比べます。position で棒の並べ方が変わります。

ggplot(penguins, aes(x = island, fill = species)) + geom_bar() # stacked（積み上げ）ggplot(penguins, aes(x = island, fill = species)) + geom_bar(position = "dodge") # 横に並べるggplot(penguins, aes(x = island, fill = species)) + geom_bar(position = "fill") # 高さを100%に

グループの大きさが違うときは件数ではなく割合で比べます。

教師合格者数受験者合格率
A1010100%
B205040%
⚠️ 割合の図（position = "fill"）では y 軸ラベルが「count」のままになります。ylab("Proportion") で必ず直しましょう。
ggplot(penguins, aes(x = island, fill = species)) + geom_bar(position = "fill")# 島ごとの種の割合ggplot(penguins, aes(x = species, fill = island)) + geom_bar(position = "fill")# 種ごとの島の割合（x と fill を入れ替えると答える質問が変わる）
③

数値 × 数値：散布図と3変数以上

見た目を足しすぎない

2つの数値変数は散布図（geom_point）。第3・第4の変数は aes に足せます。

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) + geom_point(aes(color = species, shape = island))

ただし aes を盛りすぎると、ごちゃごちゃして読めません。

⚠️ 連続変数を shape に割り当てるとエラー。形は有限個しかないので、連続変数は形に割り当てられません（"A continuous variable cannot be mapped to the shape aesthetic"）。色やサイズなら可。
④

facet で分割して見る

facet_wrap(~ 変数)

カテゴリ変数をもう1つ足したいときはfacet（分割）が便利。グラフを部分集合ごとの小窓に並べます。

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) + geom_point(aes(color = species, shape = species)) + facet_wrap(~sex) # チルダ ~ を忘れずにpenguins |> na.omit() |> ggplot(aes(x = flipper_length_mm, y = body_mass_g, color = species, shape = species)) + geom_point() + geom_smooth() + facet_wrap(~island)
⚠️ na.omit() は全列の欠損行をまとめて消します。使うなら①分析に使う列だけ ②前後の行数を確認 ③補完（imputation）も検討、を意識しましょう（→ 欠損値の回）。

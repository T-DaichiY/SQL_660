①

データを知る：palmerpenguins

変数・観測・tidy data

題材は palmerpenguins パッケージの penguins。3つの島のペンギン344羽の体の測定値です。まず用語をそろえます。

  • 変数 (variable)：測れる性質（例：flipper_length_mm）。列に入る。
  • 観測 (observation)：1羽ぶんの測定のまとまり。行に入る。
  • 値 (value)：変数を測ったときの具体的な数字や名前。

表が tidy（整然） とは、①1つの値が1つのセル ②1つの変数が1つの列 ③1つの観測が1つの行、の3条件を満たすこと。ggplot2 は tidy なデータを前提にしています。

library(tidyverse)library(palmerpenguins)library(ggthemes)penguins # 344 行 × 8 列の tibbleglimpse(penguins) # 全列を縦に並べて確認head(penguins, 3) # 最初の3行?penguins # ヘルプ（各列の意味）
Rows: 344 Columns: 8 $ species <fct> Adelie, Adelie, Adelie, ... $ island <fct> Torgersen, Torgersen, ... $ bill_length_mm <dbl> 39.1, 39.5, 40.3, NA, ... $ flipper_length_mm <int> 181, 186, 195, NA, ... $ body_mass_g <int> 3750, 3800, 3250, NA, ... $ sex <fct> male, female, female, NA, ...
📌 glimpse() は「列が多くて画面に収まらない」ときの定番。<fct> は factor（カテゴリ）、<dbl> は小数、<int> は整数。

レイヤーでグラフを作る

キャンバス → aes → geom

ggplot2 の考え方（Grammar of Graphics）は「1枚ずつ重ねる」。同じ手順で棒グラフでも散布図でも描けます。

① ggplot(data)
空のキャンバス
→
② aes(x, y)
変数→見た目
→
③ + geom_point()
図形を足す
# ① 空のキャンバス（何も描かれない）ggplot(data = penguins)# ② 軸に変数を割り当てる（まだ点はない）ggplot(data = penguins, mapping = aes(x = flipper_length_mm, y = body_mass_g))# ③ geom で点を描くggplot(data = penguins, mapping = aes(x = flipper_length_mm, y = body_mass_g)) + geom_point()

③ でヒレが長いほど体重が重い、右上がりの正の関係が見えます。ただし散布図を見るときは疑いの目を持ちましょう。

⚠️ 関連があっても原因とは限りません（相関は因果ではない）。第三の変数（種や島）が隠れているかもしれません。
📌 ggplot2 は「欠損値が黙って消える」ことをよしとしません。NA の行は警告 Removed 2 rows containing missing values が出ます（na.rm = TRUE で黙らせられる）。
③

aes：色・形を変数に割り当てる

global と local

aes() の中に書くのは「データの列を見た目に結びつける」指定です。color = species と書くと、種ごとに自動で色が決まり（scaling）、凡例も作られます。

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g, color = species)) + geom_point() + geom_smooth(method = "lm") # 種ごとに回帰直線

aes を書く場所が2種類あります。

場所呼び方効き方
ggplot(aes(...))global（全体）以降のすべての geom に引き継がれる
geom_point(aes(...))local（個別）その geom だけに効く
# local：点だけ種で色分け、直線は全体で1本ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) + geom_point(aes(color = species, shape = species)) + geom_smooth(method = "lm")
📌 色と形を同じ変数に割り当てると、凡例が1つにまとまり、白黒印刷でも区別できます。
④

ラベル・色覚への配慮・簡潔な書き方

labs / scale_color_colorblind

伝わるグラフは、タイトル・軸ラベル・凡例名を整えるところまでが仕事です。

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) + geom_point(aes(color = species, shape = species)) + geom_smooth(method = "lm") + labs( title = "Body mass and flipper length", subtitle = "Dimensions for Adelie, Chinstrap, and Gentoo Penguins", x = "Flipper length (mm)", y = "Body mass (g)", color = "Species", shape = "Species" ) + scale_color_colorblind() # ggthemes：色覚多様性に配慮した配色

慣れたら data = と mapping = は省略します（課題でもこの書き方が期待されます）。

ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) + geom_point()# パイプ版（次のM2で学ぶ）penguins |> ggplot(aes(x = flipper_length_mm, y = body_mass_g)) + geom_point()
⚠️ ggplot2 の層は + でつなぎます。パイプ |> と混同しないこと（ggplot は +、データ加工は |>）。

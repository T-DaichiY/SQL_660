dplyr の動詞と flights データ

共通ルール3つ

dplyr の関数（動詞）には共通のルールがあります。

  1. 最初の引数は必ずデータフレーム。
  2. 次の引数は、列名（引用符なし）で何をするか指定。
  3. 結果はいつも新しいデータフレーム。

動詞は対象で4グループ：行・列・グループ・表。この回は「行」です。題材 nycflights13::flights は 336,776 行 × 19 列の tibble です。

library(nycflights13)library(tidyverse)flights # tibble：先頭だけ表示glimpse(flights) # 全列を縦にclass(flights) # tbl_df, tbl, data.frame
📌 tidyverse を読み込むと stats::filter() と stats::lag() が dplyr のものに上書きされる、という競合メッセージが出ます。他パッケージの関数は パッケージ名::関数名() で明示できます。
⚠️ tibble はコードの採点システム（CodeGrade）と相性が悪いので、課題では最後に as.data.frame() へ変換するよう指示されることが多いです。
②

filter：条件に合う行を残す

比較・論理演算・%in%

filter() は列の値の条件で行を残す関数です。

記号意味
> >= < <=大小比較
==等しい（= は 1つでは代入！）
!=等しくない
& または ,かつ（and）
|または（or）
%in%いずれかに含まれる
flights |> filter(dep_delay > 120) # 2時間超の出発遅れflights |> filter(month == 1 & day == 1) # 1月1日flights |> filter(month == 1 | month == 2) # 1月か2月flights |> filter(month %in% c(1, 2)) # 同じ意味・短い書き方# 保存するなら代入jan1 <- flights |> filter(month == 1 & day == 1)
⚠️ よくある間違い：
① filter(month = 1) は = が1つでエラー（==）。
② filter(month == 1 | 2) は動くが全 336,776 行が残る（%in% c(1, 2) なら 51,955 行）。
③ filter(day == 1 & day == 2) は「同時に1日かつ2日」で0行。or の意味なら |。
# クリスマスにJFKを13時以降に出て、45分以上遅れた便flights |> filter(month == 12 & day == 25 & origin == "JFK" & sched_dep_time > 1300 & dep_delay >= 45) # 9 行 × 19 列

欠損値 NA を扱う：is.na()

NA は == で探せない

欠損値（NA）の有無は is.na()、「欠損でない」は !is.na()（感嘆符を忘れずに）。

flights |> is.na() |> sum() # 全体の NA の数flights |> filter(is.na(dep_time)) # dep_time が NA の行（8,255 行）flights |> filter(!is.na(dep_time)) # NA でない行（328,521 行）# 336,776 − 8,255 = 328,521# 複数条件は , でも & でもflights |> filter(is.na(dep_time), is.na(tailnum))flights |> filter(is.na(dep_time) & is.na(tailnum))
⚠️ filter(tailnum == NA) や filter(tailnum == "NA") はNAを見つけられません。欠損の検索は必ず is.na(tailnum)。

2つの列の NA は、ベン図の4領域で考えます。

領域dep_timetailnum行数
① どちらも NANANA2,512
② dep_time だけ NANAあり5,743
③ tailnum だけ NAありNA0（328,521 − 328,521）
④ どちらも ありありあり328,521
④

arrange と distinct と count

並べ替え・重複・件数

arrange() は行を並べ替えます（行数は変わらない）。大きい順は desc()。

flights |> arrange(day, dep_time) # 日付 → 出発時刻の昇順flights |> arrange(day, desc(dep_time)) # dep_time だけ降順

distinct() は重複行を除き、列名を渡すとその組み合わせの初出の行だけ残します。

flights |> distinct() # 完全に同じ行を除くflights |> distinct(dest) |> arrange(dest) # 行き先の種類flights |> distinct(origin, dest) # 出発地と行き先の組flights |> distinct(origin, dest, .keep_all = TRUE) # 他の列も残す（最初の行）

「何件あるか」を知りたいときは count()。sort = TRUE で多い順です。

flights |> count(origin, dest, sort = TRUE)flights |> count(tailnum, sort = TRUE) # 最多の機体番号は？（NA の行も数える）
📌 本当に重複かを確認してから消しましょう。同じ回答の別人かもしれません。

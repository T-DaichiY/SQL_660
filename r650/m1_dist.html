📊 1変数の分布（棒・ヒストグラム・密度）

1つの変数を見るときの定番グラフ。カテゴリ変数なら棒グラフ、数値変数ならヒストグラムと密度曲線を使い分けます。

① カテゴリ変数：棒グラフ② 数値変数：ヒストグラム③ 密度曲線：ヒストグラムに布をかける📝 Quiz

①

カテゴリ変数：棒グラフ

geom_bar と並び替え

カテゴリ変数は名前やラベルを値にもち、足したり平均したりできません。数え上げ（件数・割合）で要約し、棒グラフで描きます。

# 縦ggplot(penguins, aes(x = species)) + geom_bar()# 横（y に割り当てるだけ）ggplot(penguins, aes(y = species)) + geom_bar()

順序のないカテゴリは、頻度の多い順に並べると読みやすくなります。factor にして水準を並べ替えます（fct_infreq()）。

ggplot(penguins, aes(x = fct_infreq(species))) + geom_bar() + labs(x = "Species") # 軸ラベルを直すのを忘れずに
Adelie 152 / Gentoo 124 / Chinstrap 68
②

数値変数：ヒストグラム

binwidth が命

数値変数（連続・離散）は足したり平均したりできます。分布の形を見る基本はヒストグラム。データを区間（ビン）に区切り、各区間の個数を棒の高さにします。

ggplot(penguins, aes(x = body_mass_g)) + geom_histogram(binwidth = 200) # 200 g ごとの区間

binwidth（区間の幅）で印象が変わります。

binwidth見た目問題
20ギザギザの針山細かすぎて形が読めない
200なめらかな山ちょうどよい
20002〜3本の大きな塊粗すぎて特徴が消える
⚠️ 郵便番号や電話番号は数字でもカテゴリです。「平均して意味があるか」で判断しましょう。
③

密度曲線：ヒストグラムに布をかける

geom_density

密度曲線は、ヒストグラムの上に毛布をかけたような滑らかな曲線。山の数（最頻値）と歪みがひと目でわかります。

ggplot(penguins, aes(x = body_mass_g)) + geom_density()# 種ごとに色分け（線の太さ）ggplot(penguins, aes(x = body_mass_g, color = species)) + geom_density(linewidth = 0.75)# 塗りつぶし＋半透明で重なりを見やすくggplot(penguins, aes(x = body_mass_g, color = species, fill = species)) + geom_density(alpha = 0.5)
📌 color は輪郭、fill は中身の色。棒や密度では「塗る」のは fill です。

🧪 仮定が崩れたら（検定と対処法）

①

目的しだいで重要度が変わる

推測か探索か

最初に問うべきは「この分析の目的は何か」です。

目的仮定の重要度
無作為標本から母集団を推測（信頼区間・検定・p値）／原因と結果を言いたいとても重要
探索的に関係を探す／モデルを比べて強い予測変数を探す（p値に頼らない）それほど重要でない

統計学者（推測が仕事）は仮定を重視し、データサイエンティスト（探索が仕事）は比較的重視しません。

仮定が崩れたときの対処（今後の章）

  • 影響点（leverage・Cook の距離）：1〜2点が回帰を引っ張っていないか
  • 多重共線性：説明変数どうしが似すぎていないか
  • 非線形モデル（多項式回帰）
  • データの変換（直線的な関係にする）
  • 交互作用を入れる
  • データを増やす・質を上げる
📌 これらは M5（重回帰）で詳しく学びます。
②

内蔵の診断プロット

plot(model)

モデルを plot() に渡すだけで診断グラフが出ます。

temp_model <- lm(rentals ~ temperature, data = bikes)plot(temp_model)
プロット見るもの良い状態
Residuals vs Fitted線形性（残差プロット）赤い線が水平でランダム
Normal Q-Q残差の正規性点が直線に沿う
Scale-Location等分散（不等分散の発見）赤い線が水平
Residuals vs Leverage影響点（Cook の距離）極端な点がない

気温モデルでは、Residuals vs Fitted に曲線のパターンがあり、Q-Q プロットの両端に曲がりがあります。仮定を気にするなら、非線形モデルを試すべきサインです。

③

正規性・等分散の検定

Shapiro / K-S / Breusch-Pagan

図に加えて、検定で「1つの数字」の答えも出せます。（仮定が重要な場合だけ使います。）

調べること検定H₀（帰無仮説）Rの関数
残差の正規性Shapiro-Wilk正規分布に従うshapiro.test(resid)
残差の分布が指定の分布と一致Kolmogorov-Smirnov指定の分布と一致ks.test(resid, "pnorm", mean, sd)
残差の等分散Breusch-Pagan分散は一定（等分散）lmtest::bptest(model)
shapiro.test(temp_model$residuals) # p ≒ 0 → 正規でない証拠ks.test(temp_model$residuals, "pnorm", mean = mean(temp_model$residuals), sd = sd(temp_model$residuals)) # p が小さい → 正規と不一致library(lmtest)bptest(temp_model) # p が小さい → 不等分散
  • p値 ＜ α（0.05）：帰無仮説を棄却（正規でない／等分散でない証拠）。
  • p値 ＞ 0.05：棄却できない（問題の証拠はない）。
  • Shapiro-Wilk：標本が 5000 未満のとき有効で、正規性だけを調べる。
  • K-S：もっと一般的で、任意の分布と比べられる。小さい標本ではやや感度が低い。

気温モデルでは、3つとも p 値が非常に小さく、残差は正規でなく、等分散でもないという証拠が得られました（図の見立てとも一致）。

⚠️ 標本が大きいと、わずかなズレでも p が小さくなります。検定だけでなく図と合わせて判断しましょう。

①

データの型と、分析の選び方

カテゴリ・数値・順序

まず変数の型を区別します。型によって、使うグラフと要約が決まります。

  • カテゴリ（質的）：名義（nominal）／順序（ordinal）／数字でコード化したカテゴリ
  • 数値（量的）：電話・郵便番号・SSN は数字でも数値ではない
  • 2値（0/1・TRUE/FALSE）、文字、音声・画像など
# factor を作ると、水準に順序は仮定されない（名義）yearFactor <- factor(c("Freshman", "Senior", "Junior", "Sophomore"))# 順序があるなら ordered = TRUE を明示するeducation <- factor(c("Bachelor's", "High School", "PhD", "Master's"), levels = c("High School", "Bachelor's", "Master's", "PhD"), ordered = TRUE)
変数の型グラフ数値での要約
カテゴリ1つ棒グラフ・（円グラフ）件数・割合
数値1つドットプロット・ヒストグラム・密度・箱ひげ図中心・ばらつき・形
数値1つ × カテゴリ1つ並べた箱ひげ図・ヴァイオリン図グループごとの中心・ばらつき
カテゴリ2つ積み上げ棒・モザイク図グループごとの件数・割合
数値2つ散布図相関・回帰の結果
📌 コードブック（データ辞書）はデータ分析の必需品。変数の意味・単位を最初に確認しましょう。
②

相関 r とは何か

強さと向き

相関係数 r は、2つの数値変数の直線的な関連の強さと向き（正・負）を表す統計量です。例：国の GDP と平均寿命、同じ日の Apple と Nvidia の株価、気温と売上。

global <- read_csv("spi_global_rankings.csv", col_types = "iiffddd")global |> ggplot(aes(x = off, y = spi)) + geom_point() + labs(x = "Offensive Rating", y = "SPI Rating") + theme_minimal()cor(global$off, global$spi) # 約 0.958：非常に強い正の相関
  • 相関は強さと向きを表す。
  • 回帰は関係の性質（式）を表す。
  • 相関は、形（直線か曲線か）と因果は教えてくれない。
⚠️ 数字だけでなく必ず散布図も描く。相関が同じでも、図の形は全く違うことがあります（有名な Datasaurus Dozen）。
x <- seq(-5, 5, 1)y <- x^2 # 完全に関係があるのに…cor(x, y) # 0 ! （直線的ではないので r は 0）
📌 r = 0 は「関連がない」ではなく「直線的な関連がない」。逆に r = 0.999 でも直線的とは限りません。

相関の8つの性質

テストに出るポイント
#性質ポイント
1標準化された共分散r = cov(x, y) ÷ (sd(x) × sd(y))
2単位がないr = 0.958 は「95.8%」ではない
3定数の足し算・掛け算で変わらないcor(off / 10, 2 * spi + 5) は元と同じ
4x と y を入れ替えても同じ説明変数と応答変数の区別は r には関係なし
5範囲は −1 ≤ r ≤ 1|r| ≤ 1
6直線的な関連の強さと向きこの講義：|r| ≥ 0.8 を強い、|r| ≤ 0.4 を弱い（分野で変わる）
7相関は因果ではないアイスの売上とサメの被害は相関するが、アイスがサメを呼ぶのではない
8手法がいろいろPearson の r、Spearman の順位相関、Kendall の τ
cov(global$off, global$spi) # 共分散cov(global$off, global$spi) / (sd(global$off) * sd(global$spi)) # 割ると rcor(global$off, global$spi) # 同じ値cor(global$off / 10, 2 * global$spi + 5) # 変換しても r は同じcor(global$off, global$spi) == cor(global$spi, global$off)
📌 Cohen (1992) の目安では、r が 0.1 で小、0.3 で中、0.5 で大の効果量です。分野によって「強い」の基準は違います。

手計算の式（参考）：r = Σ(z_x · z_y) / (n − 1)、また r = b₁ · (s_y / s_x)（b₁ は回帰直線の傾き）。

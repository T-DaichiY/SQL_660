📏 信頼区間と予測区間（CI と PI）

予測値（点推定）には誤差の幅があります。「平均」を推定する信頼区間と、「ある1日」を予測する予測区間の違いを理解します。

① 点推定から区間推定へ② 予測区間：1日だけを当てる③ モデルで予測の精度が上がる📝 Quiz
📖 参考（出典）
  • M4 講義（SU1 Data Analytics M4 の5本の動画の書き起こし）。例題は自転車レンタル（bikes.csv）：説明変数 temperature、応答変数 rentals
①

点推定から区間推定へ

信頼区間（mean response）

回帰で出した予測は1つの数字（点推定）ですが、現実のレンタル数にはばらつきがあります。70度の日に 2400 台と予測しても、「±いくら」の幅があるはずです。そこで区間推定を使います。

期待値 E(Y₇₀) は「気温が 70 度の日の平均レンタル数」。その 信頼区間 は、平均の推定がどれくらい不確かかを表します。

ggplot(bikes, aes(x = temperature, y = rentals)) + geom_point() + geom_smooth(method = "lm", formula = y ~ x, se = TRUE, level = 0.95) + geom_vline(xintercept = 70, color = "red", linewidth = 2) + labs(title = "95% confidence band")

灰色の帯が信頼帯。データの中央付近は帯が細く（データが多く、平均を確信できる）、端では太くなります（データが少なく不確か）。

new.data <- data.frame(temperature = 70)predict(temp_model, newdata = new.data, interval = "confidence", level = 0.95)
fit lwr upr 5327 5195 5460
📌 解釈：「気温が 70 度の日の平均レンタル数は、95% の確信で 5195〜5460 台の間にある」。在庫不足を避けたい会社なら、上限の 5460 を選ぶ判断もあります（点推定との差は約 130 台）。
②

予測区間：1日だけを当てる

個別の値はもっとばらつく

混同しやすい2つの問いがあります。

問い必要なもの幅
70度の日たくさんの平均レンタル数は？信頼区間狭い
70度のある特定の1日のレンタル数は？予測区間広い

「個々の観測は平均よりばらつく」からです。クラス全体の平均点は80点前後と当てやすいですが、特定の1人の点数は大きく外れるかもしれません。

predict(temp_model, newdata = new.data, interval = "prediction", level = 0.95) # confidence を prediction に変えるだけ

点推定（fit）は同じ 5327 ですが、下限はずっと低く、上限はずっと高くなります。信頼区間は約 ±100 台でしたが、予測区間はそれよりはるかに広い幅です。

信頼帯（狭い）と予測帯（広い）の関係
信頼区間は「平均の線」の不確かさ、予測区間は「個々の点」のばらつき。どちらも中央付近が最も狭い。
📌 結論：個人（1日）の予測は、集団（平均）の予測より不確か。幅も広くなる。

参考：数式（暗記は不要）

どちらも Ŷ ± 誤差の幅（誤差の幅＝ t* × 残差の標準偏差 × ばらつきの項）。予測区間は、個々の誤差を足すぶんばらつきの項が大きいだけが違いです。「いつ・どちらを使うか」と「解釈」が大切です。

③

モデルで予測の精度が上がる

「平均だけ」との比較

気温を使わずに、平均レンタル数だけで予測するとどうなるでしょう。

モデル95% 信頼区間
気温を使わない（全体の平均）4363 〜 4645 台
気温 70 度のとき（回帰）5195 〜 5460 台

70度の日には、全体平均を使うと需要を大きく過小評価してしまいます。気温という追加情報を使うことで、予測がよりよくなります。

🍎 かんたん説明

天気予報を見ずに「だいたい平均」で自転車を用意するより、気温を見て用意するほうがぴったりに近づく、ということです🚲

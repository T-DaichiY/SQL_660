M1 ggplot2

M1 · Lesson 1
🐧
ggplot2 の第一歩（ペンギンで学ぶ）
グラフは「データ → 見た目への割り当て → 図形」を1枚ずつ重ねて作ります。ペンギンのデータで、ggplot2 の考え方（レイヤー）を身につけましょう。
→
M1 · Lesson 2
📊
1変数の分布（棒・ヒストグラム・密度）
1つの変数を見るときの定番グラフ。カテゴリ変数なら棒グラフ、数値変数ならヒストグラムと密度曲線を使い分けます。
→
M1 · Lesson 3
🔀
2変数以上の関係と facet
変数の組み合わせでグラフを選びます。数値×カテゴリは箱ひげ図、カテゴリ×カテゴリは積み上げ棒、数値×数値は散布図。さらに facet で分割して見ます。
→
M1 · Lesson 4
🛠️
保存・エラー対処・書き方
グラフを保存し、エラーが出たときに落ち着いて直す。そして読みやすいコードの書き方まで、M1 の仕上げです。
→
M1 · Practice
✏️
M1 確認演習（コードを読んで答える）
コードを読んで「何が起きるか」「どこが間違いか」を答える12問。自分で書く課題は、ggplot2_practice_v1_1.Rmd（20問）を RStudio…

欠損値・外れ値

データ整備 · Missing values
🕳️
欠損値（NA）の扱い方
現実のデータには必ず穴（NA）があります。数え方、drop_na() の危険、そして「消すより補う」補完（imputation）を学びます。
→
データ整備 · Outliers
🚨
外れ値の見つけ方（1.5IQR と 3SD）
極端な値（外れ値）をどう判定し、消すかどうかをどう決めるか。1.5×IQR ルールと 3SD ルールの違いを、赤ちゃんの体重で確かめます。

M4 単回帰

M4 · Prediction
🔮
単回帰で予測する（手計算と predict）
モデルは理解と予測のために作ります。回帰式 Ŷ = a + bX に気温を入れて、レンタル台数を予測する方法を2通りで学びます。
→
M4 · Intervals
📏
信頼区間と予測区間（CI と PI）
予測値（点推定）には誤差の幅があります。「平均」を推定する信頼区間と、「ある1日」を予測する予測区間の違いを理解します。
→
M4 · Assumptions
✅
回帰の仮定を点検する
線形回帰で推測（信頼区間・検定）をするときに確かめる条件：線形性、残差の平均0、正規性、等分散、独立性。図と数値で調べます。
→
M4 · Violations
🧪
仮定が崩れたら（検定と対処法）
仮定が満たされないとき、どうするか？その前に「分析の目的」を考えます。そして正規性・等分散を検定する Shapiro-Wilk、Kolmogorov-Smirnov、Breusch-Pagan を整理します。
→

M5 重回帰分析

M5 · 1章
📈
重回帰分析（Multiple Regression）
1つの手がかりだけで予測するのが「単回帰」。複数の手がかりを同時に使うのが「重回帰」。自転車レンタル数を例に、モデルの作り方と予測の仕方をゼロから学ぶ。
🍎 やさしい版
→
M5 · 2章
🩺
診断（Diagnostics）
モデルは作れた。でも「これは良いモデル？」を、どう判断する？1つの指標に頼らず、調整済みR²・AIC・BIC・S・RMSE・F統計量・MallowのCpを総合的に見る方法を学ぶ。
🍎 やさしい版
→
M5 · 3章
⚖️
標準化回帰係数
湿度・気温・風速は単位がバラバラ。係数の大きさをそのまま比べても「どれが一番効いているか」はわからない。単位をそろえて公平に比べる方法を学ぶ。
🍎 やさしい版
→
M5 · 3.1章
🎯
影響点分析（Influential Points）
「外れ値」と「影響点」は別もの。回帰線を大きくゆがめる“悪い影響を与える点”を、クックの距離（Cook's D）で自動的に見つける方法を学ぶ。
🍎 やさしい版
→
M5 · 4章
🔗
多重共線性とVIF
予測変数どうしが「似すぎている」と、係数がおかしくなる。相関行列では見抜けない隠れた共線性を、分散拡大係数（VIF）で検出する方法を学ぶ。
🍎 やさしい版
→
M5 · 5章
〰️
多項式回帰（Polynomial Regression）
線形回帰は「直線の関係」を前提にする。でも気温とレンタル数は“ある気温まで増えて、暑すぎると減る”曲線。直線では捉えられない関係を扱う方法を学ぶ。
🍎 やさしい版
→
M5 · 6章
🏷️
カテゴリ変数の変換
「季節＝1」「曜日＝2」…数字で表されたカテゴリ。そのまま使うと意味がわからないし、特定の季節だけ取り除くこともできない。factor化とワンホットエンコーディングで解決する。
🍎 やさしい版
→
M5 · 7章
📅
日付データの処理
「8月」と「5月」では自転車のレンタル数が違う。1つの日付列から年・月・日を取り出して、分析に使えるようにする方法を学ぶ。
🍎 やさしい版
→
M5 · 8章
✖️
交互作用（Interaction）
運動だけ、食事だけでもコレステロールは下がる。でも両方を組み合わせると、効果は単なる足し算以上になる。2変数の「組み合わせ効果」をモデルに入れる方法を学ぶ。
🍎 やさしい版
→
M5 · 9章
➡️
変数選択：前進選択（Forward）
20個の予測変数があると、組み合わせは100万通り以上。全部試すのは無理。「何もない状態」から最良の変数を1つずつ足していく、賢い選び方を学ぶ。
🍎 やさしい版
→
M5 · 10章
⬅️
変数選択：後退選択（Backward）
前進選択が「空から足す」なら、後退選択は「全部入りから削る」。最も役立たない予測変数を1つずつ取り除いていく、もう一つの賢い変数選択法を学ぶ。
🍎 やさしい版
→
M5 · 11章
🔀
ステップワイズ＆階層的選択
前進と後退、両方を同時にやったら？それがステップワイズ。さらに、専門知識（ドメイン知識）に基づいて変数を入れる順番を決める「階層的選択」も学ぶ。
🍎 やさしい版
→
M5 · 12章
🎓
モデル性能の評価（Evaluating Performance）
モデルは作れた。でも「見たことのない新しいデータでもうまくいく？」が本当の問い。訓練・テスト分割で「汎化（はんか）」を確かめ、過学習を見抜く方法を学ぶ。最終章！
🍎 やさしい版

M6 ロジスティック回帰

M6 · 1章

ロジスティック回帰とは？
M5で学んだ重回帰との違いは「何を予測するか」。バイナリ結果・確率・glm()の基礎をアバロンデータで学ぶ。
🍎 やさしい版

M6 · 2章
📐
ロジスティック回帰モデルの仕組み

🍎 やさしい版
→
M6 · 3章
🔑
ロジスティック回帰のカギ：変換を理解する
確率→オッズ→対数オッズの変換をグラフと手計算で完全理解。シグモイド関数で元に戻る仕組みも確認。
🍎 やさしい版
→
M6 · 4章
🐚
係数の解釈：アバロンの例
予測変数なしモデルの切片が対数オッズであることを、アバロンの実データで手計算しながら確認。係数→確率への変換を完全マスター。

M6 · 5章

モデル評価①：逸脱度（Deviance）

M6 · 6章
📊
モデル評価②：AIC
AIC = −2LL + 2K。予測変数追加のペナルティがある点が逸脱度との違い。2モデルをAICで比較する。

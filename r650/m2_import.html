データを R に入れる3つの方法

作業フォルダ・フルパス・URL

CSV（comma-separated values）は、1行目が列名、2行目以降が観測のテキスト表です。tidyverse の read_csv()（readr）を使います（base R の read.csv とは別物）。

# 0) パッケージ内蔵データmtcars # base R に最初から入っているlibrary(nycflights13); flights# 1) 作業フォルダに置いて読むgetwd() # 今どこ？setwd("/Users/home/Desktop/")students <- read_csv("students.csv")# 2) フルパスで読む（setwd 不要・パスが長い）students <- read_csv("/Users/home/Desktop/students.csv")# 3) URL から読む（リンク切れに注意）students <- read_csv("https://pos.it/r4ds-students-csv")
方法長所短所
作業フォルダコードが短い場所の設定が必要
フルパスsetwd が要らないパスが長く他のPCで動かない
URL保存が不要リンクが切れると読めない
📌 650 の作業は1つのフォルダにまとめて、そこを作業フォルダにするのが一番ラクです（RStudio: Tools → Global Options）。
②

型・欠損・列名のトラブルを直す

col_types / na / clean_names

students.csv には、現実のデータらしい「汚れ」があります（N/A の文字、five という文字の年齢、空白入りの列名…）。

students <- read_csv("https://pos.it/r4ds-students-csv", show_col_types = FALSE) # 型の推測メッセージを消す# 型を自分で指定（c=文字, n=数値, f=factor）read_csv(..., col_types = c("ccccc"))# "N/A" も欠損値として読む（既定は空文字だけ）read_csv(..., na = c("N/A", ""))

列名にスペースや記号があると、そのままでは扱えません（非構文名）。

# バッククォート ` で囲んで rename（引用符 \' ではない！）students <- students |> rename(student_id = `Student ID`, full_name = `Full Name`)# まとめて snake_case にlibrary(janitor)students <- clean_names(students) # favourite.food → favourite_food, AGE → age
⚠️ age に "five" という文字が混ざっていると、列全体が character になります。
③

文字を数に・数をカテゴリに

parse_number / factor

型を直す定番は、parse_number()（文字→数値）とfactor()（文字・数字→カテゴリ）です。

students <- students |> mutate(age = parse_number(if_else(age == "five", "5", age)))# 数字でもカテゴリなら factor に！# 例: 0=無神論, 1=一神教, 2=二神教, 9=無回答 …students <- students |> mutate(meal_plan = factor(meal_plan))# 読み込み時に指定してもよいread_csv(..., col_types = c("cccfn"))
⚠️ 0/1/2 のようなコード化されたカテゴリを数値のままにすると、平均などを計算してしまいます。カテゴリは factor にしましょう。

read_csv の便利な引数

read_csv("a,b,c\n1,2,3\n4,5,6") # 文字列をそのまま CSV として読むread_csv("メモ\nメモ2\nx,y,z\n1,2,3", skip = 2) # 先頭2行を読み飛ばすread_csv("# コメント\nx,y,z\n1,2,3", comment = "#") # # で始まる行を無視read_csv("1,2,3\n4,5,6", col_names = FALSE) # 列名なし（X1, X2…が付く）read_csv("1,2,3\n4,5,6", col_names = c("x","y","z")) # 列名を自分で付ける

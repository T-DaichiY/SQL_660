✅ 回帰の仮定を点検する

線形回帰で推測（信頼区間・検定）をするときに確かめる条件：線形性、残差の平均0、正規性、等分散、独立性。図と数値で調べます。

①

線形性と残差プロット

曲線が残っていないか

推測（inference）をするなら、仮定（条件）を確かめる必要があります。ただし、これらが必要なのは母集団への推測をするときだけ（最後の節で整理）。

条件1：関連が直線的であること。曲がっていてはいけません。残差プロット（残差を y、予測値や x を横軸にした図）で確かめます。

bikes$resid <- temp_model$residualsggplot(bikes, aes(x = temperature, y = resid)) + geom_point() + geom_hline(yintercept = 0, color = "red") + geom_smooth(se = FALSE) # この青い曲線が大事！
⚠️ 残差プロットを点だけで見るとランダムに見えることがあります。geom_smooth() の曲線を足すと、モデルが捉え損ねた曲がったパターンが見えます。

残差プロットは「ランダムに散らばっている」のが理想です。曲線のパターンが残っているなら、線形でないシグナルが残っているので、非線形モデルを検討します。

📌 残差の中央値がプラスかマイナスかも見ます。予測が実際より多めなら、在庫不足よりは余りが出る方向で、会社には都合のよい誤差かもしれません。
②

残差の平均0・正規性

ヒストグラム・QQ

条件2：残差の平均が 0。

mean(temp_model$residuals) # ほぼ 0

条件3：残差が正規分布に従う。残差が正規分布なら、誤差はランダムなノイズで、シグナルは捉えられているという意味になります。

# ヒストグラムと箱ひげ図、正規曲線の重ね書きggplot(bikes, aes(x = resid)) + geom_histogram(aes(y = after_stat(density)), bins = 30) + stat_function(fun = dnorm, args = list(mean = 0, sd = sd(bikes$resid)), color = "red")# QQプロット（quantile-quantile）qqnorm(temp_model$residuals)qqline(temp_model$residuals, col = "red")
QQプロットの形意味
点が赤い直線に沿う正規分布に近い（OK）
両端が曲がる・反る歪み・非正規

summary(model) の冒頭には残差の最小値・中央値・最大値が出ます。最小は「過大予測が最大の日」、最大は「過小予測が最大の日」。残差が正なら点が線の上（過小予測）です。

③

等分散と独立性

homoscedasticity・Durbin-Watson

条件4：等分散性（homoscedasticity）。homo＝同じ、scedastic＝ばらつき。残差のばらつきが、xの全範囲でほぼ同じであるべきです。

見た目名前
○ 望ましいどの x でも帯の幅がほぼ一定等分散
× 望ましくないx が大きいほど幅が広がる（ラッパ型）不等分散（heteroscedasticity）

条件5：残差が独立。時系列データでは「今日のレンタル数が明日と関連する」ように、残差が互いに関連（自己相関）することがあります。Durbin-Watson 検定（car パッケージ）で調べます。

library(car)durbinWatsonTest(temp_model)
D-W 統計量解釈
約 2自己相関なし（条件OK）
0 に近い（0〜2）正の自己相関
4 に近い（2〜4）負の自己相関

気温モデルの D-W 統計量は約 0.76。0〜2 の範囲なので正の自己相関があり、独立性の条件は満たされていません（レンタルが多い日の翌日も多い傾向）。

📌 5つの条件：①線形 ②残差の平均0 ③正規性 ④等分散 ⑤独立性。どれも「ノイズだけが残っているか」を確かめる点検です。

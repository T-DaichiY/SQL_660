🧱 列の操作（mutate / select / rename / relocate）

列を足す mutate、必要な列を選ぶ select、名前を変える rename、位置を動かす relocate。ifelse と case_when でカテゴリも作れます。

①

mutate：新しい列を作る

.before / .after / .keep

mutate() は既存の列から計算した新しい列を追加します。例：到着の遅れをどれだけ取り戻したか（gain）と、時速（speed）。

flights |> mutate( gain = dep_delay - arr_delay, speed = distance / air_time * 60 )

新しい列は既定で右端に付くので、見えにくいときは位置を指定します。

mutate(..., .before = 1) # 先頭にmutate(..., .after = day) # day の後ろに（名前で指定できる）mutate(..., .keep = "used") # 計算に使った列と新しい列だけ残す
📌 .before の先頭のドットは「列名ではなく引数名」の目印です。
⚠️ mutate の結果は保存しない限り元の flights は変わりません。①元に上書き？②新しい名前で保存？③保存不要？を決めましょう。
②

ifelse と case_when：カテゴリを作る

条件で値を分ける

2択なら ifelse(条件, 真のとき, 偽のとき)。3つ以上の場合分けは case_when() が読みやすくなります。

# 午前・午後（1159 以前は am）flights |> mutate(am_pm = ifelse(dep_time <= 1159, "am", "pm"), .before = 1)# 元の値を残しつつ一部だけ置き換えflights |> mutate(monthname = ifelse(month == 1, "Jan", month), .after = "month")# 既存の列名を再利用すると上書き（1月の day を NA に）flights |> mutate(day = ifelse(month == 1 & day <= 31, NA, day))# 2値の factor（United かそれ以外）flights |> select(carrier) |> mutate(airline = factor(ifelse(carrier == "UA", "United Airlines", "Not UA")))
⚠️ ifelse の2つの結果は同じ型が望ましい。上の monthname は文字と数字が混ざり、列全体が character になります。カテゴリは最後に factor にしましょう。
③

select / rename / relocate

列を選ぶ・名前・位置

列が多いデータは、必要な列に絞ると見通しがよくなります。

flights |> select(year, month, day) # 名前で選ぶflights |> select(year:day) # 範囲で選ぶflights |> select(!year:day) # その範囲以外flights |> select(where(is.character)) # 型で選ぶflights |> select(starts_with("dep")) # 名前の一部で選ぶflights |> rename(tail_num = tailnum) # 新名前 = 旧名前flights |> relocate(time_hour, air_time) # 先頭へflights |> relocate(year:dep_time, .after = time_hour)
関数やること
select()列を選ぶ（残す・外す）
rename()列の名前を変える
relocate()列の位置を動かす
mutate()新しい列を作る

cor() と NA の扱い

use 引数

cor() は base R（stats）の関数で、1つの値、または複数変数の相関行列を返します。

cor(global$off, global$spi)cor(global$off, global$spi, method = "pearson", use = "everything") # 既定# 相関行列（dplyr:: を付けると他パッケージとの競合を避けられる）global |> dplyr::select(off, spi, def) |> cor() |> round(3)

NA があると相関は NA になります。対処は4つ。

x <- c(10, 15, 18, 21, 27, NA)y <- c(NA, 5, 7, 10, 16, NA)cor(x, y) # NAcor(x, y, use = "complete.obs") # NA のある組を除いて計算# cor(x, y, na.rm = TRUE) # × cor には na.rm 引数が無い！mean(x, na.rm = TRUE) # na.rm が使えるのは mean など
方法メモ
dplyr で NA を先に除く明示的で安全
na.omit()全列の NA 行を消す（注意）
use = "complete.obs"cor 専用の指定
補完（imputation）データを減らしたくないとき
⚠️ cor() に na.rm 引数はありません（use を使う）。mean() などと混同しないこと。

cor.test()：相関の検定

p値と信頼区間

cor.test() は相関が 0 でないかを検定し、p値と 95% 信頼区間を返します（2変数のみ）。

  • 帰無仮説 H₀：相関 r = 0（相関なし）
  • 対立仮説 Hₐ：r ≠ 0（相関あり）
cor.test(global$off, global$spi, alternative = "two.sided", # 既定 method = "pearson", # 既定 conf.level = 0.95) # 既定
関数出力変数
cor()相関1つ、または相関行列多数OK
cor.test()r・p値・信頼区間など詳しい2つだけ

p値の読み方

  • p値 ＜ α（普通 0.05）：相関があるという統計的に有意な証拠。ただし強い・因果があるとは言えません。
  • p値が大きい：相関があるという証拠がない（ないと証明したわけでもない）。
🍎 かんたん説明

p値は「もし本当は相関がゼロなら、こんなに強い相関が偶然出る確率」。小さいほど偶然とは考えにくい、という意味です🎲

📌 解釈のテンプレ：「相関がない（r = 0）と仮定すると、観測された r = ○ 以上の強さの相関が偶然だけで出る確率は、p ＝ ○」。

相関を可視化する

corrgram / DataExplorer

変数が多いときは 相関図（correlogram） が便利です。

library(corrgram)corrgram(global) # 基本corrgram(global, lower.panel = panel.pts) # 下半分に散布図corrgram(global, lower.panel = panel.pts, diag.panel = panel.density, # 対角に密度 upper.panel = panel.cor, # 上半分に相関の数字 cor.method = "pearson")

DataExplorer は EDA（探索的データ分析）を自動化するパッケージです。

library(DataExplorer)plot_intro(global) # 欠損・型の概要plot_bar(global) # カテゴリ変数plot_histogram(global) # 数値変数の分布plot_qq(global) # QQプロット：直線なら正規分布に近いplot_correlation(global) # 相関のヒートマップglobal_leagues |> plot_boxplot(by = "league")

QQプロット は「まっすぐ＝ほぼ正規分布、曲がっている＝正規分布ではない」と読みます。

📌 競合メッセージが出たら conflicted::conflicts_prefer(dplyr::select) のように、使う関数を指定できます。

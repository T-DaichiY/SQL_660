①

group_by と summarise

データを分けて要約する

group_by() はデータを分析に意味のあるグループに分けます。ただし見た目は変わりません（以降の操作が「グループごと」に効くようになるだけ）。

代表的なグループ操作が summarise()：グループごとに1つの統計量へ要約し、グループ数だけの行になります。

flights |> group_by(month) |> summarise(avg_delay = mean(dep_delay)) # NA があると NA になる
⚠️ 欠損が1つでもあると平均は NA。na.rm = TRUE で欠損を無視します。
また Hmisc::summarize() と名前がぶつかることがあるので、英国式 summarise() を使うと混乱しません。
flights |> group_by(month) |> summarise( avg_delay = mean(dep_delay, na.rm = TRUE), count_flights = n() # n() は各グループの行数 )
📌 平均と件数だけでも、データサイエンスでは驚くほど遠くまで行けます。
②

複数のグループと .groups

グループが1段ずつ外れる

複数の変数でグループを作れます（例：日付ごと）。

daily <- flights |> group_by(year, month, day)daily_flights <- daily |> summarise(n = n(), .groups = "drop_last")

複数変数でグループ化した表を summarise すると、最後のグループが1段外れます。この挙動を明示するのが .groups 引数です。

.groups の値動作
"drop_last"最後のグループだけ外す（既定）
"drop"すべてのグループを外す
"keep"グループを保持する
⚠️ .groups は mean() の中ではなく、summarise() の中に書きます。mean(..., .groups = ...) と書くと、エラーにならず黙って無視されます。
③

.by とスライス関数

新しい書き方

dplyr 1.1.0 以降は、その操作だけのグループ化 .by も使えます（group_by は無くなりません）。

flights |> summarise( delay = mean(dep_delay, na.rm = TRUE), n = n(), .by = month # group_by しなくてよい )flights |> summarise(delay = mean(dep_delay, na.rm = TRUE), n = n(), .by = origin)

グループごとに行を取り出すのが slice_ 関数群です。

関数取り出すもの
slice_head(n = 1)各グループの先頭 n 行
slice_tail(n = 1)各グループの最後 n 行
slice_min(x, n = 1)x が最小の n 行
slice_max(x, n = 1)x が最大の n 行
slice_sample(n = 1)ランダムな n 行
# 各出発地で出発遅れが最大の便flights |> group_by(origin) |> slice_max(dep_delay, n = 1)

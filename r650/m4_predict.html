🔮 単回帰で予測する（手計算と predict）

モデルは理解と予測のために作ります。回帰式 Ŷ = a + bX に気温を入れて、レンタル台数を予測する方法を2通りで学びます。

① 回帰式と散布図② 方法① 手計算で予測する③ 方法② fitted と predict📝 Quiz
📖 参考（出典）
  • M4 講義（SU1 Data Analytics M4 の5本の動画の書き起こし）。例題は自転車レンタル（bikes.csv）：説明変数 temperature、応答変数 rentals
①

回帰式と散布図

Ŷ = a + bX

回帰式にはいろいろな書き方があります。この授業では Ŷ（ワイハット）＝ a ＋ b X を使います（Ŷ ＝ 予測値、a ＝ y切片、b ＝ 傾き）。教科書では β₀、β₁、誤差項 ε と書く流儀もあります。

ggplot(bikes, aes(x = temperature, y = rentals)) + geom_point() + geom_smooth(method = "lm", formula = y ~ x, se = FALSE, color = "red")temp_model <- lm(rentals ~ temperature, data = bikes)temp_model$coefficients # y切片 a ≒ −166、傾き b

散布図には大きなばらつき（ノイズ）があります。使っている説明変数は気温ひとつだけなので、レンタル数を決める他の要因が残っているためです。赤い直線が線形モデルで、これを使って「気温が○度の日に自転車は何台必要か」を予測します。

📌 geom_smooth(method = "lm") が ggplot で線形回帰直線を引く方法。se = FALSE は信頼帯（灰色の帯）を消します（次の回で TRUE にします）。
②

方法① 手計算で予測する

仕組みを知る

15番目の日を例にします（気温 37.3 度）。

bikes[15, ] # 15行目（, の後ろが空＝全列）bikes$temperature[15] # 37.3bikes$rentals[15] # 実際のレンタル数b0 <- temp_model$coefficients[1] # y切片（約 −166）b1 <- temp_model$coefficients[2] # 傾きtemp15 <- bikes$temperature[15]b0 + b1 * temp15 # 予測値 ≒ 2764
記号意味この例
a (b₀)y切片約 −166
b (b₁)傾き（気温が1上がるとレンタルが何台増えるか）係数の2つ目
X説明変数（気温）37.3
Ŷ予測値約 2764 台
残差 e実際 − 予測−1516（予測より少なかった）

グラフで見ると、気温 37.3 度では回帰直線は約 2700 台と高く予測していますが、実際の点は直線の下にあります。この気温では予測が実際より多い（過大予測）ことになります。

📌 手計算は仕組みの理解のため。重回帰のようなもっと複雑なモデルでも、同じ「係数 × 値の足し算」が裏で動いています。
③

方法② fitted と predict

新しいデータにも使える

モデルは各行の予測値を fitted.values に保存しています。

temp_model$fitted.values[15] # 15行目の予測値（手計算の 2764 と同じ）

ただし fitted.values はデータにある気温だけです。「10度だったら？」のような新しい値には predict() を使います。

new.data <- data.frame(temperature = 10) # データフレームにするのが必須predict(temp_model, newdata = new.data)# 複数の気温を一度にnew.data <- data.frame(temperature = c(10, 30, 70))predict(temp_model, newdata = new.data)
方法使える範囲特徴
fitted.valuesデータにある行だけすでに計算済み
predict()好きな新しい値推奨（早くて安全）
⚠️ データの範囲の外（外挿）で予測すると信頼できません。気温データの最小値〜最大値の範囲で使いましょう。

🚨 外れ値の見つけ方（1.5IQR と 3SD）

極端な値（外れ値）をどう判定し、消すかどうかをどう決めるか。1.5×IQR ルールと 3SD ルールの違いを、赤ちゃんの体重で確かめます。

①

まず分布を見る

summary・IQR・SD・箱ひげ図

外れ値を探す前に、変数の要約と図を確認します。NC 出生データの Weight（1,009 人）では次のとおりです。

summary(nc_births$Weight) # 5数要約 + 平均length(nc_births$Weight) # 1009IQR(nc_births$Weight) # 652sd(nc_births$Weight) # 487.736nc_births |> ggplot(aes(x = Weight)) + geom_boxplot()
指標値読み方
中央値3430 g（約 7.6 ポンド）半数の赤ちゃんはこれより重い
平均約 3448 g中央値とほぼ同じ → ほぼ左右対称かも
IQR652 g真ん中50%の幅
標準偏差487.736 g平均から平均的にこれだけ離れる
📌 平均と中央値がだいたい同じなら、分布はほぼ対称という証拠のひとつです（正規分布かどうかは別に検討）。

外れ値は消すべき？

  • 測定ミスなら、消して問題ない。
  • 機械学習のアルゴリズムは外れ値を除くと性能が上がるものがある。
  • 信頼区間や検定は、外れ値を除かないと結果が不安定になることがある。
  • 逆に外れ値そのものが関心事（異常検知）なこともある。
②

1.5×IQR ルール

箱ひげ図と同じ基準

箱ひげ図が外れ値とする基準が 1.5×IQR ルール です。

高い外れ値 ＞ Q3 + 1.5 × IQR　／　低い外れ値 ＜ Q1 − 1.5 × IQR

📌 1.5 は目安で、数学的な理由はありません（極端な外れ値を 3×IQR とする本もあります）。
upper_fence <- quantile(nc_births$Weight, 0.75) + (1.5 * IQR(nc_births$Weight))lower_fence <- quantile(nc_births$Weight, 0.25) - (1.5 * IQR(nc_births$Weight))nc_births_iqr_no_out <- nc_births |> filter(Weight >= lower_fence, Weight <= upper_fence)nrow(nc_births_iqr_no_out) # 1000 行（1009 − 9 = 9 人の外れ値を除去）

除去後に箱ひげ図を描き直すと、外れ値の点が消え、ほぼ左右対称な形になります。

⚠️ filter(Weight >= lower_fence, Weight <= upper_fence) はデータ全体に対する処理です。他の列の外れ値は残ります。名前（no_out）が実態より大げさになりがちです。
③

3SD ルールと、使い分け

どちらが「抵抗力」がある？

もう1つの定番が 3SD ルール。正規分布に近いデータなら、約 99.7% が平均から 3 標準偏差以内に入ります。外側の 0.3% を外れ値とみなします。

# 両側 0.15% ずつ ≒ 平均から ±3 SD の外側lower_bound <- quantile(nc_births$Weight, 0.0015, na.rm = TRUE)upper_bound <- quantile(nc_births$Weight, 0.9985, na.rm = TRUE)nc_births_3sd_no_out <- nc_births |> filter(Weight >= lower_bound, Weight <= upper_bound)
📌 厳密には 0.0015 / 0.9985 は「約 2.97 SD」に相当します。コースでは「だいたい 3SD」として使います。

3SD で除去したあとに箱ひげ図を描くと、まだ外れ値の点が残ります。箱ひげ図は 1.5×IQR で判定するからです。

1.5×IQR ルール3SD ルール
基準四分位（順位）平均と標準偏差
極端な値の影響受けにくい（抵抗力あり）受けやすい
外れ値の除去量多め少なめ（極端な値だけ）
向く分布歪んだ分布・外れ値が多いほぼ正規分布

まとめ：外れ値の5つの姿勢

  1. 外れ値を探す
  2. なぜ外れているか考える
  3. 消すべきか判断する
  4. どう消すか（どの基準か）を決める
  5. 報告するときは透明に（何をどう除いたか書く）

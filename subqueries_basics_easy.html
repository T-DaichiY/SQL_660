サブクエリって何？

カッコの中にもう1つのクエリ

🎯 これだけ覚えればOK

サブクエリ＝カッコ（　）の中に書かれたもう1つのSELECT文。先にカッコの中身が実行されて1つの結果（値・リスト・表）になり、それを外側のクエリが使います。

JOIN

2つ以上のテーブルの列を横に並べて、1つの結果として表示したいとき。基本はJOINの方が速い。

サブクエリ

「先に1つの値（平均など）を計算してから比較したい」「リストに含まれるかだけ知りたい」ときに使う。

🍎 ひとことで

JOINで書けるなら、基本はJOIN。JOINで書きにくいとき（先に値を計算したい、リストと比較したいだけ）がサブクエリの出番です。

①

スカラー・列サブクエリ

1つの値 or 1つのリスト
🔢
スカラーサブクエリ＝1つの値だけを返す。「平均より多い学生」を探すとき、平均の数字を決め打ちせず、カッコの中で毎回計算させます。

▶ 平均単位数より多い学生（スカラーサブクエリ）

SELECT name, tot_cred
FROM student
WHERE tot_cred > (SELECT AVG(tot_cred) FROM student);
📋
列サブクエリ＝1つの列・複数行のリストを返す。「このリストに含まれているか」をWHERE x IN (SELECT ...)で調べます。

▶ CS-101を履修した学生の名前（列サブクエリ）

SELECT name
FROM student
WHERE student_id IN (SELECT student_id FROM takes WHERE course_id = 'CS-101');
🍎 ひとことで

返す値が1個ならスカラー、リストならIN と組み合わせる列サブクエリ。どちらもエイリアス（別名）は不要です。

②

テーブル・相関サブクエリ

表そのもの／行ごとに毎回実行
🗂️
テーブルサブクエリ＝複数列・複数行の「一時的な表」を作ってJOINする。必ずエイリアス（AS 別名）が必要です。

▶ 学科ごとの平均単位数と比較する（テーブルサブクエリ）

SELECT s.name, d.avg_credits
FROM student AS s
JOIN (SELECT dept_name, AVG(tot_cred) AS avg_credits FROM student GROUP BY dept_name) AS d
ON s.dept_name = d.dept_name;
🔁
相関サブクエリ＝外側の1行ごとに、内側のクエリがもう一度実行される。教員が4人いれば、内側は4回実行されます。

▶ 教員ごとの指導学生数を数える（相関サブクエリ）

SELECT name,
    (SELECT COUNT(*) FROM advisor WHERE advisor.instructor_id = instructor.instructor_id) AS num_advisees
FROM instructor;
⚠️
複合主キーのテーブルをJOINすると、行が重複することがあります。同じcourse_idでも、section_idや学期が違えば「別の行」。DISTINCTや相関サブクエリで対策します。

🤔 答えられるかな？（クリックで答えが開く）

Q1. スカラーサブクエリはいくつの値を返す？A. 1つだけ（単一の値）。
Q2. 列サブクエリはどんな演算子とよく組み合わせる？A. IN 演算子。WHERE x IN (SELECT ...) の形。
Q3. 相関サブクエリが「普通のサブクエリ」と違う点は？A. 外側の行ごとに内側のクエリが毎回再実行されること。

💡 まとめ

• サブクエリ＝カッコの中のもう1つのクエリ

• スカラー＝1つの値、列＝1つのリスト

• テーブルサブクエリはエイリアス必須

• 相関サブクエリは外側の行ごとに再実行
